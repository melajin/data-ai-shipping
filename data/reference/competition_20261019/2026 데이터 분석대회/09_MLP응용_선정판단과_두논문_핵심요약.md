# MLP 응용 선정 판단과 두 논문의 핵심

기준일: 2026-10-16. **샘플 10행과 제공 공지만을 대상으로 한 현재 판단**이다. 아래 네 절은 각각 A4 약 1쪽 이내의 읽기 분량으로 구성했다. MD의 실제 페이지 수는 표시·인쇄 설정에 따라 달라진다.

## 1. 지금도 TabM·RealMLP가 적합한가? — 핵심 판단

**[판단] 두 안건을 조업형태 분류의 우선 연구 후보로 유지하는 것이 합리적이다. TabM을 먼저 검증하되, RealMLP와의 성능 우열은 아직 판정하지 않는다.**

| 판단 근거 | 현재 자료에서의 의미 |
|---|---|
| 만들 수 있는 입력과 맞는다 | WKT 좌표에서 거리·굴곡·범위를 추출하면 고정된 열의 숫자 표가 된다. 두 모델 모두 이 표를 학습할 수 있다. |
| 없는 정보에 덜 의존한다 | 점별 시각 없이 순간 속도·체류시간을 만들 필요가 없다. GIST 원 입력의 재현보다 현재 입력 준비가 단순하다. 형상 CNN 수정안이 불가능하다는 뜻은 아니다. |
| 수업과 연구를 연결하기 쉽다 | MLP·PyTorch 기초를 사용하면서 최근의 공유 앙상블 또는 전처리·학습 개선을 검토할 수 있다. |
| 비교 가능한 연구안이다 | 같은 특징·선박 분할에서 신경망 단독, 작은 LightGBM 단독, 혼합을 비교하면 채택 이유를 설명하기 쉽다. |

- **TabM을 먼저 보는 이유 [제안]:** 공유 구조로 여러 예측을 결합하는 연구 질문이 명확하다. **더 빠르거나 더 정확하다는 실측 판정은 아니다.**
- **RealMLP를 함께 남기는 이유 [제안]:** 개선된 기본 학습 설정에서 출발할 수 있다. CPU 비용이나 분할별 안정성이 더 좋으면 주력으로 바꾼다.
- **MLP 밖의 대안도 있다:** 트리·Attention 기반 표형 모델 등은 비교 대상이다. 현재 표형 입력과 CPU 조건에서 추가 복잡성이 이득이라는 근거가 없으며, 반대로 MLP가 최적이라는 근거도 없다. [T,R]

**한계:** 샘플은 10척·10행이고 두 클래스는 각 한 척뿐이다. 신규 선박 F1을 신뢰성 있게 비교할 수 없다. DTE는 이상탐지의 다른 역할이므로 분류 후보보다 열등하다고 비교하지 않는다. 두 논문의 서로 다른 벤치마크 숫자로 `TabM > RealMLP`를 확정하지도 않는다.

## 2. TabM 논문 핵심 — 오래된 MLP에서 무엇을 바꿨나?

**논문:** *TabM: Advancing Tabular Deep Learning with Parameter-Efficient Ensembling*, Yury Gorishniy·Akim Kotelnikov·Artem Babenko, **ICLR 2025**. [T]

MLP의 기본 구조가 고전적인 것은 맞다. **이 안건의 차별점은 MLP의 최초 발명이 아니라 최근의 구조·학습 개선에 있다.** 두 논문은 2024-2025년 등재 연구이며, 2026년의 가장 최신 모델이라는 뜻은 아니다.

**문제의식:** 여러 신경망의 판단을 모으면 도움이 될 수 있지만, 완전한 모델을 여러 개 보관·학습하면 비용이 커진다.

**핵심 변화는 ‘새로운 MLP 이론’보다 ‘여러 MLP 예측을 효율적으로 만드는 구조’다.**

1. **계산 규칙을 대부분 공유한다.** 각 예측 멤버가 작은 개별 조정값을 갖도록 해, 완전한 신경망을 멤버마다 따로 복제하는 부담을 줄인다.
2. **각 멤버의 예측 오류를 학습한다.** 학습 때부터 여러 예측을 함께 다루고 결합 성능을 검증한다. 분류 추론에서는 멤버별 클래스 확률을 평균한다.
3. **공유 방식과 시작 설정을 실험했다.** 단순히 출력 가지를 늘린 것만이 아니라, 어떤 부분을 공유하고 다르게 시작할지 비교한 연구다.

**쉽게 말하면:** 같은 작업장을 쓰는 여러 판단자가 일부 도구만 다르게 쓰고 의견을 모으는 방식이다. 이 비유가 멤버들의 오류가 서로 독립이라는 뜻은 아니다.

**확인된 근거:** 본문은 46개 공개 데이터, 그중 일반 무작위 분할과 다른 도메인 분할 9개를 포함해 비교했다. 도메인 분할은 학습 때와 다른 조건에서 평가하는 방식이다. 높은 표형 예측 성능과 효율을 검토했지만, 어선 신규 선박 성능을 직접 입증한 실험은 아니다. [T: §3-5]

**우리 적용 [제안]:** 항적의 숫자 특징 → TabM의 조업 확률 → 작은 트리의 확률과 필요 시 결합한다. 내부 멤버는 같은 계열이므로, LightGBM과의 결합이 별도의 알고리즘 혼합이다.

**주의:** 오래된 MLP를 그대로 쓴 안건은 아니지만 모든 자료에서 최선은 아니다. 공식 구현도 일반 MLP·트리보다 느릴 수 있음을 보여 준다. 멤버 수·폭·깊이를 줄인 후보와 CPU 전체 처리 비용을 확인한다. TabM의 분류 확률 자체를 사고 확률로 사용하지 않는다. [T-code]

## 3. RealMLP 논문 핵심 — 구조보다 학습 전체를 개선

**논문:** *Better by default: Strong pre-tuned MLPs and boosted trees on tabular data*, David Holzmüller·Léo Grinsztajn·Ingo Steinwart, **NeurIPS 2024**. [R]

**문제의식:** 표형 자료에서 신경망을 쓰려면 복잡한 구조와 긴 설정 탐색이 꼭 필요한가? 기존 MLP의 입력·초기화·학습을 함께 개선하면 어떨까?

| 개선 축 | 쉬운 설명 |
|---|---|
| 강건한 스케일 조정·완만한 값 제한 | 일반적인 값의 범위로 숫자 단위를 맞추고, 극단값 하나의 영향이 과해지지 않게 한다. |
| 수치 표현·학습 가능한 크기 조절 | 숫자를 학습하기 쉬운 표현으로 바꾸고, 특징의 영향 크기를 조정한다. |
| 초기화·규제·학습 일정 | 출발값과 학습 속도, 과한 암기를 줄이는 설정을 함께 개선한다. |
| 여러 데이터로 정한 기본 설정 | 새 자료마다 많은 설정을 처음부터 뒤지는 부담을 줄이려 한다. |

**쉽게 말하면:** 전혀 다른 엔진을 발명하기보다 연료 공급·출발 설정·운전 방식을 함께 정비한 MLP다. 그래서 ‘고전 MLP 그대로’와 ‘새로운 학습 이론’ 중 어느 한쪽으로 단순화하면 부정확하다.

**확인된 근거:** 118개 데이터에서 기본 설정을 정하고, 분리된 90개 데이터에서 평가했다. 표형 자료의 성능·시간을 비교하고 트리와의 결합도 검토했다. 저자들의 여러 모델 결합 결과가 우리 `RealMLP + LightGBM` 두 모델 조합의 성능 증거는 아니다. [R: §1,3-5]

**우리 적용 [제안]:** 같은 항적 특징을 쓰고 공식 기본 설정에서 출발한다. 숫자 결측은 학습 부분 기준으로 대체하고, 자체 전처리를 외부에서 무조건 반복하지 않는다. 자동 행 분할 대신 다른 선박의 검증 입력을 직접 연결한다. [R-code]

**주의:** 좋은 기본값도 과적합을 막는 보증은 아니다. 극단값의 영향 완화가 사고 신호 보존을 보장하지 않으므로, 이상탐지는 분류기 변환과 구분한 원래 특징 경로에서 시작한다. 논문의 meta-tuning을 사용한다고 우리 팀이 별도 메타학습기를 학습하는 것은 아니다.

## 4. 두 안건은 공지의 어느 주제에 해당하는가?

**[해석] 두 안건 모두 가장 자연스럽게는 ‘AI 응용’이며, 실제 신경망 학습을 포함하면 ‘딥러닝을 이용한 분야’에도 해당한다. ‘AI 알고리즘’은 최근 방법의 적용·비교라는 관점으로 설명할 수 있다.** 공지에 세 항목을 모두 충족해야 한다는 문구는 없다.

| 주제 항목 | TabM 안건 | RealMLP 안건 |
|---|---|---|
| **AI 응용** | 항적 특징에서 조업형태를 분류하고 이상 분석과 연결 | 같은 실제 문제에 개선된 MLP와 트리를 적용 |
| **AI 알고리즘** | 공유 앙상블의 단독·혼합 효과와 비용을 비교 | 전처리·학습 설정을 개선한 MLP의 단독·혼합 효과를 비교 |
| **딥러닝을 이용한 분야** | TabM 신경망을 실제로 학습·평가 | RealMLP 신경망을 실제로 학습·평가 |

**강의와의 직접 연결:** 두 안건 모두 **MLP·PyTorch**가 중심이다. 여러 숫자 특징을 층별로 조합해 배우는 기초를 확장한다. CNN·RNN·연합학습·지식 증류를 모두 추가할 필요는 없다. 단, 공유 구조나 개선된 입력 변환은 따로 학습해야 한다.

**주제에 적합하게 쓰는 표현:** ‘최근 MLP 기반 모델을 항적 데이터에 적용하고, 트리와의 혼합 효과 및 CPU 비용을 비교한다.’

**피할 표현:** ‘새 MLP 이론을 개발했다’, ‘모델 결합이 곧 연합학습이다’, ‘최신 논문이므로 어선 사고를 예방할 수 있다’. 트리만 최종 사용했다면 그것만으로 딥러닝 활용을 주장하지 않는다. MLP를 실제 비교 실험에 포함한 사실과 대회 제출 모델의 선택은 구분할 수 있다.

**판정 범위:** 제공된 강의 계획과 제안서 공지의 주제 문구에 따른 내용상 적합성이다. 담당자의 최종 승인·미공개 채점 기준을 확인한 것은 아니다.
