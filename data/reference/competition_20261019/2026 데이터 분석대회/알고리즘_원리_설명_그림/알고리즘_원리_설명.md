## 1. 먼저 알아 둘 기초 용어 6개

| 용어 | 쉬운 뜻 | 예시 |
|---|---|---|
| **특징(feature)** | 대상을 설명하는 숫자 한 칸 | 배의 “하루 중 정지 비율 = 0.74” |
| **특징표** | 대상마다 특징을 한 줄로 모은 표 | 배 1척 = 1행, 특징 수십 개 = 열 |
| **손실(loss)** | 예측이 정답과 얼마나 틀렸는지를 나타낸 점수. 작을수록 좋다 | 정답 자망에 10%만 줬다면 손실이 크다 |
| **기울기(gradient)** | “어느 방향으로 얼마나 고치면 손실이 줄어드는가”를 알려 주는 값 | 산에서 내려갈 방향과 경사 |
| **과적합** | 학습 데이터의 우연한 특징까지 외워서 새 데이터에서 성적이 떨어지는 현상 | 기출문제 답만 외운 학생 |
| **앙상블** | 여러 모델의 답을 모아 최종 답을 내는 것. 개별 실수가 서로 상쇄된다 | 의사 여러 명의 협진 |

## 2. LightGBM — 빠르고 강한 ‘질문 나무’ 이어 붙이기

### 2-1. 바탕 원리: 결정 트리 + 부스팅

![부스팅 개념](알고리즘_원리_설명_그림/01_boosting.png)

**결정 트리**는 “정지 비율 > 0.8?”처럼 예/아니오 질문을 이어 가며 답을 내는 나무다.
**부스팅(boosting)**은 이런 작은 나무를 하나씩 추가하면서, 매번 **지금까지의 합이 틀린 부분**만 보고 새 나무를 만든다.

| 단계 | 하는 일 | 쉬운 말 |
|---|---|---|
| 1 | 모든 배에 같은 초기 점수를 준다 | 처음엔 다 “잘 모르겠음” |
| 2 | 현재 점수가 정답과 얼마나 다른지(기울기)를 배마다 계산한다 | 오답노트 작성 |
| 3 | 그 ‘틀린 정도’를 가장 잘 설명하는 질문 나무를 새로 하나 만든다 | 많이 틀린 유형을 집중 공략 |
| 4 | 새 나무의 답을 **조금만**(학습률, 예: 0.05배) 더한다 | 한 번에 다 고치지 않고 조금씩 |
| 5 | 2~4를 수백~수천 번 반복한다 | 문제집을 여러 번 회독 |

- 4종 분류라면 클래스마다 점수를 따로 쌓고, 마지막에 4개 점수를 확률(합 = 1)로 바꾼다. `[근거: 일반적인 GBDT 다중분류 방식]`
- **GBDT**(Gradient Boosting Decision Tree)는 이 방식의 이름이다. LightGBM·XGBoost·CatBoost는 모두 GBDT 계열이다.

### 2-2. LightGBM만의 요령 — 같은 GBDT를 ‘빠르게’ 만드는 장치

![LightGBM 요령](알고리즘_원리_설명_그림/02_lightgbm.png)

| 요령 | 원리 | 효과 |
|---|---|---|
| **① 히스토그램** | 연속값을 구간(bin)으로 묶은 뒤, 나무를 나눌 후보를 **구간 경계에서만** 찾는다 | 후보가 ‘데이터 수’에서 ‘구간 수’로 줄어 빠르고 메모리가 적다 `[근거: 공식 문서]` |
| **(히스토그램 빼기)** | 한쪽 자식 칸의 히스토그램은 ‘부모 − 다른 자식’으로 계산한다 | 계산이 절반으로 준다 `[근거: 공식 문서]` |
| **② 잎 단위 성장** | 모든 칸을 한 층씩 키우지 않고, **손실이 가장 크게 줄어드는 잎 하나만** 골라 계속 쪼갠다 | 같은 잎 수에서 손실이 더 낮다. 대신 데이터가 적으면 과적합하기 쉽다 `[근거: 공식 문서]` |
| **③ GOSS** | 크게 틀린(기울기가 큰) 표본은 모두 쓰고, 이미 잘 맞힌 표본은 일부만 뽑아 가중치를 키워 쓴다 | 정확도를 거의 잃지 않으면서 계산을 줄인다 `[근거: NeurIPS 2017 논문]` |
| **④ EFB** | 동시에 0이 아닌 경우가 거의 없는 특징들을 한 열로 묶는다 | 희소한 특징이 많을 때 빠르다 `[근거: NeurIPS 2017 논문]` |
| **범주형 분할** | 범주를 원-핫으로 쪼개지 않고, 범주들을 두 묶음으로 나누는 최적 분할을 직접 찾는다 | 범주 특징을 그대로 쓸 수 있다 `[근거: 공식 문서]` |

### 2-3. 강점과 약점

| 강점 | 약점·주의 |
|---|---|
| 빠르다 (수천 척 × 수십 특징이면 수 초~수 분 `[추론]`) | 잎 단위 성장 때문에 **작은 데이터에서 과적합하기 쉽다** → 잎 수·잎당 최소 표본 수를 제한 |
| 결측값을 그대로 넣을 수 있다 | 트리는 계단 모양 함수라서, 학습 범위 밖의 값에는 ‘끝 칸’ 답만 낸다 `[근거: 트리 구조의 일반 성질]` |
| 스케일 조정(표준화)이 필요 없다 | 선박별 ‘버릇’을 외우기 쉽다 → 반드시 배 단위 교차검증 |
| 꼬리가 긴 특징, 쓸모없는 특징에 강하다 `[근거: NeurIPS 2022·2023 D&B]` | 확률은 따로 보정해야 정확해진다 |

### 2-4. 우리 과제에서 처음 만질 설정 `[제안]`

| 설정 이름 | 뜻 | 방향 |
|---|---|---|
| `num_leaves` | 나무 하나의 잎 개수 | 작게 시작(예: 15~31). 크면 과적합 |
| `min_child_samples` | 잎 하나에 들어가야 할 최소 배 수 | 배 수가 적으면 크게(예: 20 이상) |
| `learning_rate` / `n_estimators` | 한 번에 고치는 양 / 나무 개수 | 작은 학습률 + 많은 나무, 검증 점수로 멈춤 |
| `feature_fraction` / `bagging_fraction` | 나무마다 특징·표본을 일부만 사용 | 0.7~0.9로 다양성과 과적합 방지 |
| `class_weight` | 클래스별 가중치 | 조업형태 비율이 치우쳤으면 `balanced` |

## 3. TabM — 신경망 하나 안에 ‘신경망 32개’

### 3-1. 바탕: MLP(다층 퍼셉트론)란

- 입력 숫자들에 가중치를 곱해 더하고, 꺾인 함수(활성화 함수)를 통과시키는 일을 여러 층 반복하는 가장 기본적인 신경망이다.
- 학습이란, 손실의 기울기를 따라 **가중치를 조금씩 고치는 것**이다.

### 3-2. 원리 — “앙상블은 좋은데 비싸다”를 해결

![TabM 원리](알고리즘_원리_설명_그림/03_tabm.png)

| 단계 | 내용 | 쉬운 말 |
|---|---|---|
| 1. 출발점 | MLP 여러 개를 평균하면(앙상블) 하나보다 정확하고 안정적이다 | 협진이 단독 진료보다 낫다 |
| 2. 문제 | MLP k개를 따로 만들면 파라미터와 계산이 k배다 | 의사 32명 고용 비용 |
| 3. 아이디어 (BatchEnsemble) | 큰 가중치 행렬 **W는 모두 공유**하고, 구성원마다 **작은 조절 벡터**(r, s, b)만 따로 둔다. 구성원 i의 층은 `sᵢ ⊙ (W (rᵢ ⊙ x)) + bᵢ`, 즉 입력과 출력을 원소별로 살짝 키우거나 줄인다 `[근거]` | 같은 악보(W)를 각자 다른 음량 조절(r, s)로 연주 |
| 4. 동시 학습 | k = 32개 구성원을 **한꺼번에** 학습한다. 손실은 **32개 각각의 손실을 평균**한 것이다 | 32명이 각자 정답을 맞히도록 함께 훈련 |
| 5. 예측 | 32개 예측을 **평균**해서 최종 답을 낸다 | 합주 소리를 듣는다 |
| 6. TabM-mini | 조절기를 **첫 층 입력에만** 남긴 간소판. 논문에서는 이게 오히려 조금 더 좋았다 `[근거]` | 입구에서 한 번만 ‘색안경’을 다르게 씌움 |
| 7. 숫자 임베딩 (TabM†) | 숫자 하나를 구간별 직선(piecewise-linear)으로 펼친 짧은 벡터로 바꿔 넣는 변형 `[근거]` | 숫자를 ‘어느 구간쯤인지’까지 알려 줌 |

### 3-3. 왜 잘 되나 `[근거: 논문 분석]`

- **가중치 공유 = 강한 규제.** 32개가 같은 W를 써야 하므로 각자 데이터를 마음대로 외우기 어렵다. 논문은 이것이 “표 데이터에서 매우 효과적인 규제”라고 썼다.
- **하나하나는 약하고 과적합돼 있지만, 평균은 강하다.** 위 그림 오른쪽처럼 개별 예측의 들쭉날쭉함이 평균에서 상쇄된다. (그림은 개념도)
- **앙상블 전체를 보고 학습을 멈출 수 있다.** 동시에 학습하므로 ‘평균이 가장 좋을 때’ 멈추면 된다.

### 3-4. 근거와 주의

| 근거 | 주의 |
|---|---|
| ICLR 2025, 공개 데이터셋 46개(무작위 분할 37 + 시간·도메인 분할 9)에서 딥러닝 모델 중 최상위권 | 논문은 데이터셋마다 하이퍼파라미터를 튜닝했다 → 튜닝 시간이 든다 |
| TabArena(NeurIPS 2025 D&B)에서 튜닝 + 앙상블 시 상위 3위 안 | 신경망이라 표준화·결측 대치가 필요하다 (학습 폴드 안에서만) |
| GBDT와 “경쟁할 만하다”고 주장 (이긴다고는 하지 않음) | 쓸모없는 특징에 약한 신경망의 일반적 약점 → 특징 선택 후 투입 `[제안]` |

## 4. RealMLP — ‘기본 설정 묶음’이 실력인 신경망

### 4-1. 핵심 아이디어

- 새로운 구조를 발명하기보다, **전처리·구조·초기화·학습 일정 등 작은 요령을 여러 개 모아 기본값으로 고정**했다. 그래서 튜닝 없이 바로 써도 강하다.
- 논문은 “구조 외적인 요소(전처리·학습 방식)가 구조만큼 중요하다”고 정리한다. `[근거]`

![RealMLP 원리](알고리즘_원리_설명_그림/04_realmlp.png)

### 4-2. 요령 하나씩 풀기 `[근거: NeurIPS 2024 논문]`

| 단계 | 요령 | 원리 (쉬운 말) |
|---|---|---|
| ① 입력 정리 | **로버스트 스케일링**: 평균·표준편차 대신 중앙값·사분위 범위로 맞춘다 | 극단값 몇 개에 기준이 흔들리지 않는다 |
| | **부드러운 클리핑** `f(x) = x / √(1 + (x/3)²)` | 아무리 큰 값도 ±3 안으로 부드럽게 눌러 담는다 (그림 ①) |
| | 범주형: 종류 8개 이하는 원-핫, 두 종류는 −1/+1 | 범주를 숫자로 바꾸는 표준 방식 |
| ② 숫자 임베딩 **PBLD** | 숫자 하나를, 특징마다 작은 2층 네트워크로 계산한 **주기 함수 기반 4차원 벡터**로 바꿔 원래 값과 이어 붙인다 | 숫자의 ‘미세한 위치 차이’를 신경망이 알아보기 쉽게 한다 `[추론: 효과 해석]` |
| ③ **대각 스케일링 층** | 첫 층 앞에서 특징마다 학습되는 배율(초기값 1)을 곱한다. 이 배율은 학습률을 크게 준다 | 특징별 볼륨 다이얼. 쓸모없는 특징은 볼륨이 줄어들 수 있다 `[추론]` |
| ④ 몸통 | 256개 × 3층 MLP, 뉴런마다 모양이 조금씩 학습되는 **파라메트릭 활성화**(분류는 SELU 계열), NTP 파라미터화, 데이터에 맞춘 초기화 | 학습이 안정적으로 시작되게 하는 장치들 |
| ⑤ 학습 일정 | AdamW, 배치 256, 256 epoch, 학습률을 4번 오르내리는 **coslog4** 일정, 드롭아웃 0.15·가중치 감쇠 0.02도 시점별 조절 | 큰 보폭과 작은 보폭을 번갈아 써서 더 좋은 지점을 찾는다 |
| ⑥ 라벨 스무딩 ε = 0.1 | 정답을 100%가 아니라 약 92.5%로, 나머지 클래스에 약간씩 나눠 가르친다 (4종 기준, 그림 ③) | 지나친 확신을 막는다 |
| ⑦ 최고 시점으로 되돌리기 | 조기 종료 없이 끝까지 학습한 뒤, 검증 점수가 가장 좋던 epoch의 가중치로 되돌린다 | ‘가장 잘 본 모의고사’ 시점으로 복귀 |

## 5. DTE + 전역 이상 기준 — 과제 2 이상점수

### 5-1. 왜 ‘정상만 배우는’ 방식인가

- 과제 2는 시간대별 이상점수(0~1)를 내야 하는데, **사고 정보는 일부 선박에만** 있다. `[근거: 대회 공지]`
- 그래서 “사고를 맞히는 법”보다 **“평소(정상)가 어떤지 배우고, 거기서 얼마나 벗어났는지 재는 법”**이 기본이 된다.
- 주의: 사고 표시가 없다고 정상이 증명된 것은 아니다. 정상 기준 자료에 미확인 사고가 섞일 수 있다. `[근거: 팀원 교재 22장]`

### 5-2. ‘확산(diffusion)’이란

- 데이터에 **무작위 잡음을 조금씩 여러 단계 더해 가는 과정**이다. 단계 t가 커질수록 원래 모양이 흐려지고, 마지막엔 완전한 잡음이 된다.
- 비유: 선명한 사진에 지지직 노이즈를 1단계, 2단계, … 300단계까지 섞는 것.
- 이미지 생성 AI(확산 모델)는 이 과정을 거꾸로 되돌리는 법을 배운다. **DTE는 되돌리지 않는다.** 대신 “이 사진은 몇 단계 섞인 것 같나?”만 맞힌다.

### 5-3. DTE 원리 — 단계별

![DTE 원리](알고리즘_원리_설명_그림/05_dte.png)

| 단계 | 하는 일 | 쉬운 말 |
|---|---|---|
| 1. 재료 | 정상 기준 시간대들의 특징 벡터 x (예: 이동량, 회전, 시간대, 위치 특징) | 정상 사진 앨범 |
| 2. 흐리기 | x에 잡음을 t단계만큼 섞은 x_t를 만든다. t는 1~T 중 무작위 | 사진을 무작위 정도로 흐리게 |
| 3. 학습 | 모델이 x_t만 보고 **t를 맞히도록** 학습한다. 범주형 버전(DTE-C)은 t를 몇 개 구간으로 나눠 ‘어느 구간인지’ 맞히는 분류 문제로 푼다 | “이건 몇 단계 흐린 사진?” 감정사 훈련 |
| 4. 판정 | 새 시간대의 특징 벡터를 **흐리지 않고 그대로** 넣고 t를 추정한다 | 새 사진을 감정사에게 보여 줌 |
| 5. 점수 | **추정된 t가 클수록 이상**이다. 추정 분포의 평균(또는 최빈값)을 점수로 쓴다 | “원본인데 많이 흐린 사진처럼 보인다” = 정상과 멀다 |

**왜 이상하면 t가 크게 나오나** `[근거]`

- 정상 데이터 근처의 점은 잡음을 **조금만** 섞어도 도달하는 곳이다 → t가 작게 추정된다.
- 정상 데이터에서 멀리 떨어진 점은 잡음을 **많이** 섞어야 도달하는 곳이다 → t가 크게 추정된다.
- 이론적으로 t의 추정 분포는 **가까운 정상 점까지의 거리**로 정해진다. 그래서 신경망 없이 ‘k개 최근접 정상 점까지 평균 거리’로 계산하는 **비모수 버전**도 있다. 이 버전은 kNN 이상 탐지와 **같은 순위**를 낸다. `[근거]`

| 변형 | 방법 | 점수 |
|---|---|---|
| 비모수 | k-최근접 거리로 바로 계산 (학습 없음) | 평균 |
| DTE-IG | 신경망이 역감마 분포의 크기 모수를 예측 | 최빈값 |
| DTE-C | 신경망이 t의 구간을 분류 (구간 수가 적을수록 좋았다고 보고) | 평균 |

### 5-4. 근거와 한계

| 근거 `[근거: ICLR 2024]` | 한계·주의 |
|---|---|
| ADBench 57개 데이터셋(표 47 + 이미지 임베딩 5 + 텍스트 임베딩 5)에서 평가 | **정상만으로 학습하는 설정에서 “kNN을 제외한” 모든 기준 방법보다 좋았다** → 단순 kNN이 동급이라는 뜻. 반드시 kNN 기준선과 비교 `[제안]` |
| 생성형 확산 모델(DDPM) 기반 탐지보다 정확하고, 예측이 한 번의 계산이라 **자릿수가 다를 만큼 빠르다**(논문 표현: orders of magnitude). 비교한 방법 중 예측 시간이 가장 짧았다 | 거리 기반이므로 **특징 척도에 민감**하다 → 학습 기준으로 표준화 |
| 라벨 없이(혼합 데이터) 학습하는 설정에서도 경쟁력 있다고 보고 | 같은 배의 연속 시간대는 서로 독립이 아니다 → 점수의 통계적 해석에 주의 `[근거: 팀원 22장]` |

### 5-5. 전역 이상 기준 — 원점수를 0~1로

DTE 원점수는 단위가 없어 대회 형식(0~1)에 바로 쓸 수 없다. **기준 점수 분포에서 몇 등쯤인가**로 바꾸는 것이 가장 단순하다.

![전역 기준](알고리즘_원리_설명_그림/06_global_baseline.png)

**변환 식** (팀원 교재 22장 12절)

```
p_tail(s) = (1 + 기준 점수 중 s 이상인 개수) / (기준 점수 개수 + 1)
A(s)      = 1 − p_tail(s)        ← 0~1 이상점수
```

- 예시(가상): s = 2.3이고 기준 점수 4,000개 중 이보다 큰 것이 약 3%면, A ≈ 0.97이다. 그림 ① 참고.
- **이 값은 사고 확률이 아니다.** “기준 분포에서 상위 3% 쪽에 있다”는 순위 정보다. `[근거: 팀원 22장]`

**기준을 어디서 만들까** — 팀원 교재 22장 정리 `[근거]`

| 기준 | 장점 | 단점 |
|---|---|---|
| **전역(전체 선박)** | 표본이 가장 많다. 처음 보는 배(cold-start)에도 바로 쓸 수 있다 | **선박·조업형태 차이를 이상으로 오해**하기 쉽다 |
| 조업 클래스별 | 조업 방식 차이를 반영한다 | 조업형태를 잘못 분류하면 기준도 틀린다 |
| 개별 선박별 | 배마다 버릇을 반영한다 | 자료가 적고, 지속되는 고장이 ‘정상’으로 흡수될 수 있다 |

- 그림 ②(가상): 원래 점수가 높은 조업형태가 있으면, 전역 상위 5% 경계에서 그 형태만 경고가 몰린다(A형 0.7% vs B형 17.8%).
- **완화 방법** `[근거: 팀원 22장 식]`: 배마다 기준을 전역 기준 쪽으로 당겨 섞는다(수축).

```
선박 v의 기준 평균 = λ × (선박 v 자체 평균) + (1 − λ) × (전역 평균)
λ = n_v / (n_v + k₀)    n_v = 그 배의 기준 자료 수, k₀ = 신뢰도 조절값
```

- 자료가 적은 배는 전역 기준에 가깝고, 자료가 많은 배는 자기 기준에 가깝다. 자료가 없으면(n_v = 0) 전역 기준 그대로다.

**우리 과제 적용 순서** `[제안]`

1. 정상 기준 후보 시간대로 특징 → 학습 기준 표준화 → DTE(와 kNN) 학습
2. 교정용 시간대(학습에 안 쓴 것)의 점수로 **전역 기준 분포**를 만든다
3. Test B 시간대 점수를 위 식으로 0~1 변환한다
4. 조업형태별 경고 비율이 치우치는지 확인하고, 치우치면 클래스별 교정이나 수축을 비교한다
5. 과제 2는 ‘조기 탐지’로 평가하므로, 한 시간의 큰 값보다 **며칠에 걸친 점수 상승**을 잡는 누적 방식(팀원 22장의 CUSUM)도 함께 비교한다

## 6. GIST — 항적을 ‘그림’으로 바꿔 어구 분류

### 6-1. 핵심 아이디어

- 원래 항적(점의 나열)을 그대로 쓰지 않는다. **조업 구간만 잘라**, “시간 조각마다 속력·방향 변화가 어떻게 분포했나”를 **고정 크기 그림**으로 만든다.
- 그림이 되면 이미지 분류에 강한 **CNN**을 쓸 수 있다.
- **CNN**은 작은 돋보기(예: 3×3 필터)로 그림을 훑으며 반복되는 무늬를 찾는 신경망이다.

### 6-2. 원리 — 단계별 `[근거: AAAI 2025 논문]`

![GIST 파이프라인](알고리즘_원리_설명_그림/07_gist_pipeline.png)

| 단계 | 하는 일 | 쉬운 말 |
|---|---|---|
| 1. 정리 | AIS를 1분에 1점으로 맞추고, 대권(지구 곡면) 보간 후 속력(SOG)과 방향 변화(ΔCOG)를 좌표에서 다시 계산 | 들쭉날쭉한 기록을 1분 간격으로 고르게 |
| 2. 조업 섬 추출 | 저자들의 이전 비지도 방법(TripTracker)으로 일상적인 **조업 구간(fishing island)**만 남긴다. 128분 미만은 버린다 | 항해·정박은 빼고 ‘일하는 장면’만 |
| 3. 조각내기 | 조업 섬 하나를 **같은 길이 조각 128개**로 나눈다 | 영상을 128컷으로 |
| 4. 그림 만들기 | 조각마다 속력(0~20노트, 128칸)과 방향 변화(−180°~180°, 128칸) **히스토그램**을 만든다. 행 = 조각, 열 = 구간, 값 = 0~1 → **128 × 128 × 2채널** | 각 컷에서 ‘얼마나 빠르게/얼마나 꺾였나’의 분포를 한 줄씩 그림 |
| 5. 작은 CNN | 합성곱 블록 4개(합성곱 → 최대 풀링 → 드롭아웃) + 완전연결 2층, **파라미터 54,195개**. 구조는 KerasTuner로 100개 후보 중 선택 | 가벼운 판독기 |
| 6. 불균형 보정 | 연승 조업 섬이 **43개뿐** → 합성 데이터 생성기(SDV PAR)로 663개까지 늘림 | 부족한 사례를 비슷하게 만들어 보충 |

### 6-3. 결과와 비판적으로 볼 점

![GIST 결과](알고리즘_원리_설명_그림/08_gist_results.png)

| 결과 `[근거]` | 비판 |
|---|---|
| 3종(트롤·선망·연승) 정확도 **0.97**, macro F1 0.97 | **표본 단위 60/20/20 무작위 분할**(클래스당 398/133/133). 같은 배의 다른 조업 섬이 학습과 시험에 함께 들어갔을 수 있다 `[추론]` |
| 같은 데이터에서 LSTM(원 시계열) 0.78 → LSTM(GIST 그림 입력) 0.95 → GIST 0.97 | 개선의 대부분(0.78 → 0.95)은 **모델이 아니라 ‘그림 표현’에서** 나왔다 `[추론]` |

### 6-4. 우리 과제에 옮길 때 `[제안]`

| GIST | 우리 데이터 | 바꾸는 방법 |
|---|---|---|
| 1분 간격 속력(SOG) | 점마다 시각이 없음 | **점 사이 거리**로 대체 (진짜 속력이 아님 `[추론]`) |
| 조업 섬 128조각 | 1시간 레코드가 이미 조각 | 가로축을 **하루 0~23시**로 둔 ‘시간대 × 이동 분포’ 그림 (추천 PDF 4-2절) |
| 128×128×2 그림 + CNN | 배 수가 적을 수 있음 | 그림이 작으므로 **칸 값을 펼쳐 LightGBM 특징표에 추가**하는 버전과 반드시 비교 |
| 표본 단위 분할 | Test A는 처음 보는 배 | 배 단위 교차검증(`StratifiedGroupKFold`) |
