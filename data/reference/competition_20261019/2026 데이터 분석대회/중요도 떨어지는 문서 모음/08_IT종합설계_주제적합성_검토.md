# IT종합설계 프로젝트: 주제 적합성 검토

**판정: 현재 모델 구성은 공지의 주제 범위에 내용상 부합한다. 수업과 가장 직접 연결되는 중심은 MLP 기반 TabM·RealMLP와 PyTorch이다.**

첨부 공지의 주제는 ‘AI 알고리즘’, ‘AI 응용’, ‘딥러닝을 이용한 모든 분야’이다. 항적에서 조업형태를 분류하고 이상 패턴을 찾는 프로젝트는 AI 응용에 해당한다. TabM·RealMLP 또는 신경망 DTE·CNN을 실제 학습·분석에 사용하면 딥러닝 활용의 근거도 있다. 모든 보조 알고리즘이 딥러닝일 필요는 없다.

이는 제공 문구와 알고리즘 성격에 따른 **검토 판단**이다. 이미지에는 강의의 모든 기법을 반드시 사용해야 한다는 조건이 없지만, 담당자의 최종 주제 승인이나 미공개 평가 기준까지 확인한 것은 아니다.

## 1. 네 안건의 주제상 성격

| 안건 | 주제 적합성의 근거 | 정확히 구분할 점 |
|---|---|---|
| ① TabM + LightGBM | TabM은 MLP들의 계산 규칙을 공유하는 딥러닝 모델이다. 숫자로 가공한 항적 특징을 학습하므로 MLP 기반 AI 응용으로 설명할 수 있다. [1] | TabM 내부의 여러 예측과 서로 다른 알고리즘의 결합은 구분한다. LightGBM 자체는 딥러닝이 아닌 트리 기반 기계학습이다. |
| ② RealMLP + LightGBM | RealMLP는 개선된 다층 퍼셉트론이다. MLP를 실제 자료에 적용하는 수업 연계가 직접적이다. [2] | 기본 설정이 미리 조정됐다는 사실과 우리 팀이 메타학습을 구현한다는 주장은 다르다. |
| ③ DTE + 전역 기준 | 이번에 제안한 **DTE-Categorical**의 공식 코드는 MLP를 PyTorch로 학습한다. MLP·PyTorch의 응용이며, 확산 기반 이상탐지로 확장할 수 있다. [3] | 확산·잡음 단계 추정 이론은 강의 이미지에 명시되지 않아 추가 학습이 필요하다. DTE의 모든 변형을 신경망이라고 일반화하지 않는다. |
| ④ GIST 참고 CNN + 기하 분류 | 형상 이미지를 작은 CNN으로 학습하는 수정안은 CNN 활용 분야에 해당한다. [4] | 현재 WKT 형상 입력은 GIST 원 논문의 속도·방향 변화 입력과 다르므로 ‘GIST 재현’으로 소개하지 않는다. |

쉽게 말하면, **최근 논문의 모델이어도 학습의 바탕이 MLP나 CNN이면 수업에서 배운 신경망을 확장해 사용하는 주제로 설명할 수 있다.** 학회 이름만으로 수업 연관성을 주장하는 것이 아니다.

## 2. 학부 강의 항목과의 실제 연결

| 첨부 강의 항목 | 현재 구성과의 연관 | 판단 |
|---|---|---|
| MLP 복습 | TabM·RealMLP, DTE-Categorical의 신경망 추정기 | **직접 연관.** 여러 숫자 특징을 층별로 조합해 배우는 원리가 공통이다. |
| PyTorch 복습 | TabM 공식 패키지, RealMLP 구현, DTE 공식 신경망 코드. 작은 CNN도 PyTorch로 구현 가능 | **직접 연관.** PyTorch는 알고리즘 이름이 아니라 신경망 학습·구현 도구이다. [1-3] |
| CNN 복습 | ④의 항적 이미지 분류 | **④를 실제 수행할 때 직접 연관.** 숫자 특징만 사용하는 ①·②를 CNN이라고 부르지 않는다. |
| RNN 복습 | 현재 네 안건에는 RNN을 넣지 않았다 | **직접 연관 없음.** 시간별 점수나 과거와의 비교가 있다는 이유만으로 RNN을 사용한 것은 아니다. |
| Meta learning, Federated learning | 현재 계획에는 과제 간 적응 학습이나 분산된 기관의 공동 학습을 넣지 않았다 | **직접 구현 연관 낮음.** 모델을 섞는 것은 두 기법과 다르다. RealMLP 논문의 meta-tuning 문구만으로 우리 프로젝트의 메타학습 구현을 주장하지 않는다. |
| Knowledge Distillation 학습 | 현재 계획은 폭·깊이·멤버 수 등을 줄여 비용을 조절한다 | **현재 미포함.** 큰 교사의 예측을 작은 학생 모델이 배우는 지식 증류와 단순 크기 조절은 다르다. |

**학부 수준의 핵심 연결은 충분하다.** 다만 MLP 복습만으로 TabM의 공유 구조나 DTE의 확산 원리까지 이미 배웠다고 볼 수는 없다. 중심을 TabM 또는 RealMLP 한 계열에 두고, DTE·CNN은 선택 확장으로 두는 편이 수업 연계를 설명하기 명확하다. 네 안건을 모두 구현해야 주제가 적합해지는 것은 아니다.

## 3. 주제 표현에 대한 권고

추천 표현: **‘MLP 기반 경량 혼합 모델을 이용한 어선 조업형태 분류 및 이상항적 분석’**.

- 수업 연관성의 중심을 TabM 또는 RealMLP의 **실제 구현·학습·비교**에 둔다. 논문을 소개하거나 모델 이름만 적는 것으로 딥러닝 활용을 입증하지 않는다.
- LightGBM·Isolation Forest만 실제 사용한다면 AI 알고리즘·AI 응용으로는 설명 가능하지만, 그것만으로 ‘딥러닝을 이용했다’고 쓰면 부정확하다.
- 주제 적합성과 대회 성능은 별개다. 샘플 10행으로 최신 모델의 성능이나 사고 예방 효과가 입증됐다는 표현은 쓰지 않는다.
