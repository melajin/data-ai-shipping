# 추가 조건 검토 및 3차 실험 수정 제안

- 작성일: 2026-11-05
- 보완 내용: 사용자가 지적한 ‘우리 약 0.59는 이미 학습하지 않은 선박을 분류한 결과’라는 의미를 명시하고, 이를 바탕으로 3차 제안을 정정했다.
- 목적: 팀원 검토보고서에 제시된 신규 선박 평가 조건을 기존 1·2차 결과 및 3차 계획에 반영하기 위한 논의 기록
- 논의·보완 당시 상태: 2차 완료 후 일시정지, 3차 미실행. **이후 사용자가 “3차 돌려보자 일단 새 세션 오픈해서”라고 재개를 지시했다.** 현재 인계·실행 상태는 `../STATUS.json`과 `../NEXT_SESSION.md`를 따른다.
- 문서 성격: 검토 의견과 수정 제안이다. 실험 재개 승인, 공식 규정 확정 또는 새 성능 측정 결과가 아니다.

## 1. 핵심 판단

**우리의 약 0.59는 이미 학습 선박과 평가 선박을 분리한 상태에서, 학습하지 않은 선박의 항적 특징으로 업종을 예측한 결과다.** 후속 작업의 중심은 기존 평가 체계를 이어가며 이 정확도를 높이는 것이다.

쉽게 표현하면, 다음 질문에 답한 결과가 우리 약 0.59다.

> “이 배를 학습한 적은 없지만, 항적에 나타난 특징을 보면 통발 어선에 가깝다.”

따라서 신규 선박 평가를 처음부터 만드는 일을 3차의 최우선 과제로 제안했던 초안은 정정한다. 기존 선박 분리 평가와 측정 결과를 출발점으로 삼고, 추가 조건은 사용 가능한 입력 자료와 후보 방법을 점검하는 데 반영한다. 새로운 방법을 도입할 때 필요한 출처 확인과 비교 조건 고정은 해당 실험의 준비 절차로 수행한다.

팀원 모델의 높은 전체 점수는 과거 자료에 등장했던 선박이 많은 평가 집단에서 나왔다. 처음 보는 선박의 업종을 분류하는 능력과 기존 선박을 다시 찾아내는 능력을 구분해야 한다.

다만 검토보고서의 ‘공식 Test A 기대 성능 약 0.58’, ‘규정상 허용’, ‘우리보다 약 0.08 우수’라는 표현은 관측 근거보다 강하다. 내부 측정값, 규정 해석, 공식 평가 예측을 분리해서 기록해야 한다.

## 3. 팀원 결과의 의미

| 평가 집단·구성 | 보고된 micro-F1 | 해석 |

| 기존·신규가 섞인 전체 집단, 10차 최종 결합 | 0.8383 | 전체 6,526척 중 기존 ID가 5,835척, 약 89.41% |
| 신규 ID 691척, 10차 최종 결합 | 0.5427 | REF에 같은 ID가 없는 내부 개발 집단의 성능 |

전체 점수 0.8383은 신규 선박 성능 0.8383을 뜻하지 않는다. 보고서의 자기 ID 제외 진단도 높은 성적에 동일 선박 검색이 크게 기여했음을 뒷받침한다.

다만 자기 ID 제외 진단은 저장 검색 후보에서 같은 ID를 제거한 부분 진단이다. 특징 선택·변환·참고 문맥·재순위 학습을 모두 다시 구성한 완전한 신규 선박 실험으로 해석하지 않는다.

### 공식 점수 예상으로 확대하지 않을 것

0.5789는 내부 REF에 같은 문자열 ID가 없던 691척의 관측값이다. 공식 Test A와 선박 구성, 해역, 기간, 관측량, 업종 비율이 같다는 근거는 없다. 문자열 ID 비중첩이 외부 확인을 거친 물리적 선박 신원 인증을 뜻하는 것도 아니다.

따라서 권장 표현은 다음과 같다.

> 내부 신규 ID 691척에서는 전역 TabICL 단독이 micro-F1 0.5789를 기록했다. 공식 Test A 성능을 예측하거나 보장하는 값은 아니다.

## 4. 규정 관련 판단의 범위

제공 보고서에는 Test A가 ‘원칙적으로 Train에 포함되지 않은 신규 선박’이라는 공지 인용이 있다. 이번 논의에서는 이를 설계의 작업 가정으로 반영한다. ‘원칙적으로’를 모든 평가 행에 대한 절대적 보장으로 바꾸지 않는다.

별도로 전달된 ‘동일 선박의 과거 항적을 이용한 통계·행동 프로필 생성 금지’는 제공 보고서에서도 원문 미확인으로 표시됐다. 이 금지 조건은 설계 제약으로 받아들이되, 다음 사항의 공식 허용 여부는 확정하지 않는다.

- 다른 선박의 과거 자료를 이용한 검색
- 동일 ID 쌍으로 학습한 재순위 함수
- 공통 공간 통계와 세밀 격자의 사용 범위
- 금지 조건의 과제 1·과제 2 적용 범위

또한 신규 선박이라는 이유만으로 모든 규정 문제가 자동으로 사라진다고 보기는 어렵다. 추론 시 동일 ID를 직접 조회하지 않더라도, 학습과 특징 생성 단계에서 어떤 자료를 사용했는지 확인해야 한다.

**평가 기간에 제공된 본인 항적을 요약하는 것**과 **평가 기간 밖의 동일 선박 과거 이력을 별도로 참조하는 것**은 구분해서 문서화한다.

## 5. 기존 1·2차 결과와의 관계

### 5.1 ‘우리 약 0.59’의 정확한 의미

우리 실험은 선박을 기준으로 학습용과 평가용을 나눴다. 평가 대상 선박을 해당 fold 모델의 학습 선박에 넣고 같은 선박을 다시 맞히는 방식으로 점수를 계산한 것이 아니다.

평가 과정은 다음과 같다.

1. 다른 학습 선박들의 항적 특징과 업종 정답으로 모델을 학습한다.
2. 해당 모델의 학습에 사용하지 않은 평가 선박의 항적을 특징값으로 표현한다.
3. 모델에 그 특징값을 넣어 네 업종의 확률과 최종 업종을 예측한다.
4. 예측이 끝난 뒤 평가 선박의 실제 업종과 비교하여 정답 수와 F1을 계산한다.

예를 들어, 평가 대상 A호가 해당 fold의 OUTER에 속한다면 A호는 그 fold의 FIT나 INNER에 속하지 않는다. 모델은 FIT 선박으로 학습하고 INNER에서 필요한 조기 종료·선택을 수행한 뒤, OUTER인 A호의 업종을 예측한다.

**이때 ‘처음 보는 선박’은 해당 예측을 만든 모델의 학습 선박 명부에 없는 선박이라는 뜻이다.** 실제 세상에서 새로 건조된 배라는 뜻도 아니고, 연구자가 데이터 파일에서 한 번도 ID를 본 적 없다는 뜻도 아니다. 일부 특징의 비라벨 집계 범위는 별도로 확인해야 하며, 그 문제는 5.6절에서 구분한다.

### 5.2 선박을 나누어 평가한 방식

기존 개발 집단은 5,897척이며, 각 fold 안에서 한 선박은 FIT·INNER·OUTER 중 하나의 역할만 가진다.

| 역할 | 사용 목적 | OUTER 선박과의 관계 |
|---|---|---|
| FIT | 모델 학습 | 같은 fold에서 선박 ID가 겹치지 않음 |
| INNER | 조기 종료 및 방법 선택 | 같은 fold에서 선박 ID가 겹치지 않음 |
| OUTER | 해당 fold의 예측 성능 계산 | 학습·선택 역할과 분리된 선박 |

3개 fold의 OUTER는 각각 1,966척, 1,966척, 1,965척이다. 이를 모으면 개발 선박 5,897척이 각각 한 번씩 OUTER 평가에 포함된다.

한 선박이 다른 fold에서는 FIT 또는 INNER에 포함될 수 있다. 그러나 그 선박의 OUTER 점수에는 **그 선박을 FIT·INNER에서 제외한 fold 모델의 예측**을 사용한다. fold마다 역할이 달라진다는 사실을 ‘자기 자신을 학습한 모델로 평가했다’는 뜻으로 해석하지 않는다.

2차에서는 INNER를 다시 조기 종료용 INNER_ES와 혼합 선택용 INNER_SELECT로 나누었다. 혼합계수는 INNER_SELECT에서 정하고 OUTER 예측 전에 고정했다.

### 5.3 0.59를 실제 정답 수로 읽기

이 과제는 선박 한 척에 네 업종 중 하나의 정답이 있는 단일정답 분류다. 모든 클래스를 포함해 계산한 micro-F1은 정확도, 즉 `맞힌 선박 수 ÷ 평가 선박 수`와 같다.

| 우리 실험 | 정답 / 평가 선박 | micro-F1 | 의미 |
|---|---:|---:|---|
| 1차 저장 5-seed LightGBM 재현 | 3,497 / 5,897 | 0.593013 | 기존 모델 재현 및 CSV 정밀도 진단, 새 학습 없음 |
| 2차 seed42 LightGBM 재학습 | 3,476 / 5,897 | 0.589452 | 2차의 비교 기준 |
| 2차 CatBoost | 3,424 / 5,897 | 0.580634 | 기준 대비 정답 52척 감소, 채택 거절 |
| 2차 fold별 혼합 | 3,474 / 5,897 | 0.589113 | 기준 대비 정답 2척 감소, 채택 거절 |

따라서 ‘우리 약 0.59’는 대략 **학습에서 분리한 선박 100척 중 59척의 업종을 맞혔다**는 의미다. 모든 업종에서 각각 59%를 맞혔다는 뜻은 아니다. 특히 통발 등 업종별 성능은 별도로 확인해야 한다.

1차의 0.593013은 이 평가 방식으로 만들어진 기존 저장 모델의 결과를 다시 재현한 값이다. 1차에서 새로운 모델을 학습해 그 수준에 처음 도달했다는 뜻은 아니다. 2차는 새로 학습한 기준 모델과 후보 모델을 비교했다.

같은 5,897척에서 micro-F1 0.7 이상이 되려면 최소 4,128척을 맞혀야 한다. 산술적으로 1차 재현값보다 순정답 631척, 2차 기준보다 652척이 더 필요하다. 이는 개선 규모를 이해하기 위한 계산이며, 추가로 맞힐 수 있다는 예측이나 공식 테스트 성능 보장이 아니다.

### 5.4 선박 분리 평가와 독립 최종 평가는 구분한다

이 값들은 반복 노출된 개발 OUTER 5,897척의 결과다. 독립 평가나 공식 제출 점수가 아니다. 1차와 2차도 seed 구성과 학습 조건이 달라 행 간 차이를 단일 알고리즘 효과로 해석하지 않는다.

다음 두 사실은 동시에 성립한다.

- **모델 학습 관점:** 해당 OUTER 선박은 그 fold 모델의 FIT·INNER와 분리되어 있다. 따라서 학습하지 않은 선박의 업종을 예측한 평가다.
- **개발 과정 관점:** 연구 과정에서 같은 OUTER 결과를 반복해서 확인했다. 이후 방법 설계에 그 관찰이 영향을 줄 수 있으므로 완전히 미사용인 최종 시험 성능으로 볼 수 없다.

‘개발 OUTER가 반복 노출됐다’는 한계를 설명한다고 해서, 기존 선박 분리가 없었던 것이 되지는 않는다. 반대로 선박을 분리했다고 해서 공식 테스트의 성능까지 증명된 것도 아니다.

### 5.5 팀원 수치와 우리 수치를 비교하는 범위

새 검토보고서에서 ‘우리 기존’으로 사용한 정확도 0.4990은 이번 1·2차 결과와 다른 과거 결과다. 0.5789−0.4990이라는 산술 차이를 현재 실험 대비 개선 효과로 사용할 수 없다. 현재 점수 약 0.59와 팀원 신규 점수 0.5789 역시 대상과 조건이 달라 직접적인 우열 비교가 불가능하다.

우리의 신규 선박 평가 자체가 없었다고 판단하거나, 팀원 자료가 등장했으므로 평가를 처음부터 새로 만들어야 한다고 결론 내릴 근거는 없다. 팀원 방식의 일부를 도입한다면 기존 비교 조건에 맞춰 실제 도움이 되는지를 확인하는 것이 후속 과제다.

### 5.6 입력 자료 점검은 기존 평가의 의미와 구분한다

기존 코드에는 fold 안에서 선박별 FIT/INNER/OUTER 역할이 중복되지 않도록 검사하는 절차가 있다. 그러나 모델 학습의 선박 분리와 특징 생성에 사용한 모집단의 분리는 별개다.

기존 출처 기록에서 확인한 사항은 다음과 같다.

| 입력 구성 | 기록된 생성 범위 | 새 조건에서 확인할 사항 |
|---|---|---|
| T5의 공통 정박지 후보 | 정답 없는 2026 Train 및 2025 Test 좌표 포함 | 평가 자료의 좌표를 사전에 함께 사용해도 되는지, 새 선박 도착 시 같은 절차가 가능한지 |
| T5의 업종별 참조 통계 | fold별 FIT 라벨만 사용 | 위 공통 공간 기준과 라벨 사용 범위를 구분해서 평가 |
| 지역 상대 특징 70열 | 전체 2026 Train 집단의 지역별 중앙값·MAD, 자기 선박 포함 | FIT에서만 기준 통계를 만들도록 변경할 필요가 있는지 |
| 행동 특징 68열 | 각 선박의 2026년 1~6월 관측을 개별 요약 | 실제 평가 시 제공되는 관측 기간과 일치하는지 |

이는 평가 정답 누수를 확인했다는 뜻이 아니다. **새 평가 조건에 맞는 정보 사용인지 확인이 필요하다는 뜻**이다. 모델 학습의 선박 분리는 이미 수행되어 있으며, 여기서 점검하는 것은 일부 특징의 비라벨 집계에 사용한 자료 범위다.

특징 생성에 평가 집단의 정답 없는 좌표나 통계를 사용했다는 사실과, 동일 선박의 과거 업종을 찾아 정답처럼 활용하는 방식은 구분해야 한다. 둘을 같은 문제로 묶어 우리 약 0.59의 평가 의미를 설명하면 부정확하다.

1차의 재현 성공과 2차의 동일 고정 입력을 사용한 비교 결과는 보존한다. 새 조건을 반영한다는 이유로 기존 점수를 덮어쓰지 않으며, 기존 검증을 새 조건 충족의 증명으로 확대하지도 않는다.

## 6. 3차 수정 제안

### 6.1 중심 과제 — 기존 선박 분리 평가를 이어가며 정확도 개선

3차의 중심 과제는 기존 개발 OUTER 5,897척의 선박 분리 평가를 바탕으로 약 0.59에서 개선할 방법을 찾는 것이다. 이번 추가 조건만으로 기존 분할을 폐기하거나 신규 평가 체계를 처음부터 만들도록 변경하지 않는다.

비교할 기준선과 후보의 조건을 맞추고, 변경 변수·실행 상한·채택 기준을 실험 전에 고정한다. 후보가 어느 선박을 새로 맞혔고 어느 선박을 새로 틀렸는지 함께 계산한다. 기존 1차 5-seed 기준과 2차 seed42 기준은 서로 다른 조건이므로 이번 후보와 맞는 기준을 명시한다.

### 6.2 추가 조건 — 사용할 입력과 도입할 방법의 범위 확인

기존에 기록된 특징 출처를 바탕으로 새 금지 조건과 관련된 부분을 점검한다. 새로운 검색·참고 문맥·전처리 방법을 도입할 때는 평가 선박이 다음 구성에 들어가는지 확인한다.

1. 검색 자료
2. TabICL 참고 문맥
3. 특징 선택 학습
4. 결측 대체·공간 SVD·지역 통계 등 변환 기준
5. 재순위 학습 쌍

이는 우리 평가에서 선박 분리가 빠져 있었기 때문에 새로 시작하는 절차가 아니다. **새로 도입하는 경로와 기존에 확인된 비라벨 집계 범위를 점검하는 준비 절차**다. 사용하지 않는 구성요소까지 새로 구현하지 않는다.

특징 생성 범위를 바꿔야 한다면 변경된 입력에서 기준 모델과 후보를 함께 비교한다. 입력 변경 전의 0.59와 변경 후 후보 점수의 차이를 모델만의 개선 효과로 계산하지 않는다. 평가 집단의 비라벨 정보를 함께 사용하는 방식이 별도로 허용된다면 그 조건도 구분해 기록한다.

기존 개발 자료를 재분할하더라도 새로운 독립 평가가 생기는 것은 아니다. 보호 holdout은 노출 이력 확인과 평가 계획 동결 전까지 열지 않는다.

### 6.3 기존 R0 및 팀원 방법의 비교 위치

기존에 제안한 R0 판정 보정 비교는 정확도 개선 후보로 유지한다. 원확률 argmax, 기존 업종 배수, INNER에서 선택한 새 배수의 손익을 같은 저장 예측과 선박에서 비교하는 작업이다. 분할·확률 출처가 확인된 자료를 사용하고, OUTER 결과를 본 뒤 가장 좋은 배수로 덮어쓰지 않는다.

팀원 전역 TabICL이나 특징 구성도 추가 후보로 검토할 수 있다. 실제 도입할 때 LightGBM과 같은 평가 선박·기간·정보 범위를 맞추며, 입력 특징까지 다르면 모델만의 효과가 아니라 파이프라인 비교임을 명시한다.

팀원 모델의 222개 입력, 기존 TabICL A의 F156 계열, 현재 LightGBM의 X304는 서로 다른 구성이다. 점수, 체크포인트, 전처리, 수정 방법을 같은 구성으로 취급하지 않는다.

R0 저장 확률 비교가 원모델 재현이나 새로운 전처리 전체의 검증을 대신하지는 않는다. 그러나 기존에 검토한 정확도 개선 작업을 모두 중단하고 별도의 신규 평가 체계를 만드는 단계로 되돌릴 필요도 없다.

### 6.4 후속 후보 — 신규 선박 오답을 줄이는 방법

‘같은 배인가’를 학습한 검색·재순위 방식을 ‘같은 업종의 다른 배인가’로 변경하는 것은 검토할 가설이다. 성능 향상이 확인된 방법은 아니다.

실험을 설계한다면 다음을 사전에 정한다.

- 같은 업종의 다른 선박으로 양성 쌍을 구성하는 방식
- 비슷한 해역의 다른 업종 등 어려운 음성 쌍 구성
- 선박 단위 학습·선택·평가 분리
- 검색 단독, 전역 TabICL 단독, 결합의 동시 비교
- micro-F1뿐 아니라 업종별 재현율·F1 및 짧은 관측 집단의 손해 확인

공간이 비슷한 효과와 조업 행동이 비슷한 효과를 구분해야 한다. 라벨만 바꾸면 충분하다거나 비용이 작다고 미리 확정하지 않는다.

출력층 직접 조정·rank2 수정 등 기존 구조 변경 제안도 후속 후보로 남긴다. 해당 모델의 재현 조건과 실행 자원이 확보되면 같은 조건에서 비교한다. 이번 문서 보완만으로 이 후보들을 새로 실행하거나 폐기하지 않는다.

## 7. 집중할 오류와 해석상 한계

두 작업에서 공통으로 보이는 취약점은 통발과 연안복합·자망의 구분이다. 우리 2차에서는 CatBoost와 혼합의 통발 재현율이 기준 모델보다 낮아졌고, 팀원 보고서에서도 신규 통발 재현율이 낮았다.

따라서 이 업종 경계를 구분하는 특징과 사례 선택을 우선 검토할 근거는 있다. 다만 두 실험의 입력과 평가 대상이 다르므로, 같은 원인 때문에 발생한 오류라고 확정하지 않는다.

좌표별 시각이 없는 자료에서 실제 순간 속력·가속도를 계산했다고 주장하지 않는다. 관측 날짜 수를 운항시간으로 해석하거나 관측량과 성능의 관계를 곧바로 인과관계로 설명하지 않는다.
