### S1 — 지역·시기 사전확률 고해상도화 (저비용·저위험)

**가설:** 최강 특징축(`t5_*` = 다른 선박 기반 항구 사전확률, AUC 0.64)은 **공간 해상도와 시간 분해능이 거칠다.** 이를 다중해상도 격자 × 월 단위로 직접 사후확률화하면 통발·자망 분리가 개선된다.

**규칙 1.1 준수 설계 (필수):**
- 격자별 클래스 카운트는 **해당 fold의 FIT 선박 라벨만** 사용한다.
- 특징을 계산하는 선박 자신은 카운트에서 **제외한다(leave-self-out)**. 이것이 "동일 선박의 과거 항적 이용"을 피하는 핵심 장치다.
- 평가 대상 선박은 **자신의 평가기간 좌표만** 써서 어느 격자에 있는지를 정한다. 그 선박의 다른 기간 좌표는 절대 쓰지 않는다.

**특징 설계 (총 24열):**
- 해상도 3종: 0.01° / 0.05° / 0.10°
- 각 해상도마다: 선박이 점유한 격자들의 FIT 클래스 사후확률을 **점유 시간 가중평균** → 4열
- 각 해상도마다 **월별 사후확률의 최대-최소 폭** → 4열 (계절 어장 이동 반영)
- 스무딩: Laplace, `alpha = 5`, 사전 고정
- 미관측 격자는 상위 해상도로 폴백, 전부 없으면 FIT 전역 사전확률

**적용 위치 (중요):** 이 24열은 **메타 스태커가 아니라 LightGBM base 모델의 입력 304열에 직접 추가**한다(→ 328열). 2.1에서 스태커 경로는 폐기됐다.

**실행 상한:** 3 fold × 1 seed, 하이퍼파라미터 탐색 0회, 기준선도 동일 조건으로 재실행.

**사전 고정 판정 관문:**
- **통과:** 동일 seed42 LightGBM(3,476) 대비 **순증 >= +40척** 그리고 `class0 TP >= 2389`, `class3 TP >= 90`(동일절차 기준)
- **부분:** +10 ~ +39척 → 기록만 하고 채택 보류, S2로 즉시 이동
- **폐기:** +10척 미만 또는 보호 실패 → **지역 사전확률 축을 종료한다. 변형 재시도 금지.**

판정에 paired bootstrap(5,000회, seed 20261105) 구간을 병기하되, **구간이 아니라 사전 고정 척수**로 판정한다.

### S2 — 세그먼트 단위 학습 + 분포 집계 (0.7의 유일한 경로)

**핵심 논리.** 현재 모든 모델은 선박 1척 = 학습 표본 1개다. FIT는 3,144표본, 특징 304열은 전부 "일자별 p10/중앙/p90/IQR" 같은 **요약 통계**다. 이 표현에는 치명적 한계가 있다:

> **연안복합은 복합 어업 면허다. 통발·자망·채낚기 행동을 섞어서 한다.**
> 섞인 행동을 백분위수로 요약하면 **평균 쪽으로 뭉개져서** 단일 어구 선박과 구분이 사라진다.
> 통발 재현율이 12.9%(835척 중 108척)이고 525척이 연안복합으로 흘러가는 직접 원인이 이것이다.

**설계.** 선박이 아니라 **선박-일(vessel-day)** 을 학습 단위로 바꾼다.

1. **세그먼트 특징 생성**
   - 단위: `(rfid_id, part_dt)` 1일. 원자료 3,887,069행 → 약 50만 선박-일.
   - 특징: 기존 F156의 **일자별 원값**(백분위수로 집계하기 **전** 값) + 해당 일의 시간대 히스토그램 + S1의 격자 사후확률.
   - 라벨: 그 선박의 어구(약라벨). **보고서에 "일별 행동 정답"이라고 쓰지 않는다** — `CYCLE_PROTOCOL.md` 7항.
   - 원자료 스캔은 스트리밍으로 가능함이 확인됐다: 3,887,069행 전체 **52초**, 상수 메모리 (`temp/hypo_20261105/scan.py` 참고).

2. **세그먼트 분류기**
   - LightGBM 4클래스, FIT 선박의 세그먼트만 학습. `threads <= 3`.
   - **선박 단위 분리 엄수:** 한 선박의 세그먼트는 전부 같은 역할(FIT/INNER/OUTER)에 있어야 한다. 섞이면 누출이다.

3. **분포 집계 → 선박 특징 (이 단계가 본체)**
   각 선박의 세그먼트 확률 집합에서 **단순 평균을 쓰지 말고 분포 전체**를 뽑는다:
   - 클래스별 세그먼트 확률의 평균 / 중앙 / p90 / 표준편차 (16열)
   - **클래스별 argmax 세그먼트 비율** (4열) ← 연안복합의 "혼합" 서명을 직접 포착
   - 세그먼트 예측의 **엔트로피 평균**과 **고유 예측클래스 수** (2열)
   - 최빈 클래스 비율, 2위 클래스 비율, 둘의 차이 (3열)

   → 25열. **"이 배는 통발형 날 30% + 자망형 날 40%"** 가 비로소 표현 가능해진다. 현재 304열로는 원리적으로 불가능한 정보다.

4. **최종 선박 분류기**
   304열 + S1의 24열 + S2의 25열 = **353열**로 LightGBM 재학습.

**실행 상한:** 세그먼트 분류기 3 fold × 1 seed, 최종 분류기 3 fold × 1 seed. 하이퍼파라미터 탐색 0회. 사전 고정값: `n_estimators=400, learning_rate=0.05, num_leaves=63, colsample_bytree=0.7, subsample=0.8, min_child_samples=50`.

**RAM 설계:** 50만 세그먼트 × 약 60열 float32 ≈ 120MB. 상한 내. 특징 생성은 월별 스트리밍 후 분할 저장.

**사전 고정 판정 관문:**
- **0.7 도달:** 전체 >= 4,128척
- **중간 성공:** >= 3,774척 (0.64) 그리고 보호 통과 → 채택 후 S3 설계
- **통과:** 동일 seed42 LightGBM 대비 **+150척 이상** 그리고 보호 통과
- **폐기:** +50척 미만 → 세그먼트 경로 종료. 이 경우 **0.7은 현재 자료·자원으로 도달 불가로 기록하고**, 억지 재시도 대신 그 판정을 사용자에게 보고한다.

**선행 검증 (전체 실행 전 필수, 약 10분):** fold0 FIT 3,144척만으로 **FIT 내부 4-fold CV**를 돌려 세그먼트 집계 25열의 추가 효과를 먼저 잰다. 기준은 304열 단독 **0.5779 (1817/3144)** 이다 (이미 측정해 둔 값). **+1.5%p 미만이면 전체 실행을 시작하지 않는다.** 이 선행 관문이 이 문서의 핵심이다 — round_004~021에 이것이 없어서 매번 전체 라운드를 태웠다.
