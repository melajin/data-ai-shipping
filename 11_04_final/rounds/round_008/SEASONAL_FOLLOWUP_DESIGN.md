# 월별 변화 후보의 후속 설계 메모 — 이번 회차 실행 아님

근거는 round007/SEASONAL_FEATURE_INVENTORY.md와 그 metadata다. 새로운 데이터 읽기/특징추출/학습/F1은 수행하지 않았다. 현재 재현에는 특징을 추가하지 않는다.

후속 후보의 질문은 월별 관측량을 넘는 형태·지역 변화가 선박 단위 분류에 추가 정보를 주는가이다. 우선 읽기전용 코드/metadata에서 사용 가능한 일별 요약과 날짜계약, 관측일 분모, 결측mask를 확인해야 한다. timezone 미확정 상태에서는 native hour를 쓰고 한국 야간으로 단정하지 않는다. 1–6월은 반년 자료이며 사계절 또는 연도 독립 평가가 아니다.

검증 가능한 최소 비교는 동일 개발 분할·FIT 전처리·학습/선택 예산에서 (A) 기존특징, (B) A+월관측량, (C) B+월별형태/지역변화이다. 이 회차에서는 세 후보를 실행 승인하거나 수치를 예상하지 않았다. 새 회차에서는 먼저 시간/메모리와 기존 기준선 조건을 정하고 하나의 유한 비교로 좁혀야 한다. 기존 sqrt_macro5seed와 다른 모델/seed 결과를 특징효과로 직접 빼지 않는다.

월별 특징을 만들 때 무관측월을 0활동으로 만들지 않는다. 각 통계는 유효관측수와 결측mask를 동반한다. 선박의 월을 서로 다른 train/test에 나눠 선박독립 일반화라고 주장하지 않는다. 지역 변화는 관측 좌표 분포 변화이며 실제 항해거리·속력·조업행동으로 부르지 않는다. 원자료에 대한 새 읽기는 후속 동결계약에 한정하고 보호자료 이력관문을 유지한다.

학습 질문: 관측량 효과를 분리하려면 왜 B가 필요한가? 월별중앙값 간 차이를 조업량 변화라 할 수 없는 이유는? 반복 개발OUTER의 선택편향을 재분할이 해결하지 못하는 이유는?
