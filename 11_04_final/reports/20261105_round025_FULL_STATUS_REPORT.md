## 2. micro-F1을 어떻게 읽으면 되는가

이번 과제는 한 선박을 네 업종 중 하나로 분류하는 문제입니다. 이 조건에서 micro-F1은 전체 선박 중 정답을 맞힌 비율과 같습니다. 예를 들어 0.593013397은 약 59.30%를 맞혔다는 뜻입니다.

점수를 볼 때는 **어떤 선박 집합에서 계산했는지**를 함께 봐야 합니다.

- **전체 개발 OUTER 5,897척:** 기존 모델과 과거 후보를 비교해 온 전체 개발 평가 집합입니다. 이미 여러 번 결과를 관찰했습니다.
- **이번 FIT 3,144척:** 새 특징의 가능성을 먼저 확인하기 위해 사용한 학습 집합입니다. 내부를 네 부분으로 나눠 교대로 검증했습니다.
- **독립 평가 자료:** 연구 과정에서 충분히 분리되어 있고 노출 이력이 확인된 자료여야 합니다. 이번에는 평가하지 않았습니다.
- **공식 점수:** 실제 공식 제출 결과가 있어야 합니다. 이번에는 제출하지 않았습니다.

따라서 이번 후보의 0.566475827을 전체 5,897척의 새 점수로 바꿔 말하면 안 됩니다. 이번 회차에서 전체 5,897척을 새로 평가한 횟수는 **0회**입니다.

## 4. 이번 실험은 무엇을 확인했는가

가설은 다음과 같았습니다.

> 기존 선박 특징에 지역·시기별 업종 분포 정보를 더하면, 자망·통발을 더 잘 구분하면서 전체 정답 수를 늘릴 수 있는가?

기존 모델에 쓰는 입력 항목은 304개였습니다. 후보에는 지역·시기 정보를 요약한 S1 특징 24개를 더해 총 328개를 사용했습니다. 두 모델의 학습 설정과 분할은 같게 유지했습니다.

3,144척을 786척씩 네 집단으로 나눴습니다. 한 집단을 검증용으로 남기고 나머지로 학습하는 과정을 네 번 반복했습니다. 각 분할에서 기준과 후보를 하나씩 학습했으므로 총 학습 횟수는 **4 × 2 = 8회**입니다.

지역별 업종 비율처럼 정답을 이용해 만드는 특징은 매 분할의 학습 선박만으로 다시 계산했습니다. 검증 선박의 정답이 특징에 섞이지 않게 했으며, 학습 선박 자신의 정답도 자기 특징에 반영되지 않도록 제외했습니다.

이번 S1은 원래 항적 도형 전체의 공간 점유를 직접 표현한 것이 아니라, 시간대별 중심 좌표를 이용한 **근사 표현(proxy)**입니다. 따라서 결과의 적용 범위도 이 표현에 한정됩니다.

| round024 | 진입 RAM 조건 미달, 학습 0회 |
| **round025** | **8회 학습·검산 완료, 이번 근사 특징 후보 미채택** |
| 원래 항적 도형 전체를 이용한 S1 확장 | 이번 근사 표현 실험으로 검증됐다고 볼 수 없음 |
| 일별 세그먼트 학습 S2 | 미실행 |
| 새 전체 3fold 확인·최종 5seed 확인 | 미실행 |
| 독립 평가·공식 제출 | 미실행 |

원장에 기록된 001–024의 새 fit 호출은 14회이고 이번 8회를 더하면 22회입니다. 서로 다른 종류의 학습 호출을 합친 수이며, 원장 시작 전 저장 모델의 학습까지 포함한 역사 총횟수는 아닙니다. 회차 수가 많다는 것이 그만큼 새 성능 실험을 많이 했다는 뜻은 아닙니다.

이번에 확인한 중요한 차이는 **실행 문제와 성능 문제를 분리했다는 점**입니다. 앞선 일부 회차는 RAM·시간 때문에 비교를 끝내지 못했습니다. 이번에는 비교를 정상적으로 끝냈고, 이번 표현으로는 사전 개선 기준을 충족하지 못한다는 결과를 얻었습니다.

왜 이런 결과가 났는지에 대해서는 더 신중해야 합니다. 표현의 중복, 평활화, 중심 좌표 근사의 정보 손실 등은 가능한 설명이지만 이번 한 비교로 원인을 확정하지 않았습니다. 이번 실패만으로 모든 S1 설계나 미래 모델에서 0.7이 불가능하다고 결론내리지 않습니다.

## 10. 평가와 데이터 사용의 한계

전체 개발 5,897척은 이미 반복 노출됐습니다. 여기서 잘 나온 점수를 새 독립 검증 성능이라고 부를 수 없습니다.

이번에는 승인된 기존 캐시와 개발 fold0 특징을 사용했습니다. 원래 NPZ의 개발 자료 배열을 읽은 뒤 FIT 행을 선택하므로 비FIT 개발행이 메모리에 전혀 없었다고 주장하지 않습니다. 비FIT 개발행은 이번 학습·선택·점수 계산에 사용하지 않았습니다.

새로운 holdout/Test 개별 특징·라벨·예측·평가를 읽거나 원자료를 다시 스캔하지 않았습니다. 기존 T5 공용 항구의 무라벨 위치 집계에 대한 승인 경계도 유지했습니다. 동일 선박의 과거 프로필을 찾아 라벨을 옮기는 재식별은 사용하지 않았습니다.

원자료와 이전 저장소는 수정하지 않았습니다. 외부 업로드, 공식 제출, 새로운 유료 자원 사용, 실제 선박 운용과 하드웨어 검증도 하지 않았습니다.

관리자 Sol/high와 보조 Luna/xhigh는 생성 요청과 호스트 turn_context 기록을 구분해 보존했습니다. 이는 호스트가 기록한 모델·effort의 증거이며, 내부 실행 모델을 별도로 인증했다는 주장은 아닙니다.

## 11. 목표까지 얼마나 남았고, 다음에는 무엇을 할 수 있는가

5,897척에서 micro-F1 0.7 이상이 되려면 최소 **4,128척**을 맞혀야 합니다.

| 비교 출발점 | 현재 정답 | 목표까지 추가로 필요한 정답 |
| --- | --- | --- |
| 현재 채택 5seed | 3,497 | **631척** |
| 동일조건 seed42 기준 | 3,476 | 652척 |
| 미채택 탐색값 | 3,528 | 600척 |

현재 채택 점수와 목표의 차이는 약 **10.70%p**입니다. 이번 24개 특징 추가는 그 간격을 줄이지 못했습니다. 앞으로 개선할 여지가 얼마나 되는지는 아직 측정하지 않았습니다.

사용자가 재개를 명시하면 검토할 수 있는 다음 제안은 **S2 준비 작업**입니다. 선박 전체 요약만 보는 대신, 날짜별 특징에서 얻은 예측의 분포를 선박 수준으로 모으는 방식입니다. 다만 선박 업종 라벨은 일별 행동의 정답이 아니므로 약라벨로 다뤄야 합니다. 같은 선박이 학습과 검증에 섞이지 않도록 하고, 학습용 집계 특징도 그 선박을 제외한 모델의 예측으로 만들어야 합니다.

이 제안은 실행하지 않았습니다. 다음 회차를 재개하더라도 먼저 자료 범위, 분할과 교차적합, 낮은 메모리로 처리하는 방법, 유한 실험 수와 진행 기준을 고정해야 합니다. 이번에 미달한 S1 근사 특징을 자동으로 다음 후보에 포함하지 않습니다.

**현재는 사용자 지시에 따른 일시 중지 상태입니다.** STATUS의 current_round는 round_025, handoff.ready는 true, next_session_launched는 false이고 user_pause는 유효합니다. 자동 인계 차단 설정을 유지했으며, 명시적인 재개 지시 전에는 다음 회차를 실행하지 않습니다.
