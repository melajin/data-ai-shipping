# 어선 항적 분석 — 개발 결과물

현재 상태: 제출 형식 준비. 최종 데이터·모델·코드 선정 및 복사 전이며, 실행 가능한 최종 제출본은 아닙니다.

## 1. 결과물 구성

| 경로 | 내용 | 현재 상태 |
| --- | --- | --- |
| README.md | 구성, 환경, 실행 방법, AI 활용 및 제출 점검 | 작성 틀 준비 |
| data/ | 학습·평가 데이터 및 데이터 설명 | 배치 예정 |

사용하지 않는 폴더는 최종 정리 시 생략하고 이 표에 사유를 기록합니다.

## 2. 데이터 및 모델

- 데이터명·출처·이용조건: 최종 선정 후 기재
- 파일별 용도, 컬럼·단위, 결측 처리, 전처리 방법: 기재 예정
- 학습·검증·평가 분할 및 누출 방지 기준: 기재 예정
- 모델명·구조·주요 설정·난수 시드: 기재 예정
- 모델 파일 및 함께 필요한 전처리 객체: 기재 예정
- 평가 지표·결과·한계: 검증된 결과와 근거 파일을 기재

합성 데이터 실험과 실제 데이터 평가를 구분합니다. 좌표별 시각이 없는 데이터에서 실제 속력·가속도를 산출한 것으로 설명하지 않습니다.

## 3. 실행 환경(HW/SW)

| 항목 | 제출본 기준 기록 |
| --- | --- |
| 운영체제 | 확인 예정 |
| CPU / RAM / 필요 저장공간 | 확인 예정 |
| Python 및 주요 프로그램 버전 | 확인 예정 |
| 주요 라이브러리 및 상세 버전 | 확정 환경에서 추출 예정 |
| GPU 모델 / VRAM | 사용 여부 확인 예정 |
| NVIDIA Driver / CUDA | GPU 사용 시 확인하여 기록 |
| 외부 AI 서비스·API | 실행 의존성 여부 확인 예정. 필요하면 서비스·모델·설정 기재 |

확정된 실행환경에 맞는 설정 파일을 이 폴더 루트에 포함합니다.

- pip: 검증된 환경에서 `python -m pip freeze > requirements.txt`
- conda: `conda env export > environment.yml`
- uv: `uv lock` 실행 후 `pyproject.toml`과 `uv.lock` 동봉

현재는 환경이 확정되지 않아 임의의 버전이나 환경 파일을 만들지 않았습니다. 인증정보가 필요한 경우 README나 코드에 저장하지 않고 별도 전달합니다.

## 4. 환경 구성 및 실행 방법

최종 파일 배치 후 아래 항목을 실제 실행 명령으로 작성하고 새 환경에서 검증합니다.

1. 환경 생성 및 의존성 설치
2. 데이터 배치 위치와 전처리 실행
3. 모델 학습 실행과 저장 위치
4. 저장 모델을 이용한 평가·추론 실행
5. Notebook 실행 순서와 결과 확인

각 명령의 작업 디렉터리, 입력·출력 경로, 예상 실행시간을 함께 기록합니다. 현재 실행 명령은 미확정입니다.

## 5. Jupyter Notebook 및 데모

Notebook은 데이터 불러오기 → 전처리 → 모델 구성·학습 → 평가 또는 추론 → 결과 시각화 순서로 구성합니다. 각 단계의 목적, 입력·출력, 설계 이유와 결과 해석을 Markdown 또는 주석으로 설명합니다. 재시작 후 전체 셀 실행을 확인합니다.

데모영상은 입력 준비, 실행, 예측 결과 확인 과정을 포함하고 영상 파일명·재생시간·재현 명령을 기록합니다. 영상은 아직 포함되어 있지 않습니다.

## 6. 외부 자료 및 민감정보

데이터·코드·모델·라이브러리별 출처, 버전, 라이선스, 재배포 조건을 최종 확정 후 기록합니다. 이용조건 검토는 미완료입니다.

제출 대상 파일에 개인정보, API Key, 비밀번호, 토큰, 인증 파일, 불필요한 로컬 경로가 포함되지 않는지 확인합니다. Notebook 출력과 영상 화면도 점검합니다. 현재 전체 제출물의 민감정보 검사는 미완료입니다.

## 7. AI 활용범위 및 주요 검토 과정

- 활용 도구: Codex(AI 코딩 에이전트). 이번 형식 정리 작업의 실행 모델 버전은 별도 확인하지 않음.
- 이번 활용 단계: 제출 구조 및 문서 작성 틀 정리.
- 주요 활용 내용: 요청된 폴더 구조 생성, README 항목 및 제출 점검표 작성.
- 참가자 주요 기여: 제출 요구사항과 우선 작업 범위를 제공함. 모델 선택·수정·검증 기여는 실제 기록에 따라 추가 예정.
- 프로젝트 전체 AI 활용: 기존 작업 기록을 확인해 도구·모델·활용 단계·생성 내용을 추가 예정.
- 검토한 대안 및 실패사례: 실험 기록에 근거해 접근법·결과·제외 사유를 추가 예정.
- 최종 선택 이유: 최종 모델 선정 근거와 성능·비용·복잡도 비교를 추가 예정.

AI가 수행한 검증과 참가자가 직접 수행한 검증을 구분하며, 미확인 활동을 수행한 것으로 기재하지 않습니다.
