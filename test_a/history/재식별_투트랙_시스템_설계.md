# 기존 선단 모니터링 기반 투트랙 조업분류 시스템

> 작성일: 2026년 11월 2일 · 상태: **설계안 (실험 전)**
> 이 문서는 시스템의 구성과 검증 계획을 정리한 것이며, 아래의 기대 효과는 아직 실험으로 확인되지 않았다.

---

## 1. 왜 새로운 구조가 필요한가

### 1.1 지금까지의 결과

어선의 항적만 보고 업종 4종(연안복합·자망·통발·채낚기연승낚시)을 맞히는 모델을 여러 방식으로 만들어 왔다. 표 형태 모델(TabM·TabICLv2), 시계열 모델(ATENet·GRU), 최신 알고리즘 다섯 종(ModernTCN·TSLANet·MantisV2·xRFM·Mitra-v2)을 모두 시험했다.

결과는 **학습에 없던 선박 기준 Macro-F1 약 0.54에서 정체**됐다. 가장 좋은 모델은 TabICLv2(0.537)였고, 알고리즘을 바꿔도 이 선을 넘지 못했다. 공통적으로 자망·통발 어선을 연안복합으로 잘못 분류하는 문제가 반복됐다.

### 1.2 데이터에서 발견한 특징

| 관찰 | 내용 |
|---|---|
| 선박이 대부분 겹친다 | 테스트(2025년) 선박 7,768척 중 88%(6,842척)가 학습(2026년) 선박과 같은 ID |
| 신규 선박은 관측이 적다 | 나머지 12%(926척)는 관측일 중앙값 7일, 35%가 10행 미만 |
| 위치가 중요하다 | 위치 특징을 넣으면 성능이 오르고(0.445→0.480), 지역을 나눠 평가하면 떨어진다 |
| 어선은 같은 곳을 반복한다 | 항적을 직접 살펴보면 대부분의 배가 늘 다니던 동선을 오간다 (정량 확인 필요) |

### 1.3 핵심 아이디어

지금까지는 모든 선박을 "처음 보는 배"로 가정하고 하나의 모델로 분류했다. 하지만 실제 테스트 선박의 대부분은 이미 학습 데이터에 있는 배이고, 어선은 쉽게 바뀌지 않으며 같은 어장을 반복해서 다닌다.

그래서 선박을 **두 갈래(투트랙)**로 나눈다.

- **트랙 1 — 기존 선단 모니터링:** 이미 알고 있는 배와 동선이 닮았다면, 그 배(또는 같은 어장을 쓰는 배들)의 업종을 참고한다.
- **트랙 2 — 신규 선박 분류:** 닮은 배를 찾지 못하면 기존의 일반 분류 모델로 업종을 판단한다.

이 구조는 실제 수산 행정의 필요와도 맞는다. 해마다 반복 조업하는 등록 어선은 꾸준히 모니터링하고, 새로 들어온 배는 따로 판별하는 것이 현실적인 운영 방식이기 때문이다.

## 2. 시스템 전체 구성

```
              [ 테스트 선박의 항적 ]
                       │
                       ▼
        ① 선박 지문 만들기 (이 배는 어디서, 언제, 어떻게 움직이는가)
                       │
                       ▼
        ② 닮은 배 찾기 ── 학습 선박 지문 DB에서 가장 비슷한 배 K척 검색
                       │
          ┌────────────┴────────────┐
          ▼                         ▼
  ③ 트랙 1: 이웃 업종 투표      ④ 트랙 2: 일반 분류 모델
  "닮은 배들은 어떤 업종인가"    "항적 특징으로 보면 어떤 업종인가"
          │                         │
          └────────────┬────────────┘
                       ▼
        ⑤ 신뢰도에 따라 두 결과를 섞기
           (닮은 배를 확실히 찾았으면 트랙 1 비중↑,
            애매하거나 관측이 적으면 트랙 2 비중↑)
                       │
                       ▼
        ⑥ 결과: 업종 · 확신도 · 어느 트랙을 주로 썼는지 · 참고한 배
```

**두 트랙을 칼같이 나누지 않고 섞는 이유:** "닮았다/안 닮았다"를 한 기준선으로 자르면 기준선 근처의 배는 작은 차이로 결과가 뒤집힌다. 닮은 정도에 비례해 두 결과를 섞으면 이런 급변이 사라진다. 이 방식은 이전 실험(5단계 E)에서 관측일수에 따라 두 모델을 섞었던 구조를 그대로 확장한 것이라, 기존 코드를 재사용할 수 있다.

## 3. 구성 요소별 설명

### 3.1 선박 지문: "이 배는 어떤 배인가"

기존 분류 모델의 특징은 "어떤 **종류**의 배인가"를 설명한다. 지문은 "**어느** 배인가"를 설명한다. 같은 항구에서 같은 어장을 다니는 배들끼리 지문이 비슷해진다.

| 지문 요소 | 의미 | 만드는 방법 |
|---|---|---|
| 활동 해역 | 주로 머무는 곳 | 바다를 약 1km(0.01°)와 약 5km(0.05°) 칸으로 나눠, 각 칸에 머문 비중을 계산 |
| 모항 | 출발·귀항 지점 | 멈춰 있는 시간이 가장 많은 칸 |
| 활동 반경 | 얼마나 멀리 나가는가 | 모항으로부터의 거리 분포 |
| 활동 시간대 | 언제 조업하는가 | 하루 24시간 중 활동 비중 |
| 행동 패턴 | 어떻게 움직이는가 | 기존에 만든 행동 유형 34가지의 비중 |

- **두 가지 칸 크기를 함께 쓰는 이유:** 해마다 어장이 1~2km만 옮겨가도 1km 칸만으로는 전혀 다른 배처럼 보인다. 5km 칸을 함께 보면 이런 작은 이동을 흡수할 수 있다.
- **제외한 요소:** 신호가 잡히는 간격이나 품질 표시는 배의 고유한 습관이 아니다. 기지국과의 거리, 해역 혼잡도, 그해의 수신 환경에 따라 달라진다. 실제로 우리 데이터에서도 품질 정보만으로 연도를 어느 정도 구별할 수 있었다. 따라서 이 정보는 닮음 판단에 쓰지 않고, 지문이 얼마나 믿을 만한지(관측이 충분한지) 표시하는 데만 쓴다.

### 3.2 닮은 배 찾기

테스트 선박의 지문을 학습 선박 7,372척의 지문과 비교해 가장 비슷한 배 K척을 찾는다.

1. **후보 좁히기:** 모항이 가깝고 활동 해역이 겹치는 배만 후보로 남긴다.
2. **닮음 점수 계산:** 활동 해역 분포의 차이와 나머지 요소의 차이를 합쳐 점수를 낸다. 요소별 비중은 검증용 데이터에서 정한다.

**목표는 "같은 배 찾기"가 아니라 "같은 업종의 이웃 찾기"다.** 같은 항구·같은 어장의 배들은 동선이 비슷해서 정확히 그 배를 못 찾을 수도 있다. 하지만 찾은 이웃들이 같은 업종이라면 결과는 맞다. 실제로 연안 어업 연구에서도 어장 반복성은 개별 선박보다 같은 항구 선단 단위로 나타난다고 보고된다.

### 3.3 트랙 1: 이웃 업종 투표

찾은 K척의 업종으로 투표하되, 더 닮은 배에 더 큰 표를 준다. 결과는 "연안복합 60%, 자망 30%…"처럼 업종별 확률로 나온다.

주의할 점이 있다. 연안복합은 거의 모든 해역에 섞여 있다. 그래서 단순 투표를 하면 자망·통발 배 주변의 연안복합 이웃 때문에 결과가 연안복합 쪽으로 쏠릴 수 있다. 이를 막기 위해 업종별 비율을 보정한 투표와 보정하지 않은 투표를 둘 다 시험한다. 그리고 반대 방향 오류(연안복합을 다른 업종으로 잘못 보내는 경우)가 늘지 않는지도 함께 확인한다.

### 3.4 트랙 2: 일반 분류 모델

지금까지 가장 좋았던 TabICLv2 모델(Macro-F1 0.537)을 그대로 쓴다. 관측이 7일 이하로 짧은 배에는 짧은 이력에서 더 나았던 E 구성을 쓴다. 이번 설계에서 트랙 2 모델 자체는 바꾸지 않는다.

### 3.5 두 결과 섞기

```
최종 확률 = α × (트랙 1 확률) + (1 − α) × (트랙 2 확률)
```

α(트랙 1의 비중)는 세 가지에 따라 정해진다.

- **닮음 점수:** 닮은 배를 확실히 찾을수록 α가 커진다.
- **1등과 2등의 차이:** 후보들이 비슷비슷하면 α가 작아진다.
- **관측량:** 관측이 적어 지문이 불안정하면 α가 작아진다.

또 하나의 안전장치를 둔다. 트랙 1이 자망·통발이라고 하는데 트랙 2가 연안복합이라고 하면, 트랙 2 쪽으로 쉽게 넘어가지 않게 한다. 트랙 2 모델은 원래 자망·통발을 연안복합으로 잘못 보는 경향이 있어서, 그대로 두면 트랙 1이 찾아낸 정답을 덮어쓸 수 있기 때문이다. 이 규칙은 업종별로 α를 다르게 두는 방식으로 검증한다.

### 3.6 결과물

선박마다 다음을 함께 제출·기록한다.

- 예측 업종과 확신도
- 주로 사용한 트랙 (트랙 1 비중 α)
- 참고한 이웃 선박과 닮음 점수 (근거 설명용)

## 4. 데이터 준비 절차

원본 CSV에서 지문 DB까지의 과정이다. 앞 단계(S0~S1)는 이미 만든 결과를 재사용한다.

| 단계 | 하는 일 | 결과물 |
|---|---|---|
| S0 원본 확인 | 원본 CSV 12개가 바뀌지 않았는지 확인 | 확인 기록 (기존 결과 재사용) |
| S1 시간별 정리 | 배·날짜·시간별로 항적을 정렬하고 기본 형태 특징 계산 | 기존 캐시 재사용 |
| S2 위치 점 정리 | 항적을 이루는 좌표 점을 표로 풀어서 저장 | 위치 점 표 |
| S3 시간별 요약 | 시간마다 대표 위치, 정지 여부, 이전 기록과의 간격 정리 | 시간별 요약 표 |
| S4 칸 나누기 | 대표 위치를 1km·5km 칸 번호로 변환 | 칸 번호 |
| S5 기간 나누기 | 검증을 위해 기간별로 데이터를 분리 (5장 참고) | 기간 블록 |
| S6 지문 만들기 | 배·기간마다 지문 계산 | 지문 DB |
| S7 점검 | 행 수 보존, 기간 경계 침범 여부, 계산 오류 확인 | 점검 기록 |

**지켜야 할 원칙**

- **기간 경계를 넘지 않는다.** 한 기간의 지문에 다른 기간의 기록이 하나라도 섞이면 검증 결과를 믿을 수 없다.
- **없는 데이터를 만들지 않는다.** 신호가 끊긴 구간을 선으로 잇거나, 기록이 없는 시간을 "정지"로 채우지 않는다.
- **선박 ID는 정답 확인용으로만 쓴다.** "ID가 같으면 같은 배"라는 정보를 모델에 넣지 않고, 검증할 때 결과를 채점하는 데만 쓴다.

**사람이 보는 자료: 선박 카드.** 배마다 활동 해역 지도, 모항, 관측량, 업종을 이미지 한 장으로 만든다. 같은 ID의 2026년 카드와 2025년 카드를 나란히 놓으면 "같은 동선을 반복한다"는 전제를 눈으로 먼저 확인할 수 있다. 보고서와 발표의 시각 자료로도 쓸 수 있다.

## 5. 검증 계획

시스템을 한 번에 만들지 않고, **전제부터 하나씩 확인하며 단계적으로 진행**한다. 앞 단계에서 전제가 무너지면 다음 단계로 가지 않는다.

### 5.1 1단계 — 전제 확인: 정말 닮은 배를 찾을 수 있는가

라벨 없이 바로 할 수 있는 검사들이며, 가장 먼저 실행한다.

| 검사 | 방법 | 알 수 있는 것 |
|---|---|---|
| 자기 자신 찾기 | 2025년 공통 ID 선박의 지문으로 2026년 7,372척을 검색해, 같은 ID가 상위에 오는 비율을 본다 | 해가 바뀌어도 같은 배가 같은 동선을 다니는가 |
| 서로 1등인 비율 | 양방향으로 검색해 서로를 1등으로 찾는 비율 | 매칭이 우연인지, 확실한지 |
| 이웃의 업종 일치율 | 2025년 선박의 상위 K 이웃(2026년 배)의 업종이 그 배의 2026년 업종과 같은 비율 | **트랙 1이 실제로 쓸모 있는가 (핵심 지표)** |
| 신규 선박 오인율 | 신규 ID 926척을 검색했을 때 "확실히 닮은 배가 있다"고 잘못 판단하는 비율 | 처음 보는 배를 기존 배로 착각하는가 |
| 모항 이동 분포 | 공통 ID의 2025·2026년 모항 사이 거리 분포 | ID만 같은 다른 배, 또는 해역을 옮긴 배가 섞여 있는가 |

**계속 진행할 조건:** 이웃의 업종 일치율이 기존 분류 모델의 정확도보다 확연히 높아야 한다. 자기 자신을 1등으로 못 찾더라도, 이웃 업종 일치율이 높으면 트랙 1은 유효하다.

### 5.2 2단계 — 성능 확인: 업종 예측에 실제로 도움이 되는가

2026년 데이터 안에서 기간을 나눠, 앞 기간으로 지문을 만들고 뒤 기간의 업종을 맞혀 본다. 같은 배의 붙어 있는 시간이 학습과 평가에 나뉘어 들어가면 점수가 부풀려지므로, 반드시 기간 단위로 나눈다.

기간을 나누는 방식은 두 가지를 함께 쓴다.

- **전반·후반 분할 (1-3월 → 4-6월):** 단순하지만 겨울과 봄의 어종·어장 차이가 섞인다.
- **격주 교차 분할:** 홀수 주와 짝수 주로 나누고, 경계에 며칠의 빈 기간을 둬 한 번의 항해가 양쪽에 걸치지 않게 한다. 계절 차이가 없는 비교가 된다.

두 결과를 비교하면 계절이 미치는 영향도 알 수 있다. 3개월 지문은 실제 6개월 지문보다 관측이 적으므로, 기준값을 정할 때 관측량 차이를 보정한다.

### 5.3 3단계 — 안전성 확인: 처음 보는 배가 섞여도 괜찮은가

2단계 평가에 학습에 전혀 없던 선박을 실제 신규 선박처럼 짧은 관측으로 맞춰 약 12% 섞는다. 이 배들이 트랙 1로 잘못 처리되는 비율과 그로 인한 손해를 잰다. 1단계의 "신규 선박 오인율"과 함께 보면 실제 테스트 상황을 가장 가깝게 재현할 수 있다.

### 5.4 4단계 — 최종 비교: 전체 시스템이 기존보다 나은가

투트랙 전체를 기존 최고 모델(TabICLv2, 0.537)과 비교한다. 지금까지와 같은 채택 기준을 적용한다.

- 전체 Macro-F1이 0.005 이상 오를 것
- 무작위 재추출로 구한 개선 폭의 95% 범위가 0보다 클 것
- 두 번의 반복 실행 모두에서 개선될 것
- 어느 업종도, 관측이 짧은 선박 집단도 0.01 넘게 나빠지지 않을 것

업종별 성적과 "어느 업종이 어느 업종으로 잘못 갔는지"(특히 자망·통발→연안복합)도 함께 보고한다. 진단용으로는 "트랙 1을 쓰는 비율 대 정확도" 곡선을 그린다. 트랙 1이 어느 범위에서 믿을 만한지 보여 주는 자료다.

### 5.5 진행 순서 한눈에 보기

```
대회 규정 확인
   → 데이터 준비 (S0~S7) + 선박 카드
```

## 7. 대회 규정과 발표 시 유의점

**규정 확인이 먼저다.** 공식 채점에 기존 선박이 포함되는지, 학습 데이터의 업종 정보를 테스트 선박에 활용해도 되는지 주최 측 공지나 문의로 확인한 뒤 진행한다.

**시스템의 성격을 정확히 설명한다.** 이 시스템은 "ID로 정답을 찾아 복사"하는 방식이 아니다.

- ID 정보는 모델에 넣지 않는다. 오직 항적의 닮음만으로 판단한다.
- 트랙 1은 "이 배가 몇 번 배인가"가 아니라 **"이 어장·이 동선을 쓰는 배들은 주로 어떤 업종인가"**를 참고한다. 연안 어업에서 어장은 곧 어구와 연결되므로(자망은 암반, 통발은 특정 수심 등), 이는 과거 조업 사례를 참고하는 정당한 추론이다.
- 학습은 2026년, 테스트는 2025년이라는 시간 역전 때문에 "미래 정답을 과거에 덮어썼다"는 오해를 받을 수 있다. 발표에서 이 점을 먼저 설명한다.

**발표용 명칭 제안:** "기존 선단 모니터링과 신규 선박 분류의 투트랙 시스템". "과적합 활용"이라는 표현은 검증 실패로 오해받을 수 있어 쓰지 않는다.

## 8. 기대 효과

- **성능:** 테스트 선박의 88%를 차지하는 기존 선박에서, 같은 어장 이웃의 정보를 활용해 자망·통발→연안복합 오분류를 줄일 수 있다. (1~4단계에서 확인 필요)
- **실무 적합성:** 등록 어선의 상시 모니터링과 신규 어선의 판별이라는 실제 수산 행정 구조와 맞닿아 있다.
- **설명 가능성:** 예측마다 "어떤 배들을 참고했는지"를 함께 제시해, 결과의 근거를 사람이 확인할 수 있다.
- **확장성:** 과제 2(이상 항적 탐지)에서도 "이 배의 평소 동선"이라는 기준으로 지문을 재사용할 수 있다. 단, 이상탐지에서는 점수를 매기는 시점 이전의 기록만으로 지문을 만들어야 한다.
