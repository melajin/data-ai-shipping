# 2026 데이터 분석대회 데이터 분석 정리

사용자 제공 ZIP의 파일 구조·샘플 CSV·첨부 공지와 **10월 19일 추가 제안서**를 통합한 Obsidian 진입 노트다. **ZIP에는 샘플 CSV 10행과 설명·제안 자료가 있으며, 정식 Train·Test A·Test B와 사고정보는 없다.** 샘플 구조와 계산 결과를 직접 확인했고, 전체 자료의 적합성과 모델 성능은 미확인이다.

## 추가 제안서 반영

10쪽 분량의 [IT종합설계 프로젝트 제안서](data/reference/competition_20261019/additional/IT%EC%A2%85%ED%95%A9%EC%84%A4%EA%B3%84%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8_%EC%A0%9C%EC%95%88%EC%84%9C_C215192%20%EC%B5%9C%EC%8A%B9%EB%B9%88.pdf)를 기존 노트에 반영했다. 별도 요약본을 늘리는 대신 [02의 평가·추진 계획](docs/competition_20261019/02_분석해석과_다음단계.md)과 [03의 설계 방향·문서 대조](docs/competition_20261019/03_첨부자료와_분석방향.md)를 보완했다.

현재 **문서상 설계 방향은 MLP 기반 조업 분류와 별도의 이상항적 분석**이다. 형상·관측 상태를 구분해 TabM·RealMLP·작은 LightGBM의 단독·혼합을 비교하고, 이상점수는 학습자료로 정한 기준에서 출발한다. Transformer·TabPack·확률 보정은 조건부 확장이다. 이는 후속 실험 계획이며 최종 모델 선택이나 구현·평가 완료가 아니다.

추가 PDF는 데이터 파일이 아니므로 아래 샘플 집계와 F1 상태는 달라지지 않는다. 원본 ZIP 35파일에 별도 PDF 1개를 더해 출처로 관리한다.

## 직접 확인한 핵심

| 항목 | 결과 |
| --- | --- |
| 샘플 크기 | 10행·10척. 날짜는 전부 2025-01-01, 시간대는 전부 0 |
| 컬럼 | `part_dt`, `rfid_id`, `rfid_time`, `geom`, `fishing_code` + 전부 비어 있는 무명 7열 |
| 조업 라벨 | 자망 4, 연안복합 4, 통발 1, 채낚기연승낚시 1 |
| 경로 | 2D MULTILINESTRING 10개, 부분선 16개, 좌표점 246개 |
| 반복 좌표 | 부분선 내부 인접쌍 230개 중 같은 XY 쌍 158개(68.70%) |
| 원본 검사기 | 빈 헤더 때문에 의미 검증을 생략. 별도 전체 CSV 점검으로 5개 명명열과 WKT를 확인 |

반복 좌표는 바로 정박이나 수집 오류로 확정하지 않는다. 부분선 사이를 이어 거리를 만들지 않는다. 점별 시각이 없으므로 실제 속력·가속도·체류시간은 계산할 수 없다. 사고정보가 없다는 이유로 정상 라벨을 만들지도 않는다.

## 프로젝트에서의 현재 위치

2026-10-09의 원자료 미확보 기록과 달리, 이번에는 **첨부 샘플 CSV를 직접 확보·점검했다.** 보관 위치는 `data/reference/competition_20261019/`이며 `data/raw`에 정식 데이터를 확보한 것은 아니다. F1의 샘플 구조 증거를 보완했으나 CRS·점별 시각·전체 라벨·정식 데이터·평가 규격이 미확정이라 F1 전체 통과로 처리하지 않는다.

[기존 통합 학습 가이드](어선%20항적%20통합%20학습%20가이드.md)는 2026-10-13 시점의 해설과 S0를 연결한다. [실행 계획](docs/fishing_execution_plan.md)에서 현재 단계와 후속 관문을 확인한다. 실제 조업 라벨과 S0의 생성 경로 이름은 서로 대응시키지 않는다.

이번 정리는 본인 학습용이다. 설명을 읽었다는 사실과 스스로 구조·계산·한계를 설명할 수 있다는 학습 달성은 따로 확인한다.
