## 공통 평가 규칙 (모든 스크립트 동일)

- 평가 대상: 팀원 F156 분할의 개발 5,897척, 3-fold **OUTER**(학습에 없던 배) Macro-F1.
- 하이퍼파라미터·혼합비 α·통발 배수 w·kNN k·특징 선별은 **전부 INNER(또는 FIT)에서만** 고르고
  OUTER에는 한 번만 적용한다. 지시 011의 선택 편향 사고 재발 방지.
- 시드 3개(42, 2026, 7) 확률 평균.
- 채택 기준: Δ ≥ +0.005 **이고** 같은 선박 5,000회 재추출한 대응 95% 구간 하한 > 0
  **이고** 업종별 F1·관측 1~7일 집단 하락이 0.01 이내.
- 기준선 `base` = F156 + T5, LightGBM 3시드 평균 = **0.53185**.
  이 값은 `results/work_014/dev.json`의 `ours_seed_avg_3`(0.5318490119247774)와
  소수점 다섯째 자리까지 일치한다 — 하네스 재현이 맞다는 독립 확인.
