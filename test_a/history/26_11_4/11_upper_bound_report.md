## 3. 실험별 핵심 수치

* **S1 (Bayes 오차 추정)**: 원본 166차원 공간 1-NN 오차율 $e_{1NN} = 0.53587$ (95% 구간 [0.5235, 0.5489]). Cover-Hart 부등식 수치해에 따른 Bayes 오차 하한 $e^* = 0.34920$. 이상적 혼동 구조 가정 환산 macro-F1 상한은 0.71395 (PCA 95% 분산 73차원 축소 공간에서도 0.71712로 유사). 3-최근접 이웃 전원이 다른 업종인 구조적 불가 선박은 21.79% (1,285척).
* **S2 (판정 규칙 오라클)**: 통발뿐 아니라 4개 업종 임계값 배수를 OUTER에서 직접 좌표하강으로 맞췄을 때 도달 가능한 최대치는 macro-F1 0.54059 (Δ+0.00874). 반면 INNER에서 4차원 배수를 고른 실현값은 macro-F1 0.52957 (Δ-0.00228)로 선택 과적합이 발생해 기준 미달 기각.
* **S3 (확률 보정 오라클)**: IsotonicRegression으로 확률의 단조성을 완벽 보정했을 때 정확도는 0.59183까지 상승하나, 다수 클래스(연안복합) 빈도에 편향되어 macro-F1은 0.51123(w=1.5 적용 시 0.52686)으로 하락.
* **S4 (모델 선택 오라클)**: 6개 상이 모델군(LightGBM, MLP, ExtraTrees, B69, kNN, TabICLv2) 평가 결과, 6개 모델 전원이 오답을 낸 선박이 22.15% (1,306척). 전원 오답 선박을 제외하고 1개라도 맞힌 모델을 선택하는 오라클 macro-F1은 0.74059 (정확도 0.77853). 6개 모델 확률 가중합의 OUTER 최적 상한은 macro-F1 0.55538. INNER 최적화 6개 모델 가중합 실현값은 macro-F1 0.54524로 채택 통과.
* **S5 (모델 용량 진단)**: LightGBM이 FIT 학습 데이터 자체를 예측했을 때 macro-F1 0.87017, 정확도 0.87141 달성. OUTER 평가(0.53185 / 0.56300)와의 일반화 갭은 macro 기준 +0.33832, 정확도 기준 +0.30841. 모델 파라미터 용량 부족이 아니라 미관측 선박에 대한 특징 중복이 병목임을 증명.
* **S6 (대용량 모델 실현)**: 305열(F156 + T5 + B69 + local_rel)을 `num_leaves=127, lr=0.01`의 대형 LightGBM 5시드로 평가한 결과, macro-F1 **0.54843** (기준 대비 Δ+0.01658, 95% 신뢰구간 [+0.00274, +0.03040]), 정확도 모드(w=1.0) 0.59183. 채택 기준(Δ≥+0.005 and 95% 하한 > 0) 정식 통과.
* **S7 (기간 분할 데이터 안정성)**: 동일 선박의 1~3월(전반기)과 4~6월(후반기) B69 벡터를 독립 예측했을 때 일치율은 65.37%. 전·후반기 모두 정답을 맞힌 비율은 36.01%, 둘 다 틀린 비율은 36.97%.
* **S8 (민감도 분해)**: 연안복합-자망 간 상호 오분류 선박 1,346척을 완벽 분리할 경우 macro-F1이 0.54307에서 0.69452(+0.15145)로 대폭 상승. 소수 업종 채낚기(126척) F1 ±0.05 변동 시 macro-F1은 ±0.0125 변동.

## 4. "지금 어디까지 왔나" (수치 및 갭 분석)

현재 달성된 모델 실현 최고값(S6 macro **0.54843**)과 가장 빡빡한 오라클 상한(S4 가중합 macro **0.55538**) 사이의 간격은 **macro-F1 기준 불과 0.00695**이다.

이 간격을 분해하면 다음과 같다:
1. **판정 규칙(임계값 배수) 최적화의 몫**: S2 오라클이 보여주듯 기존 모델 확률 위에서 배수만 사후 조정해 얻을 수 있는 추가 여지는 macro 기준 최대 +0.00874p이다.
2. **확률의 질 및 모델 다양성 결합의 몫**: S4 가중합 오라클이 보여주듯 이종 모델 계열을 최적으로 혼합해 얻는 추가 여지는 약 +0.0070p 내외이다.
3. **정보 자체의 부재에 의한 구조적 천장**: 6개 상이 모델이 전원 오답을 낸 22.15%(1,306척)의 선박과, S1에서 확인된 3-NN 전원 불일치 선박 21.79%(1,285척), 그리고 동일 선박조차 계절 분할 시 35%가 다른 업종으로 판별되는 현상(S7 둘 다 적중 36.01%)은 오라클 상한과 1.0 사이의 남은 오차가 모델 복잡도 부족이 아닌 순수 항적 데이터 내의 업종 간 행동 패턴 중복과 시간적 변동성에서 기인함을 수치로 증명한다.

지시 011의 사전 설정 기준표(10항)에 따르면, 가장 빡빡한 상한이 0.55538로 **`≤ 0.56` 구간**에 해당한다. 모델 트랙 자체의 순수 특징 추가 여지는 사실상 한계선에 근접했다.
