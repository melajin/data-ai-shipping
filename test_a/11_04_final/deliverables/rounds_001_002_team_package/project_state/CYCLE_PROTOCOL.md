## 평가 계약

1. 단일정답 4클래스의 선박 단위 micro-F1은 정확도와 같다. 클래스 순서는 `[연안복합, 자망, 통발, 채낚기연승낚시]`. 지표 계산은 동일 선박·분모·라벨 순서로 검산한다.
2. 기존 개발 5,897척과 3-fold FIT/INNER/OUTER 역할을 재사용하는 비교는 모두 개발 평가다. 재분할이나 새 seed가 이 노출 이력을 지우지 않는다.
3. FIT에서만 지도학습·라벨 기반 T5 참조를 적합한다. 같은 fold INNER로 선택하고 여러 fold INNER를 모아 전역 선택하지 않는다. 해당 OUTER는 그 fold의 학습·조기 종료·결합 선택에 쓰지 않는다.
4. 새 모델/결합 회차에서는 조기 종료용 자료와 결합 선택용 자료를 분리하거나 FIT 내부 교차적합을 사용한다. 기존 INNER를 조기 종료와 결합 선택에 재사용한 한계는 보존한다. 절차가 달라지면 기준선도 같은 절차로 재실행하여 비교한다.
5. T5의 기존 항구 통계는 Train2026+라벨 없는 Test2025 geometry, local_rel은 Train cohort 통계에 자기 자신 포함이라는 transductive 조건이다. 이를 FIT-only 전처리로 쓰지 않는다. 재현 회차는 이 조건을 고정하고, FIT-only 실험은 별도 변경 변수로 다룬다.
6. holdout 개별 특징·라벨·예측은 노출 이력과 평가 계획이 동결되기 전 읽지 않는다. 명부·파일 메타데이터와 과거 사용 기록으로 독립성을 먼저 판단한다. 이미 본 holdout을 새 맹검으로 재명명하지 않는다.
7. 좌표별 시각 없는 자료에서 실제 속력·가속도·정지시간을 계산했다고 하지 않는다. 부분선을 연결하지 않으며 선박 업종 라벨을 매 구간 행동 정답으로 바꾸지 않는다.
8. 새 후보의 비교에는 micro/macro, 클래스 recall/F1, 1–7/8–30/31–90/91+ 관측일 구간, paired 추가정답·새오답·순증, 같은 선박의 bootstrap 구간을 남긴다. 여러 후보 중 선택된 개발 최고값의 구간을 독립 최종 증거로 사용하지 않는다.
9. 성능 채택 회차는 최소 유의미 개선폭·허용 subgroup 하락폭·seed·모델 용량·선택 규칙·동점 규칙을 실행 전 `ROUND_PLAN.md`에 고정한다. 진단 회차는 성능 상승이 아니라 원인 판별/재현 증거 확보가 완료조건이다.
