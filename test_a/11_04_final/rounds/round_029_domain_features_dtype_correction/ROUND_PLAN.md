# Round029 — 자료형 교정 후 동일조건 관문

작성 시각: 2026-11-05 17:10 KST. 모델 실행 전 고정.

## 원인과 범위

Round028은 FIT 내부 4-fold에서 기준선 1816/3144, 신규 특징 1810/3144로
순증 −6이었다. 그러나 Round025에 저장된 동일조건 기준선 1811/3144와
예측 257건이 달라 재현 관문이 실패했다. 원본 304특징 행렬은 `float64`인데
Round028 실행 코드가 모델 입력을 `float32`로 변환했고, T5와 신규 특징도
`float32`로 변환했다. 이는 구현 오류이며 Round028 성능을 정식 관문으로
사용하지 않는다. 본 회차는 그 오류만 교정한다.

원시 Train2026 WKT에서 만든 두 특징 CSV와 해당 코드·수식·결측 처리·
사전 판정 기준은 Round028 그대로 읽기 전용으로 사용한다. 원시 6개월
파일을 다시 스캔하지 않는다. 라벨·OUTER·Test로 특징이나 임계값을
재선택하지 않는다. 추가 후보는 없다.

## 실행 계약

- 원본 fold0 FIT 3144×304 행렬의 `float64`를 보존한다. Round025 각
  fold에서 저장한 T5 배열도 원래 자료형으로 156:166열에 대입한다.
- 신규 두 특징을 ID 순서로 붙인 `float64` 3144×306 후보를 만든다.
- Round025 저장 train/validation 인덱스, 라벨, LightGBM 매개변수,
  seed 42, 단일 스레드, 300 trees를 그대로 사용한다. 각 fold의 기준선
  예측은 원본 `predict_proba`→`float32`→`argmax`와 동일하게 계산해
  Round025 저장 예측과 완전 일치해야 한다. 불일치 시 후보 학습 전에 중단한다.
- 기준선·후보 합계 최대 8 fits, fold별 순차 실행. OUTER 평가 0회.
- 기존 고정 관문은 후보 정답 ≥1833 **그리고** 동일조건 기준선 대비
  순증 ≥16이며, 자망 또는 통발 TP·F1 개선과 연안복합·채낚기 TP 비감소도
  요구한다. 실패하면 확장하지 않는다. 개발 반복 노출로 독립 검증 주장은 금지한다.
- 8 fit 완료 후 저장 예측에서 micro/macro, 클래스별 TP/F1, paired gain/loss,
  결측·오류와 fold 차이를 확인한다. 기존 Round025 기준선 재현 실패 시
  후보 우열 판정을 보류한다.

## 자원

확인한다. 예상 최대 0.5 GiB(3144×306 `float64` 행렬과 순차 LightGBM

정리를 진행한 후 시작 직전 다시 확인한다. 사용자 프로세스는 건드리지 않는다.
