# Round006 학습 관찰과 질문

기술 목표는 선택 속성 진단을 수정하고 원래 문맥의 두 확률을 제한된 조건에서 재현하는 것이다. 학습 목표는 오류 계층과 증거의 종류를 구별하는 것이다. 개인 학습자용이며 장치 실험은 아니다.

1. cache_mode_ 속성이 아예 없는 경우와 값이 None인 경우가 왜 다른가? kv_cache=False에서 어떤 상태가 정상인지 패키지 소스 근거로 설명한다.
2. fit이 반환했다는 사실을 진단 기록보다 먼저 저장하는 이유는 무엇인가? 진단 함수의 실패가 앞 단계 완료 증거를 지우지 않게 하는 방법을 설명한다.
3. fake-object 검사 통과가 실제 모델 forward 성공을 뜻하지 않는 이유는 무엇인가? 실제 확률 재현도 분류 F1 개선을 뜻하지 않는 이유를 설명한다.
4. CPU 두 질의와 과거 CUDA 전체 INNER의 확률이 다르면 입력·전처리·shuffle·backend·연산순서 중 무엇을 근거로 좁힐 수 있는가? 미측정 원인을 확정하지 않는다.
5. RAM 사용량의 sampled working set, OS peak, 사용가능 물리메모리, timeout은 각각 무엇을 측정하는가? 이번 작은 질의 실험값을 전체추론/학습 비용으로 외삽할 수 있는가?
6. 사용자 계절 가설: 월별 관측량, 관측된 활동 패턴, 실제 조업 여부를 어떻게 구별할 것인가? 같은 선박의 월별 행을 무작위로 나누면 어떤 평가 문제가 생기는가?

조건·예상·계산값·해석과 코드/실제자료 검증 결과는 ROUND_PLAN 및 ROUND_REPORT와 원시 로그에 남긴다. 이 질문에 대한 학습자의 설명을 아직 확인하지 않았으므로 이해 달성을 완료 처리하지 않는다.
