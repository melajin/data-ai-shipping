## 1. 좋아진 점 — 파라미터 튜닝이 실제로 INNER에서 이루어졌다

Round 026의 핵심 결함(혼합비·승수를 OUTER로 고름)이 이번 회차에서는 코드 수준에서 교정되어 있다.

```python
# worker_c_synthesis/run_worker_c_synthesis.py  (C1 격자탐색)
pred_in = apply_specialist_fallback_rule(p_fused_in, gamma, tau, gamma21=0.0)
tp0 = ((y_in == 0) & (pred_in == 0)).sum()
if tp0 < MIN_TP0_IN: continue          # INNER 보호게이트
correct_in = (y_in == pred_in).sum()
if correct_in > best_c1_in["score"]:   # INNER 점수로만 갱신
    pred_out = apply_specialist_fallback_rule(p_fused_out, ...)   # OUTER는 그 뒤 1회
```

Worker A도 `m_in["correct"]` / `m_in["rule_*_pass"]`로만 운영점을 고르고, Worker B는 `optimize_rule_b1_nested()`로 fold별 중첩 탐색을 한다. **이 구조는 그대로 유지할 가치가 있다.**

## 2. 결함 1 — 챔피언 C4의 파라미터는 학습된 적이 없다

C4 격자(`g21 × g12 × conf` = 8×6×4 = 192점)는 **INNER 보호게이트를 통과한 조합을 하나도 찾지 못했다.** 따라서 다음 폴백 분기가 발동했다.

```python
if best_c4_in["pred_out"] is None:          # 격자 전멸
    best_c4_in["params"] = {"g21": 1.2, "g12": 1.8, "conf": 0.40}   # 하드코딩 상수
```

`worker_c_results.json`에 기록된 C4 파라미터가 정확히 이 상수값 `{g21: 1.2, g12: 1.8, conf: 0.4}`다. 그리고 C4의 INNER TP3 = 36 < 38 — **4개 전략 중 유일하게 보호게이트 실패**이며, 이는 폴백 분기가 발동했음을 교차 확인해 준다.

즉 보고서 §5의 *"gamma21과 gamma12 허들을 INNER 3-fold OOF에서 튜닝"* 은 C4에 대해서는 **사실이 아니다.** Round 026의 `a3` 격자 상한 사건과 같은 유형의 반복이다.

## 7. 가장 중요한 발견 — micro는 고를 수 없고, 통발F1·macro는 고를 수 있다

후보 30개에 대해 INNER 지표와 OUTER 지표의 상관을 측정했다.

```
INNER 통발F1  →  OUTER 통발F1   Pearson r = +0.915
INNER macro   →  OUTER macro    Pearson r = +0.717
INNER micro   →  OUTER micro    Pearson r = +0.493
  (참고: Round 026 후보 22개에서는 INNER micro → OUTER micro  r = -0.229)
```

이것이 26회차에 걸친 정체의 구조적 원인이다.

- **micro-F1은 INNER에서 OUTER를 예측하지 못한다.** 그래서 micro를 좇는 선택은 매 회차 운에 지배되고, 결국 "OUTER를 슬쩍 보는" 유혹으로 귀결된다(Round 026 사례, 본 회차 C4 사례).
- **통발 F1은 r = +0.915로 거의 완전히 예측된다.** 즉 통발 쪽 개선은 INNER에서 고르면 OUTER에서 그대로 재현되는, **부풀릴 필요가 없는 진짜 개선**이다.

Round 027의 가장 큰 성과는 C4의 +2척이 아니라 **"측정 가능하고 선택 가능한 개선 축을 찾았다"**는 사실이다.

## 8. Round 028 전달 사항

1. **C4를 챔피언으로 등록하지 말 것.** 파라미터가 하드코딩 폴백 상수이고, INNER 게이트 실패이며, R026 대비 p=0.87이다. `ROUND_027_FALLBACK_REPORT.md` §9.2의 "공식 등록" 문구는 철회 대상이다.
2. **폴백 분기를 실패로 승격할 것.** `if best_X["pred_out"] is None:` 에서 조용히 상수로 채우는 패턴이 Round 026(`a3` 격자)과 Round 027(C4 격자) 두 번 연속 같은 사고를 냈다. 격자가 전멸하면 **그 전략을 탈락 처리하고 로그에 남겨야** 한다.
3. **1차 목표 지표를 macro-F1(또는 통발 F1)로 바꿀 것.** 근거는 §7의 상관(+0.717 / +0.915 vs +0.493). micro를 1차 목표로 두는 한 선택 신호가 없어 회차마다 노이즈를 좇게 된다. 대회 지표가 micro라면, **선택은 macro로 하고 보고는 micro로** 하는 이원 운영이 현실적이다.
4. **채택 권고: `b1_Blend_Grand|local`** (통발 171, macro 0.5329, 보호 PASS). 단순 절대임계 fallback이라 재현·설명이 쉽고, INNER로 선택되고 OUTER에서 재현되었다.
5. **통발 정밀도가 다음 병목이다.** 통발 예측 389척 중 171척만 정답(정밀도 0.44)이다. 재현율을 20%까지 끌어올린 다음 단계는 **통발 FP 218척을 가려낼 특징** — 투·양망 주기성, 정지 지점 군집 개수 같은 행동 기하량이다(선박 재식별 경로는 금지).
