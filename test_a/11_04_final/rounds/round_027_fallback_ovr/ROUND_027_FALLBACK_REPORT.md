## 2. 도메인 및 수학적 배경: 왜 Specialist-then-Fallback인가?

### 2.1 도메인적 특수성 (어업 면허 및 어구의 본질)
- **연안복합(Coastal Complex, Class 0)**:
  - 전체 선박의 약 49.5% (OUTER 5,897척 중 2,920척)를 차지하는 지배적 다수 클래스.
  - 연안복합은 단일 고정 어구가 아니라, 계절·어종·수온에 따라 주낙, 채낚기, 문어단지, 소형 통발, 자망 등을 복합적으로 교체 사용하는 '다목적 면허 선박'임.
  - 따라서 궤적 데이터에 자망의 표류(drifting) 패턴이나 통발의 투양망 정선 패턴이 부분적으로 섞여 나타남.
- **전문 어구 (자망 Class 1, 통발 Class 2, 채낚기 Class 3)**:
  - 특정 전문 장비(양망기, 권승기, 집어등)를 갖추고 표준화된 전문 조업 방식을 고수하는 전형적 궤적 특성을 지님.
- **기존 4-클래스 대등 Argmax의 구조적 결함**:
  - 소프트맥스 함수 $\sigma(z)_c = \frac{e^{z_c}}{\sum_{k=0}^3 e^{z_k}}$는 4개 클래스를 대등한 원-핫 공간의 경쟁자로 가정함.
  - 연안복합 선박이 자망이나 통발의 국소적 특징을 조금만 보여도 대등 확률 분모 효과로 인해 $P(0)$이 $0.35$ 미만으로 떨어지고 전문 어구가 $0.38$만 되어도 섣부르게 전문 어구로 판정됨.
  - 그 결과, 실제 연안복합 선박 **530여 척 이상이 억울하게 전문 어구로 오분류**되는 막대한 FP(False Positive) 유출이 발생함.

### 2.2 수학적 정식화 (Mathematical Formulation)

#### 1) 2단계 계층 게이트 모델 (Two-Stage Hierarchical Specialist Formulation)
데이터 생성 과정을 다음과 같이 베이즈 분해(Bayesian Factorization)함:
$$P(Y = c \mid X) = \begin{cases} 1 - P(Y \in \{1,2,3\} \mid X), & \text{if } c = 0 \\ P(Y \in \{1,2,3\} \mid X) \cdot P(Y = c \mid Y \in \{1,2,3\}, X), & \text{if } c \in \{1, 2, 3\} \end{cases}$$

- **1단계 게이트 분류기 ($M_0$)**: 선박이 전문어구 $\{1, 2, 3\}$에 속하는지 여부만을 판별하는 고정밀 이진 모델:
  $$P_{\text{spec}}(X) = P(Y \in \{1,2,3\} \mid X)$$
- **2단계 순수 전문 분류기 ($M_{123}$)**: 연안복합을 100% 배제하고 **오직 전문어구 선박(약 1,588척)**만으로 학습한 3-클래스 분류기:
  $$P_{M123}(c \mid X) = P(Y = c \mid Y \in \{1,2,3\}, X), \quad c \in \{1, 2, 3\}$$
  연안복합의 노이즈 간섭 없이 오직 '자망 vs 통발 vs 채낚기'의 순수 작업 속력 및 회전각 차이만을 학습하여 경계 선명도를 극대화함.

#### 2) Specialist Relative Hurdle & Fallback 결정 규칙
선박 $x$가 전문 어구 $c \in \{1, 2, 3\}$로 인정받기 위해서는 다음의 2중 허들을 통과해야 함:
1. **상대적 우위 허들 (Relative Hurdle over Class 0)**:
   $$P(c \mid x) \ge \gamma_c \cdot P(0 \mid x)$$
2. **절대 확신도 허들 (Absolute Minimum Confidence)**:
   $$P(c \mid x) \ge \tau_{\min, c}$$

통과한 전문 어구 집합 $S(x) = \left\{ c \in \{1, 2, 3\} \mid P(c) \ge \gamma_c P(0) \ \wedge \ P(c) \ge \tau_{\min, c} \right\}$에 대해:
$$\hat{y}(x) = \begin{cases} \arg\max_{c \in S(x)} \frac{P(c \mid x)}{\gamma_c}, & \text{if } S(x) \neq \emptyset \\ 0 \ (\text{Default Fallback to Class 0}), & \text{if } S(x) = \emptyset \end{cases}$$
