# Round 027 결과 독립 검토

## 범위

`results.json`, `selection_frozen.json`, `verification.json`, `ROUND_REPORT.md`만 읽었다. 새 계산, 학습, 모델 실행은 하지 않았다. 검토 대상은 저장 결과의 결론과 한계다.

## 판정

**채택하지 않는 결론은 타당하다. 이번 재검사는 동일조건 기준선보다 성능 개선을 보이지 않았다.**

- SELECT 선택 절차와 동일조건 기준선 모두 3,538/5,897, micro-F1 0.599966이다. 선택 절차 macro-F1은 0.516117로 기준선 0.517485보다 낮다.
- 기준선 대비 정답 gain/loss/net은 24/24/0이다. paired bootstrap 95% 구간은 [-14, 13], McNemar p=1.0이다.
- TP0는 2,538에서 2,547로 늘었지만 TP3는 93에서 92로 줄었다. `selected_vs_same_baseline_tp0_tp3_no_drop`가 false이므로 클래스 보호 조건을 통과하지 못했다.
- 절대 TP 기준 플래그가 true인 사실은 기준선 대비 TP3 감소를 상쇄하지 않는다. 새 5-seed 확인도 아니므로 최종 채택 근거가 없다.
- 개별 고정 후보도 기준선을 넘지 않았다. 단독 신뢰는 3,488정답, 단독 재검사는 3,516, 무표=0은 3,439, 네 그룹 강제 통합은 3,412였다. 0·1 이진 재검사는 3,534, 정확히 0·2 재검사는 3,537이었다. 0·1 base 제한은 기준선과 같았다.

## 외부 관찰과 proxy 범위

팀원 수치는 참고 가설로만 취급한 보고서 서술이 적절하다. 이 실험은 Worker A 저장 점수 각각에 0.5 기준을 적용한 proxy 이름표를 사용했다. 그 결과 singleton은 4,283척, 무표는 1,498척, 0·1 동시 포함은 110척, 정확히 0·2는 3척이었다. 이는 팀원 관찰의 모집단·선택 절차를 재현한 결과가 아니다.

proxy singleton 이름표의 정확도는 2,674/4,283(62.4%)였다. proxy 무표 집단에서 실제 0은 646/1,498(43.1%)였다. 0·1 동시 포함 집단에서 실제 2/3은 10척이었다. 이 값으로 원래 팀원 이름표에 관한 결론을 내릴 수 없다.

## 남은 한계

- `verification.json`은 저장 예측 산술, 11개 예측 열, 34개 입력 해시, 선택 규칙과 분할 분리 검사를 통과했다고 기록한다. 그 자체로 독립 일반화나 모델의 재현성을 입증하지 않는다.
- 보고서가 밝힌 것처럼 일부 원모델은 과거 INNER 전체를 조기 종료에 사용했다. 새 SELECT 교차적합은 그 노출 이력을 되돌리지 않는다.
- OVR 저장 확률에는 당시 ID와 실행 snapshot 해시가 없었다. 현재 메타데이터 정렬과 label 대조로 보강했지만 원래 실행의 완전한 행별 계보는 남아 있지 않다.
- 새 holdout, 공식 제출, 실제 장치 실험은 수행되지 않았다. 관측일 구간 평가도 입력에 해당 필드가 없어 미수행이다.

따라서 이 결과는 반복 노출 개발 진단으로만 기록한다. 기준선 채택을 유지하고, 이 결과나 팀원 관찰만으로 최종 모델 또는 목표 지표를 변경하지 않는다.
