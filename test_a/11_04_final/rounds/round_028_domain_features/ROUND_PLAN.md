# Round028: 자망·통발 행동기하 특징 실험

상태: 입력·특징 적합성 관문. 2026-11-05 사용자 지시: 현재 관리자 모델이 전체 관리하고 GPT-6 Luna가 작업 이행. Luna의 사용자 요청 effort `ultra`는 호스트 지원 범위 밖이어서 최고 지원 `max`로 요청했다. 실행 모델 호스트 확인값은 별도 기록한다.

## 문제와 학습 목표

Round027 이름표 재검사는 같은 조건 기준선 3,538/5,897척에서 정답 순증 0, 자망 TP −3·통발 TP −5였다. 새 실험의 가설은 **기존 304특징에 없는 항적의 공간적 반복·굴곡 정보**가 두 업종의 경계를 개선한다는 것이다. 정지 시간·속력·양망 주기·수심처럼 자료에 없는 물리량을 만들지 않는다. 이전 S2의 약지도와 공간 kNN의 기존 지문·거리 특징을 새 특징 효과로 다시 이름 붙이지 않는다.
기존 304 이름 목록 직접 확인(2026-11-05 16:25 KST): F156에 `straightness__day_*`, `turn_mean_rad__day_*`, `turn_p90_rad__day_*`, `turn_gt_pi2_fraction__day_*`, `observed_turn_count__day_*`가 이미 있고, 격자 엔트로피 계열도 있다. 그러므로 단순 직진성·평균 회전각·큰 회전 비율·격자 엔트로피는 새 후보에서 제외한다. 새 후보는 부분선 내부의 **국소 되돌아옴/연속 전환 순서**처럼 기존 요약으로 복원할 수 없는 순서 통계여야 한다.

학습자는 원자료→부분선별 좌표→거리/방향의 무차원 요약→선박 특징→FIT 학습→SELECT 선택→OUTER 평가의 흐름과 각 단계의 실패 원인을 설명한다. 이번 단계는 전용 특징의 기술 실험이며 학습자의 이해 달성은 별도다.

## 단계·계약

1. **입력 적합성:** 읽기 전용 원천 또는 기존 허용 캐시에 선박별 부분선 경계·순서 있는 2026 좌표가 실제 있는지 확인한다. 각 점의 시각이 없다면 점 간 이동시간, 실제 속력·가속도·체류시간을 계산하지 않는다. 서로 다른 부분선의 끝과 시작도 잇지 않는다. 라벨·예측·holdout/Test 개별자료는 특징 추출에 넣지 않는다. 기존 304 및 S2 특징과 중복 여부를 이름·연산식으로 표기한다. 충족되지 않으면 점수 실험에 진입하지 않고 원인·대체 입력을 기록한다.
2. **구현 및 작은 검산:** 기존 304에 없는 아래 **2개** 순서 통계만 구현한다. 영거리 구간·한 점·EMPTY·좌표계 미확인·장거리 튐·부분선 다중 상황을 테스트한다. 선박 식별번호·정박항구·지역 자체를 업종의 이름표로 사용하지 않는다.
3. **FIT 내부 관문:** 확정된 동일 선박 FIT 3,144척에서 기존 304 기준 LightGBM과 `304+신규`를 동일 seed, 파라미터, 조기 종료 분리, 4-fold 선박 CV로 비교한다. baseline도 새 절차에서 재학습한다. 목표는 신규 후보가 baseline 대비 정답 ≥16척 증가, 통발 또는 자망 TP·F1 개선, 연안복합/채낚기 TP 하락 0이다. 단일 후보만 평가한다. 불통과면 OUTER는 보지 않는다.
4. **개발 평가:** 관문 통과 시 3 원래fold에 같은 조건 기준선과 후보를 FIT 학습·INNER_ES 조기종료·INNER_SELECT 선택 후 각 OUTER 한 번 평가한다. 한 척당 한 예측. micro/macro, 클래스별 precision/recall/F1/TP/FP, gain/loss, 관측일 구간, fold별 효과, paired CI를 남긴다. 2026 개발 OUTER 5,897척은 반복 노출되었으므로 독립 검증으로 주장하지 않는다. 단일seed 판정 TP0≥2389 및 TP3≥90, 후속 5seed 확인은 TP0≥2381 및 TP3≥92와 기존 모델 각각의 gain/loss를 별도로 기록한다. 보호 실패는 micro 상승으로 상쇄하지 않는다.

## 현재 미확정 입력 관문

읽기 전용 Train2026 원천은 `F:\문제 데이터_수정_1027\vpass_26년(1월_6월) 데이터\vpass_1월_6월 데이터\`의 6개 월별 CSV, 합계 5,863,777,667바이트(파일명·크기는 worker provenance에서 고정). `geom` WKT MultiLineString의 2026 개발 로스터 선박만, 월별/행별 streaming. Train 레이블 열은 투영하지 않는다. Test·holdout 데이터/라벨/예측은 추출하지 않는다. `s3_hourly.parquet`에는 순서 있는 점이 없어 이 특징 입력으로 사용하지 않는다.

**고정 특징 수식**(다른 후보·임계값 탐색 없음):

1. `turn_sign_reversal_fraction`: 각 WKT 부분선에서 서로 다른 연속 점의 진행방향 변화량을 `(-π,π]`로 감싼 부호 있는 회전각으로 정의한다. 절댓값 <15°인 회전은 불안정한 미소변화로 제외한다. 남은 인접 유효 회전의 부호가 바뀌는 횟수 / 인접 유효 회전 쌍 수. 서로 다른 부분선·행 사이에는 쌍을 만들지 않는다.
2. `nonlocal_return_vertex_fraction`: 한 부분선의 현재 정점이, **같은 부분선**에서 누적 경로길이가 500m 이상 앞선 어느 과거 정점으로부터 수평거리 ≤100m이면 되돌아온 정점으로 센다. 분모는 해당 부분선에서 과거 500m 이상 이격 정점이 하나 이상 있는 현재 정점 수. 경로·수평거리는 WKT lon/lat로 확인된 경우에만 국소 구면 근사 또는 haversine으로 계산한다. 이는 시각/체류시간/속도가 아니다. 여러 부분선·행의 분자/분모를 선박별로 합산한 뒤 나눈다.

각 특징의 분모가 0이면 `NaN`과 원인을 남긴다. 유효 분모가 있고 사건이 0회이면 0이다. malformed/EMPTY/좌표 범위 밖/상한 초과 행은 명시적으로 누락·카운트하며 임의로 0을 채우지 않는다. WKT 각 점이 lon/lat라는 것은 원천 계약과 수치범위로 확인하되 EPSG/측량 정확도는 미확인이다. 100m/500m는 검증된 어구 물리 상수가 아니라 평가 전 고정한 설계 가정이다. 304의 기존 직진성·회전각 요약·공간 엔트로피와 수식 수준 중복이 없음을 별도로 검산한다.

현재 학습/평가 0회. 학습 실행 상한은 내부 관문 baseline+후보 합계8fit, 전체 확장은 별도 단계로만 허용한다. 기존 round026/027 산출물은 읽기 전용이다. 모든 새 파일은 이 폴더에 저장한다.

## 자원과 실패

좌표는 최대 100,000점, 되돌아옴 후보 거리 비교는 최대 1,000,000회다.
