# Round 003 학습 연결

본인 학습자용이다. 선수지식·학습 가능 시간은 미확인이다. 이번 실행은 반복 작업과 검산을 지원하며, 아래 해석 질문의 답을 사용자가 설명할 수 있는지는 별도 확인해야 한다.

이번 작은 전체 흐름은 **이미 저장된 선박별 확률 → 판정 규칙 → 업종 예측 → 같은 선박의 정답과 비교**다. 원자료·센서·하드웨어를 새로 처리하는 단계가 아니다. 입력은 각 선박의 네 클래스 확률, ID, fold, 정답, 관측 날짜 수다. 출력은 클래스 하나와 검산 지표이며 확률과 업종 순서를 보존한다.

| 활동 | 관찰 | 설명할 질문 |
|---|---|---|
| 원확률 최대 클래스를 선택 | 보정 없는 판정 | 최댓값 클래스가 왜 micro 기준의 출발점인가? 확률이 잘 보정되지 않아도 이 규칙이 항상 최선인가? |
| 통발 점수에 기존 배수를 적용 | 통발로 바뀌는 예측과 양방향 손익 | 통발 recall이 높아져도 전체 정답 수는 낮아질 수 있는가? |
| INNER에서 제한된 배수 선택 | micro와 클래스·짧은 관측 집단의 제약 | 선택 집단에서 좋아진 규칙이 OUTER에서도 좋아질 것이라고 보장할 수 있는가? |
| 고친 오답과 새로 만든 오답을 함께 계산 | gain−loss=정답 순증 | 오류만 담긴 CSV로 전체 개선을 계산하면 무엇을 놓치는가? |
| 두 seed를 같은 선박 단위로 재표집 | seed별 결과의 상관성 | 같은 배를 seed마다 독립 선박으로 세면 불확실성 추정은 왜 달라지는가? |
| 코드·메타데이터·실행 증거 대조 | 설명 문서와 전처리 코드의 불일치 | 저장 확률의 검산과 원모델의 재추론 성공은 어떻게 다른가? |

기술적 완료는 계획대로 계산하고 별도 검토자가 검산한 상태다. 교육적 달성은 사용자가 위 질문을 설명하고, 조건 변경 시 결과 해석을 수정할 수 있는 상태다. 두 상태를 같은 것으로 기록하지 않는다.
