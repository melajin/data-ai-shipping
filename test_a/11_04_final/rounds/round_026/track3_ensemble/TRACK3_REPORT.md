## 1. 배경 및 Round 021 실패 원인 규명

### 1.1 Round 021의 구조적 결함
- **작은 표본 대비 높은 자유도**: Round 021은 fold당 불과 394척짜리 `INNER_SELECT` 표본에 12~20개 변수의 다항 로지스틱 회귀를 적합했습니다.
- **손실 함수와 평가 제약의 불일치**: Log-loss(교차 엔트로피) 최소화는 클래스 불균형 상황에서 다수 클래스에 편향되며, `TP0 >= 2,389` 및 `TP3 >= 92`라는 비대칭적 하한 조건을 학습 단계에서 전혀 고려하지 않았습니다.
- **결과**: `연안복합(class 0)`에서 111척이 이탈하고 `채낚기(class 3)` TP가 `90 -> 75`로 붕괴하여 micro-F1이 0.5778(12열) / 0.5703(20열)으로 급락했습니다.

### 1.2 왜 단순 평균(S0)에서 TP3가 흔들렸는가? (사전분포 불일치 규명)
- Round 017에서 단순 50:50 평균(`S0`)은 3,528척(0.598270)을 기록했으나, `TP3`가 87척으로 기준선(90~92척)에 미달했습니다.
- **원인 분석**:
  1. **TabICLv2**는 클래스 가중치 없는 원본 경험분포로 학습되어 Class 3의 평균 예측 확률이 **0.0220(2.2%)**에 불과하며, 예측 확신도(평균 최대 확률 0.6052, 평균 엔트로피 0.8624)가 높습니다.
  2. 반면 **LightGBM 5-seed**는 `sqrt_macro` 가중치로 학습되어 Class 3 평균 확률이 **0.0392(3.9%)**, seed42는 **0.0455(4.6%)**로 상대적으로 높습니다.
  3. 두 모델을 단순 평균하면 TabICL의 극도로 낮은 Class 3 사후확률이 LightGBM의 신호를 억제하여 `argmax` 시 Class 3 예측 빈도가 급감합니다.
- **해결 원리 (Bayes Decision Rule & Prior-Shift)**:
  결정 규칙을 $\hat{y} = \arg\max_c (\alpha_c \cdot P_{\text{blend}}(c))$로 정의하고, TabICL의 사전분포 왜곡을 상쇄하는 클래스별 승수 $\alpha_3 \approx 1.45 \sim 1.50$, $\alpha_0 \approx 1.03 \sim 1.04$를 INNER에서 학습함으로써 Class 0과 Class 3를 모두 완벽히 보호할 수 있습니다.

### 6.1 INNER 3-fold OOF 탐색 및 가중치 선정
- **결합 후보군 탐색**:

  - `CatBoost` (연안복합 고정밀도 트리)
