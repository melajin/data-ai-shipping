# 어선 이상항적 분석 시스템과 결과 보고서

**Test B 범위를 실행 가능한 패키지와 19쪽 보고서로 완성했다.** 기하 요약 입력과 고정 기준자료에서 기존 점수를 다시 계산하고, 100척의 검토 후보와 근거를 생성한다. 창의성 20·우수성 50·효과성 30의 공지 평가 요소에 맞춰 방법·재현성·활용성과 실패 결과를 함께 제시한다.

먼저 [결과 보고서](reports/어선_이상항적_시스템_결과보고서.md)를 읽는다. 편집 가능한 [보고서 원문](reports/어선_이상항적_시스템_결과보고서.md), 보고서 생성 코드, [선박별 근거 CSV](results/reproduction_001/candidates.csv), [재현 검증 JSON](results/reproduction_001/summary.json)이 연결된다.

## 실행

이 폴더에서 실행한다. 실제 확인 환경은 Windows 11, Python 3.13.3, CPU이며 라이브러리 버전은 `requirements.txt`에 고정했다. GPU나 외부 AI API는 필요하지 않다. 다른 OS·새 가상환경 설치는 별도 실행 검증하지 않았다.

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe src/run_analysis.py --output results/reproduction_new
.venv\Scripts\python.exe -m unittest discover -s tests -v
```


`data/observations.parquet`은 원 WKT가 아니라 기존 전처리에서 나온 기하 요약이다. `stored_expected.parquet`와 `stored_candidates.csv`는 재현 비교용이며 점수 계산의 정답·학습자료가 아니다. 이 실행기는 동봉된 고정 100척 입력에 대한 재현용으로 구성됐다. 임의의 새 선박 데이터에 대한 일반 추론 서비스는 별도 입력 계약을 필요로 한다.

출력 폴더에는 `scored_rows.parquet`(시간별 전체 점수)·`candidates.csv`(선박별 근거 100행)·`summary.json`(재현 대조 결과와 실행 기록) 세 파일만 생성된다. 실행 시점·환경의 전체 기록은 `summary.json`과 보고서의 §5·§10에 있다.

종합점수는 가용한 `s_zone`·`s_change`·`s_gap`의 평균이다. 후보는 선박별 전기간 최고점이며 동점은 원본 `source_ordinal` 최솟값으로 처리한다. 사고 확률이나 자동 경보가 아니다. 직전 3/2/1시간의 근거는 그 정확한 시간에 관측이 있을 때만 채운다. 이번 입력의 해당 시각 존재 수는 각각 33/38/58척이다.

그림의 공간 좌표는 시간대 기하 중심점이다. 점들을 실제 항로로 연결하거나 실제 속력·침로로 해석하지 않는다. 39척의 후보에는 앞선 관측이 24행보다 적어 구성점수 3개를 모두 사용할 수 없다. 최고 점수 사례도 과거 관측 9행으로 변화점수가 없다는 점을 보고서에 공개했다.

## 평가 요소와 보고서 연결

| 평가 요소 | 제시할 내용 | 위치 |
|---|---|---|
| 창의성 20 | 세 점수와 정보 부족을 함께 설명하는 구성, 선박축·시각축 분리 설계 | §1~§4 |
| 우수성 50 | 데이터 경계, 실제 재계산, 전수 대조, 전 선단 실측, 사례, 라운드별 실패 기록 | §2~§8 |
| 효과성 30 | 후보 목록의 검토 절차, 적용 조건, 학습·운영 활용 | §9~§10 |

배점은 공지의 평가 요소이며 예상 획득 점수나 순위를 산정하지 않았다. 관제 화면·웹 앱은 확인된 필수 제출물이 아니므로 추가하지 않았다. 조업형태 분류 Test A의 연구 결과는 보고서의 별도 배경으로만 소개하며 해당 모델은 이 Test B 패키지에 포함하지 않는다.

## 실시간 적용 검증

`support/README.md`에 별도 실행 명령이 있다. 시간대·실제 가용 시각이 확인되지 않은 자료는 유보하고, 미래·역순·상충 입력은 격리한다. 점수나 경보를 생성하지 않는다. 동봉된 가공 9행은 수락 3·중복 1·격리 3·유보 2다.

2026년 기준자료로 2025년 점수를 재현하는 사후 분석과 2025년 당시의 실시간 판단은 다르다. 실제 수신 기록, 당시 가용한 참조자료, 확정 정상·사고 라벨, 경보 임계값 검증이 갖춰져야 현장 운영으로 전환할 수 있다.
