# 선박 조업형태 분류 방법

## 문제와 데이터

과제1은 선박별로 제공된 항적 묶음에서 조업형태를 분류하는 문제입니다. 클래스는 연안복합·자망·통발·채낚기연승낚시의 네 가지입니다. 선박 ID는 행을 묶고 제출 결과를 연결할 때만 사용합니다.

학습 자료7,372척을 FIT4,423척, TUNE1,474척, REPORT1,475척으로 선박 단위 분할했습니다. FIT는 문맥과 특징 기저 적합, TUNE은 판정 계수와 체크포인트 선택에 사용했습니다. REPORT는 개발 평가에 사용했습니다.

Test A는 공식 제출 대상100척의 원자료를 읽었습니다. 월별 원자료4,212,389행을 순차 조회해 대상 선박 관측22,733행을 추출했습니다. 라벨 열은 읽지 않았습니다.

## 전처리

각 관측 행의 실제 MultiLineString에서 길이·범위·직진성·방향·회전·부분 수 등을 계산합니다. 떨어진 선분과 관측 공백은 연결하지 않습니다. 좌표에 임의의 시각이나 속도를 붙이지 않습니다.

선박 특징337개는 다음 세 묶음입니다.

| 묶음 | 개수 | 주요 내용 |
|---|---:|---|
| 기본 요약 | 98 | 관측 형상의 평균·표준편차·중앙값·최댓값, 관측일 수, 실제 시각 분포 |
| 공간 배치 | 52 | EPSG5179 투영 좌표의 일별·전체 hull,100·500·2000m 격자 방문, 실제 관측 간격 |
| 상태·시간 | 187 | 측정 길이·직진성8개 상태, 시간대 분포, 정확히1시간 인접 전이, 상태별 형상 |

원래63회차와 같은 중간 CSV 정밀도를 적용한 뒤 float32로 추론합니다. 네 클래스에서 각각 한 척을 골라 원자료부터 다시 계산한1,348개 특징 값은 기존 값과 모두 같았습니다.

## 신경망 학습

공개 TabICLv2에서 시작했습니다. ICL12블록 중 중간4블록의 원본 파라미터8,578,048개와 뒤4블록 FFN의 신규 게이트2,101,248개를 학습했습니다. 열·행·레이블 인코더, 앞4블록, 뒤4블록의 원래 값 경로·attention, 최종 norm과 판독기는 고정했습니다.

게이트는 `2*sigmoid(Gx)`이며0으로 초기화해 시작 함수가 원본과 같도록 했습니다. FIT2-fold 문맥에서4개 native 앙상블을 사용하고,20개 과제의 결합 손실을 최적화했습니다. 손실은4분류 cross-entropy, 공개 교사 T2 KL, 앙상블 일관성 JS의 합입니다. 학습 관계 분기 비중은0.5로 사전에 고정했습니다.

두 번의 순전파를 사용하는 방식으로 출력 경사를 구한 뒤 본체 경사를 누적했습니다. BF16 autocast의 weight cache를 끄고 GradScaler 없이 수행했습니다. 학습률은 원본1e-5·게이트1e-4, 최대6epoch, epoch당2update, patience1입니다. 실제4update 후 종료됐고 epoch1·update2의 가중치를 선택했습니다.

## 제출 추론

최종 정책의 관계 분기 비중은0입니다. 추론은 compact150의4분류·6쌍과 state337의4분류·6쌍, 총14과제를 사용합니다. 문맥은 기존 FIT4,423척으로 고정했습니다. TUNE·REPORT를 문맥에 추가하지 않았습니다.

compact와 state를 각각0.5로 결합하고, joint와 쌍 비교 로그 점수를0.5씩 반영합니다. 클래스 가중치는 `(1,1,1,0.8)`입니다. 선택된 학습 본체 반영 비중은1입니다. 최종4개 로그 점수를 softmax로 정규화해 예측 클래스의 확률을 제출합니다.

추론 코드는 state dictionary·특징 목록·문맥을 명시적으로 읽습니다. Python 추론 어댑터를 pickle로 저장하거나 복원하지 않습니다.

## 실행과 활용

`scripts/build_features.py`가 라벨 없는 관측을337열로 만들고, `scripts/predict_testA.py`가 고정된 모델로 예측합니다. 원자료를 다시 읽지 않아도 포함된 Test A 특징으로 실행할 수 있습니다. ID·클래스·확률을 가진 CSV를 생성하며, 과제2 결과와 통합 엑셀로 저장합니다.

운영에서는 새 선박의 제공 관측 묶음을 같은 함수로 처리할 수 있습니다. 원자료 규모가 커도 CSV를 청크 단위로 읽고 대상 ID를 먼저 골라 형상 계산량을 줄입니다. 반복 추론에 공통 본체와 FIT 문맥을 재사용하며 외부 서비스 호출은 없습니다.
