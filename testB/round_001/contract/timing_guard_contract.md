# 시각 준비 인터페이스 보완 계약 v0.2

독립 검산 w1_w2_001의 두 fail 및 관련 미확정 한도를 반영한다. 실제자료 예측/임계값 선택은 계속 금지한다. 본 계약은 시각 입력을 기존대로 정수 시간대 시작 인덱스(1시간 cadence)로 한정하는 합성 인터페이스 계약이다.

1. A는 원입력 순서에서 최초 최대값이다. 시간순 정렬은 B/C 구간 검색에만 사용한다. 현재 manifest와 이를 생성하는 코드의 이전 문구도 함께 정정한다.
2. 미관측 시간대를 넘어 구간을 잇지 않는다. hourly 입력의 max_gap_hours는 0보다 크고 1 이하만 허용한다. 1을 넘기면 ContractError로 거부한다. 값이 1 이하면 기존보다 엄격하게 구간을 분리할 수 있으나 실제 수치를 선택/적용한 것은 아니다. 고유 인접 시각이 두 시간 이상 떨어지면 어떠한 허용 매개변수로도 같은 구간이 될 수 없어야 한다.
3. 중복 시각 행은 원행 ID로 보존하고 지속 행수는 고유 시각 수로 센다. 동일 시각의 유효 점수가 서로 다르거나 결측/유효가 충돌하면 해당 선박을 data_conflict / duplicate_timestamp_scores_conflict 상태로 반환하고 A/B/C를 채우지 않는다. 같은 시각·같은 점수 중복은 추적정보를 보존한다. NaN/None은 결측 동등으로 처리한다. 충돌을 평균/최대/선택으로 숨기지 않는다.
4. positive floor를 정상확신·사고확률로 읽지 않는다. 현재 인터페이스는 유한 점수 처리를 보존하되 floor의 실제 판정 근거/자료 충분성은 향후 승인 입력의 별도 조건이다. 이 미확정을 해결했다고 표시하지 않는다.
5. 기존 합성 검사와 별도 독립 재검산으로 계약 준수를 확인한다. 사전 알려진 실제 Test B 점수나 사고시각을 보고 파라미터를 선택하지 않는다.

파일 수정 단독 담당은 새 timing 수정 worker이며 timing/만 소유한다. 이전 완료 W2 및 감사자는 같은 파일을 쓰지 않는다. 수정 전 파일/해시·실제 exit·변경 이유와 검사 로그를 보존한다. 모든 큰 작업은 AGENTS.md의 RAM 확인·작업전환·재확인 규칙을 따른다.
