# 다음 감독 세션 인계 준비

현재는 Round 001 진행 중이며 아직 새 감독 세션을 생성하지 않았다. 단일 감독은 STATUS.json의 active_supervisor_session이다.

라운드 종료 전에 이 파일을 실제 결과로 갱신한다: 근본 목표·성공 기준, 이전 대비 변화, 이번 결과/해석/계산불가, 입력 버전 및 허용 사용 범위, 고정 계약·분할·임계값의 확정/미확정, 파일별 소유권, 미해결 검산, 다음 한정 검증, 실행/검산/감독 모델 영수증.

다음 세션은 실제 Orca gpt-6.1-sol / high로 생성하고 인계 ACK를 받아야 한다. ACK 이전에는 현 감독이 소유권을 유지하며, ACK 뒤에는 중복 감독·동시 실행을 하지 않는다. 생성 방법은 실제 버전 guide의 handoff/launch 규칙을 확인한다. 성공 기준 미충족을 완료로 기록하지 않는다.
