## 2. 과제 정의 — 혼동 금지 항목

### 2.1 이 실험이 푸는 문제

```
선박 1척의 평가 기간 항적 전체  →  모델  →  업종 1개
```

| 클래스 인덱스 | 업종 |
|---:|---|
| 0 | 연안복합 |
| 1 | 자망 |
| 2 | 통발 |
| 3 | 채낚기연승낚시 |

### 2.2 이 실험이 **아닌** 것

| 아님 | 근거 |

| 시점별 조업/이동 판정 | 출력은 선박당 업종 1개 |
| 사고·이상탐지 (과제 2) | 보고서 명시: 6~10차에서 실행·평가하지 않음 |
| 실시간 판정 | 5~6월 두 달을 **모아서** 일괄 분류 |
| 공식 테스트 성적 | 2025 테스트 정답을 채점한 것이 아님 |

## 3. 시스템 구조

### 3.1 입력 생성

```
시간대별 MultiLineString 항적
  → 날짜별 요약
  → 기간 전체 선박별 특징 161개
  → TabICLv2 입력 222개
```

**222개 구성:** ExtraTrees로 선택한 숫자 특징 112 + 결측 표시 44 + 공간 SVD 압축 64 (0.02°·0.005° 격자 각 32) + REF 공간 사전 관측 비중 2

**특징 4종:**

| 종류 | 예시 | 표현 대상 |
|---|---|---|
| 경로 모양 | 선 내부 길이, 직선성, 선회 정도, 활동 범위, 반복 좌표 비율 | 어떻게 움직이는가 |
| 기간 분포 | 중앙값, IQR, 분위수 | 활동이 얼마나 일정한가 |
| 관측 시간·품질 | 시간대별 관측 비중, 관측 날짜 수, 결측 비율 | 언제 얼마나 관측됐는가 |
| 공간 사용 | 5종 격자(0.1°/0.02°/0.005°/0.001°/0.0002°) 위치 분포 | 주로 어디에서 활동하는가 |

**측정 한계 (보고서 명시):**
- 좌표별 시각이 없음 → 순간 속도·가속도·정확한 체류시간 미계산
- 공간 히스토그램은 **시간대 선분의 길이 가중 중심점**이며, 완전한 점유 지도가 아님
- 0.001° ≈ 남북 111m, 0.0002° ≈ 남북 22m (위도 35° 기준, 동서는 더 짧음). **원자료 위치 정확도가 그만큼이라는 뜻이 아님**
- `observed_days`는 기록이 존재하는 날짜 수. 운항일·연속 운항시간이 아니며, 유효 도형이 없는 날도 포함될 수 있음

### 3.2 두 경로와 결합

| 경로 | 하는 일 |
|---|---|
| 검색 | REF(1~3월) 6,585척 이력에서 닮은 선박을 찾아 그 업종을 참조 |
| TabICLv2 | 222개 특징과 참고 사례로 업종 추론 (전역 + 지역·월별 문맥 50:50) |
| 결합 | 신뢰도 기반 가중 평균 + 업종별 배수 보정 |

**10차 결합 규칙:**

```
s = 학습 재순위의 1등 점수
d = 1등 점수 − 2등 점수

if spatial_days > 0 and spatial_evidence > 0.05:
    a = 0.75 × [0.4 + 0.6 × clip(d / 0.05, 0, 1)] × clip(s, 0, 1)
else:
    a = 0

결합 점수 = a × 검색 업종 점수 + (1 − a) × TabICL 혼합 점수
업종별 [1.0, 0.9, 1.1, 0.9] 곱한 뒤 정규화 → argmax
```

실제 평균 검색 비중: 기존 집단 **0.5851**, 신규 집단 **0.3179**.

> ⚠️ `s`는 인위적 가중치(양성 12 : 음성 1) 아래 학습된 점수다. **"1등 점수 0.9 = 같은 배일 확률 90%"로 읽으면 안 된다.**
> ⚠️ `accepted_reid`는 검색 비중이 양수인 행일 뿐, 신원 확정 표시가 아니다.
> ⚠️ `temperature=0.08`은 기록되지만 k=1 단일 후보 투표에서는 효과가 없다.

### 3.3 실제로 학습된 부분

| 구성요소 | 한 일 | 하지 않은 일 |
|---|---|---|
| TabICLv2 본체 | 기학습 v2 체크포인트 사용, 마지막 ICL 블록 FFN 기여 **0.5배** | 신경망 전체·출력층 역전파 재학습 |
| 특징 선택 | REF 업종 정답으로 ExtraTrees 학습 | INNER·OUTER 정답 사용 |
| 재순위 (7·10차) | REF 1월→2월/3월 동일 ID 쌍을 정답으로 HGB 학습 (116,363쌍) | 평가 ID를 조회해 업종 복사 |
| 지역 문맥 (8차) | PCA+KMeans 12개 군집, 군집별 참고 선박 + 가장 먼 월 요약 | 선박별 개별 신경망 학습 |
| 최종 판정 | INNER에서 이웃 수·결합 규칙·업종 보정 선택 | OUTER에 맞춰 사후 덮어쓰기 |

**→ "TabICLv2를 5번 재학습해 성능을 높였다"는 설명은 틀리다.** 가중치는 고정이었고, 바뀐 것은 검색·재순위·참고 문맥·결합 방식이다.

**재순위 학습 쌍의 실체:** 116,363쌍 = 8,951개 월별 질의 × 13쌍 (정답 1 + 어려운 오답 12). **116,363척의 독립 선박이 아니다.**

### 3.4 ID 사용에 대한 정확한 표현

| 피해야 할 표현 | 정확한 표현 |
|---|---|
| 선박 ID를 전혀 사용하지 않았다 | ID는 **학습 쌍의 정답·그룹 구성·사후 진단의 제외 기준**에 사용했고, 추론 입력이나 업종 정답 조회에는 사용하지 않았다 |

## 4. 분할과 성적

### 4.1 시간 분할

| 역할 | 기간 | 선박 수 | 용도 |
|---|---|---:|---|
| REF | 2026-01 ~ 03 | 6,585 | TabICL 참고 문맥, 검색 자료, 특징 선택·변환 기준, 재순위 학습 |
| INNER | 2026-04 | 5,981 | 이웃 수, 혼합 비중, 신뢰도 규칙, 업종 보정 선택 |
| OUTER | 2026-05 ~ 06 | 6,526 | 선박당 업종 1개 예측 후 채점 |

REF는 끝까지 1~3월로 고정했고, 4월의 새 선박을 검색 자료에 추가하지 않았다.

### 4.2 OUTER 집단 구성 — 성적 해석의 핵심

| 집단 | 척수 | 비율 | 맞힌 수 | Micro-F1 |
|---|---:|---:|---:|---:|
| 기존 (REF에 같은 ID 있음) | 5,835 | **89.41%** | 5,096 | **0.8734** |
| 신규 (REF에 ID 없음) | 691 | 10.59% | 375 | **0.5427** |
| 전체 | 6,526 | 100% | 5,471 | **0.8383** |

```
Micro-F1 = (5,096 + 375) ÷ (5,835 + 691) = 5,471 ÷ 6,526 = 0.838339
```

단일정답 분류이므로 **Micro-F1 = 정확도**다.

> '기존/신규'는 **REF에 같은 문자열 ID가 있는가**라는 내부 구분이다. 외부 기관의 물리적 선박 신원 인증이 아니다. 추론 시 이 구분을 모델에 알려주지 않는다.
> 이 비율은 원자료에서 자연스럽게 나온 값이며, 점수를 높이려 신규를 뺀 것이 아니다.

**집단 구성 민감도 (각 집단 정확도 고정, 비율만 변경):**

| 신규 비율 | 전체 Micro-F1 |
|---:|---:|
| 10.59% (실제) | 0.8383 |
| 25% | 0.7907 |
| 50% | 0.7080 |
| 100% | 0.5427 |

→ 새 자료의 성능 예측이 아니라, **평가 집단 구성만 바뀌어도 전체 점수가 크게 달라진다**는 산술 예시다.

### 4.3 회차별 성적 (동일 OUTER)

| 시도 | INNER | OUTER | 연안복합 | 자망 | 통발 | 채낚기연승 | Macro |
|---|---:|---:|---:|---:|---:|---:|---:|
| 6차 | 0.8142 | 0.7536 | 0.7945 | 0.7303 | 0.6774 | 0.7126 | 0.7287 |
| 7차 | 0.8136 | 0.7629 | 0.8050 | 0.7349 | 0.6978 | 0.6498 | 0.7219 |
| 8차 | 0.8184 | 0.7679 | 0.8123 | 0.7391 | 0.6814 | 0.6783 | 0.7278 |
| 9차 | 0.8569 | 0.8054 | 0.8396 | 0.7789 | 0.7509 | **0.7860** | 0.7889 |
| 10차 | 0.8686 | **0.8383** | **0.8667** | **0.8148** | **0.8119** | 0.7261 | **0.8049** |

**선택 목적함수 (6~10차 공통):**
```
선택 점수 = Micro-F1 + 0.20 × Macro-F1 + 0.10 × 최저 업종 F1
```
→ Micro 최대만 고른 것이 아니다. 10차 선택안의 INNER Micro는 후보군 최고보다 약 0.0010 낮았다.

> ⚠️ **10차가 모든 면에서 최선은 아니다.** 채낚기연승 F1은 9차 0.7860 → 10차 0.7261로 하락했다 (부트스트랩 95% 구간 −0.1175 ~ −0.0029).
> → 10차 = 전체 Micro 우수 구성, 9차 = 채낚기연승 우수 구성으로 **병기 기록**해야 한다.

## 5. 성적의 출처 — 검색 의존성 (핵심 분석)

### 5.1 구성요소 분해 (동일 OUTER, 저장 예측 재채점)

| 구성 | 전체 Micro | 신규 Micro | 통발 F1 | 채낚기 F1 |
|---|---:|---:|---:|---:|
| 전역 TabICLv2 단독 | 0.6515 | **0.5789** | 0.3496 | 0.7279 |
| 지역·월별 TabICLv2 단독 | 0.5458 | 0.4457 | 0.4136 | 0.1983 |
| 두 TabICL 50:50 혼합 | 0.6336 | 0.5427 | 0.4130 | 0.4021 |
| **검색 1등 업종만** | **0.8282** | 0.5166 | 0.8076 | 0.7390 |
| 10차 최종 결합 | **0.8383** | 0.5427 | 0.8119 | 0.7261 |

**→ TabICLv2가 혼자 0.83까지 간 것이 아니다.** 검색 1등만으로 0.8282이고, 결합이 더한 것은 0.0101이다.

### 5.2 결합의 순효과

| 비교 대상 | 고친 척수 | 망친 척수 | 순증 |
|---|---:|---:|---:|
| 검색 단독 → 최종 결합 (전체) | 213 | 147 | **+66** |
| TabICL 혼합 → 최종 결합 (전체) | 1,646 | 310 | **+1,336** |
| TabICL 혼합 → 최종 결합 (**신규**) | 72 | 72 | **0** |

**→ 결합의 이득은 전부 기존 집단에서 나왔다. 신규 집단 순이득은 정확히 0이다** (맞힌 배가 뒤바뀌었을 뿐).

### 5.3 검색이 누구를 찾았는가에 성적이 걸려 있다

| 검색 1등 후보의 정체 | 척수 | 최종 Micro-F1 |
|---|---:|---:|
| **질의 선박 본인의 과거** | 4,292 (65.8%) | **0.9937** |
| 다른 ID, 같은 업종 | 1,113 | 0.8922 |
| 다른 ID, 다른 업종 | 1,121 | **0.1900** |

본인을 찾으면 99.4%, 엉뚱한 배를 찾으면 19%.

> 이 표는 **내부 2026 ID 일치 여부**이며, 외부 확인을 거친 물리적 재식별 정확도나 공식 2025 테스트 성능을 증명하지 않는다.

### 5.4 자기 과거 제외 진단 — 가장 중요한 증거

저장된 검색 후보에서 **질의 선박과 같은 ID만 제거**하고 다음 후보로 채점:

| 검색기 / 기존 선박 | 원래 | 자기 ID 제외 | 차이 |
|---|---:|---:|---:|
| 6차 | 0.7763 | **0.4956** | −0.2807 |
| 10차 | 0.8651 | **0.4809** | −0.3842 |

> ### 결론적 두 숫자
> **자기 이력을 제외한 검색 성능: 6차 0.4956 → 10차 0.4809**
> **개선이 없다. 미세하게 하락했다.**
>
> → 6~10차의 발전은 "업종 구별 능력의 보편적 향상"이 아니라 **"동일 선박 재발견 능력의 향상"**으로 설명하는 것이 증거에 부합한다.

**이 진단의 한계:** 저장된 검색 후보에서 자기 ID만 지운 **부분 진단**이다. TabICL 참고 문맥·특징 선택·변환 기준·재순위 학습 쌍까지 전부 제외하고 재학습한 완전한 신규 선박 실험은 아니다. (신규 선박은 원래 자기 ID가 후보에 없으므로 제외 전후 예측이 동일함을 확인했다.)

## 6. 남은 취약점

### 6.1 신규 선박 — 특히 통발

| 실제 신규 통발 75척의 예측 | 척수 |
|---|---:|
| 통발 (정답) | **6** |
| → 연안복합 | 46 |
| → 자망 | 20 |
| → 채낚기연승 | 3 |

- **재현율 = 6/75 = 8%**
- F1 0.1017은 여기에 **오탐**(타 업종을 통발로 예측)까지 반영한 값 → "10.17% 맞혔다"와 다른 뜻
- 전체 통발 F1 0.8119와 신규 통발 F1 0.1017의 격차 → **전체 F1만으로는 이 구멍이 보이지 않는다**
- 신규 자망도 236척 중 129척이 연안복합으로 분류됨

**신규 집단 정답 분포:** 연안복합 356 / 자망 236 / 통발 75 / 채낚기연승 24

### 6.2 구조적 원인 — 랭커가 "모른다"를 배우지 않았다

재순위 학습 쌍 구성:
- **양성:** 같은 ID의 1월 ↔ 2월, 1월 ↔ 3월 (8,951개 질의)
- **음성:** 항적이 비슷한 **다른 배** 12척

→ "A와 B 중 누가 더 본인인가"는 배웠으나, **"둘 다 본인이 아니다"는 학습 대상이 아니었다.**

실측: 신규 691척 중 **464척(67.15%)**에 검색 가중치가 0보다 컸다. 처음 보는 배의 3분의 2가 "누군가의 기억"을 참조해 답을 정했다.

추가 한계 (구현 비판검토):
- 양성 선박이 초기 후보에 없어도 학습 쌍에는 강제 추가 → 추론 시 후보에 정답이 없으면 재순위만으로 복구 불가

### 6.3 업종 경계 — 진짜 미해결 과제

| 실제 → 예측 | 척수 | 전체 오류 중 |

| 자망 → 연안복합 | 390 | 36.97% |
| 연안복합 → 자망 | 249 | 23.60% |
| 통발 → 연안복합 | 129 | 12.23% |
| 연안복합 → 통발 | 79 | 7.49% |

**합계 847척 = 전체 오류 1,055척의 80.28%**

→ 이 경계가 사라진 것이 아니라, 기존 선박에서는 **재식별로 우회**했을 뿐이다.

## 7. 과적합 판단

### 7.1 네 가지를 구분해야 한다

| 문제 | 판정 | 근거 / 한계 |
|---|---|---|
| 계산 오류·점수 조작 | **확인되지 않음** | CSV 재계산, 혼동행렬, 확률 결합, SHA-256 지문 일치 |
| 직접적 평가 정답 누수 | **검토 경로에서 미발견** | REF만으로 변환·검색 자료·학습 쌍 구성. 단, 모든 누수의 부재를 수학적으로 증명한 것은 아님 |
| 의도한 기존 선박 특화 | **작동하며 유용함** | 비중첩 이후 기간에서 기존 집단 0.8734 |
| 지나친 특화·선택 과적합 | **위험 크고 최종 검증 미완료** | 신규·짧은 관측 취약, 세밀 좌표 의존, 반복 개발 평가 |

### 7.2 확인된 누수 방지 장치

- 기간 분할 후 그 기간 안에서 특징·정답 재집계
- 공간 사전은 REF에서만 생성 (평가 위치를 몰래 추가하지 않음)
- 재순위 월별 쌍은 1~3월 내부에 한정
- ID 문자열·기존/신규 마스크를 최종 예측 입력에서 제외
- 라벨 누락 1행은 정답 투표에서만 제외 (어려운 선박 선별 삭제 없음)

### 7.3 반복 개발 노출 — 확인된 사실

```
6차 → OUTER 채점 → 결과 보고 7차 설계
7차 → OUTER 채점 → 8차 설계
...
10차 → OUTER 채점 → 0.8383
```

**같은 OUTER를 5회 보며 설계했다.** → OUTER는 봉인된 시험셋이 아니라 **개발 자료**다.

회차별 내부 정책 비교 수: 6차 216 / 7차 216 / 8차 432 / 9차 864 / 10차 207
(9차는 선택안의 216개 조합 재계산분 포함 — 별도 독립 실험으로 세면 안 됨)

> 보고서가 스스로 기록한 사실: **6~9차는 설정 선택 전에 OUTER 파일을 메모리에 로드해 정답 일관성을 점검했다.** 점수 계산에는 INNER만 썼지만, "선택 전 OUTER를 전혀 열지 않았다"는 설명은 사실이 아니다.

**"OUTER 정답을 gradient에 넣지 않았다" ≠ "OUTER가 설계에 영향을 주지 않았다".** 전자는 확인됐고 후자는 아니다.

### 7.4 INNER-OUTER 차이는 과적합 크기가 아니다

| 시도 | INNER | OUTER | 차이 |
|---|---:|---:|---:|
| 6차 | 0.8142 | 0.7536 | −0.0606 |
| 7차 | 0.8136 | 0.7629 | −0.0506 |
| 8차 | 0.8184 | 0.7679 | −0.0506 |
| 9차 | 0.8569 | 0.8054 | −0.0515 |
| 10차 | 0.8686 | 0.8383 | −0.0302 |

INNER는 1개월·OUTER는 2개월이고 대상 선박도 다르다. 10차에서 양쪽 공통 **5,601척**만 비교하면 0.8777 → 0.8657로 하락폭이 줄어든다. → 전체 −0.0302에는 **선박 구성 차이도 포함**된다. (반대로 이를 근거로 과적합이 없다고 결론내려서도 안 된다.)

### 7.5 부트스트랩이 보정하는 것과 못 하는 것

고정 OUTER 예측 4,000회 복원추출 (paired):

| 지표 | 10차 | 95% 구간 | 6→10 개선량 | 개선량 구간 |
|---|---:|---|---:|---|
| Micro-F1 | 0.8383 | [0.8295, 0.8472] | +0.0847 | [+0.0740, +0.0961] |

| 자망 | 0.8148 | [0.8020, 0.8273] | +0.0845 | [+0.0702, +0.1000] |
| 통발 | 0.8119 | [0.7921, 0.8315] | +0.1345 | [+0.1118, +0.1580] |
| 채낚기연승 | 0.7261 | [0.6667, 0.7790] | +0.0134 | **[−0.0594, +0.0828]** |

0.25° 공간 블록 202개 재표본: Micro 구간 [0.8221, 0.8547], 개선량 [+0.0689, +0.0979]

**보정하는 것:** 이 6,526척 안의 표본 우연
**보정하지 못하는 것:** 반복 설정 선택의 낙관 편향, 새 지역·새 연도, 시간 의존성 (5~6월 합산 예측뿐이라 독립 월 블록 부족)

> 채낚기연승 개선량 구간은 0을 포함한다 → 뚜렷한 향상으로 단정 불가.

### 7.6 세밀 격자의 양면성

0.0002° 셀이 기억할 수 있는 것:
- 특정 선박의 고정 주요 관측 위치·정박 후보 위치
- 특정 해역·선박의 수신 특성
- 기간별로 달라지는 대표 위치 계산·좌표 오차

→ **"어업 동작을 더 정확히 이해했다"가 아니라 "현재 과거-미래 선박 집합의 공간 대응이 더 유용해졌다"**로 해석해야 한다.

## 8. 공식 규정과의 관계

### 8.1 확인된 공지 (원본 이미지 4장 직접 확인)

> "학습데이터에는 fishing_code를 정답 Label로 제공하되, 최종 평가용 **Test A에서는 fishing_code를 제거하고 항적데이터만 제공**" (공지-문제 과제)

> "**모델이 선박 ID를 단순 암기하지 못하도록** 조업형태 판별용 Test A의 rfid_id는 **원칙적으로 Train에 포함되지 않은 신규 선박으로 구성**한다." (공지-문제 과제)

> "GIS MultiLineString 형태의 항적에서 이동거리, 방향 변화, 선회 특성, 직선성, 이동범위 등 **데이터로 산출 가능한 특징을 참가자가 자체 추출**" (공지-문제개요)

### 8.2 추가 전달된 규정

> **"동일 선박의 과거 항적을 이용한 통계·행동 프로필 생성은 금지"**

⚠️ **이 문장은 확인한 공지 이미지 4장에 없다.** 이후 나온 공지 또는 Q&A 답변으로 추정된다. **원문 출처(공지 번호·날짜)를 확보해 보관할 것.**

### 8.3 해석 — 좁게 읽는 것이 맞다

| 행위 | 판정 | 근거 |
|---|---|---|
| 동일 선박 과거 프로필로 자기 라벨 가져오기 | **금지** | 규정 문구 직접 해당 |
| **타 선박** 과거 항적으로 사례 라이브러리 구성·검색 | **허용** | 규정이 "**동일** 선박의"로 범위를 한정. 공지가 요구하는 사례 기반 학습 그 자체 |
| 평가 기간 내 **본인 항적**의 통계 요약 | **허용** | 공지가 명시적으로 요구 ("참가자가 자체 추출") |
| 동일 선박 쌍으로 학습된 재순위 함수 | **합법으로 판단** | 저장된 프로필이 아닌 학습된 함수. Train 내부 자기지도 신호. 추론 시 ID 미조회 |
| 세밀 격자 특징 | **허용** | 당해 기간 본인 항적의 공간 요약. 격자 자체는 금지 대상 아님 |

**근거 1 — 자기 모순 회피:** 공지-문제 과제 목표 2는 정반대를 **요구**한다.
> "정상 및 사고 구간이 포함된 항적데이터를 활용하여 **선박별** 또는 동일 조업형태별 **평상시 항적패턴을 분석**"
> "이상징후 예시: ... **동일 선박의 평상시 항적**과 현저히 다른 패턴 등"

→ 규정을 넓게 읽으면 과제 2가 성립 불가. **과제 1에만 적용되는 것으로 읽어야 한다.**
→ ⚠️ 다만 이 범위는 주최 측 확인 후 문서화 권장. (팀원 작업은 전부 과제 1이므로 현재 결론은 불변.)

**근거 2 — 규정은 거의 중복이다:**
```
Test A = 신규 선박  →  동일 선박의 과거 항적이 애초에 존재하지 않음
                   →  프로필을 만들 대상이 없음
```
이 규정은 새 족쇄라기보다 **신규 선박 구성이 이미 강제하던 것을 문장으로 재확인**한 것이다.

### 8.4 결론 — 구속 조건은 규정이 아니라 평가 집단 구성

| | 엄격 해석 | 좁은 해석 |
|---|---:|---:|
| Test A 기대 성능 | ≈0.58 | ≈0.58 |

**해석을 어떻게 하든 숫자가 같다.** ≈0.58은 규정 문구가 아니라 **신규 691척 실측값(전역 TabICL 0.5789)**에서 나왔기 때문이다.

→ 따라서 "무엇을 떼어내야 하는가"가 아니라 **"신규 선박에서 작동하는 것이 무엇인가"**가 올바른 질문이다.

## 9. 규정·Test A 조건에서의 기대 성능

### 9.1 구성별 적합성과 실측

| 구성 | 전체 | 신규 | Test A 적용 가능성 |
|---|---:|---:|---|
| 10차 최종 결합 | 0.8383 | 0.5427 | 작동하나 **검색이 무의미하게 소모됨** |
| 검색 1등 업종만 | 0.8282 | 0.5166 | 타 선박 매칭만 남음 |
| TabICL 50:50 혼합 | 0.6336 | 0.5427 | 지역 경로가 발목 |
| **전역 TabICLv2 단독** | 0.6515 | **0.5789** | **현재 최선** |

### 9.2 신뢰할 수치

**전체 0.6515도 깨끗하지 않다.** 이 값은 TabICL ICL 참고 문맥(REF)에 **질의 선박 본인의 과거가 포함된 상태**의 결과다.

**가장 깨끗한 추정치 = 신규 691척의 0.5789.** 이 배들은 검색·문맥·재순위 어디에도 본인 흔적이 없다.

> ### 핵심 수치
> ```
> 보고된 성적      0.8383   (기존 89% + 신규 11% 혼합)
> Test A 기대값   ≈0.5789   (신규 선박 전역 TabICL 실측)
> ```

### 9.3 신규 조건에서는 결합이 손해다

| 신규 집단 | Micro-F1 |
|---|---:|
| 전역 TabICL 단독 | **0.5789** |
| 10차 최종 결합 | 0.5427 |
| 차이 | **−0.0362** |

§5.2의 "신규 순이득 0"과 일관된다. → **Test A 제출 구성은 결합 가중치를 신규 조건에서 다시 잡거나, 전역 경로 단독으로 가는 것이 유리하다.**

## 10. 우리 기존 결과와의 비교

### 10.1 지표·조건이 모두 다르다

| 항목 | 우리 기존 | 팀원 6~10차 |
|---|---|---|
| 대표 지표 | **Macro-F1 0.2996**, 정확도 0.4990 | **Micro-F1 0.8383**, Macro-F1 0.8049 |
| 평가 조건 | 학습/평가 **선박 분리** | **89%가 과거에 본 선박** |
| 주요 입력 | 기하 특징 + 분포 | 기하·관측·공간 + **과거 검색** |
| 모델 | MLP·선형·ExtraTrees 비교 | TabICLv2 + 검색 + 학습 재순위 |
| 최종 평가 | 동결 후 **1회** | 같은 OUTER **5회** 반복 개발 |

### 10.2 조건을 맞추면

| 비교 | 팀원 | 우리 | 격차 |
|---|---:|---:|---:|
| 기존 방식 (혼합 집단 vs 분리) | 0.8383 | 0.4990 | +0.34 |
| **Test A 조건 (신규 선박)** | **0.5789** | 0.4990 | **+0.08** |

단일정답 분류에서 Micro-F1 = 정확도이므로 지표 단위는 맞다. 다만 **선박 구성·기간·분할·사용 가능한 과거 정보량이 달라 직접 대조는 여전히 불가**하다.

→ **"팀원 쪽이 압도적"이라는 인상은 성립하지 않는다.** 실제 격차는 0.34가 아니라 0.08 수준이며, 그마저도 조건이 다르다.
