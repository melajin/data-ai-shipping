### S1 — 특징공간 중복도에서 오는 원리적 바닥 (Bayes 오차 추정)

**묻는 것:** 특징이 똑같은데 업종이 다른 배가 얼마나 있나.
그런 배는 **어떤 모델로도** 구분할 수 없다.

**방법**
1. 특징 = F156 + T5 (현재 모델 입력과 같음). FIT 중앙값 대체 → FIT 기준 표준화.
2. 두 공간에서 각각 한다:
   - (a) 원본 166차원
   - (b) FIT에서 적합한 PCA로 분산 95% 유지한 축소 공간
     (고차원에서 유클리드 거리가 무의미해지는 것을 보정하기 위한 대조군)
3. 각 OUTER 선박에 대해 **같은 fold의 FIT 선박 중** k-최근접을 찾는다. k ∈ {1, 3, 5, 10, 20}.
   거리 유클리드. OUTER끼리는 이웃으로 쓰지 않는다.
4. 다음을 낸다.
   - `e_1NN` = 1-최근접 이웃의 라벨이 다른 비율 (전체 / 업종별)
   - `e_kNN` = k-최근접 다수결이 틀린 비율
   - 이웃 k개가 **전원 다른 업종**인 비율 (= 구조적으로 가망 없는 배)
   - 이웃 k개의 라벨 엔트로피 분포
5. **Bayes 오차 하한 추정.** Cover–Hart 부등식 (M=4 클래스):

   ```
   e* ≤ e_1NN ≤ e* · (2 − M·e*/(M−1))
   ```

   오른쪽 부등식을 `e*`에 대해 수치해로 풀어 **e*의 하한**을 얻는다
   (`scipy.optimize.brentq`, 구간 [0, (M−1)/M]).
   표본 1-NN 추정의 불확실성은 부트스트랩 5,000회로 구간을 낸다.
6. **macro-F1 상한으로 환산.** 업종별 Bayes 오차 하한 `e*_c`를 그대로
   "그 업종에서 원리적으로 틀릴 수밖에 없는 비율"로 보고, 나머지를 전부 맞히는
   가장 유리한 혼동 구조를 가정해 업종별 F1 상한과 macro 평균을 낸다.
   **환산 가정을 json에 문장으로 적는다** — 이 환산은 느슨하다(진짜 상한보다 높게 나온다).

**한계로 반드시 적을 것:** 유클리드 거리는 "특징이 같다"의 한 정의일 뿐이다.
모델이 쓰는 거리는 다르다. 이 값은 **느슨한 상한**이다.

### S2 — 판정 규칙 오라클: 확률은 그대로, 임계값만 완벽하게

**묻는 것:** 지금 확률을 하나도 안 바꾸고, 네 업종 배수만 정답 보고 맞추면 얼마인가.
이게 **후처리만으로 가능한 최대**다.

**방법**
1. `08_probs.npz`의 `outer_L_base`를 쓴다.
2. 배수 벡터 `c = (1.0, c1, c2, c3)` (c0는 1로 고정 — 스케일 자유도 제거).
   판정 = `(P * c).argmax(1)`.
3. `c1, c2, c3`를 **OUTER 정답으로 직접** macro-F1 최대화.
   좌표하강, 격자 `0.2 ~ 5.0`을 로그 등간격 40점, 6라운드 또는 수렴까지.
4. 같은 절차를 micro-F1(정확도)로도 한 번 더 한다.
5. 비교 대상 세 개를 한 표에:
   - 현재 방식 (통발 배수만, INNER에서 선택) — 오늘 값 0.53185
   - 4차원 배수, INNER에서 선택 — **이건 오라클 아님. 실제 채택 후보다.**
   - 4차원 배수, OUTER 오라클 — 상한

**이 실험이 바로 쓸모 있는 이유:** 가운데 줄(INNER에서 4차원 배수 선택)이
기존 기준을 넘으면 그대로 채택할 수 있다. 상한과 실현값의 간격이
"판정 규칙을 더 정교하게 해서 얻을 수 있는 여지"다.

### S3 — 확률 보정 오라클: 순위는 그대로, 값만 완벽하게

**묻는 것:** 확률이 매기는 **순서**는 그대로 두고 값만 완벽히 보정하면 얼마인가.

**방법**
1. 업종 c마다 1-vs-rest로 보고, `P[:, c]`에 대해
   `sklearn.isotonic.IsotonicRegression(out_of_bounds="clip")`을
   **OUTER 라벨로 직접** 적합한다(오라클).
2. 보정된 네 값을 행 합 1로 정규화하고 argmax.
3. macro-F1 / micro-F1을 낸다.
4. 대조군: 같은 isotonic을 INNER에서 적합해 OUTER에 적용한 값(= 실제 채택 가능).

**해석:** S3와 S2의 차이가 "확률값의 모양을 고쳐서 얻는 몫",
S3와 1.0의 차이가 "순위 자체가 틀려서 못 고치는 몫"이다.

### S4 — 모델 선택 오라클: 여러 모델 중 맞는 걸 고를 수 있다면

**묻는 것:** 우리가 가진 모델들이 **서로 다른 배를 틀린다**는 것은 이미 확인했다
(014: 모델은 맞고 이웃은 틀린 배 840척, 반대 706척).
선박마다 맞는 모델을 고를 수 있다면 어디까지 가나.

**방법**
1. 후보 6개의 OUTER 확률을 모은다:
   `L_base, M_base, E_base, L_b69, K_base` (`08_probs.npz`) +
   `TabICL_A` (`T\evaluation\seed_42\...` 와 `seed_2026\...` 평균).
   **TabICL A의 행 순서를 fold·rfid_id로 정렬해 08의 OUTER 순서와 맞춘다.
   정렬 후 `y_true`가 전부 일치하는지 assert.**
2. **오라클 1 (모델 선택):** 선박마다 "맞힌 모델이 하나라도 있으면 정답"으로 처리한
   가상의 예측을 만들고 macro-F1·micro-F1을 낸다. 이게 가장 느슨한 상한.
3. **오라클 2 (가중합):** 6개 확률의 가중합 가중치를 **OUTER에서 직접** 최적화
   (좌표하강, 격자 0~1 0.05 간격, 배수도 함께).
4. **실현값 대조:** 같은 가중치를 INNER에서 고른 값 (오늘 `08`의 전체가중합 0.54307).
5. 몇 개 모델이 맞혔는지 분포도 낸다 (0개/1개/…/6개 맞힌 선박 수).
   **6개 모두 틀린 선박**이 핵심이다 — 그게 현재 모델군이 못 닿는 영역이다.

### S5 — 모델 용량 상한 (참고용)

**묻는 것:** 모델이 학습 데이터조차 못 맞히는가, 아니면 외우고도 일반화를 못 하는가.

**방법**
1. 각 fold에서 FIT으로 학습한 LightGBM으로 **FIT 자신**을 예측한다.
2. FIT macro-F1과 OUTER macro-F1의 차이를 낸다.

**해석:** FIT도 낮으면 모델 용량 부족(더 큰 모델로 해결 가능),
FIT은 높은데 OUTER가 낮으면 과적합/정보 부족.
**이 값은 상한이 아니다. 진단용이다.** 표에서 분리해 적는다.

3. 시드 5개(42, 2026, 7, 1, 2024) 확률 평균.
4. 통발 배수는 INNER에서 선택. OUTER 한 번 평가.
5. 기존 기준으로 판정한다(Δ≥+0.005 and 95% 하한 > 0). **넘으면 채택 후보다.**

### S7 — 같은 배의 두 기간이 같은 업종으로 보이는가 (데이터 안정성 바닥)

모델이 같은 답을 내는가? 못 낸다면 그 불일치가 **데이터 자체의 흔들림**이고,
어떤 모델도 그 아래로 못 내려간다.

**방법**
1. `H`(시간별 집계)에서 2026 선박마다 관측 구간을 **1~3월 / 4~6월**로 나눈다.
2. 각 반쪽에서 B69를 다시 만든다
   (`code/01_build_behavior_features_20261104.py`의 `build()`를 날짜 구간 인자로 호출.
   `--truncations`와는 다른 구간 정의이므로 함수에 `date_range` 인자를 추가해도 된다.
   추가하면 기존 호출 결과가 바뀌지 않는지 확인하고 보고한다).
3. 양쪽 반에 각각 **관측 7일 이상** 있는 선박만 쓴다. 쓴 척수를 보고한다.
4. fold의 FIT으로 학습한 **B69 전용** 모델(오늘 `06`의 N1과 같은 설정)로
   OUTER 선박의 전반기 벡터와 후반기 벡터를 각각 예측한다.
5. 낸다:
   - 두 예측이 **같은 업종**인 비율 (전체 / 업종별 / 관측일수 구간별)
   - 전반기만 맞은 / 후반기만 맞은 / 둘 다 맞은 / 둘 다 틀린 비율
   - 두 반쪽 B69 벡터의 코사인 유사도 분포

**해석:** "둘 다 맞은" 비율이 상한의 현실적 근사다.
같은 배조차 기간이 바뀌면 다르게 보인다면, 그 흔들림이 성능 천장을 만든다.

**한계:** B69만으로 하는 측정이라 F156을 쓰는 본 모델보다 약하다.
이 수치는 **F156을 포함한 본 모델의 상한이 아니다.** 방향만 읽는다.
(F156은 원본 CSV가 이 PC에 없어 구간별 재계산이 불가능하다 — 지시 003이 막힌 것과 같은 이유.)

### S8 — 업종 하나를 완벽히 맞히면 macro-F1이 얼마나 오르나

**묻는 것:** 남은 힘을 어느 업종에 써야 가장 이득인가.

**방법**
1. 기준 예측 = 오늘의 `08` 전체가중합 OUTER 예측.
2. 업종 c ∈ {연안복합, 자망, 통발, 채낚기} 각각에 대해:
   "실제가 c인 배는 전부 c로 맞히고, 실제가 c가 아닌데 c로 예측한 배는
   전부 올바른 업종으로 고친다"고 가정한 예측을 만들고 macro-F1·micro-F1을 낸다.
3. 쌍 단위로도 한다: 어려운 세 쌍 (연안복합-자망, 연안복합-통발, 자망-통발) 중
   한 쌍만 완벽히 갈린다고 가정했을 때의 값.
4. 채낚기 126척의 표본 크기 영향도 낸다: 채낚기 F1을 ±0.05 흔들었을 때
   macro-F1이 얼마나 움직이는지 (macro 평균이 소수 업종에 얼마나 민감한지).

**이 실험이 중요한 이유:** macro-F1은 네 업종을 같은 무게로 센다.
126척짜리 채낚기가 2,920척짜리 연안복합과 같은 1/4 무게다.
**"어디를 고쳐야 macro가 오르나"와 "어디를 고쳐야 micro가 오르나"가 다를 수 있으며, 공식 채점은 macro-F1이다.** 둘의 거동 차이를 분석하기 위해 같은 표에 나란히 둔다.
