## 핵심 발견 — 확정 사실과 추론 구별

1. 네 목적을 분리해야 한다: 신규 선박 4어업 분류, 시기 간 선박 매칭, 시간 구간 이상 점수, S0 합성 학습용 시연. 부분선을 임의로 잇거나 좌표별 시각 없이 실제 속력·가속도를 계산하지 않는다.
2. FIT/INNER/OUTER 3fold에서 INNER를 전 fold 통합해 weight/혼합비를 고르면 다른 fold OUTER의 라벨이 선택에 들어간다. 5897 개발 선박 중 INNER 합집합 2121, 각 OUTER와 교집합 699/716/706. baseline .53185도 함께 재평가해야 한다. .54307/.54524/.54843은 저장된 탐색 결과이며 누출 영향의 크기는 아직 측정하지 않았다.
3. S4 INNER TabICL 확률이 같은 fold의 inner_predictions가 아니라 전역 OUTER OOF에서 ID로 조회된다. 라벨 일치는 모델 학습 계보 일치의 증거가 아니다.
4. S6 통과 조건에 기존 1–7일 하위집단 비열화 조건이 빠졌다. .55538은 이론적 상한이 아니라 제한된 모델군·반복 평가에서 얻은 사후 결과다.
5. 실제 저장소 Test A/B 최소 구현은 완료됐다. Test B 사고167건 ±1h/5km 매칭0으로 실제 사고 탐지 성능은 검증되지 않았다. 대상 제외·참조 연도·density 변환 설명/코드 불일치 추가 확인이 필요하다.
6. 016 T5 v4는 결측만 2025로 메운 부분 수정이다. TestA100의 source는 train_period87/test_period_gapfill11/none2. 기존 87척은 2026 조회값 유지. 전면 수정이라고 쓰지 않는다.
7. 현재 018 제출 후보 CSV/XLSX는 실제 존재하며 보고서 해시와 일치한다. 코드가 공식 micro-F1을 가정해 w=1을 사용하지만 최신 내부 문서는 macro 유지라고 한다. **018 w=1 고정 자체를 S6 macro 전역 weight 선택 누출과 동일시하지 않는다.** 모델 구조 선택·반복 OUTER 노출·전처리 범위 문제는 별도다. 공식 산식 원문 확인이 우선.
8. 018 특징 실제304 vs S6 보고305, 추론 모델 미저장/삭제, 검증 all_ok 실패 시 중단 여부, 확률 보존 등 재현성 점검이 남았다. 외부 제출 승인·수신 여부는 확인하지 않았다.
