## 2. 원 논문 수치를 현 과제 성능으로 옮기면 안 됨

`E/(참고 논문) 선박종류 분류 모델 개발.txt:1063–1079`는 2018년 AIS로 격자 통계 DB를 구축하고 위도 34–35°N·경도 126–127°E를 분석 범위로 서술한다. `:1188–1215`의 평가는 2019년 6월 1–4일 3,054척이며 **화물선·여객선·기타선·어선** 분류다. 보고값은 각 96.5%·83.9%·66.7%·76.1%, 전체 평균 정확도 86.7%다. 이 86.7%는 현재 자망·통발·연안복합·채낚기연승낚시의 4종 Macro-F1이 아니다. 수치만으로 집계 공식을 추가 추정하지 않았다. 혼동행렬 그림 세부는 이번 텍스트 독해로 검증하지 않았다.

논문 `:1230–1235`는 속력·회두율 수준 조합을 쓰고, `:1311–1324`는 **어선 세부 업종 딥러닝 분류를 후속 연구**로 남긴다. 따라서 격자 통계라는 설계 아이디어의 근거는 되지만, 현재 시각 없는 WKT에 원 논문 입력을 재현했다고 하거나 현 어구 성능 상한·목표값으로 쓰면 안 된다. 실제 AIS 속력·회두율 입력과 현재 도형 기반 특징은 구분해야 한다.

GIST도 같은 경계가 있다. `E/04_어선항적_모델선정_4안건_통합보고서.txt:188–205`는 원 연구의 SOG·방향변화 이미지, 특정 3어구, 128분 입력과 현재 WKT 형상 수정안을 구분한다. `E/조업형태_분류_알고리즘_추천.txt:93–95`의 97%는 원 연구 보고값이고 분할 방식도 확인하지 못했다고 적었다. 현 작은 CNN·다중 축척 이미지의 개선 결과가 아니다.

## 3. 혼합 계수의 방향이 문서 사이에서 바뀜

`E/03_NeurIPS_근거기반_혼합알고리즘_선정가이드.txt:479–482`는 `p=(1−α)p_RealMLP+αp_tree`, 즉 α가 **트리 비중**이다. `E/04_어선항적_모델선정_4안건_통합보고서.txt:224–226`는 `p=αp_neural+(1−α)p_tree`, 즉 α가 **신경망 비중**이다. 각 수식은 자체로 가능하나 문서 간 설정값을 그대로 이식하면 α=0.25와 0.75의 의미가 반대다. 같은 클래스 순서뿐 아니라 `neural_weight`, `tree_weight`의 의미와 양 끝 단독 모델을 기록해야 한다. 0.5에서는 이 오류가 가려진다. 이번 독해만으로 현 코드에 같은 오류가 있다고 단정하지 않았다.

## 4. 최초 제안서와 후보 추천은 실행 결과가 아님

OOF라는 이름만으로 전처리·모델·혼합비 선택까지 독립임이 보장되지는 않는다. 최신 pooled INNER 문제는 부모·Astra의 별도 실행 증거를 따라 판단하며 이 초기 문서가 그것을 면제하지 않는다.
