# 2026-11-04 전체 문서 검토 범위와 실행 근거

사용자 요청: 프로젝트 문서를 모두 읽고 전체 구조와 지금 해야 할 절차를 판단한다. 이번 작업은 읽기·분석과 새 검토 문서 작성이다. 기존 실험 문서, 모델, 제출물은 변경하지 않았고 재학습·외부 데이터 다운로드·기관 연락은 수행하지 않았다.

**문서 인벤토리**

`document_inventory.json`은 최초 목록의 321개 파일을 경로·바이트·SHA-256으로 기록한다. Markdown 267개, TXT 31개, PDF 17개, TOML 6개다. 가상환경, 설치 라이브러리, Git 내부, 코드 스냅샷, NotebookLM용 코드/JSON 텍스트 사본은 제외했다. 원자료 CSV·Parquet·모델 바이너리는 문서 전수 읽기 대상이 아니며 필요한 검증 자료만 별도 확인한다.

사용자가 후속으로 지정한 `D:/repos`에는 `fishing-track-classification` 저장소가 있다. `repo_document_inventory.json`은 그 안의 문서·설정 252경로를 기록하며, 216경로는 앞선 인벤토리와 바이트 해시가 같고 36경로는 새 내용 또는 차이가 있다. 중복은 원문 읽기에 연결하고 신규·변경 본문은 부모와 Astra가 추가로 읽었다. 두 위치 합계 573경로는 고유 문서 수와 다르다. 저장소의 README·ROLES도 읽었으며 마감 확인은 사용자가 닫은 항목, 이 검토는 GPT 의견 구역의 분석으로 취급한다.

추가로 참가신청서 HWP 1개에서 문단 본문을 추출했고, 과제·데이터·문제개요·평가기준 공지 PNG 4개를 직접 읽었다. HWP의 표·제어코드 일부는 텍스트 추출에서 장식 문자로 남으므로 원본 레이아웃을 재현했다고 주장하지 않는다. PDF는 저장된 추출문과 대응해 읽으며 PDF 그림 전체의 시각 검증은 별도 범위다. HTML 대시보드 두 개의 모든 상호작용을 이번에 다시 시험하지 않았다.

위 세 호출은 모두 `fork_turns=none`과 모델·effort를 명시했고 도구가 해당 task_name 생성을 반환했다. 이는 단순 설정파일 존재보다 강한 생성 요청·응답 증거다. 별도 서버 내부 라우팅이나 결제 상태를 조회했다는 뜻은 아니다. 부모 세션 모델을 변경했다고 주장하지 않는다. `.codex/config.toml`의 저장 기본값은 Astra high다.

역할별 결과와 완독 경로는 이 폴더의 `*_review.md`, `*_read_paths.json`에 보존한다. 동일한 SHA의 사본 또는 문서 간 완전 동일 행은 최초 읽은 본문에 대응시켜 중복 읽기를 줄였다. 요약문만 읽고 원문 전체를 읽었다고 처리하지 않는다.

**외부 확인**

- 2026-11-04 공식 문제 페이지를 열어 현재 배포 표시 `문제 데이터_수정_1103_v2.zip`과 표시 크기 `1398158.8 Kbyte`를 확인했다. ZIP 본문은 다운로드하지 않았으므로 1027판과의 실제 내용 차이는 미확인이다. 마감은 후속 작업의 선행조건이나 미해결 항목으로 두지 않는다. https://aida.kisti.re.kr/competition/main/problem/PROB_000000000004601/detail.do
- 현재 내부 문서의 공식 macro-F1 합의는 유지한다. 이번 공식 페이지 텍스트와 보관 공지 그림에서는 macro-F1 산식 원문을 독립적으로 확인하지 못했다. 기관 회신이나 공식 평가 명세를 근거 묶음에 보존할 필요가 있다.
- 모델 식별자 `gpt-6-astra`의 공식 문서를 확인했다. 계정의 Pro 구독과 이번 부모 모델의 실제 선택 여부를 이 문서로 판정하지 않는다. https://developers.openai.com/api/docs/models/gpt-6-astra
- 선택과 평가 자료를 분리하는 교차검증의 원칙은 scikit-learn 공식 설명을 대조했다. 프로젝트의 누출 판정은 일반론만이 아니라 실제 코드와 역할표 교집합에 근거한다. https://scikit-learn.org/stable/auto_examples/model_selection/plot_nested_cross_validation_iris.html
