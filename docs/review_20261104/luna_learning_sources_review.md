# 학습자료·기준 문서 검토

## 검토 요약

프로젝트에는 서로 다른 목적의 세 층이 있다. 공통 AI 교재 1–18장은 넓은 분야의 개념·수학·평가 참고서이고, 녹조 적용편 19–25장은 세포수 시계열 회귀를 위한 별도 학습 경로다. 어선 적용편 19–26장과 프로젝트 안내서는 항적 분류·이상 분석으로 이어지며, 이 가운데 실제 구현 근거가 있는 것은 합성 자료만 쓰는 S0 개인 학습 시스템이다. 녹조와 어선 적용편은 장 번호가 겹치므로 파일명까지 포함해 인용해야 한다.

현재의 실제 과제 적합성은 아직 판단할 수 없다. 대회 제안서의 TabM, RealMLP, LightGBM, DTE, CNN/GIST, Transformer 조합은 후보·연구 제안이다. S0의 숫자는 합성 생성기에서 나온 수치다. 10행 샘플 CSV는 구조 점검 자료이며 정식 학습·최종 평가 자료가 아니다. 실제 항적에서 성능을 측정했다거나 사고를 예측한다고 말할 근거는 이 범위에서 확인되지 않았다.

## 교육과 제품 구조

### 공통 AI 교재

[`모델 해석 목차`](../ai_textbook/모델%20해석%20목차.md)는 문제·데이터부터 수학, 확률, 계산, 기호 AI, 학습 패러다임, 신경망·생성·강화학습·언어·멀티모달·구조화 모델·인과·시스템·평가까지 18개 공통 장으로 안내한다. [`92_sources`](../ai_textbook/92_sources.md), [`93_glossary`](../ai_textbook/93_glossary.md), [`90_solutions`](../ai_textbook/90_solutions.md), [`91_model_cases`](../ai_textbook/91_model_cases.md)는 참고자료, 용어, 문제 해설과 공개 사례를 지원한다. 교재는 알고리즘 목록이라기보다 각 방법의 가정·입력·평가 조건을 확인하라는 공통 학습 바탕이다.

### 녹조 적용편

[`algae_learning_path`](../ai_textbook/algae_learning_path.md), 녹조 장 19–25 및 [`algae_prediction_system`](../algae_prediction_system.md)은 남조류 세포수(cells/mL)를 예측하는 별도 시계열 회귀 과정을 제안한다. 작은 흐름은 제공자료·측정시점·값의 가용시각 점검 → persistence 기준선 → 상태·환경 입력의 단계적 비교 → 시간순 평가다. 로그 변환, 불규칙 관측, 결측과 공개 지연, 구간 예측은 학습 주제이며, 교재의 가상 계산이 실제 수역 모형 성능을 뜻하지 않는다. 이 자료에는 실제 제공 데이터에 대한 학습·평가 결과가 없다.

### 어선 적용편과 실제 프로젝트

[`95_fishing_guide`](../ai_textbook/95_fishing_guide.md), 어선 장 19–26, [`fishing_sample_system_guide`](../fishing_sample_system_guide.md)는 학습자용 자료다. 19장은 WKT·부분선·좌표계와 기하 특징, 20장은 분류, 21장은 순서·시간, 22장은 이상 점수, 23장은 환경자료의 가용시각과 결합, 24장은 가상 유닛, 25장은 독립 평가·시스템 전달을 다룬다. 26장과 S0 실습서는 실행한 합성 분류·이상 기준 시스템을 교육 목적으로 해설한다.

실제 경진 자료의 흐름은 [`fishing_integration/01`](../fishing_integration/01_과제와_현재상태.md)부터 [`99`](../fishing_integration/99_출처와_통합판단.md), [`통합 검증 기록`](../fishing_integration/통합_검증기록.md), [`샘플 시스템 가이드`](../fishing_sample_system_guide.md), [`기준선 해설`](../fishing_guided_baseline_20261026.md), [`10월 26일 반복 결과`](../fishing_iteration_results_20261026.md)에서 통합된다. 데이터 적합성 관문과 S0 합성 실험은 별도 트랙이다. S0 실행은 실제 데이터 사용 승인이나 F1 적합성 통과를 뜻하지 않는다.

## 현행 시스템과 근거 수준

### 실제로 기록된 자료 확인

[`docs/competition_20261019/01`](../competition_20261019/01_데이터구조와_직접집계.md) 및 후속 기록은 샘플 CSV 10행·10척·16개 부분선·246개 좌표점을 집계한다. 부분선 내부의 이웃 점 230쌍 중 동일좌표 반복은 158쌍(68.7%)으로 집계되었다. 이 파일은 샘플의 구조를 설명할 뿐 전체 학습자료의 대표성은 입증하지 않는다. 기록된 검사기 v1.1은 빈 헤더 때문에 종료 코드 1을 냈고 WKT의 의미적 기하 적합성을 검증하지 않았다. 별도 구조·WKT 제한 검사는 통과한 것으로 문서화되어 있다.

Sol의 추출문 완독·독립 재계산 메모에 따르면, 초기 이해 가이드의 균등 간격 속도 계산과 부분선 사이 임의 연결 예시는 후속 자료 계약과 맞지 않는다. 원 CSV에서 샘플 3행의 부분선 내부 길이는 85.0145m이고, 연결 처리 시 108.9893m로 23.9748m 늘었다. 5행은 132.5073m에서 149.2077m로 16.7004m 늘었다. 이 차이는 부분선 간에 실제 이동이 있었다는 증거가 아니라, 끊긴 부분선을 연결해 생긴 계산 효과다. 후속 계약과 현재 교재는 부분선을 잇지 않고, 좌표별 시각 없이 속력·가속도를 계산하지 않도록 정리한다.

### S0 합성 학습 시스템

26장 개인 학습 노트와 S0 안내서에 기록된 시스템은 생성기 seed 42의 가상 항적 그룹 84개, 1,008개 레코드, 3개 경로 계열 라벨(직선·쓸기·회전)로 구성된다. 이 라벨은 실제 조업 코드나 사고 라벨이 아니다. 부분선 단위 기하에서 8개 특징과 결측 여부 8개를 만들고, 학습 자료로만 전처리 값을 맞춘다. 그룹이 겹치지 않도록 학습·검증·보정·시험·스트레스 집합을 둔다. 선형 분류기와 16-unit tanh MLP 후보를 비교하고 검증 NLL로 선택한 뒤, 보정 자료에서 온도 보정을 한다. 이상 점수는 분류 결과가 아니라 클래스 공분산 기반 Mahalanobis 거리이며, 검증 점수의 95백분위가 데모 임계값이다.

문서에 기록된 기본 실행의 시험 정확도는 0.8125, macro-F1은 0.8104이고, 스트레스 조건의 정확도는 0.6181, macro-F1은 0.6180이다. 스트레스는 크기·잡음·결측·간격을 함께 바꾸므로 어느 변화가 점수 차이를 만들었는지 분리하지 못한다. 이후 [`10월 26일 반복 결과`](../fishing_iteration_results_20261026.md)는 10개의 새로운 합성 seed에서 shape9 전역 특징 변형의 macro-F1 평균이 기준 대비 정상 조건 +0.0347, shift 조건 +0.1068이었다고 기록한다. shift에서 10회 모두 개선되었지만 생성기 내부 반복의 증거이며 실선 성능 추정은 아니다. 이 문서에 기재된 bootstrap 구간도 해당 합성 반복 단위에만 적용된다.

### 제안과 공개 논문 근거

[`data/reference/…/09_MLP…`](../../data/reference/competition_20261019/2026%20데이터%20분석대회/09_MLP응용_선정판단과_두논문_핵심요약.md), 12·13번 문서와 알고리즘 원리 설명은 논문이나 공식 코드의 주장과 프로젝트 적용 제안을 구분한다. 이 자료에서 TabM, RealMLP, LightGBM은 조업 분류 후보이고 DTE·전역 기준은 이상 점수 후보이며 GIST/CNN·Transformer·TabPack 등은 조건부 확장이다. 이 후보들의 공개 벤치마크 결과를 어선 데이터의 실측 성능으로 옮겨서는 안 된다. 초기 문서와 후속 통합 판단 사이에 상태 표현이 다르면 최신 실행 기록과 실제 산출물에 더 가까운 날짜의 문서를 우선해야 한다.

특히 참고 PDF의 선박 종류 분류 결과 86.7%는 cargo/passenger/fishing/other 네 선종 분류의 수치다. 어구 네 종류의 현재 대회 과제 성능으로 인용하면 잘못이다. 해당 문서는 세부 조업어구 분류를 향후 연구로 둔다. 제안서의 목표·예상 화면, CPU 비용 예상, 85분 예시도 설계안·가상 계산이지 실행 측정값이 아니다.

자료를 읽을 때 다음 증거 수준을 유지해야 한다.

| --- | --- | --- |

## 해결되지 않은 계약과 평가 질문

1. **정식 데이터:** 샘플 10행과 분리된 공식 train/test 원자료의 범위·버전·허용 사용 규칙이 필요하다. CSV 샘플을 학습자료로 간주할 수 없다.
2. **좌표·시간:** WKT의 CRS, 좌표축·단위, 부분선의 의미, 좌표별 시각 및 시간대가 확인되지 않았다. 점 순서만으로 속력·가속도나 시간별 체류를 계산할 수 없다. 부분선을 임의로 이어서는 안 된다.
3. **라벨:** 실제 `fishing_code` 전체 목록과 의미 대응표, 행 단위와 부분선·시간대 단위의 관계가 필요하다. 샘플의 라벨 이름을 실제 코드 정의로 일반화할 수 없다.
4. **평가:** Test A의 공식 제출 단위·metric, 클래스 매크로 방식·후처리 조건, Test B의 사고 양성 정의·사건 시간 창·평가 지연·오경보 집계가 문서에서 확정되지 않았다. macro-F1, AUROC/AP, 선행시간, S0의 95백분위 임계값은 제안 또는 내부 실습 설정이며 공식 채점식이 아니다.
5. **정보 가용시각:** 시간대 항적이 실제 처리에 들어오는 시점, 사고 라벨 가용시점, 환경 관측의 관측·발표·수신·수정 시각을 구분해야 한다. 사후 가용 정보를 조기 경보 입력으로 쓰면 안 된다.
6. **분할·불확실성:** 신규 선박 조건을 보장하는 선박·항차 단위 holdout과 최종 평가 집합, 클래스별 선박 수, 점수 변동을 정해야 한다. 같은 원본의 증강·부분선이 양쪽 분할에 섞이면 안 된다.
7. **학습자 여건:** 학습자 수준, 선수지식, 실습 시간, CPU·GPU·메모리와 설치 환경은 미확인이다. 수식과 모델 선택 난이도를 조절하기 전에 확인이 필요하다.

현재 물리 센서·회로·펌웨어·통신 장치를 만드는 요구는 없다. 선박 위치 장치의 맥락은 소개할 수 있지만, 실제 전압·핀·샘플링 주기나 하드웨어 성능을 가정한 실습은 범위에 없다. 이 프로젝트에서는 문서·코드·합성 자료 분석과 실제 장치 시험을 구별한다.

## 다음 학습 순서

1. **자료 계약과 관찰 가능성:** 행 단위, WKT 구조, 부분선 경계, 단위·CRS·시각·누락을 확인하고, 알고 있는 것·가정·미확인을 표로 나눈다. 학습 환경도 함께 기록한다.
2. **이미 구현한 S0를 학습 대상으로 재현:** 26장과 [`S0 실습서`](../fishing_sample_system_guide.md)를 따라 한 단계씩 설명한다. 생성 라벨이 실제 조업 코드가 아닌 이유, 그룹 분할, 학습 범위 전처리, calibration/test 분리, Mahalanobis 점수와 사고 라벨의 차이를 독립적으로 설명한다. 문서에 적힌 수치를 실제 데이터를 재학습해 얻은 결과로 표현하지 않는다.
3. **실자료 적합성 관문:** 원자료가 확인되면 계약과 표본 품질을 먼저 검사한다. CRS·점별 시각·레이블·사고 연결 정보를 알 수 없으면 해당 기능을 계산하거나 평가하지 않는다.
4. **작은 기준선과 데이터 단위 평가:** 계약이 충족된 입력부터 단순 특징과 기준선으로 시작하고, 선박 단위 분할·학습 전용 변환·독립 시험을 고정한다. 기준 개선 전에는 추가 복잡성을 넣지 않는다.
5. **분류·이상·환경 경로를 별도로 확장:** 조업 분류의 확률, 정상 기준에서의 이상 점수, 외부 환경 입력을 다른 출력으로 유지한다. 공식 라벨·평가 규칙을 확인하고 각 확장을 같은 독립 조건에서 비교한다.
6. **성취 평가:** 코드가 돌아가는지와 학습자가 설계 이유·단위·오류 사례·조건 변경을 스스로 설명하는지 별도로 확인한다. 이번 자료만으로 학습자 성취가 측정된 것은 아니다.

## 읽기 범위·제한

이 보고서는 검토 인벤토리에 명시한 89개 텍스트 경로를 대상으로 한다. 66개는 직접 완독했고, `outputs/competition_20261019`의 20개와 `tmp/pdfs/integration_20261013`의 P1–P3 3개는 Sol이 전문 완독한 뒤 결과를 전달했다. 따라서 총 89개 텍스트 경로의 본문 확인이 끝났다. P1/P2/P3은 각각 이해 가이드·01 통합본·02 전처리 및 모델설계 추출 텍스트와 페이지 표식을 제외한 본문 라인 대조로 대응했다.

워크스페이스에서 PDF 경로 17개를 찾았다. 그중 3개는 다른 디렉터리에 있는 PDF의 SHA-256 완전 사본이라 고유 PDF는 14개다. 17개 경로 모두 대응하는 출력 추출 TXT가 확인되고, 본문은 완독되었다. P1–P3은 각각 이해 가이드·01·02 추출 TXT와 페이지 표식을 제외한 본문 라인 중복으로 확인했다. PDF 페이지 그림·표·레이아웃은 시각적으로 다시 확인하지 않았다. 읽은 전체 파일, 해시와 대응 경로는 [`luna_read_paths.json`](luna_read_paths.json)에 있다.
