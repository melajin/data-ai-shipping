## 채택 전 해결할 평가 문제

### 1. 전역 INNER 선택이 다른 fold의 OUTER 라벨을 사용

외부 실행 코드 `D:/repos/fishing-track-classification/11월 4일/code/08_final_ensemble_20261104.py:169–231`은 fold별 확률을 만든 다음 INNER/OUTER를 각각 합친다. `:255–275`는 합친 INNER로 전역 배수·혼합 비율을 선택하고 `:296`에서는 OUTER 결과로 후보를 정렬한다. 로컬 `26_11_4/work/상한선_011/code/S6_large_capacity_model.py:176–195`도 같은 전역 배수 선택을 한다. S4는 `S4_model_oracle.py:263–268`에 같은 문제가 있다.

읽기 전용 재집계 입력은 `29-30일 모델 심층 분석/31일/팀원자료/TabICLv2_F156_공유자료/splits/development_roles_wide.csv`다. 전체 개발5897척 중 INNER ID 합집합은2121척이다. 이 합집합과 fold별 OUTER 교집합은 다음과 같다.

| OUTER | 전체 | 다른 fold를 통한 전역 INNER 선택 참여 ID |
|---|---:|---:|
| fold0 | 1966 | 699 |
| fold1 | 1966 | 716 |

이는 같은 fold의 FIT 학습에 OUTER를 직접 넣었다는 주장과 다르다. 전역 후처리 파라미터를 고르는 데 평가 선박 일부의 라벨이 다른 fold를 통해 참여한 **선택 분리 위반**이다. 역사 담당 `/root/sol_history`가 코드와 집계를 독립 재확인했다. 각 fold에서 자기 INNER로 선택하고 자기 OUTER에 적용한 뒤 평가를 합쳐야 한다. 기준선도 원래 전역 선택에서 얻은 w=1.5를 계승하므로 0.53185를 새 비교의 무조건 고정 정답으로 취급하면 안 된다. S6 코드:200–207은 이 기존 w=1.5 기준선을 하드코딩해 비교한다.

반복 OUTER 결과로 다음 실험 설계와 최종 후보를 정한 적응적 선택은 별도 한계다. fold별 직접 선택을 고쳐도 누적된 OUTER 노출 이력은 사라지지 않는다. 고정 예측의 부트스트랩 CI는 이러한 선택 편향까지 교정하지 않는다.
