이 프로젝트는 어선의 이동 경로에서 조업 형태와 평소와 다른 움직임을 분석하고, 그 판단 근거를 사람이 이해할 수 있게 보여주는 시스템을 만드는 데 목적이 있다. [해양경찰청 주관 대회](https://aida.kisti.re.kr/competition/main/problem/PROB_000000000004601/detail.do)의 요구는 조업 형태 분류와 시간대별 이상점수 산출이며, 이를 하나의 판단 모델에서 처리하고 시뮬레이터·3차원 뷰어와 연결하는 것은 프로젝트의 확장 계획이다. 전체 흐름은 실제 항적 입력 → 자료 점검·정리 → 경로 특징 추출 → 조업 분류·이상점수 출력 → 경로와 판단 근거 표시로 구성할 예정이다. 가상 경로도 같은 분석 흐름에 넣어 조건에 따른 결과 변화를 비교하려 한다.

공식 설명상 한 행은 선박·날짜·시간대 단위의 항적이다. 날짜(`part_dt`, YYYYMMDD), 선박 식별자(`rfid_id`), 시간대(`rfid_time`, 0~23), 경로(`geom`), 학습용 조업 라벨(`fishing_code`)이 주요 항목이다. 경로는 여러 선 묶음을 좌표로 표현하는 WKT MultiLineString 형식이며, 좌표 순서는 경도·위도다. Train은 조업 라벨을 이용한 학습에, Test A는 주로 새로운 선박의 조업 분류 평가에, Test B는 사고 정보가 숨겨진 상태에서 이상점수와 사고 전후 변화·조기 탐지 평가에 쓰인다. 현재 원자료는 확보 전이므로 실제 파일 구성·행 수·라벨 분포와 설명의 일치 여부를 확인해야 한다.

자료를 받으면 원본을 보존하면서 결측·중복·잘못된 좌표를 점검하고, 확인된 좌표계와 경로 순서를 바탕으로 부분선별 길이·방향 변화·공간 범위를 계산할 계획이다. 끊어진 선 사이를 임의로 잇지 않으며, 좌표별 시각이 확인되지 않으면 실제 속력·가속도는 계산하지 않는다. 조업 라벨은 분류 학습에, 학습 자료에서 추정한 평상시 경로 특징은 이상점수의 기준에 활용한다. 제공되는 사고 식별자와 시각은 사건 전후 평가에 사용하되 판단 시점 이후 정보가 입력에 섞이지 않게 한다. 새 선박에 대한 적용은 선박을 분리해 검증하고, 원본·정리된 자료·경로 특징·합성자료·예측 결과는 출처와 선박·날짜·시간대 정보를 유지해 구분할 예정이다.

외부 데이터는 [기상청 해양기상부이](https://data.kma.go.kr/data/sea/selectBuoyRltmList.do?pgmNo=52)의 바람·파고와 [국립해양조사원 해양관측부이](https://www.data.go.kr/data/15155516/openapi.do)의 바닷물 흐름 방향·세기를 우선 후보로 검토한다. 항적의 위치·시간대와 결합해 경로 변화의 배경을 설명하고, 가상 선박의 환경 조건을 설정하는 데 활용하려 한다. 실제 도입은 해당 해역·기간의 과거자료 가용성, 관측 간격·단위·시간대, 이용 규칙과 대회의 외부자료 허용 조건을 확인한 뒤 결정한다. 관측소 자료가 선박 위치의 환경을 정확히 나타낸다고 가정하지 않으며, 조기 탐지 실험에는 판단 당시 이용할 수 있었던 자료만 사용한다.

가상 유닛은 목적과 상태 변화 규칙을 가진 가상 선박으로 제작할 계획이다. 먼저 실제 학습 항적에서 조업별 경로 특징을 정리한 뒤, 이동·조업·귀항 등의 상태와 전환 조건을 정한다. 상태에 따라 다음 위치를 생성하고 환경 입력에 따른 경로 변화 가정을 더하되, 시뮬레이션 시간은 실제 관측 시각과 구분한다. 경로 굴곡과 이동 범위 등의 변화량을 낮음·중간·높음으로 조절하고, 생성 조건과 난수 시작값을 기록해 같은 실험을 재현한다. 생성 경로는 실제자료와 구분해 표시하고 특징 분포를 비교하며, 변형 후에도 조업 라벨의 의미가 유지되는지 검토한다. 합성자료는 우선 실험·설명에 쓰고 모델의 실제 성능은 분리된 실제자료로 평가한다. 시뮬레이터와 뷰어에서는 환경·활동·변동 수준을 바꿔 판단 결과를 관찰하도록 한다. 높은 변동이나 이상점수는 사고의 확정 판정이 아니다. 원자료 확보와 별도 승인을 기다리는 후속 범위인 모델 학습·가상 유닛·시뮬레이터·뷰어는 아직 구현하지 않았다.
