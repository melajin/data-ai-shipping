# Shape9 모델 비판 검증과 반례 — 2026-10-27

대상은 `shape9_mlp_d9101_i42.json` 한 개의 저장 모델과 해당 합성 생성 자료다. 최종 10개 생성 seed 전체의 특성을 한 모델에서 단정하지 않는다. 실제 선박·실제 사고 성능도 아니다.

## 사용자 비판 중 실증적으로 맞는 부분

### 학습이 400 epoch 한도에서 끝났다

저장 이력에서 train NLL은 1.006129→0.299169, validation NLL은 1.010059→0.365201로 내려갔다. 두 값 모두 399번의 연속 변화에서 반등이 없다. 선택 epoch는 400이며 patience=35에 의한 종료가 아니라 epoch 한도 도달이다. 마지막 validation NLL 변화는 약 −0.0002068, 전체 train gradient의 L2 norm은 약 0.092995다. 이 실행에서 학습이 제한된 지점에서 끝났다는 것은 확인된다.

다만 **전역적으로 미수렴했다**, **과소적합이다**, **최적 epoch가 400보다 크다**는 결론은 이 이력만으로 확정할 수 없다. 더 긴 학습의 validation·새 조건 결과, 다른 초기화, 모델 용량과 정규화를 비교해야 한다. 학습을 오래 한다는 사실이 일반화 개선을 보장하지도 않는다.

### 결측 표시의 미학습 가중치는 실제 위험 가설이다

기하 특징 9개와 결측 표시 9개가 입력이다. 해당 생성 seed의 train 432건, validation/calibration/test/stress 각 144건에서 **9개 특징 모두 결측 0건**이었다. `all_missing=false`는 “전부 결측은 아니다”라는 뜻이며, 그 값만으로 결측이 한 건도 없다고 판단할 수 없다. 이번 0건은 원본 합성 데이터에서 별도로 계산한 수치다.

마스크 입력이 항상 0이므로 그 9×16개 연결 가중치의 데이터 gradient는 0이다. 이 모델은 L2=0이어서 해당 가중치가 초기화값과 비트 단위로 동일하다. 이는 **기록된 결측 없는 입력에서 예측에 기여하지 않는다.** “이미 미세 노이즈에 과적합되어 예측을 오염시켰다”는 것은 관찰되지 않았다.

대신 특성 하나를 인위적으로 NaN으로 바꿔 train 중앙값 대치와 해당 mask=1을 적용하면, 같은 대치 입력에서 해당 mask 가중치만 0으로 둔 반사실적 계산과 예측이 달라질 수 있다. 432개 train 표본을 각 특징에 하나씩 적용한 결과 예측 클래스 변화 수는 특징 순서대로 `[13, 21, 37, 8, 5, 26, 52, 16, 7]`건이고, 가장 큰 확률 차이는 약 0.4673이다.

이는 **학습에서 관측되지 않은 mask 채널의 입력 개입 실험**이다. 실제 결측 사례의 발생률·실제 오분류율이나 현실적 결측 패턴을 측정한 것은 아니다. 실제 경로에서 그 특정 특징만 빠지는 것이 가능한지도 별도 확인이 필요하다. L2는 0입력 채널의 가중치를 줄일 수 있지만, 0/1 채널의 실제 결측 의미를 학습했다는 보증은 아니다. 미관측 결측은 원인·대치·입력 적합성을 확인하고 필요하면 추론을 유보하는 설계가 필요하다.

예를 들어 데이터 gradient가 계속 0이고 학습률이 0.03인 full-batch GD에서, L2=0.01을 1200회 적용한 가중치는 초기값의 `(1−0.03×0.01)^1200 ≈ 0.6976`배다. L2=0.001이면 약 0.9646배다. 이는 중간에 학습이 멈추지 않았을 때의 계산 예로, **L2를 켰다고 미관측 mask 가중치가 곧바로 0이 되는 것은 아니다.**

### 시각과 실제자료에 대한 한계는 타당하다

이 모델의 대상은 straight/sweep/turn **합성 생성 경로 유형**이다. 실제 fishing_code나 사고 정답이 아니다. 실제 샘플은 구조를 10행 확인했으나 점별 시각·정확한 CRS·라벨 단위와 정식 평가 계약이 미확정이다. 이 상태에서 실제 속력·가속도·체류시간 계산이나 현장 성능을 주장할 수 없다.

사용자가 제안한 속력 평균·분산과 시간 간격은 [별도 합성 시각 모듈](../fishing_demo/synthetic_temporal_features.py)로 구현했다. 생성기의 가상 초 단위 시간과 같은 부분선 안의 인접 점만 사용한다. 시각을 2배로 바꾸면 간격은 2배, 합성 속력은 절반, 속력 분산은 1/4로 바뀌는 것과 부분선을 연결하지 않는 것을 테스트했다. 실제 선박의 관측시간이나 실제 속력으로 부르지 않는다.

현재 생성기는 각 항적마다 단일 가상 시간 간격을 뽑고, 점마다 이 간격을 곱한 시각을 부여한다. 클래스별 정지·가감속·체류 패턴은 생성하지 않는다. 따라서 이 합성 시간 실험의 결과가 실제 동역학 정보의 가치를 증명하지는 않는다. 같은 간격에서는 속력 평균·분산이 각각 보폭 평균·분산을 시간 간격과 그 제곱으로 나눈 값이므로, 시간 후보와 **보폭 특징만 추가한 대조군**을 함께 비교한다.

별도로 보고된 조건 변화 정확도 67.71%는 기존 최종 **10개 생성 seed × 2개 초기화, 20회 실행의 평균**이다. 이 감사의 단일 모델(seed 9101, 초기화 42)은 조건 변화 정확도 68.75%다. 다만 현장 합격 기준·오류비용·실제자료 평가가 정해지지 않았으므로 이 숫자 하나만으로 모든 실제 용도의 보편적 합격/불합격 기준을 산출할 수는 없다. 현재 모델의 실용성은 **미검증**이다.

## 수정이 필요한 주장

### 학습 데이터는 60건이 아니다

대상 실행은 합성 선박 36그룹×3클래스×4경로 = **432 train 레코드**를 사용했다. 60은 다른 seed의 개발 train 항적에서 특징 민감도를 검사한 짝 실험 표본 수다. 두 숫자를 혼동해 “학습 표본 60개보다 파라미터 355개가 많다”고 결론낼 수 없다.

파라미터 355개 계산 자체 `(18×16)+16+(16×3)+3`은 맞다. 이 중 결측 마스크 연결은 144개이며, 대상 train에서 모두 0인 입력에 연결돼 데이터 gradient가 0이다. 경로가 같은 선박 그룹에 속할 수 있어 432행을 무조건 독립 표본 432개로 간주해서도 안 된다. 행 수 대 가중치 수의 비율 하나만으로 과적합·MLP 부적합을 증명할 수 없다.

### T가 1보다 작다는 사실은 원인을 식별하지 않는다

T=0.7079458은 별도 calibration 분할의 NLL로 정한 값이다. 같은 양의 T로 모든 logit을 나누면 최댓값의 클래스 순서는 유지된다. 해당 실행의 보정 전→후 NLL은 다음과 같다.

| 합성 분할 | NLL 보정 전 | NLL 보정 후 |
| --- | ---: | ---: |
| calibration | 0.357145 | 0.336594 |
| test | 0.292127 | 0.255712 |
| stress | 0.740719 | 0.830287 |

일반 test에서는 개선됐지만 조건 변화 stress에서는 악화했다. 이는 보정 효과가 자료 조건에 따라 다를 수 있다는 중요한 관찰이다. **T<1이 학습 미완료 때문에 생겼다는 인과관계는 확인되지 않았다.** Temperature scaling의 계산과 log-loss 기반 보정은 [scikit-learn 확률 보정 설명](https://scikit-learn.org/stable/modules/calibration)에서 확인할 수 있다. NLL 개선 하나만으로 모든 보정 품질이나 현장 적용성을 보증하지 않는다.

### 다른 모델의 우위는 아직 가설이다

기존 반복 실행은 original8·shape7·shape9·shape15의 MLP 비교였고, ExtraTrees는 설정만 등록된 채 실행되지 않았다. 앞선 별도 선형 모델은 8특징 기준이어서 현재 9특징 MLP와 직접 공정 비교가 아니다. 선형이나 트리가 더 빠르거나 정확하다는 주장은 동일 특징·데이터·검증 조건의 실행으로 확인해야 한다.

실험 설계에 여러 분리·잠금·seed 단위 비교가 적용된 것은 장점이다. 그렇지만 하나의 합성 생성기와 조건에만 국한되고, 라벨 구조·현장 자료·공식 평가 규격이 불확실하므로 ‘최상위’, ‘완벽’ 같은 등급을 사실로 확정할 근거도 부족하다.

이 비교에서는 선형 모델이 조건 변화 Macro F1 및 보정 후 NLL에서 기존 MLP보다 좋은 수치를 보였다. ExtraTrees의 Macro F1도 기존 MLP와 비슷했지만 확률 손실은 더 컸다. 1200 epoch MLP들은 Macro F1이 높았지만 NLL도 높아졌다. 어떤 결과도 실제자료에서의 우열이나 안전성을 증명하지 않는다.

이 그림에서 왼쪽은 보통/조건 변화의 Macro F1이고, 오른쪽은 조건 변화의 보정 전후 NLL이다. seed별 두 초기화를 평균한 뒤 데이터 생성 seed 10개의 평균을 나타낸다. 같은 데이터에 대한 여러 보조 비교이므로, 표에서 가장 높은 점수 하나만 골라 통계적 우위를 확정하면 안 된다.

학습 연장 MLP의 보정 전 validation NLL은 20회 평균으로 400 epoch의 0.3511에서 1200 epoch의 0.2808로 낮아졌다. 그러나 조건 변화의 보정 후 NLL은 기준 모델 0.8752에서 1200 epoch·L2=0의 0.9468로 높아졌다. 세 L2 설정 모두 20회 전체에서 validation 최적 checkpoint가 1200 epoch였다. 이 결과는 400 epoch 한도가 더 긴 validation 학습을 막았다는 비판을 뒷받침하지만, 1200 epoch에서 최적점에 도달했거나 그 이후가 항상 좋다고 증명하지 않는다.

가상 시각·속력을 추가한 모델의 조건 변화 Macro F1은 0.4636, 보폭 기하 대조는 0.3385였다. 같은 생성기의 단일 합성 시간 간격에서 유도한 숫자이므로 두 결과는 실제 관측 속도·시간의 유용성 평가가 아니다. 합성 Δt만 추가한 대조는 0.6731이었다. 결과 차이를 입력 하나의 원인으로 확정하지 않는다.

[최종 결과 파일](../outputs/critique_comparison_20261027/final/results.json)에는 아홉 설정, 각 20회의 분할별 점수·손실·학습 이력과 보정 전후 결과가 저장돼 있다. 평가 뒤 새로운 모델을 골라 채택하거나 기존 최종 seed에 맞춰 재설정하지 않았다.

최종 저장 예측에 대한 [독립 감사](../outputs/critique_comparison_audit_20261027.json)에서 180회 실행의 51,840개 예측으로 지표를 재계산하고 72개 seed 단위 bootstrap 구간과 619개 파일 해시를 대조했다. 4,374건 수치 비교의 최대 차이는 0이었다. 개발 코드 및 관련 회귀 테스트 59개와 최종 단계 테스트 8개가 통과했다. 이 검증은 합성 실험의 계산 일관성을 확인한 것이며 실제자료나 학습자의 이해를 검증하지 않는다.
