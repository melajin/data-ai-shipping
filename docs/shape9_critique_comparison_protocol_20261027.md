# Shape9 비판 검증과 모델 비교 — 실행 전 고정 계약

사용자는 2026-10-26의 합성 shape9 모델에 대해 학습 종료·결측 마스크·표본 수·시간 정보·트리/선형 기준선에 관한 비판을 제기하고, 정규화·학습 연장 및 단순 모델을 비교하도록 요청했다. 2026-10-26의 최종 seed 9101~9110은 이미 공개된 과거 결과이며 새로운 모델 선택·최종 평가에 사용하지 않는다. 이 실험은 S0 생성 경로 유형에 관한 합성 연구이며 실제자료 학습·사고 탐지·운항 검증이 아니다.

## 동일 조건에서 비교할 질문

1. 기존 MLP의 검증 손실이 400 epoch까지 내려간다는 관찰은 1200 epoch 한도의 검증 손실·성능 변화와 어떻게 연결되는가? 이것만으로 전역 수렴이나 과소적합을 단정하지 않는다.
2. 같은 9개 기하 특징에서 MLP의 L2를 바꾸거나 선형 softmax·ExtraTrees를 쓰면 성능·확률·학습 시간·결측 반응이 어떻게 달라지는가?
3. 사용자가 요청한 시간 간격과 속력 평균·분산은 **가상의 시뮬레이션 시각**으로만 계산한다. 보폭만 추가한 기하 대조군 및 Δt만 추가한 음성 대조군과 비교한다. 실제 속력·가속도·체류시간으로 해석하지 않는다.

## 고정 후보와 평가

| 역할 | 이름 | 조건 |
| --- | --- | --- |
| 기준 | shape9 MLP 400 | 9기하특징, hidden16, L2=0, max400 epoch |
| 학습 연장 | shape9 MLP 1200 | hidden16, L2=0, max1200 |
| 정규화 | shape9 MLP L2=.001 | hidden16, L2=.001, max1200 |
| 정규화 | shape9 MLP L2=.01 | hidden16, L2=.01, max1200 |
| 선형 | shape9 linear | hidden0, L2=.01, max1200 |
| 트리 | shape9 ExtraTrees | 256 trees, min_samples_leaf=2, max_features=1, n_jobs=1 |
| 가상 시각 | shape9_simtime4 MLP | shape9 + 같은 부분선 안의 평균 Δt, 합성 속력 평균·분산·변동계수. hidden16, L2=0, max400 |
| 기하 대조 | shape9_edge3 MLP | shape9 + 같은 부분선 안의 평균 보폭·보폭 분산·변동계수. hidden16, L2=0, max400 |
| 음성 대조 | shape9_dt_only MLP | shape9 + 같은 부분선 안의 평균 합성 Δt. hidden16, L2=0, max400; formal 선택 제외 |

모든 MLP/선형은 NumPy full-batch GD, lr=.03, patience35, validation NLL로 checkpoint를 선택한다. 기존 클래스의 400 epoch 제한은 바꾸지 않고 별도 연구 전용 최대 1200 wrapper를 쓴다. wrapper의 400 epoch 결과는 기존 구현과 대조한다. 양의 온도는 별도 calibration에서 NLL로 정한다. ExtraTrees는 class 순서를 확인하고 확률의 로그에 온도 보정을 적용한다. 확률 출력·손실·정확도·macro F1·클래스별 혼동 및 소요 시간/모델 규모를 기록한다. 양의 온도는 argmax를 바꾸지 않는다.

특징 차원이 다른 후보는 각자의 train만으로 대치·스케일을 적합한다. 같은 특징의 후보는 동일한 train 통계를 사용한다. 원래 기하 유효성 기준과 평가 행·선박 그룹을 모든 후보에 동일 적용하며, 추가 특징의 결측은 train 통계 대치와 mask로 남긴다.

## 개발 선택과 최종 비교

- 개발 데이터: 생성 seed 2101, 2102, 2103; 모델 초기화 seed 42, 137. **독립 생성 반복은 3개**이며 초기화 6회를 독립 자료 6개로 세지 않는다. 각 seed의 두 초기화를 평균한 뒤 seed 단위 차이를 계산한다. 3개 seed는 방향성 탐색이며 우위의 통계적 입증이 아니다.
- 개발 적격: 기준 대비 보통 조건 macro F1 평균 차이 ≥−.01, 조건 변화 평균 차이 ≥+.05, 3개 seed 모두 조건 변화 차이 양수, 평가 분모 동일. Δt 단독 음성 대조는 formal 선택하지 않는다.
- 적격 중 사전 순위: 조건 변화 차이 큰 순 → 보통 차이 큰 순 → 보정된 보통 NLL 작은 순 → 보정된 보통 Brier 작은 순 → 선언 순서. 1e−12 이내는 동률로 처리하며 측정시간은 선택에 사용하지 않는다.
- 최종 자료: fresh 생성 seed 12101~12110, 각 초기화 42·137. 최종 생성 전에 후보 전체·학습 절차·지표·개발 선택·source hash·final seed를 동결한다.
- 사용자가 선형과 ExtraTrees의 직접 비교를 요청했으므로 **사전 고정한 모든 후보**를 동일한 새 최종자료에서 1회 평가한다. 개발 적격 후보가 없어도 이 고정 비교는 수행한다. 이것은 모델의 재선정이 아니라 비교표를 위한 사전 지정 평가다.
- 확인적 primary는 개발에서 선택해 잠근 후보 하나 대 shape9 MLP 기준선뿐이다. 개발 적격이 없으면 primary는 없다. 이 밖의 최종 비교와 95% 구간은 **다중비교 보정 없는 보조·탐색 결과**다. 점수가 가장 높다는 이유로 최종 결과를 보고 새 모델을 채택하거나 재설정하지 않는다.
- primary 성공은 normal 차이 ≥−.01, shift 차이 ≥+.05, 10개 중 8개 이상 shift 차이 양수, 동일 분모 및 generator seed 단위 paired bootstrap 2,000회(seed=20261027)의 95% 하한>0이다. 이는 이 합성 실험의 기준이다.

## 시각·보폭 해석과 검증

생성기는 항적마다 시뮬레이션 간격 하나를 추출하고 원래 점마다 그 배수인 시각을 부여한다. 클래스별 가감속·정지·체류 과정은 생성하지 않았다. 따라서 시간 추가로 점수가 바뀌어도 도메인 효용이나 시간의 독립 효과로 단정할 수 없다. 같은 시간 간격에서 속력 평균·분산은 보폭 평균·분산을 시간으로 나눈 값이다. 두 입력 묶음의 공정한 대조를 보고, 모델이 입력을 비선형으로 처리하므로 단순히 같은 예측을 보장한다고도 하지 않는다.

실제 샘플의 점별 시각과 정확한 CRS는 확인되지 않았다. 부분선 내부의 좌표·합성 시각만 사용하며 다른 부분선을 이어 속력을 만들지 않는다. 시간을 2배로 바꾸면 Δt는 2배, 합성 속력 평균은 1/2, 속력 분산은 1/4, 변동계수와 기하 대조는 유지되는 짝 검산을 한다. 경로 연결, 라벨의 입력 사용, 데이터 누수, 유보 분모 변경을 금지한다.

## 결과의 해석

결측 mask가 train에서 늘 0이면 관련 가중치의 데이터 gradient는 0이다. L2=0의 초기값 잔존이 실제 관측 결측 없이 학습 데이터의 예측을 오염시켰다는 뜻은 아니다. 강제한 결측에 대한 모델 반응은 **인공 입력 개입 진단**이며 실제 결측 발생률이나 현장 실패율이 아니다. L2나 특정 모델의 우위를 선험적으로 보장하지 않는다.

각 후보의 손실 이력, 선택 epoch, 학습시간과 정상/조건변화 metrics를 보존한다. 추가 모델의 결과가 없는 경우와 final에서 기대한 개선이 나오지 않는 경우도 보고한다. 실제자료에 적용하기 전에는 별도로 입력·라벨·시간·CRS·이상/사고 정답·공식 평가 계약을 확인한다.

역할: 설계 검토 astra_decision/GPT-6 Astra/high, 기존 모델 수치 감사 sol_review/GPT-6.1 Sol/high, 비교 구현 sol_complex/GPT-6.1 Sol/max. 부모는 공통 통합과 합성 시각 특징을 담당한다. 역할은 생성 요청에 기록되며 부모 실행 모델 변경을 뜻하지 않는다.
