# 교재 검증 기록

이 폴더는 교재의 편집 검사와 선택한 교육용 계산의 검산 결과를 보관한다. 학습자가 개념을 이해했다는 평가나 실제 모델·장치의 성능 시험과는 구분한다.

## 녹조 예측 확장 검사

2026년 10월 7일 작성한 녹조 확장 19~25장에는 21개 문제와 분리 해설이 있다. `check_algae.py`는 단위·로그·미분·성장·물질수지·회귀·트리·잠재 상태·지표의 선택한 가상 계산을 확인한다. 유한차분으로 로그 미분과 로지스틱 해의 미분을 비교하고, 완전혼합 물질수지의 유출 상쇄를 여러 조건에서 검사한다.

문서 검사는 녹조 7개 장과 길잡이·출처·해설의 총 10개 문서로 범위를 정한다. 이 문서들의 로컬 링크, 수식·코드 경계, 문제와 해설의 대응을 확인한다. 같은 폴더의 다른 확장 교재는 이 검사의 대상이 아니다.

교재 폴더에서 `python validation/check_algae.py`로 재실행한다. [녹조 검사 보고서](algae_report.json)에 조건·예상값·계산값과 통과 여부를 기록한다. 검사 통과는 모든 수식의 형식적 증명, 실제 모델 학습·성능 검증, 실제 장치 실측 또는 학습자의 이해 완료를 뜻하지 않는다.

## 어선 항적 적용편 검사

2026-10-07에 작성한 어선 적용편 19~25장에는 기초 설명·수식·유도·중간 계산·조건 변경과 21개 연습·분리 해설이 있다. `check_fishing_examples.py`가 공간 기하, CE의 유한차분 미분, HMM·Kalman, Gaussian·고립 경로·라벨 마스크, 보간, 가상 운동·OU·KL, 분류·순위·보정·선행 시간의 선택한 계산 **83개를 검사해 모두 통과**했다. 조건·예상값·계산값·허용 오차는 [어선 수치 검사 보고서](fishing_numerical_report.json)에 남겼다.

7개 어선 장의 수식 구분자·중괄호·문자와 코드 블록을 점검했고, 여러 장의 수식·단위·정보 가용성 조건은 독립 검토를 거쳤다. 이 과정에서 거리 단위에 따른 상대 가중 표현, 모든 환경 관측이 제외된 경우, 사건 주변 평가 창의 정의와 수식 표기 누락을 수정했다. 문서 구조·로컬 링크 검사에서도 오류·경고가 없었다. 외부 자료는 공식 문서·원논문을 본문의 해당 설명에 연결했으나 로컬 링크 검사는 외부 URL의 지속적 가용성을 보장하지 않는다.

교재 폴더에서 다음 명령으로 어선 계산 검사를 재실행한다.

```text
python validation/check_fishing_examples.py
```

검사 대상은 교육용 가상 계산이다. 실제 CSV의 품질·모델 학습·실제 조업 및 사고 성능·합성 경로의 현실성·하드웨어 실측은 검증하지 않았다. 모든 수식의 형식적 증명이나 학습자의 이해 완료를 뜻하지 않는다. 기존 이론편 및 다른 적용편의 수치 검사는 각각의 도구·보고서로 구분한다.

## 기존 AI 교재 검사

최종 제작·검수일은 2026-10-07이다. 18장 본문과 54개 문제·해설을 대조했고, 선택한 계산·코드 검증 136개가 통과했다. 구체적인 값과 문서 구조 검사 결과는 아래 JSON 보고서에서 확인한다.

## 검사 방법

`check_book.py`는 필수 공통 이론 18장과 어선 적용편 7장, 각 장의 문제 식별자 3개와 대응 해설을 확인한다. 폴더에서 발견한 Markdown 문서의 로컬 링크·제목 링크, 코드 블록 닫힘과 UTF-8 문자도 검사하므로 보고서의 전체 장 수에는 다른 적용편이 포함될 수 있다. 다른 적용편의 내용·계산·해설은 해당 적용편의 전용 검사 범위다. 결과는 [구조 검사 보고서](structure_report.json)에 저장한다. 문제가 없는 링크라고 해서 외부 자료의 주장이나 본문 내용까지 입증되는 것은 아니다.

`check_examples.py`는 본문의 선택한 합성 데이터·수치 조건으로 확률, 손실, 기울기, 평가 지표, 인과 표준화, 비용 등을 다시 계산한다. 일부 기울기는 유한차분과 비교하고, M04의 Python 예제는 코드를 확인한 뒤 실제 실행한다. 각 조건·예상값·계산값·통과 여부는 [수치 검사 보고서](numerical_report.json)에 남긴다. 모든 수식의 형식적 증명이나 모든 구현의 시험은 아니다.

재실행에는 Python 표준 라이브러리만 필요하다. 교재 폴더에서 다음 명령을 각각 실행한다.

```text
python validation/check_book.py
python validation/check_examples.py
```

문제의 조건을 바꾸면 해설과 해당 검산 조건도 함께 바꾼다. 숫자가 일치하는 것과 그 계산이 올바른 질문에 답하는 것은 다르므로 가정·단위·해석은 본문 검토와 함께 확인한다.

## 확인 범위

- 설명·개념 경계·교육 순서는 GPT-6 Astra ultra의 감독과 GPT-6.1 Sol ultra의 집필·통합 검토를 거쳤다. 출처·기초 초안에는 GPT-6 Luna xhigh의 수집·작성 결과를 사용했다. Astra의 전권 내용 승인 후 수식 표기와 로컬 탐색을 최종 정리했다.
- 가상 예제와 실제 출처가 보고한 결과를 구분했다. 회사 모델의 비공개 구조는 추정으로 채우지 않았다.
- 코드 실행, 수치 검산, 실제 장치 시험은 다른 상태다. 이 교재 제작에서는 실제 모델 훈련, 외부 유료 API 평가, 하드웨어 연결·실측을 수행하지 않았다.
- 문서 작성 완료는 학습 완료가 아니다. 각 장의 문제와 README의 관문에서 독립 설명과 조건 변경 대응을 별도로 확인한다.
