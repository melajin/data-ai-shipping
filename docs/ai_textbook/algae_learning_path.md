# 녹조 예측 모델 학습 길잡이

현재 녹조 상태, 성장 조건, 물의 이동과 계절을 결합해 약 7일 뒤 유해남조류 농도를 예측하는 모델을 배우는 응용 교재다. 쉬운 설명에서 시작해 기호·단위·가정, 수식 유도, 손계산, 모델 선택과 검증으로 이어진다.

기존 AI 교재 01~18장을 모두 읽어야 시작할 수 있는 것은 아니다. 각 장의 필요한 부분을 참고한다. 이 확장에는 7개 장과 21개 연습이 있고 해설을 분리했다. 교재 작성과 수치 검산은 실제 데이터 모델 학습이나 학습자의 독립 수행 평가와 구분한다.

## 기초에서 유도까지 공부하는 방법

1. 문장 설명에서 입력과 출력이 무엇인지 말한다.
2. 기호마다 뜻과 단위를 적는다.
3. 유도의 한 줄을 가리고 이전 식에서 직접 이어 본다.
4. 완료 예제의 숫자를 계산하고 조건 하나를 바꾼다.
5. 연습을 먼저 풀고 힌트를 확인한다.
6. 필요할 때 [별도 해설](95_algae_solutions.md)을 읽는다.

예를 들어 성장식에서는 $dN/dt=rN$의 뜻 → 변수 분리와 적분 → 지수해 → 제한 성장 → 물질수지 순으로 읽는다. 회귀에서는 오차의 제곱 → 미분 → 최적 조건 → 정규화 순으로 읽는다.

신경망의 게이트와 attention은 물리법칙에서 반드시 도출되는 식이 아니라 계산 구조의 정의다. 물질수지의 보존식 유도, 통계 손실의 최적해 유도, 신경망 구조 정의를 구분한다.

## 처음 구현할 모델

처음에는 한 지점에서 현재값 유지 모델을 만든다. 이후 상태·추세 모델, 환경 융합 모델을 같은 날짜순 검증에서 비교한다. 불규칙한 관측을 과거 특징 표로 만든 경우 작은 트리 기반 회귀를 후보로 검토하되, 실제 자료를 확인해 결정한다.

LSTM·Transformer·공간 그래프·물리 혼합 모형은 설명 대상이다. 모두 구현하거나 처음부터 함께 사용하는 요구사항은 아니다. 해결할 오류와 필요한 데이터가 분명할 때 확장한다.
