# 23. 외부 환경자료의 정렬·보간·모델 결합

[어선 적용편 길잡이](../95_fishing_guide.md) · 선수: [공간 특징](19_fishing_data_geometry.md), [확률](03_probability.md) · 연결: [확률모형](07_probabilistic_models.md), [인과](15_causality.md)

## 학습 목표와 선수 질문

“이 경로 변화가 바람이나 해류와 함께 나타났는가?”를 조사하려면 두 자료가 같은 장소·시점·단위를 가리키는지 먼저 알아야 한다. 이 장에서는 환경자료의 관측시각과 사용 가능 시각을 나누고, 보간식의 가정과 특징 결합의 수식을 설명한다. 선수 질문은 “가까운 관측소의 값은 선박 위치의 실측인가?”, “내일 공개된 어제 자료를 어제의 조기 탐지 입력에 넣어도 되는가?”다.

현재 바람·파도·바닷물 흐름은 외부자료 후보다. 실제 확보·결합·성능 개선은 검증하지 않았다. 자료 제공 설명의 확인일은 2026-10-07이며, 아래의 관측 간격·이용 조건은 채택 때 다시 확인한다. 수치 예제는 가상 조건이고 실측 해양환경이 아니다.

## 1. 외부 데이터마다 다른 역할

| 후보 | 모델에 주는 정보 | 채택 전에 확인할 내용 |
| --- | --- | --- |
| 기상청 해양기상부이 | 바람·파고·파주기·파향 등 환경 관측 | 항적 기간·해역의 관측소, 품질, 결측, 단위·방향 규약 |
| 국립해양조사원 해양관측부이 | 유향·유속 등 바닷물 흐름 관측 | 해당 변수·지점의 과거자료 확보 가능성, 제공 지연·이용 조건 |
| 해안선·항만·수심 자료 | 경로와 지형의 공간 관계 | 선택적 확장, 좌표계·수직 기준·갱신일·이용 조건 |
| 예보자료 | 당시 예측된 환경 | 예보 발표시각, 예측 유효시각, 사후 수정 여부 |

기상청 안내에는 시간·일·분자료와 바람·파고 등의 제공 요소가 명시되어 있다. 분자료는 기본 30분 간격이며 일부 지점의 간격이 다르다. 지점별 제공기간도 같지 않다. 국립해양조사원 후보 API는 **최신 관측데이터** 안내이므로 그것만으로 과거 대회 기간 자료를 확보할 수 있다고 판단하면 안 된다. 각 데이터의 이용규칙과 대회 외부자료 허용조건을 별도로 확인한다. [기상청 공식 자료 안내](https://data.kma.go.kr/data/sea/selectBuoyRltmList.do?pgmNo=52), [국립해양조사원 공식 API 안내](https://www.data.go.kr/data/15155516/openapi.do)

관측자료는 경로 변화의 배경 설명과 환경 조건별 성능 비교에, 시뮬레이터의 입력은 [24장](24_fishing_virtual_units.md)의 가정에 따른 조건 변화에 사용한다. 외부자료를 추가한 모델과 항적만 사용한 모델을 같은 실제 평가자료에서 비교해야 효과를 알 수 있다. 환경 예측 모델 자체의 제작은 별도 문제이며 현재 과제의 필수 단계가 아니다.

## 2. 네 종류의 시간과 정보의 가용성

환경 레코드를 다음처럼 표현하자.

$$E_j=(r_j,t^{obs}_j,t^{pub}_j,t^{valid}_j,e_j,q_j).$$

$r_j$는 관측 위치 또는 격자 셀, $t^{obs}$는 관측시각, $t^{pub}$는 공개·수신 가능 시각, $t^{valid}$는 예보가 가리키는 유효시각, $e_j$는 환경 변수 벡터, $q_j$는 품질 정보다. 관측에는 유효시각을 관측시각과 같게 둘 수 있지만 자료의 정의를 따른다. 시스템 처리 완료 시각도 따로 기록한다.

판단 실행 시각 $\tau$의 사용 가능한 집합은 설계상

$$\mathcal A(\tau)=\{j:t^{pub}_j\le\tau,\ q_j\text{가 품질 조건을 만족}\}$$

로 제한한다. 과거 관측을 직접 쓰는 경우 $t^{obs}_j\le\tau$도 필요하다. 미래 유효시각의 **예보**는 발표가 $\tau$ 이전이면 사용할 수 있지만 미래 **실측**을 넣는 것은 다르다. 뒤늦게 수정된 관측은 수정 버전의 당시 이용 가능 여부를 확인한다.

가상 예로 10:00 관측 2m가 10:10 공개되고 11:00 관측 4m가 11:10 공개된다고 하자. 10:30 판단에는 앞의 2m만 사용 가능하다. 두 값을 선형 보간한 3m는 11:10 뒤의 사후 분석값이다. 보간값이 부드럽다는 이유로 과거 판단에 사용 가능한 정보가 되지는 않는다.

항적에 점별 시각이 없다면 각 좌표와 환경 순간값의 정확한 대응도 알 수 없다. 우선 확인된 시간대 구간과 공간 범위의 환경 요약을 연결하고, 이는 시간대 단위의 근사라고 표시한다. 전체 한 시간 경로가 들어온 뒤 그 안의 사고를 그보다 먼저 탐지했다고 말할 수 있는지도 [25장](25_fishing_evaluation_system.md)에서 판단한다.

## 3. 단위와 방향을 맞추기

파고 m, 유속 m/s, 풍속 m/s, 각도 deg/rad처럼 변수마다 단위가 다르다. knot를 쓴 자료라면 1 knot=$1852/3600\approx0.514444$m/s라는 단위 정의로 변환하고 원래 단위도 보존한다. 시간 간격은 초·분·시간 중 무엇인지 명시한다. 수심은 해수면·해도 기준면 등 수직 기준을 확인하기 전 3D 뷰어의 실제 깊이로 해석하지 않는다.

### 방향은 숫자 평균 대신 벡터로

교육용으로 방향 $\theta$를 북쪽 0·시계방향 양·**흘러가는 방향**이라고 정의하자. 크기 $V$의 동쪽·북쪽 성분은

$$u=V\sin\theta,\qquad v=V\cos\theta.$$

동쪽으로 1m/s면 $(u,v)=(1,0)$, 북쪽으로 1m/s면 $(0,1)$이다. 반대로 자료가 바람이 **불어오는 방향**을 주고 같은 각도 규약이라면 이동 벡터는 $(-V\sin\theta,-V\cos\theta)$다. 실제 변수 설명에서 규약을 확인하고 선택해야 한다. 유향·풍향·파향이 모두 같은 규약이라고 가정하지 않는다.

350도와 10도의 두 방향이 같은 크기를 갖는다면 단순 각도 평균 180도보다 성분을 평균한 뒤 atan2로 복원하는 것이 원형 구조를 보존한다. 두 벡터가 정확히 반대라 평균 크기가 0이면 평균 방향은 정의하기 어렵다. 또한 파고를 벡터 속력처럼 더하는 것은 파랑의 물리 정의와 맞지 않는다. 벡터화는 해당 물리량에 적용할 수 있을 때만 쓴다.

## 4. 공간 보간의 원리와 계산

보간은 알려진 위치의 값으로 미관측 위치를 **추정**하는 일이다. 자료가 없는 바다를 실제로 측정한 값으로 바꾸지 않는다. 해안·섬·수심과 환경 변수의 공간 변화가 단순한 거리 가정을 깨뜨릴 수 있다. [QGIS의 공간 보간 설명](https://docs.qgis.org/3.44/en/docs/gentle_gis_introduction/spatial_analysis_interpolation.html)

### 4.1 최근접과 역거리 가중

최근접은 조건을 만족하는 가장 가까운 관측소의 값을 사용한다. 거리가 작다는 이유만으로 충분히 대표한다고 판단하지 않으며 최대 거리·최대 시간차·품질 제한을 둔다. IDW는 가까운 관측소를 더 많이 반영한다.

$$a_j=(d_j+\epsilon)^{-p},\quad
w_j=\frac{a_j}{\sum_ka_k},\quad
\widehat e(r)=\sum_jw_je(r_j).$$

$d_j$는 같은 미터 좌표계에서 계산한 거리, $p>0$는 감소 정도, $\epsilon\ge0$는 수치 처리용 값이다. $\epsilon=0$에서 관측점과 정확히 겹치면 그 관측을 반환하는 별도 규칙을 사용한다. $w_j\ge0$, 합 1이므로 상수 환경은 상수로 보존한다. 거리 단위와 $\epsilon$ 단위는 일치해야 한다.

가상 관측소 A·B의 거리가 1km·2km이고 파고가 2m·5m, $p=2$, $\epsilon=0$이면 미터 기준 비정규화 가중은 $10^{-6},2.5\times10^{-7}$이며 상대 가중은 $1,1/4$이다. 정규화하면 $w_A=0.8,w_B=0.2$, 추정 파고는 $0.8(2)+0.2(5)=2.6$m다. $p=1$이면 $2/3,1/3$이므로 3m다. 다른 $p$가 다른 가정을 담는다는 뜻이다. $p$를 시험자료 성능으로 고르면 평가 누수다.

### 4.2 격자자료의 쌍선형 보간

사각형 셀의 좌하·우하·좌상·우상 값을 $e_{00},e_{10},e_{01},e_{11}$이라 하고 셀 안 비율 $a,b\in[0,1]$를 정의하면

$$\widehat e=(1-a)(1-b)e_{00}+a(1-b)e_{10}
 +(1-a)be_{01}+abe_{11}.$$

가중합은 1이다. 먼저 두 가로 방향에서 선형 보간하고 그 결과를 세로 방향으로 보간하면 이 식이 나온다. $e=(1,2,3,4)$m, $a=b=0.25$이면 가중은 $(0.5625,0.1875,0.1875,0.0625)$라 결과는 1.75m다. 바다 격자에 육지·결측 셀이 섞이면 네 값이 있다는 조건부터 실패하므로 육지 경계를 넘는 보간을 그냥 허용하지 않는다.

### 4.3 심화: 공분산을 사용하는 kriging

거리만 이용하는 IDW 대신 환경의 공간 공분산을 모델링할 수 있다. 평균이 알려진 0인 Gaussian process에서는 관측 공분산 $K$, 목표와 관측 사이 공분산 $k$에 대해

$$\widehat e_0=k^\top K^{-1}e,\qquad
\operatorname{Var}(e_0\mid e)=K_{00}-k^\top K^{-1}k.$$

관측 잡음이 있으면 그 분산을 $K$에 더한다. 같은 단위의 공분산 요소는 변수 단위의 제곱이다. 평균이 알려진 GP와 평균 미지의 ordinary kriging은 조건이 다르다. 후자는 상수 평균을 보존하기 위해 $\mathbf1^\top w=1$을 추가하고

$$\begin{pmatrix}K&\mathbf1\\\mathbf1^\top&0\end{pmatrix}
\begin{pmatrix}w\\\mu\end{pmatrix}
=\begin{pmatrix}k\\1\end{pmatrix}$$

을 푼다. 왜 이 식일까? 예측 오차 분산 $K_{00}-2w^\top k+w^\top Kw$를 $\mathbf1^\top w=1$ 조건 아래 최소화하면 미분에서 $Kw+\mu\mathbf1=k$가 나온다. 예측은 $w^\top e$, 오차분산은 위 식에 해를 대입한 값이다. 행렬 역행렬을 직접 계산하기보다 안정적인 선형계 해법을 사용한다. 추정 분산도 선택한 공분산·잡음·평균 가정 아래의 불확실성이며 모든 해양환경 오차를 포함하지 않는다. [GPML 저자 교재의 Gaussian 회귀 유도](https://gaussianprocess.org/gpml/chapters/RW2.pdf)

초기 프로젝트에 반드시 kriging을 넣어야 하는 것은 아니다. 가까운 유효 관측만 쓰는 기준선으로 시작하고 거리별 오차·해안 경계 문제에 근거가 있을 때 확장한다.

## 5. 시간 보간과 시간대 요약

두 시점 $t_0<t<t_1$의 선형 보간은

$$\alpha=\frac{t-t_0}{t_1-t_0},\qquad
\widehat e(t)=(1-\alpha)e(t_0)+\alpha e(t_1).$$

이는 그 사이 값이 선형으로 바뀐다는 가정이다. 양쪽 값이 판단 때 모두 사용 가능하면 사후 분석에 쓸 수 있다. 미래 관측이 필요하면 온라인 조기 탐지에서 사용할 수 없다. 직전 값 유지 $\widehat e(t)=e(t_{\mathrm{last}})$는 정보 시점 조건을 지키기 쉬우나 오래된 값의 편향을 만든다. 마지막 관측 후 경과시간도 특징·품질 정보로 전달한다.

불규칙 환경 관측의 시간 평균을 구하려면 가중의 의미부터 정한다. 조각별 상수 유지 가정에서 시간대 $[a,b)$를 유효 구간 $I_j$로 나누면

$$\bar e=\frac{\sum_j|I_j|e_j}{\sum_j|I_j|},\qquad
\mathrm{coverage}=\frac{\sum_j|I_j|}{b-a}.$$

여기서 $I_j$들은 서로 겹치지 않는 유효 구간이며 분모가 0이면 평균은 결측이다. 점을 단순 평균한 것과 시간을 가중한 평균은 다르다. 각 구간의 실제 지속시간이 없으면 이 역시 가정이다. 항적 공간 재표본화점의 환경값 평균도 공간 평균이며 선박이 겪은 시간 평균으로 바꿔 부르지 않는다.

예를 들어 한 시간 중 유효 구간 20분은 2m, 다음 10분은 5m, 나머지 30분은 미관측이라면 유효 부분 평균은 $(20\cdot2+10\cdot5)/30=3$m, 관측 범위는 $30/60=0.5$다. 이를 한 시간 실측 평균으로 단정하면 미관측 절반을 숨긴다.

## 6. 모델 입력으로 결합하는 세 방식

### 6.1 먼저 결합하는 기준선

항적 특징 $x\in\mathbb R^d$, 환경 특징 $e\in\mathbb R^q$, 가용성 마스크 $m\in\{0,1\}^q$, 마지막 관측 후 경과시간 $a$를 준비한다. 학습자료에서 적합한 표준화 뒤

$$z=[\widetilde x;\widetilde e;m;a],\qquad
p(y=c\mid z)=\operatorname{softmax}(Wz+b)_c$$

같이 연결할 수 있다. 결측 환경값을 0으로 채웠다면 “실제 0”과 “없어서 0”을 마스크로 구별한다. 전체자료의 평균을 쓰거나 시험기간까지 보간 규칙을 맞추면 누수다. 표준화된 환경의 0은 물리적으로 무풍을 뜻하는 것도 아니다.

### 6.2 표현을 만든 뒤 결합하기

각 입력의 encoder를 $h_x=f_\theta(x)$, $h_e=g_\psi(e,m,a)$라 하고

$$h=\sigma(W_xh_x+W_eh_e+b)$$

로 융합한 뒤 [20장](20_fishing_classification.md)의 조업·이상 출력에 전달할 수 있다. 환경이 없을 때의 입력을 학습·검증에 포함하고, 없다는 사실을 조업 라벨의 편법 신호로 쓰는지도 확인한다.

많은 주변 관측소를 이용하는 심화 구조는 경로 질의 $Q$, 환경 key $K$·value $V$로

$$\operatorname{CrossAttention}(Q,K,V)
=\operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}+M\right)V$$

를 계산한다. $M$은 이용 불가능·품질 부적합 위치를 제외하는 마스크다. 모든 위치가 제외되면 softmax를 계산하지 않고 환경 부재 상태를 표시해 항적 표현으로 복귀한다. attention은 관련 표현의 가중합이며 바람이 항적 변화를 일으켰다는 인과 증명도, 실제 환경의 공간 보간 정확도 보장도 아니다. 구조의 전체 유도는 [21장](21_fishing_sequence_models.md)에 연결한다. [Transformer 원논문](https://arxiv.org/abs/1706.03762)

### 6.3 결과를 결합하기

두 분류기의 클래스 분포 $p_x,p_{xe}$를 $p=\alpha p_x+(1-\alpha)p_{xe}$로 결합하면 $\alpha\in[0,1]$에서 합 1을 유지한다. $\alpha$는 검증자료에서 선택하고 환경 부재 때 항적 모델로 돌아가는 규칙을 정의한다. 서로 단위가 다른 이상점수는 이렇게 단순 평균해도 같은 의미가 되지 않는다. 먼저 점수의 방향·분포·교정 범위를 맞춰야 한다.

## 7. 환경을 조건으로 보는 이상과 인과의 한계

환경 조건의 정상 특징 평균을 $\mu(e)$, 공분산을 $\Sigma(e)$라 모델링하면

$$s(x,e)=(x-\mu(e))^\top\Sigma(e)^{-1}(x-\mu(e))$$

를 환경 대비 잔차 점수로 사용할 수 있다. 잔차의 공분산이 양의 정부호가 되도록 추정·정규화하고 충분한 학습 표본을 확인한다. 가상 예로 특징 평균이 평온 때 4, 거친 환경에서 6이며 관측 특징 7, 표준편차 1이라면 환경을 무시한 제곱 잔차 9와 환경 조건 잔차 1이 다르다. 이 숫자는 조건 모델의 효과를 설명할 뿐 환경이 원인이라는 실측 결과가 아니다.

$P(x\mid e)$를 학습했다고 $P(x\mid\operatorname{do}(e))$를 알게 되는 것은 아니다. 조업 목적·해역·계절·관측소 배치가 함께 달라질 수 있다. 실제 항적의 통계적 관계, 가상 유닛의 규칙에 따른 환경 개입, 실제 선박의 인과 효과는 별도의 증거다. [15장 인과 설명](15_causality.md)

환경 추정 오차를 전달하려면 모델 $f(e)$ 주변에서

$$f(e+\delta e)\approx f(e)+J\delta e,\qquad
\operatorname{Cov}(f)\approx J\Sigma_eJ^\top$$

같은 일차 근사를 이해할 수 있다. $J$는 환경 변수에 대한 Jacobian, $\Sigma_e$는 가정하거나 추정한 입력 오차 공분산이다. 비선형성이 크면 부정확하며 변수 간 상관을 무시하면 오차를 잘못 평가할 수 있다. 환경을 일정 범위로 바꿔 출력 민감도를 보는 실험도 실제 인과 효과와 구분한다.

## 8. 단계별 검증과 실패 진단

| 단계 | 기술 결과 | 학습 확인·검증 |
| --- | --- | --- |
| 자료 선택 | 변수·단위·시각·출처 표 | 무엇이 아직 확보되지 않았는지 설명 |
| 작은 결합 | 가상 두 관측소의 보간 | 가중합·단위·최대 거리·결측을 손계산 |
| 실제 정렬 | 허용 자료의 시간대·해역 결합 | 시간대 규약·공개 지연·공간 오차 기록 |
| 모델 비교 | 항적만/환경 추가의 같은 평가 | 성능 변화와 추가 결측·자료 편향 비교 |
| 조건 변경 | 관측소 누락·지연·환경 범위 변화 | 입력, 정렬, 표현, 모델의 실패를 구분 |

환경자료 도입이 학습 목적이나 실제 검증에 기여하지 않으면 복잡성을 줄인다. 원자료와 결합 자료, 관측값과 보간값, 후보자료와 채택자료를 구분해 저장한다.
