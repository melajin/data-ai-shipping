# 11. 강화학습, 의사결정과 제어

[교재 길잡이](../모델%20해석%20목차.md) · 선수: 확률·알고리즘·[통계학습](06_statistical_learning.md) · 연결축: ③⑤⑥⑨

## 학습 목표와 선수 질문

보상·정책·가치를 구분하고 작은 벨만 계산과 업데이트를 수행한다. 모델 기반·비기반, 모방·오프라인 학습과 제어의 조건을 비교하며, 피드백 안정성을 단순 모델에서 확인한다. “지금 높은 보상과 미래 높은 보상은 충돌할 수 있는가?”, “같은 관측이면 다음 결과 분포도 같은가?”를 먼저 생각한다.

## 행동이 다음 데이터에 영향을 주는 학습

지도학습은 주어진 자료에서 예측을 평가하지만 행동 문제에서는 선택이 이후 상태와 관측을 바꾼다. 정책 $\pi(a\mid s)$는 상태 $s$에서 행동 $a$를 선택하는 분포다. 보상 $r_t$는 단계별 신호이며 진짜 목적의 완전한 표현이 아닐 수 있다. 목표는 보통 할인된 누적 보상 $G_t=\sum_{k=0}^\infty\gamma^kr_{t+k+1}$의 기대를 크게 하는 것이다. $0\le\gamma<1$은 먼 미래를 할인하는 계수다. 이 무한합을 유한하게 다루는 충분조건으로 단계 보상의 절댓값에 일정한 상한이 있다고 가정한다.

보상을 잘못 설계하면 원래 목표와 다른 행동이 학습된다. 속도만 보상하면 안전·에너지·품질을 놓칠 수 있다. 보상 최적화의 성공과 사용 목적 달성을 분리해야 한다.

## 밴딧, MDP와 부분 관측

밴딧은 행동마다 보상을 얻되 일반적인 MDP처럼 행동이 미래 상태를 바꾸는 구조는 다루지 않는 기본 문제다. 탐험은 덜 알려진 행동의 정보를 얻고 활용은 현재 좋은 행동을 고른다. $\varepsilon$-greedy는 일정 확률로 탐험하고, UCB는 추정 보상과 불확실성 보너스를 합친다. 정적인 독립 보상 가정에서 얻는 보장을 변하는 사용자 환경에 그대로 적용할 수는 없다.

MDP는 상태·행동·전이확률 $P(s'\mid s,a)$·보상·할인계수로 정의한다. 마르코프 가정은 필요한 과거 정보가 현재 상태에 포함된다는 뜻이다. 미래와 관련된 정보를 빼고 상태를 만들면 알고리즘보다 모델 정의에 문제가 생긴다.

POMDP에서는 실제 상태를 완전히 보지 못하고 관측만 얻는다. 이전 믿음, 행동, 새 관측으로 상태의 belief distribution을 갱신한다. 정확한 모델 아래 이 믿음은 필요한 이력을 요약할 수 있지만 고차원에서는 계산이 어렵다. RNN 메모리를 넣는 것만으로 부분 관측의 모든 불확실성이 해결되지는 않는다.

## 가치와 벨만 관계

$V^\pi(s)$는 상태에서 정책 $\pi$를 따를 때의 기대 누적 보상, $Q^\pi(s,a)$는 처음 행동만 $a$로 정한 뒤 $\pi$를 따를 때의 값이다. 벨만 관계는 한 단계의 보상과 다음 가치를 연결한다.

$$V^\pi(s)=\sum_a\pi(a\mid s)\sum_{s'}P(s'\mid s,a)
[r(s,a,s')+\gamma V^\pi(s')].$$

최적 가치는 행동 평균 대신 최댓값을 취한다. 알려진 전이 모델에서는 가치 반복·정책 반복 같은 동적계획을 쓸 수 있다. 단순 유한 할인 MDP의 보장과 신경망 근사·오프폴리시 데이터의 실제 학습 안정성은 구분한다.

작은 문제에서 상태 A는 종료 행동으로 보상 1을 받고 끝내거나, 보상 0으로 B에 갈 수 있다. B에서는 보상 3을 받고 끝난다. 종료 상태의 가치는 0이다. $\gamma=0.9$이면 $V(B)=3$, $Q(A,\mathrm{stop})=1$, $Q(A,\mathrm{go})=0+0.9(3)=2.7$이므로 B로 간다. 즉시 보상만 비교하면 잘못된 결정을 내린다.

Q-learning의 한 표기에서 학습률 $\alpha$, 관측 보상 $r$, 다음 상태 $s'$를 쓰면

$$Q(s,a)\leftarrow Q(s,a)+\alpha[r+\gamma\max_{a'}Q(s',a')-Q(s,a)].$$

위 사례에서 현재 $Q(A,\mathrm{go})=1$, 다음 최대값 3, $\alpha=0.5$이면 목표는 2.7, 갱신은 $1+0.5(2.7-1)=1.85$다. 한 번의 갱신이 곧 최적 값을 완성한 것은 아니다. 조건을 바꿔 $\gamma=0.2$이면 go의 최적값은 0.6으로 stop보다 작아진다.

## 표본, 정책 학습과 모델 사용

Monte Carlo는 실제로 관측한 전체 return을 이용한다. TD는 $r+\gamma V(s')$처럼 현재 추정치를 재사용해 먼저 갱신한다. TD는 빠르게 피드백을 얻지만 근사치의 오류를 전달할 수 있다. SARSA는 실제 다음 행동의 값을 사용하고, Q-learning은 다음 최댓값을 사용하므로 행동 정책과 평가 목표의 관계가 다르다.

정책경사는 정책 매개변수 $\theta$에 대한 $\nabla_\theta\log\pi_\theta(a\mid s)$에 return 또는 advantage를 가중해 정책을 조정한다. $A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s)$인 advantage는 해당 행동이 그 상태에서 정책이 평균적으로 얻는 가치보다 얼마나 나은지를 나타낸다. 점수의 기울기는 행동의 확률을 늘리거나 줄이는 방향을 제공한다. 상태에만 의존하는 baseline은 분산을 줄이면서 적절한 조건에서 기대 기울기를 바꾸지 않는다. Actor–critic은 정책 actor와 가치 critic을 함께 학습한다. critic의 근사·bootstrap 오차와 정책 업데이트의 불안정성이 남는다.

모델 기반 방법은 전이·보상 모델로 계획하거나 학습 데이터를 가상으로 만든다. 모델 비기반은 가치·정책을 직접 갱신한다. 모델 기반은 표본을 재사용할 수 있지만 모델 오차를 긴 rollout에서 누적할 수 있다. 비기반도 전이 가정과 상태 표현이 필요하므로 “아무 모델 가정도 없다”는 뜻은 아니다.

모방학습의 행동 복제는 전문가의 상태–행동 쌍으로 정책을 지도학습한다. 학습 데이터와 달리 자신의 실수 뒤 도달한 상태에는 전문가 예시가 부족할 수 있다. 오프라인 RL은 고정 로그에서 누적 보상을 개선하려 하며 자료에 없는 행동의 가치를 과대추정하는 문제가 있다. 보수적 추정·정책 제약·지원집합 확인이 필요하고, 로그에 전혀 없는 행동의 효과를 데이터만으로 확정할 수는 없다.

## 제어와 안정성을 계산해 보기

제어는 동역학과 피드백을 명시적으로 다룬다. 스칼라 이산 시스템 $x_{t+1}=ax_t+bu_t$에서 $x_t$는 상태, $u_t$는 입력, $a,b$는 설계한 계수다. 피드백 $u_t=-kx_t$를 쓰면 $x_{t+1}=(a-bk)x_t$다. 이 선형·무잡음·무제약 모델은 $|a-bk|<1$일 때 초기 상태가 0으로 감쇠한다.

$a=0.8,b=1,k=0.3,x_0=2$이면 계수는 0.5, 상태는 $2,1,0.5,0.25,\ldots$다. $k=2$면 계수 -1.2, 상태는 $2,-2.4,2.88,\ldots$로 부호를 바꾸며 커진다. 강한 피드백이 무조건 안정적이지 않음을 알 수 있다.

이는 교육용 동역학 계산이다. 실제 장치에는 지연·포화·측정 잡음·미확인 계수·허용 입력이 있다. 위 $k$를 실제 모터나 장치에 적용하라는 지시가 아니다. 실제 구동 전에는 장치의 허용 전압·핀·전원·입력 범위와 안전 조건을 확인해야 한다.

시스템 식별은 입력–상태 관측으로 동역학 매개변수를 추정한다. 충분한 입력 변화가 없으면 서로 다른 계수가 같은 관측을 설명할 수 있다. 모형에 맞춘 시뮬레이션 성공과 실제 동역학 확인을 나눈다. 로보틱스는 인식, 상태 추정, 계획, 제어의 연결이며 각 계층의 불확실성과 인터페이스를 함께 다룬다.

## MPC와 월드모델

MPC는 현재 추정 상태에서 유한 미래 구간의 입력열을 최적화하고 첫 입력만 적용한 뒤 다시 계산한다. 목적은 상태 오차·입력 비용, 제약은 동역학·허용 상태·입력 등을 포함한다. 한 단계의 $x'=x+u$, 비용 $(x+u)^2+u^2$에서 미분을 0으로 두면 $u=-x/2$다. $x=2$면 입력 -1, 다음 상태 1, 비용 2다. 제약을 추가하면 같은 해를 그대로 쓸 수 없다.

반복 최적화는 피드백을 제공하지만 일반적으로 모든 모델 오류와 지연에서의 안정성을 자동 보장하지 않는다. horizon, terminal 조건, 관측기와 제약 처리가 중요하다. 강화학습과 MPC는 경쟁 명칭만이 아니라 보상·동역학·계획·정책의 역할에 따라 결합할 수 있다.

월드모델은 관측과 행동에서 상태 변화 또는 잠재 상태의 변화를 예측하는 모델이다. 잠재공간에서 “상상한” 경로로 계획·정책 학습을 할 수 있지만 복원·예측 손실이 낮다는 사실만으로 제어에 필요한 변수가 보존된다고 단정할 수 없다. 행동 변화에 따른 실제 결과와 긴 경로의 오차를 확인한다.

## 오개념 점검

- 보상은 실제 목표의 완전한 정의라는 가정부터 검토한다.
- 한 번의 Q 갱신이나 시뮬레이션 성공은 최적 정책·실제 하드웨어 검증이 아니다.
- 오프라인 자료가 없는 행동의 효과를 마음대로 외삽하지 않는다.
- 할인계수, 행동 주기와 물리적 지연은 다른 값이며 함께 기록한다.

## 연습과 단계 힌트

### M11-Q1

A–B 예제에서 $\gamma=0.5$일 때 두 행동의 값을 구하라. 이어 B의 종료 보상만 1로 바꾸면 선택이 어떻게 달라지는가?

힌트 1: B의 보상에는 A에서 한 단계의 할인을 적용한다. 힌트 2: 종료 뒤 가치는 0이다. 힌트 3: 두 조건에서 stop의 값은 바뀌지 않는다.

### M11-Q2

현재 Q값 0, 관측 보상 1, 다음 최대 Q값 4, $\gamma=0.5,\alpha=0.2$일 때 Q-learning 목표와 새 값을 계산하라.

힌트 1: 학습률과 할인계수를 혼동하지 않는다. 힌트 2: 목표에서 현재 값을 뺀다. 힌트 3: 부분 갱신이므로 목표에 바로 도달하지 않는다.

### M11-Q3

$a=0.8,b=1$에서 피드백 $k=1.9$의 안정성을 판단하고 안정적인 $k$ 구간을 구하라. 실제 장치에는 추가로 무엇을 확인해야 하는가?

힌트 1: 폐루프 계수를 계산한다. 힌트 2: $-1<a-bk<1$을 푼다. 힌트 3: 실측하지 않은 동역학·지연·입력 허용값을 구분한다.
