# 08. 신경망, 표현과 최적화

[교재 길잡이](../모델%20해석%20목차.md) · 선수: 02~04장과 [통계학습](06_statistical_learning.md) · 연결축: ④⑤⑨

## 학습 목표와 선수 질문

순전파와 역전파를 손으로 추적하고, 구조의 귀납편향과 최적화 선택을 구분한다. CNN·RNN·Transformer·SSM·MoE가 무엇을 재사용하고 어떤 계산을 하는지 설명한다. “연쇄법칙의 각 미분은 어디에서 오는가?”, “가중치 공유가 가정하는 입력 구조는 무엇인가?”를 먼저 점검하자.

## 표현을 함께 학습하는 함수

신경망은 입력을 여러 변환으로 표현한 뒤 목적에 맞는 출력을 만든다. 한 층은 보통 $h=\phi(Wx+b)$다. $x$는 입력 벡터, $W$는 가중치 행렬, $b$는 편향, $\phi$는 비선형 함수다. 비선형 활성화가 없다면 여러 층의 합성도 하나의 $W'x+b'$ 형태인 아핀 변환으로 합쳐진다. 편향이 없을 때는 하나의 선형 변환이다. 따라서 이런 층을 깊게 쌓는 것만으로 새로운 비선형 관계를 표현할 수는 없다.

ReLU는 $\phi(z)=\max(0,z)$로 양의 입력을 통과시키고 음의 입력을 0으로 만든다. sigmoid와 tanh는 값을 제한하지만 포화 구간에서 기울기가 작아질 수 있다. 어떤 활성화가 좋다는 말은 입력 규모·초기화·구조·목적 조건과 함께 판단한다. 임베딩은 이산 항목의 ID를 학습 가능한 벡터로 매핑하는 표현이며, 가까운 벡터의 의미는 학습 목적과 데이터가 만든 관계다.

계산그래프는 연산과 값의 의존성을 기록한다. 역전파는 출력 손실에서 각 매개변수로 이어지는 연쇄법칙을 재사용해 미분한다. 자동미분은 이 과정을 계산하지만, 손실 정의나 연결이 잘못된 모델을 올바르게 설계해 주는 도구는 아니다.

## 한 번의 역전파를 끝까지 계산하기

스칼라 입력 $x=2$, 목표 $y=2$에 대해

$$z=w_1x+b_1,\quad h=\mathrm{ReLU}(z),\quad \widehat y=w_2h+b_2,\quad L=\tfrac12(\widehat y-y)^2$$

를 사용한다. 초기값은 $w_1=1,b_1=-1,w_2=0.5,b_2=0$이다. 순전파는 $z=1,h=1,\widehat y=0.5,L=1.125$다.

출력의 미분은 $\partial L/\partial\widehat y=\widehat y-y=-1.5$다. 따라서

$$\frac{\partial L}{\partial w_2}=-1.5h=-1.5,\quad
\frac{\partial L}{\partial b_2}=-1.5,\quad
\frac{\partial L}{\partial h}=-1.5w_2=-0.75.$$

$z>0$이라 ReLU 미분은 1이다. $\partial L/\partial w_1=-0.75x=-1.5$, $\partial L/\partial b_1=-0.75$를 얻는다. 학습률 0.1로 네 값을 **같은 초기 상태에서 계산한 기울기로 동시에** 갱신하면

$$w_1=1.15,\quad b_1=-0.925,\quad w_2=0.65,\quad b_2=0.15.$$

다시 계산한 $h=1.375$, $\widehat y=1.04375$, $L=0.45720703125$다. 갱신 도중 바꾼 $w_2$로 앞 층 기울기를 다시 계산하면 원래 손실의 한 번의 경사하강과 달라진다.

조건을 바꿔 초기 상태에서 $x=0.5$로 두면 $z=-0.5$라 ReLU를 거쳐 앞 층으로 가는 미분은 0이다. 출력 편향 등 다른 매개변수는 여전히 학습될 수 있다. $z=0$에서는 일반 미분이 존재하지 않아 구현이 특정 값을 선택하므로, 미분 검사 예제는 경계점을 피한다.

## SGD, 초기화와 정규화

경사하강은 $\theta\leftarrow\theta-\eta\nabla_\theta L$이다. SGD는 전체 데이터 대신 표본이나 미니배치의 기울기를 이용한다. 잡음 때문에 한 번의 갱신이 전체 손실을 항상 줄이지는 않는다. 배치 크기, 학습률, 데이터 순서와 난수 조건을 기록한다. 모멘텀은 최근 기울기를 누적해 방향을 안정화하고, 적응적 방법은 좌표별 규모를 조절한다. 어느 최적화법도 모든 비볼록 문제의 전역해를 보장하지 않는다.

초기화는 층을 통과할 때 신호와 기울기 규모가 과도하게 커지거나 작아지지 않도록 설계한다. 모든 은닉 유닛을 동일한 값으로 시작하면 동일한 역할을 유지해 대칭이 깨지지 않을 수 있다. 정규화는 가중치 벌점, 데이터 증강, 조기 중단, dropout 등으로 학습을 제한한다. dropout은 학습 중 일부 표현을 무작위로 제거하는 방식이며 평가 시 처리까지 일관되어야 한다.

정규화 층의 “normalization”과 과적합을 제한하는 “regularization”은 용어가 비슷하지만 같은 정의가 아니다. 정규화 층은 선택한 축의 활성값으로 평균 $\mu$와 분산 $\sigma^2$를 구해 $\widetilde h=(h-\mu)/\sqrt{\sigma^2+\epsilon}$처럼 규모를 조정한다. $\epsilon>0$은 분모가 0이 되는 것을 피하는 작은 상수이며, 이후 학습하는 배율 $\gamma$와 이동값 $\beta$로 $\gamma\widetilde h+\beta$를 만들 수 있다. Layer normalization은 각 샘플의 지정한 특성 축을, batch normalization은 학습 중 배치와 정해진 공간 축 등을 사용하므로 같은 연산이 아니다. 일반적인 batch normalization은 평가 때 누적한 통계 추정치를 쓰므로 학습·평가 모드와 축의 선택을 확인해야 한다. 이러한 규모 조정이 일반화나 학습 성공을 자동으로 보장하지는 않는다.

잔차 연결은 $h_{\mathrm{new}}=h+F(h)$처럼 기존 정보를 더하는 경로를 두어 깊은 모델의 학습을 돕는다. 잔차만으로 모든 최적화 문제가 사라지지는 않는다.

## CNN과 RNN의 귀납편향

CNN은 가까운 위치의 정보와 가중치 공유를 활용한다. 1차원 입력 $(1,3,2)$에 길이 2 필터 $(1,-1)$를 뒤집지 않고 적용하면 출력은 $(1-3,3-2)=(-2,1)$이다. 실제 라이브러리의 convolution이라는 연산명에는 이런 상호상관 형태가 쓰이기도 하므로 정의를 확인한다. stride와 padding은 출력 크기와 경계 정보를 바꾼다. 지역성과 이동에 대한 구조가 이미지·신호에 적합할 수 있지만 전역 관계를 학습하려면 층이나 다른 연결이 필요하다.

RNN은 $h_t=\tanh(W_hh_{t-1}+W_xx_t+b)$로 이전 상태를 재사용한다. $t$는 시간, $h_t$는 숨은 상태다. 긴 시간에 걸친 미분은 여러 Jacobian의 곱이 되어 소실·폭주할 수 있다. LSTM·GRU는 게이트로 정보 유지·갱신 경로를 조절한다. 순서 표현에 자연스럽지만 시간 단계의 의존성 때문에 학습 병렬화에 제한이 생길 수 있다.

## Attention과 Transformer

Attention은 질의 $Q$, 키 $K$, 값 $V$를 이용해 필요한 위치의 정보를 가중합한다. 키 벡터 차원 $d_k$에 대해

$$\mathrm{Attention}(Q,K,V)=\mathrm{softmax}(QK^\top/\sqrt{d_k})V.$$

softmax는 각 질의의 키 점수에 대해 계산한다. 질의 $(1,0)$, 키 $(1,0),(0,1)$, $d_k=2$이면 점수는 $(1/\sqrt2,0)$이고 가중치는 약 $(0.669762,0.330238)$이다. 값이 $(2,0),(0,4)$이면 결과는 약 $(1.339523,1.320954)$다. 질의와의 내적 점수가 큰 키에 연결된 값이 더 큰 가중치를 받으며, 키와 값은 같은 역할이 아니다. 벡터 크기를 따로 제한하지 않은 내적 점수를 유클리드 거리의 가까움과 동일시하지 않는다.

Self-attention은 같은 시퀀스에서 질의·키·값을 만들고, cross-attention은 서로 다른 표현을 연결한다. 위치 정보를 넣지 않으면 단순한 self-attention만으로 순서를 충분히 구별할 수 없다. 위치 표현과 마스크는 역할이 다르며, 자기회귀 생성의 causal mask는 미래 토큰을 보지 못하게 한다.

Transformer는 attention, 위치별 변환, 잔차와 정규화 등으로 구성된다. 원 논문은 encoder–decoder 번역 모델을 제안했으며 이후 encoder-only·decoder-only 등 다양한 구성이 사용된다. 구조 이름만으로 실제 모델의 학습 자료·목적·내부 세부를 확정하지 않는다. 모든 토큰 쌍을 다루는 기본 attention의 점수 행렬은 길이 $T$에 대해 $T^2$개 원소를 가지지만, 실제 구현의 메모리·시간은 계산 재사용과 다른 연산도 함께 좌우한다. [Attention Is All You Need](https://arxiv.org/abs/1706.03762)

## 심화: SSM, 희소구조와 MoE

이산 선형 상태공간 모델의 기본 형태는 $h_{t+1}=Ah_t+Bx_t,\ y_t=Ch_t$다. $h_t$는 내부 상태, $A,B,C$는 전이·입력·출력 변환이다. 예를 들어 스칼라 $A=0.5,B=1,h_0=0$, 입력 2·0이면 상태는 2·1로 변한다. 이전 정보가 감쇠하며 남는다. S4는 구조화된 상태공간으로 긴 시퀀스를 처리하는 설계를 연구했고, Mamba는 입력에 따라 일부 상태공간 매개변수·선택 과정을 조절한다. 단순 선형 예제가 이 논문들의 전체 알고리즘은 아니다. 선형 시간이라는 설계 특성도 실제 하드웨어에서 항상 더 빠르다는 뜻은 아니다. [S4](https://arxiv.org/abs/2111.00396), [Mamba](https://arxiv.org/abs/2312.00752)

희소 attention은 각 위치가 모든 위치 대신 일부에 접근하게 하여 계산을 줄인다. 어떤 경로를 생략하는지가 긴 거리 정보의 전달을 제한할 수 있으므로 패턴과 과제를 함께 설계한다. MoE는 라우터가 입력별로 일부 expert를 선택하여 $y=\sum_{e\in\mathcal S(x)}g_e(x)f_e(x)$처럼 결합한다. $\mathcal S(x)$는 선택된 집합, $g_e$는 가중치다. 총 매개변수와 한 입력에서 활성화하는 매개변수는 다르다. 부하 불균형, 통신, 라우팅 안정성, 저장 메모리는 남은 비용이다. [Switch Transformers](https://arxiv.org/abs/2101.03961)

## 오개념과 선택 기준

“역전파가 곧 학습법 전체다”라는 말은 목적·최적화·데이터를 빠뜨린다. “attention 가중치는 확실한 인과 설명이다”라는 말은 내부 가중합과 원인 검증을 혼동한다. “매개변수가 많으면 모두 매번 계산한다”는 MoE 등에서 맞지 않으며, 반대로 적게 활성화한다고 저장·통신 비용까지 자동으로 작아지는 것도 아니다.

입력의 지역성·순서·관계, 길이, 자원과 오류 형태를 기준으로 구조를 고른다. 기술 목표는 작은 순전파·기울기 계산의 일치이며, 학습 목표는 그 연산과 가정이 왜 필요한지 설명하는 것이다.

## 연습과 단계 힌트

### M08-Q1

역전파 예제의 초기값은 유지하되 목표를 $y=1$로 바꿔 손실, 네 기울기, 학습률 0.1의 갱신값을 구하라.

힌트 1: 순전파 값은 그대로다. 힌트 2: 출력 잔차만 먼저 바뀐다. 힌트 3: 앞 층으로 전달할 때 초기 $w_2$를 쓴다.

### M08-Q2

시퀀스 순서를 구분해야 하는 과제에서 위치 표현을 제거한 self-attention만 썼다. 어떤 문제가 있는가? causal mask만 추가하면 모든 위치 정보 문제가 해결되는지 설명하라.

힌트 1: 입력·키·값을 함께 순열로 바꾼 경우를 생각한다. 힌트 2: 가중합과 순서 인식은 다른 문제다. 힌트 3: 보이는 정보의 범위와 위치의 표현을 나눈다.

### M08-Q3

MoE의 총 매개변수가 더 많은데도 한 입력의 연산은 적을 수 있는 이유를 설명하라. 작은 지연을 확인하기 위해 측정할 항목 세 가지 이상을 설계하라.

힌트 1: 전체 expert와 선택 expert를 나눈다. 힌트 2: 라우팅·부하·통신을 포함한다. 힌트 3: 입력 길이·배치·장비 조건을 고정한다.
