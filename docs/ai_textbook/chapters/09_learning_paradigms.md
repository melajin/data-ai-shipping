# 09. 학습 신호, 지식 재사용과 분산 조건

## 학습 목표와 선수 질문

같은 시스템을 학습 신호·재사용·데이터 접근 조건으로 각각 설명하고, 자기지도·전이·연합 학습을 배타적인 유형으로 취급하지 않는다. 어떤 레이블이 어디에서 왔는지 추적하고 작은 가중 평균을 계산한다. “레이블이 없다”와 “목적이 없다”는 같은가? “이전 모델을 쓴다”와 “그 모델의 가중치를 바꾼다”는 같은가?

## 학습 신호의 출처부터 보기

지도학습은 입력과 목표값의 쌍을 이용한다. 비지도학습은 외부 정답 없이 입력의 구조·분포를 찾는다. 자기지도학습은 원자료의 일부를 목표로 만드는 방식이다. 문장의 일부를 가리고 복원하거나 다음 토큰을 예측할 수 있다. 자료에서 목표를 만들었더라도 전처리·과제 설계·데이터 선택이라는 사람의 가정은 존재한다. 자기지도를 비지도의 하위로 묶는 문헌도 있으므로 정의 범위를 먼저 적는다.

준지도학습은 레이블 있는 소량 데이터와 레이블 없는 데이터를 함께 쓴다. 의사라벨은 모델 예측을 임시 정답으로 사용하는 방법이다. 자신감이 큰 오답을 반복 학습하면 오류가 강화된다. 일관성 학습은 의미가 보존되는 입력 변형에 대해 예측이 일치하도록 요구하지만, 변형이 실제 목표를 바꾸면 잘못된 제약이 된다.

대조학습은 관련된 두 표현을 가까이, 비교 대상은 상대적으로 멀게 만드는 목적을 사용한다. 어떤 쌍이 “관련”인지는 데이터와 증강의 설계다. 마스킹은 가린 정보를 복원하도록 하며 어떤 정보가 쉽게 복사되거나 누수되는지를 점검해야 한다. 이 목적이 만든 표현이 후속 과제에 유용한지는 별도 평가한다.

## 대조 목적의 작은 계산

질의 표현과 정답 짝의 유사도 $s_+=1$, 비교 짝의 유사도 $s_-=0$, 온도 $\tau=1$로 두자. 두 후보에 대한 softmax형 손실은

$$L=-\log\frac{\exp(s_+/\tau)}
{\exp(s_+/\tau)+\exp(s_-/\tau)}
=\log(1+e^{-1})\approx0.313262.$$

온도를 0.5로 바꾸면 $L=\log(1+e^{-2})\approx0.126928$이다. 이는 같은 점수를 더 뾰족하게 만든 계산이며 온도가 낮을수록 학습과 일반화가 항상 좋아진다는 증거는 아니다. 의미가 같은 다른 샘플을 음성 짝으로 잘못 넣거나 증강이 핵심 정보를 지우면 목적 자체가 잘못될 수 있다. [SimCLR의 대조학습 설계](https://arxiv.org/abs/2002.05709)

## 전이와 적응: 무엇을 바꾸는가

전이학습은 이전 과제·분포에서 얻은 표현이나 매개변수를 새 과제에 활용한다. 고정된 표현 위에 작은 예측기를 학습하는 방법과 전체 가중치를 미세조정하는 방법은 변경 범위가 다르다. 이전 지식이 새 과제의 중요한 구분을 무시하면 부정적 전이가 생길 수 있다. 사전학습의 규모만으로 전이 성공을 단정하지 않는다.

다중과제학습은 여러 목적을 함께 최적화한다. $\sum_k\lambda_kL_k$에서 $L_k$는 과제 $k$의 손실, $\lambda_k$는 상대 가중치다. 표현을 공유해 표본을 재사용할 수 있지만 목적의 기울기가 충돌하거나 데이터가 많은 과제에 치우칠 수 있다. 평가도 각 과제에 따로 남긴다.

도메인 적응은 입력이나 레이블 분포가 다른 환경으로 옮겨 가는 문제다. Covariate shift는 입력 분포 $p(x)$가 바뀌지만 $p(y\mid x)$는 유지된다는 가정이다. Label shift는 클래스 비율 $p(y)$가 바뀌지만 각 클래스 안의 입력 분포 $p(x\mid y)$는 유지된다는 가정이다. 클래스 비율이 달라졌다는 관측만으로 label shift의 조건 전체를 확인한 것은 아니다. 두 조건부 분포는 방향이 다르므로 “분포가 달라졌다”만으로 어떤 보정이 필요한지 정해지지 않는다. 목표 환경에 레이블이 없는 경우 성능 확인 자체가 어려우므로 가정과 확인 가능한 부분을 명시한다.

문맥 내 학습은 예시·지시를 입력 문맥으로 제공해 반응을 바꾸는 사용 방식이다. 일반적인 사용 시점에는 모델 가중치를 갱신하지 않는다. 이를 미세조정과 혼동하면 비용·재현성·정보 보존의 기대가 달라진다. 외부 검색을 통해 문맥을 제공하는 RAG의 시스템 구성은 17장에서 다룬다.

## 심화: 메타, 지속과 능동 학습

메타학습은 여러 과제의 경험으로 새로운 과제에 빠르게 적응하는 방식을 학습한다. MAML의 한 형태는 과제별 학습 집합에서 $\theta'=\theta-\alpha\nabla_\theta L_{\mathrm{train}}(\theta)$로 적응한 뒤, 별도 질의 집합의 $L_{\mathrm{query}}(\theta')$가 작아지도록 초기 $\theta$를 조정한다. $\alpha$는 내부 학습률이다. 같은 데이터를 내부·외부 평가에 섞으면 적응 능력 평가가 왜곡된다. 훈련 과제 분포와 아주 다른 새 과제로의 성공을 보장하지 않는다. [Model-Agnostic Meta-Learning](https://arxiv.org/abs/1703.03400)

지속학습은 연속으로 들어오는 과제를 배우며 이전 지식을 유지하려는 문제다. 단순 미세조정은 이전 과제에 중요한 매개변수를 바꾸어 망각할 수 있다. 재생은 이전 자료나 생성 예시를 다시 쓰고, 정규화는 중요한 매개변수의 변화를 제한한다. EWC는 이전 매개변수 $\theta^*$와 중요도 근사 $F_j$를 이용해 $\sum_jF_j(\theta_j-\theta_j^*)^2$ 형태의 벌점을 추가한다. 대각 중요도 근사와 과제 식별 등의 조건이 있으며 개인정보·저장·새 과제 적응과의 균형도 필요하다. [Overcoming catastrophic forgetting](https://arxiv.org/abs/1612.00796)

능동학습은 레이블을 얻을 표본을 선택한다. 불확실한 표본, 대표성이 높은 표본, 모델 간 의견이 다른 표본 등을 선택할 수 있다. 레이블 비용을 줄일 수 있지만 선택된 표본이 전체 분포를 대표하지 않거나, 불확실성이 오보정되면 효율이 떨어진다. 성능 평가용 표본까지 같은 선택 편향을 갖게 만들지 않도록 구분한다.

## 연합·분산은 데이터 접근과 계산의 조건

분산학습은 여러 계산 자원에 데이터나 모델 연산을 나누는 방식이다. 연합학습은 보통 원자료가 여러 참여자에게 남아 있는 상황에서 업데이트를 모아 학습한다. 두 방식은 겹칠 수 있지만 같은 뜻은 아니다. 지도·자기지도 같은 신호와 동시에 적용할 수 있다.

FedAvg에서는 참여자들이 같은 구조의 모델과 같은 전역 매개변수에서 시작해 각자 자료로 지역 갱신을 수행한 뒤 결과를 집계한다. 서로 다른 구조나 독립적으로 초기화한 모델을 임의로 평균한다는 뜻은 아니다. 한 라운드에 참여한 대상들을 $k$로 표시할 때, 단순한 집계는 참여자 $k$의 표본 수 $n_k$, 업데이트된 매개변수 $\theta_k$에 대해

$$\theta_{\mathrm{new}}=\sum_k\frac{n_k}{\sum_jn_j}\theta_k$$

로 쓴다. 스칼라 예에서 참여자 A는 표본 3개·매개변수 2, B는 표본 1개·매개변수 5다. 표본 가중 평균은 $(3\cdot2+1\cdot5)/4=2.75$이고 균등 평균은 3.5다. 둘은 서로 다른 목표 가중을 구현한다.

두 참여자의 분포가 다르고 각자 여러 번 갱신하면 지역 모델이 다른 방향으로 이동할 수 있다. 평균만으로 중앙집중 최적화와 항상 같아지는 것은 아니다. 원자료를 보내지 않아도 업데이트에서 정보가 유출될 수 있으므로 연합이라는 이름만으로 개인정보 보호가 보장되지 않는다. 통신 비용, 참여자 선택, 부하와 실패, 보안·차등개인정보는 별도 설계 대상이다. [Communication-Efficient Learning of Deep Networks from Decentralized Data](https://arxiv.org/abs/1602.05629)

## 선택 기준과 오개념

레이블의 양·비용, 원자료 접근, 새 과제의 차이, 지식 유지 필요, 평가 가능성을 먼저 적는다. 신호가 부족하면 자기지도·준지도, 새 과제의 표본이 적으면 전이·메타, 과제가 이어지면 지속, 레이블이 비싸면 능동, 자료가 나뉘어 있으면 연합의 질문을 검토한다. 이들은 결합 가능한 설계 축이며 자동으로 효과가 보장되는 처방은 아니다.

“자기지도에는 사람의 가정이 없다”, “의사라벨은 정답이다”, “문맥 내 학습은 곧 가중치 학습이다”, “연합이면 개인정보가 안전하다”, “온도를 줄였더니 손실이 작아져 모델이 좋아졌다”를 각각 반례와 조건으로 고쳐 말할 수 있어야 한다.
