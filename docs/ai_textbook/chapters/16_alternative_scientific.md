# M16. 통합·대안 접근과 과학 AI

관련 축은 ④ 표현·귀납편향, ⑤ 학습·추론, ⑥ 전문 분야다. 이 장은 신경망과 다른 표현을 결합하거나, 탐색·시간·물리 구조를 이용하는 이유를 설명한다. 대안이라는 말은 주류보다 우월하다는 순위를 뜻하지 않는다. 각 접근이 줄여 주는 어려움과 새로 요구하는 가정을 비교한다.

## 1. 목표와 선수 질문

학습 목표는 신경기호, 프로그램 합성, 진화, 퍼지, 스파이킹, 물리제약 학습, 신경연산자, 대칭성 학습을 같은 신경망 이름 목록으로 취급하지 않고 표현·목적·계산의 차이로 설명하는 것이다. 기술 목표는 작은 규칙·후보 프로그램·방정식 잔차를 직접 계산하는 것이다. 코딩, GPU, 실제 센서가 필수인 장은 아니다.

선수 질문은 세 가지다. 규칙의 참·거짓과 확률은 어떻게 다른가? 연쇄법칙을 적용하려면 함수에 어떤 성질이 필요한가? 방정식을 만족하는 것과 관측값에 가까운 것은 왜 다른가? 논리와 탐색은 M05, 확률은 M03·M07, 미분과 최적화는 M02·M08에서 필요한 부분만 보충한다. 과학 사례의 시간과 상태는 정규화된 수학량으로 다루므로 특정 장치 연결 지시가 없다.

## 2. 신경기호: 지각 결과를 규칙에 연결하기

신경기호 접근은 패턴을 인식하는 신경 부분과 조합·관계·제약을 다루는 기호 부분을 연결한다. 예를 들어 이미지에서 숫자를 읽고 두 숫자의 합이 특정 값인지 판단하는 문제에서, 신경망은 각 이미지의 숫자 분포를 내고 기호 규칙은 가능한 숫자 쌍을 합의 조건으로 묶는다. 최종 합의 정답으로부터 인식 부분까지 학습 신호를 전달할 수도 있다. 이 형태의 실제 원리 사례는 신경 술어를 확률 논리 프로그램에 넣은 [DeepProbLog, Manhaeve 등, 2018](https://arxiv.org/abs/1805.10872)다.

두 이미지의 숫자를 $D_1,D_2$, 입력을 $x_1,x_2$, 합을 $S$라고 하자. $p_1(d\mid x_1),p_2(e\mid x_2)$는 숫자값 $d,e$의 확률이다. 입력을 조건으로 두 숫자 인식이 독립이라는 단순 모형에서

$$
P(S=s\mid x_1,x_2)=\sum_{d+e=s}p_1(d\mid x_1)p_2(e\mid x_2)
$$

이다. $s$는 목표 합, $P$는 모형의 확률, 합 기호는 조건을 만족하는 모든 숫자 쌍을 더한다. 이미지 1이 숫자 0일 확률 0.2, 1일 확률 0.8이고 이미지 2가 0일 확률 0.7, 1일 확률 0.3이라면 합 1의 확률은 $0.2(0.3)+0.8(0.7)=0.62$다. 합 0은 0.14, 합 2는 0.24이므로 전체 합은 1이다. 규칙이 확률을 조합하지만 잘못된 입력 인식을 없애 주지는 않는다.

기호 지식의 형식, 추론 계산의 가능성, 신경 출력의 의미가 명시되어야 한다. 확률 논리의 사건들이 종속이면 위처럼 확률을 무조건 곱할 수 없다. 규칙이 실제 문제를 잘못 표현하거나 탐색 공간이 크면 결합 자체가 병목이 된다. 규칙을 손실의 벌점으로 넣는 소프트 제약, 출력 후 규칙으로 걸러내는 검사, 논리 프로그램 내부에서 학습하는 방식도 서로 다르다. “규칙을 붙였다”는 사실만으로 형식적 보장을 주장하지 않는다.

## 3. 프로그램 합성: 예제를 만족하는 절차를 찾기

프로그램 합성은 입력·출력 예제나 논리적 명세를 만족하는 프로그램을 찾는다. 후보 언어 $\mathcal L$, 프로그램 $p$, 예제 $(x_i,y_i)$, 예제 수 $n$을 정하면 기본 조건은 모든 $i=1,\ldots,n$에 대해 $p(x_i)=y_i$다. $\mathcal L$은 허용 연산·자료형·반복 등의 범위를 정한다. 탐색은 열거, 제약 풀이, 확률적 탐색, 신경망의 후보 순위 제안 등으로 수행할 수 있다. 명세가 강하면 검증이 명확해지지만 탐색 비용이 늘고, 예제만 있으면 여러 프로그램이 똑같이 적합할 수 있다.

입력 0에 출력 1, 입력 1에 출력 2라는 두 예제를 보자. $p_1(x)=x+1$, $p_2(x)=x^2+1$은 둘 다 만족한다. 입력 2에서는 각각 3과 5다. 두 예제의 성공은 명세 밖에서의 일반화를 증명하지 않는다. 프로그램 길이를 선호하는 사전분포나 새 입력을 물어보는 능동적 명세 보강이 후보를 좁힐 수 있다. [DreamCoder, Ellis 등, 2020](https://arxiv.org/abs/2006.08381)는 프로그램 검색을 유도하는 신경망과 재사용 가능한 추상화를 배우는 언어를 함께 학습하는 사례다. 이 결과가 임의의 프로그램 명세를 항상 풀 수 있다는 보장은 아니다.

## 4. 진화·유전·신경진화: 미분 대신 후보 집단 평가하기

진화 알고리즘은 후보 집단을 평가하고 선택·변이·교차를 반복한다. 후보를 $g$, 평가 함수를 $F(g)$라고 하자. $g$는 수치 매개변수뿐 아니라 프로그램이나 신경망의 연결 구조일 수 있다. 적합도 $F$는 최대화하는 점수로 설계하며 실제 목표를 대신하는 대리 지표라는 점을 M01과 연결한다. 유전 알고리즘은 보통 유전자 형태의 부호화와 교차를 사용하고, 신경진화는 신경망의 가중치·구조·학습 규칙 등을 진화 대상으로 삼는다. 모두 같은 세부 알고리즘은 아니다.

미분할 수 없는 시뮬레이터나 이산 구조에도 적용할 수 있다는 장점이 있지만, 많은 후보를 평가해야 한다. 잡음이 큰 평가에서는 우연히 좋은 후보를 반복 선택할 수 있으므로 평가 반복, 공통 조건, 별도 검증 과제가 필요하다. 탐색 결과가 전역 최적이라는 보장은 일반적으로 없다. 다양한 후보를 유지하면 조기 수렴을 줄일 수 있지만 추가 계산과 설계가 필요하다. [NEAT, Stanley·Miikkulainen, 2002](https://nn.cs.utexas.edu/downloads/papers/stanley.ec02.pdf)는 연결 유전자의 대응을 관리하고 종 분화로 새 구조를 보호하며 단순한 네트워크에서 구조를 확장하는 방법이다. 그 논문의 과제별 실험 결과를 모든 최적화 문제의 우월성으로 옮기지 않는다.

## 5. 퍼지: 확률과 다른 연속적 소속도

퍼지 집합 $B$는 대상 $x$마다 소속도 $\mu_B(x)\in[0,1]$을 부여한다. $\mu_B$는 소속함수다. “온도가 덥다”의 경계를 점진적으로 만들 수 있다. 0.7이라는 소속도는 “더울 확률이 70%”라는 뜻이 아니다. 측정 불확실성에 관한 확률분포와, 언어적 범주에 얼마나 부합하는지를 표현하는 소속도는 역할이 다르다. 이 구분은 [Zadeh의 *Theory of Fuzzy Sets*, 1977, 정의와 기본 연산](https://www2.eecs.berkeley.edu/Pubs/TechRpts/1977/ERL-m-77-1.pdf)에 근거한다.

한 선택에서는 AND를 최소값, OR를 최대값, NOT을 $1-\mu$로 정의한다. 다른 결합 연산도 가능하므로 선택한 연산을 명시해야 한다. 규칙이 내는 소속도나 활성도를 수치 출력으로 바꾸는 비퍼지화도 별도 설계다. 다음 계산의 가중평균은 단일 상수 출력을 갖는 규칙으로 정한 예제이며 모든 퍼지 제어기가 이 방식을 쓰는 것은 아니다.

온도 $T$의 단위는 °C, $\mu_w$는 따뜻함, $\mu_h$는 더움의 소속도다. 가상 규칙을

$$
\mu_w(T)=\max(0,1-|T-25|/10),\qquad
\mu_h(T)=\min(1,\max(0,(T-20)/20))
$$

로 정한다. 온도 차의 분모 10과 20도 °C 단위이므로 소속도는 무차원이다. 따뜻함 규칙의 출력 $v_w=30$, 더움 규칙의 출력 $v_h=70$은 가상 출력 비율의 퍼센트 값이다. 출력

$$
v=\frac{\mu_w v_w+\mu_h v_h}{\mu_w+\mu_h}
$$

는 활성도의 합이 양수일 때 정의한다. $T=28$이면 $\mu_w=0.7,\mu_h=0.4$이므로 $v=(21+28)/1.1\approx44.55$다. 이 값은 계산한 가상 명령값이며 실제 팬의 회전수·전압과 대응한다고 검증하지 않았다. 두 활성도가 모두 0이면 기본 동작이나 오류 상태를 별도로 정해야 한다. 소속함수와 규칙을 전문가가 정했다는 사실만으로 폐루프 안정성이나 허용 장치 동작이 증명되지는 않는다.

## 6. 스파이킹과 시간 부호화

스파이킹 신경망은 연속적인 활성값만 전달하는 대신 특정 시각에 발생하는 사건인 스파이크를 다룬다. 누설 적분 발화 모형에서는 입력을 적분한 막전위가 임계값을 넘으면 사건을 발생시키고 상태를 초기화한다. 간단한 물리 형태는

$$
\tau\frac{du(t)}{dt}=-(u(t)-u_{rest})+RI(t)
$$

이다. $t$는 초 단위 시간, $u$는 V 단위 막전위, $u_{rest}$는 휴지 전위, $R$은 Ω 단위 저항, $I$는 A 단위 입력 전류, $\tau$는 초 단위 시간 상수다. 임계값 $\vartheta$ 역시 V이며 $u$가 임계값을 아래에서 넘으면 스파이크 시각을 기록하고 지정한 초기화 전위로 바꾼다. 전위 방정식과 발화·초기화 규칙을 모두 명시해야 모형이 완성된다. [Gerstner 등, *Neuronal Dynamics*, §1.3](https://neuronaldynamics.epfl.ch/online/Ch1.S3.html)은 이 원리와 단순화의 범위를 설명한다.

발화율 부호화는 일정 구간의 스파이크 수를, 시간 부호화는 첫 발화 시각·간격·상대 순서를 정보로 이용한다. 시간 해상도와 관찰 구간을 바꾸면 같은 입력의 표현도 달라질 수 있다. 임계값 사건은 일반적인 미분에서 불연속이므로 대리 기울기, 국소 가소성 규칙, 기존 신경망의 변환 등 다른 학습 방법이 필요하다. 대리 기울기는 실제 계단 함수의 정확한 미분이라는 주장이 아니라 학습을 위한 근사다. 사건이 드문 입력과 적합한 실행 장치에서는 연산을 줄일 수 있지만, 시간 시뮬레이션 비용·메모리·장치 특성까지 확인하지 않고 에너지 절감 수치를 주장하면 안 된다. 위 회로 해석은 수학 모형의 설명이며 실제 부품으로 연결하라는 지시가 아니다.

## 7. 물리제약 학습: 데이터 오차에 방정식 잔차 더하기

과학 AI는 과학·공학 문제의 예측, 역문제, 발견, 계산을 지원하는 분야다. 특정 신경망 구조 하나의 이름이 아니다. 물리 지식을 학습 목적이나 구조에 넣는 방법은 그 일부다. 물리정보 신경망(PINN)은 함수 근사 $u_\theta$에 데이터·초기조건·경계조건과 지배 방정식의 잔차를 함께 적용하는 대표 방식이다. $\theta$는 학습하는 매개변수다. 원리의 근거는 [Raissi·Perdikaris·Karniadakis의 저자 자료, 연속시간 모형](https://maziarraissi.github.io/PINNs/)이다.

일반적인 손실을 $L=L_{data}+\lambda L_{phys}$로 쓰자. $L_{data}$는 관측·초기·경계 데이터와의 오차, $L_{phys}$는 선택한 점에서 방정식 잔차의 평균제곱, $\lambda\ge0$는 상대 가중치다. 각 항의 단위와 규모가 다르면 정규화나 단위에 맞는 가중치가 필요하다. 방정식을 알고 필요한 미분이 가능하며 초기·경계 조건이 문제를 적절히 정한다는 가정이 있다. 잔차를 줄인 점들 사이와 새로운 영역에서의 해 오차는 별도 검사 대상이다. 강한 다중 시간척도, 불연속 해, 잘못된 방정식, 손실 항 사이의 불균형은 학습을 어렵게 만든다. 잔차를 벌점으로 넣은 소프트 제약과 항상 성립하도록 구조에 넣은 하드 제약도 구분한다.

### 완료 계산 예제: 해의 오차와 잔차

무차원 시간 $t$와 상태 $u$에서 $u'(t)+ku(t)=0$, $u(0)=1$을 생각하자. $u'$는 시간에 대한 미분, $k>0$는 무차원 시간에 대한 감소율이다. 처음에는 $k=1$이다. 후보 함수 $u_a(t)=e^{-at}$를 쓰며 $a$는 양의 후보 감소율, $e$는 자연상수다. 이 함수는 모든 $a$에서 초기조건을 만족하지만 방정식은 $a=k$일 때 만족한다.

미분하면 $u_a'=-ae^{-at}$, 따라서 잔차는 $r_a(t)=u_a'+ku_a=(k-a)e^{-at}$다. 검사용 점을 0과 1로 정하고 $L_{phys}=[r_a(0)^2+r_a(1)^2]/2$로 계산한다. $k=1,a=0.5$이면 $r(0)=0.5$, $r(1)=0.5e^{-0.5}\approx0.30327$다. 손실은

$$
L_{phys}=\frac{0.25+0.25e^{-1}}2\approx0.170985.
$$

정확한 해는 $u_*(t)=e^{-t}$이며 별표는 이 문제의 정확한 해를 뜻한다. 시간 1에서 후보는 0.606531, 정확한 해는 0.367879이므로 절대 오차는 0.238651이다. $a=1$로 바꾸면 잔차는 모든 시간에서 0이고 이 함수족에서는 정확한 해가 된다. 이 결론은 후보 함수의 식을 직접 계산해 확인한 것이지 임의의 학습 모형에서 두 점의 잔차만 보고 얻은 보장은 아니다.

조건 변경으로 감소율을 $k=2$로 바꿔 보자. 기존 $a=1$ 후보의 잔차는 $e^{-t}$이고 두 점의 손실은 $(1+e^{-2})/2\approx0.567668$이다. 새 정확한 해의 시간 1 값은 $e^{-2}\approx0.135335$다. 옛 후보의 0.367879와 비교한 절대 오차는 0.232544다. 물리 조건이 바뀌면 이전에 정확했던 함수를 재검증해야 한다. 결과는 해석식과 수치 계산의 검산이며 실제 물체의 냉각·감쇠 실험 결과가 아니다.

## 8. 신경연산자: 한 함수에서 다른 함수로

보통 회귀가 벡터를 벡터로 보내는 함수를 학습한다면, 신경연산자는 초기 상태나 공간별 계수 같은 입력 함수에서 해 함수로 가는 연산자를 학습한다. $\mathcal G_\theta:a(\cdot)\mapsto u(\cdot)$에서 $a$는 위치에 따라 달라지는 입력 함수, $u$는 해 함수, $\mathcal G_\theta$는 매개변수화한 함수 사이의 사상이다. 앞 예제에서 여러 감소율과 초기조건에 대한 해를 묶어 배우려는 목표는 단일 조건의 해를 근사하는 목표와 다르다.

Fourier Neural Operator(FNO)의 한 층을 간략히

$$
v_{\ell+1}(x)=\sigma\!\left(Wv_\ell(x)+
\mathcal F^{-1}[R_\ell\mathcal F(v_\ell)](x)\right)
$$

로 나타낼 수 있다. $x$는 공간 좌표, $v_\ell$는 $\ell$번째 층의 채널별 함수, $W$는 위치별 선형변환, $\mathcal F$와 $\mathcal F^{-1}$는 Fourier 변환과 역변환, $R_\ell$은 선택한 주파수 모드에 작용하는 학습 가중치, $\sigma$는 채널별 비선형 함수다. 이 식은 비국소적 상호작용을 주파수 공간에서 계산하는 원리를 보여 준다. [Li 등, FNO, 2020/2021, §2~4](https://arxiv.org/html/2010.08895v3)는 함수 공간과 이산화의 관계를 설명한다.

함수 공간의 사상을 학습한다는 목표가 모든 격자·경계·새 물리 조건에서 정확하다는 뜻은 아니다. 학습 해 데이터의 생성 비용과 오차, 입력 함수의 분포, 경계 처리, 보존량, 해상도 변경의 오차를 확인해야 한다. 한 조건의 적은 데이터로 해를 찾는 PINN과 많은 조건에 대한 빠른 반복 예측을 목표로 하는 연산자 학습은 용도가 다르며 서로 결합할 수도 있다. 논문이 제시한 속도 결과는 해당 방정식·해상도·비교 환경의 결과로 읽는다.

## 9. 기하와 대칭성: 변환 후 무엇이 유지되어야 하는가

입력을 이동·회전·순열했을 때 출력이 어떻게 바뀌어야 하는지를 구조에 넣을 수 있다. 변환 $g$가 입력에 작용하는 연산을 $T_g$, 출력에 작용하는 연산을 $S_g$, 예측 함수를 $f$라고 하면 등변성은 $f(T_gx)=S_gf(x)$다. 불변성은 출력이 변하지 않는 경우인 $f(T_gx)=f(x)$다. 물체의 분류는 회전에 불변하게, 물체의 위치나 힘 벡터는 회전에 따라 함께 변하도록 설계할 수 있다.

벡터 $x=(1,0)$, 90도 회전 $T_gx=(0,1)$, 함수 $f(x)=2x$를 보자. 회전 후 예측은 $(0,2)$, 예측 $(2,0)$을 회전한 결과도 $(0,2)$로 등변적이다. 벡터 길이를 내는 함수는 회전 전후 모두 1로 불변적이다. 출력의 종류에 맞는 성질을 선택해야 한다. [Cohen·Welling, G-CNN, 2016](https://arxiv.org/abs/1602.07576)은 군의 변환과 가중치 공유를 연결한 원논문이다.

대칭성이 실제 과제에 성립하면 필요한 데이터와 계산의 낭비를 줄이는 귀납편향이 된다. 그러나 중력이 있는 환경에서 모든 회전을 같은 것으로 취급하거나, 방향이 의미 있는 문자를 회전에 불변하게 만들면 필요한 차이를 지운다. 실제 이산화와 수치 오차에서 등변성이 어느 정도 유지되는지도 측정해야 한다. 데이터 증강은 변환한 예를 학습에 추가하는 절차이며 구조적으로 등변성을 보장하는 설계와 동일하지 않다.

## 10. 방법 선택과 오개념

| 문제의 조건 | 먼저 검토할 접근 | 함께 점검할 한계 |
| --- | --- | --- |
| 지각과 명시 규칙이 모두 중요 | 신경기호 | 규칙 오류, 확률 의존성, 추론 비용 |
| 실행 절차가 결과물이어야 함 | 프로그램 합성 | 명세 부족, 탐색 폭발, 예제 밖 검증 |
| 구조가 이산적이거나 평가가 미분 불가 | 진화·신경진화 | 평가 횟수와 잡음, 대리 적합도 |
| 언어적 경계가 점진적 | 퍼지 | 소속도와 확률 혼동, 규칙 검증 |
| 사건 시각이 중요한 입력 | 스파이킹 | 시간 해상도, 학습 근사, 실행 비용 |
| 방정식과 초기·경계조건을 활용 | 물리제약 학습 | 방정식 오류, 잔차와 해 오차의 차이 |
| 다양한 함수 조건의 해를 반복 예측 | 신경연산자 | 데이터 생성, 조건·격자 변화 |
| 알려진 기하 변환이 과제에 유효 | 대칭성 학습 | 잘못된 대칭, 불변·등변 구분 |

“신경기호면 논리적으로 항상 옳다”, “진화는 전역 최적을 보장한다”, “퍼지 소속도는 정답 확률이다”, “스파이크가 있으니 생물학을 완전히 재현한다”, “물리 손실이 작으니 실제 장치에서도 정확하다”는 모두 조건을 생략한 주장이다. 이 장의 접근은 표현·목적·실행 층의 선택이므로 하나의 시스템에서 결합할 수 있다. 결합 수 자체를 학습 성과로 삼지 말고 필요한 문제 조건을 해결했는지 평가한다.

## 11. 연습과 단계 힌트

### M16-Q1

**합성 명세를 보강하기.**

예제 $0\mapsto1,1\mapsto2$를 만족하는 후보 $p_1(x)=x+1,p_2(x)=x^2+1$이 있다. 둘을 구별하는 입력 하나와 각 출력을 제시하라. 입력이 0과 1만 허용되는 과제라면 왜 이 후보 차이가 현재 명세의 실패가 아닌지도 설명하라. 힌트 1: 두 식을 같게 만드는 입력을 먼저 찾는다. 힌트 2: 입력 영역을 명세에 포함한다. 힌트 3: 간결한 후보 선호와 정당성 증명은 다른 판단이다.

### M16-Q2

**퍼지 출력과 불확실성.**

본문의 소속함수와 출력 규칙으로 $T=30$일 때 활성도 두 개와 출력 $v$를 계산하라. 설계 변경으로 따뜻함 활성도만 0.25가 된다면 출력이 어떻게 바뀌는가? 이 숫자들을 “팬이 안전하게 돌 확률”로 해석할 수 없는 이유를 설명하라. 힌트 1: 소속도는 각각의 함수에 입력해서 구한다. 힌트 2: 출력은 활성도 합으로 나눈다. 힌트 3: 안전한 동작 확률에는 실제 장치 조건과 별도 관측 근거가 필요하다.

### M16-Q3

**물리 조건 변경.**

$u'+2u=0,u(0)=1$인데 기존 후보 $u=e^{-t}$를 유지했다. 시간 0·1의 잔차, 평균제곱 잔차, 시간 1에서의 정확한 해와 후보의 절대 오차를 구하라. 다른 복잡한 함수의 두 점 잔차가 0인 경우 전체 시간에서 정확한 해라고 결론 낼 수 있는가? 힌트 1: 미분과 방정식 계수를 따로 대입한다. 힌트 2: 정확한 해는 초기조건을 포함해 구한다. 힌트 3: 유한한 점의 검사와 함수 전체에 대한 조건을 구분한다.

## 12. 검증 기록과 다음 연결

종이에 실행 가능한 프로그램 비교표, 확률 합 계산, 퍼지 출력, 방정식 잔차를 남긴다. 기술 확인은 산술과 명세 만족 여부, 학습 확인은 후보를 구분하는 조건과 가정 실패를 설명하는 능력이다. 현재 기록은 해석식·수치 검산이며 실제 신경망 학습 실험이나 물리 실측은 아니다. 실제 과학·하드웨어 실습으로 확장할 때는 현상 → 센서 → 회로 → 펌웨어 → 통신 → 응용의 흐름과 허용 전압·핀·단위·범위·샘플링·전원·오류 상태를 먼저 확인한다.

[M17](17_systems.md)은 선택한 방법의 비용과 상태·권한·오류를 시스템 수준에서 연결한다. [M18](18_evaluation.md)은 규칙 위반, 방정식 잔차, 해 오차, 분포 밖 오류를 서로 다른 지표로 평가한다. 실제 회사 모델이 이 방법을 쓴다는 주장은 공식 기술 자료에 공개된 경우만 연결한다.
