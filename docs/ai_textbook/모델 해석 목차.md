# AI 이론과 실제 모델 해석 교재

이 교재는 본인의 학습을 위해 만든 한국어 입문·심화 연결 교재다. 문제와 데이터에서 출발해 수학·계산, 기호·통계·확률·신경 접근, 생성·의사결정, 전문 분야, 시스템과 책임을 배우고 공개 모델 사례를 이론에 연결한다. 모든 논문·제품·연구 분야를 망라한 백과사전이라는 뜻은 아니다.

각 장에는 개념 설명, 기호와 가정, 중간 계산까지 보이는 수치·추적 예제, 조건 변경, 한계·오개념, 연습 3개와 힌트가 있다. 공통 이론 18장에 연습 54개가 있으며 [해설](90_solutions.md)은 별도다. 추가된 [어선 적용편 19~25장](95_fishing_guide.md)은 기초 설명에서 수식·유도·모델 선택까지 연결하고 연습 21개와 [별도 해설](94_fishing_solutions.md)을 제공한다. 공통 이론과 어선 적용편을 합치면 25장·75문항이며 특정 외부 API나 GPU가 없어도 개념과 손계산을 시작할 수 있다.

녹조 예측 프로젝트에는 [녹조 예측 학습 길잡이](algae_learning_path.md)를 사용한다. 19~25장에 기초 수학, 성장·물질수지, 데이터 특징, 회귀·시계열·혼합 모델, 평가와 실습을 추가했다. 확장 연습 21개와 [별도 해설](95_algae_solutions.md)이 있으며 실제 관측자료 학습은 아직 수행하지 않았다.

## 학습을 시작하는 방법

처음에는 아래 진단 질문에 답하고 01장을 읽는다. 각 장의 선수 질문에서 막히면 해당 개념의 앞 장으로 돌아간다. 입문 설명을 먼저 읽고 예제를 직접 따라간 뒤 심화 수식·방법 선택을 연결한다. 심화 구현은 깊이와 순서를 조정할 수 있지만 이론 분야의 개관 자체를 생략하는 선택 과정은 아니다.

- 벡터 내적·행렬 곱·미분·조건부확률을 설명할 수 있는가?
- Python의 반복·함수·리스트와 코드 결과를 읽을 수 있는가?
- 주당 시간, 학습용 도구와 CPU/GPU·메모리·계산 자원은 무엇인가?
- 이번 활동에서 설명, 계산, 설계, 직접 구현 중 무엇을 확인할 것인가?

현재 작업공간은 Windows·PowerShell로 확인됐지만 학습자의 수학·Python 수준, 가용 시간과 실습 환경·자원은 아직 미확인이다. 따라서 기본 설명부터 읽을 수 있도록 구성했고 수식·구현 심화를 연결했다. 기간이나 장비 규모를 확정하지 않는다.

권장 활동은 **설명 읽기 → 예제를 손으로 추적 → 조건 하나 변경 → 연습과 자신의 판단 기록 → 힌트 → 필요할 때 해설**의 순서다. 해설을 보고 이해한 상태와 해설 없이 해결한 상태를 나눠 기록한다. 실행 가능한 선택 예제와 학습자가 채우는 연습 코드는 구분해서 사용한다.

용어는 서로 다른 질문에 답할 수 있다. 지도·비지도는 **학습 신호**의 구분(01·09장), Transformer는 **모델 구조**(08장), LLM은 큰 규모의 **언어 분포 모델**(12장), RAG는 검색을 생성에 연결하는 **시스템 구성**(17장)이다. 따라서 하나의 시스템을 여러 축으로 함께 설명할 수 있으며 이들을 같은 단계의 경쟁 분류로 외우지 않는다.

## 어선 항적 모델 적용편

세 PDF의 과제·전처리·제안서 설명과 현재 구현을 함께 읽으려면 [어선 항적 통합 학습 가이드](../../어선%20항적%20통합%20학습%20가이드.md)부터 시작한다. 과제 이해에서 8개 기하 특징·모델·평가·실습까지 연결하며, PDF 보고값과 저장된 S0 합성 결과를 구분한다.

이번에 구현한 합성 시스템 전체를 한 문서로 학습하려면 [26장: 샘플 시스템 개인 학습 노트](chapters/26_fishing_sample_system_personal_study.md)를 읽는다. NotebookLM용 단독 소스로 사용할 수 있도록 생성 수식·코드·저장된 실험 결과·시각화 해석·과적합 통제·실제자료 적용 절차를 본문 안에 연결한다. 기존 19~25장의 이론과 연습에 추가된 구현 실습이다.

어선 모델 제작에 필요한 개념·대표 모델·자세한 수식을 배우려면 [적용편 길잡이](95_fishing_guide.md)부터 읽는다. 공간 특징, 조업 분류와 공유 표현, 순서·시간 모델, 이상 탐지, 외부 환경자료, 가상 선박·생성, 평가·시스템을 7장으로 연결했다. 기호·단위·가정과 중간 손계산을 함께 설명하며, 좌표별 시각이 없는 자료의 제한과 실제·합성 자료의 경계를 유지한다.

19 → 20의 단순 기준선 → 22의 이상 기준으로 시작하고 25장의 분할·시점 조건을 처음부터 적용한다. 순서 모델·환경 결합·가상 유닛은 필요한 조건에서 확장한다. 기존 18장 학습과 적용편 문서 제작 완료를 실제 어선 모델 학습·성능 검증 완료로 표현하지 않는다.

## 진행 관문 G0~G5

관문은 기술 결과와 학습 이해를 나누어 기록하기 위한 기준이다. 단순히 읽은 장 수로 통과를 판단하지 않는다.

| 관문 | 연결 범위 | 기술 결과 | 학습 확인 |
| --- | --- | --- | --- |
| G0 | 시작 진단 | 수준·환경·목표 기록 | 필요한 선수 개념과 이번 활동의 범위를 설명한다. |
| G1 | 01~04 | 작은 입력→기준선→출력→분리 평가 | 목표·손실·지표·누수와 계산 조건을 설명한다. |
| G2 | 05~08 | 작은 문제의 두 접근 비교·핵심 연산 | 표현·가정·오류·계산 비용 차이를 설명한다. |
| G3 | 09~11·15·16 | 선택한 작은 실험·계산·사고 실험 | 모든 이론군을 개관하고 신호·생성·정책·인과·대안의 관계를 설명한다. |
| G4 | 12~14 및 관련 분야 | 필요 분야의 작은 실습·오류 기록 | 모든 전문 분야의 입력·출력·지표·조건 차이를 설명한다. |
| G5 | 17~18 | 최소 시스템·로그·비용·오류 복구 | 계층별 실패와 조건 변경에 대응하는 이유를 설명한다. |

18장의 평가는 01장부터 누적한다. 실제 회사 모델 사례도 마지막에만 보지 않고 관련 원리를 배울 때 붙인다. 수행 상태는 **미확인 / 안내받아 수행 / 독립 수행 / 조건 변경 대응**으로 기록한다.

실습의 종류와 깊이는 선택할 수 있다. 증명·반례·손계산·사고 실험이 적합한 개념에 코드를 강제하지 않는다. 모든 이론군의 핵심 문제·정의·원리·가정·한계는 학습 대상이며, 이를 실제 구현 규모의 선택과 혼동하지 않는다.

## 검증 기록과 범위

자신의 기록에는 조건 → 예상 → 관찰·계산·측정값 → 해석 → 남은 확인을 쓴다. 손계산·코드 테스트·시뮬레이션·실제 장치 실험은 다른 증거다. 교재의 설계 수치와 검산을 실제 모델 학습이나 하드웨어 실측으로 표현하지 않는다.

제작 중 수행한 계산·코드·문서 구조 검사의 범위와 재실행 방법은 [검증 기록](validation/README.md)에 남긴다. 검사를 통과한 수치와 링크가 본문의 모든 이론을 기계적으로 증명하는 것은 아니며, 학습자가 독립적으로 문제를 해결했다는 증거도 아니다.

물리 실습은 현상→센서→회로→펌웨어→통신→응용 흐름으로 확장한다. 실제 부품의 허용 전압·핀·단위·측정 범위·샘플링·전원·지연·오류 상태를 확인한 뒤 연결한다. 데이터시트 값·설계 가정·실측값을 구분한다.

AI는 도구 설정과 반복 작업을 도울 수 있다. 그러나 이번 활동의 가정·모델·실험 조건·핵심 연산을 본인이 선택하거나 구현할 과정은 보존한다. 교재 본문의 제작 완료와 학습자의 관문 통과는 별도 상태다.
