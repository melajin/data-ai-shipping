업로드한 자료를 바탕으로 다음 보고서를 작성해줘.

제목:
어선 항적 분석 시스템 — 개인 학습과 팀 협업을 위한 해설 보고서

목적:
1. 내가 시스템의 개념·수학·설계·구현·검증 방법을 기초부터 학습한다.
2. 팀원이 프로젝트 목적과 제작 방법, 데이터 활용, 역할 분담을 이해한다.

독자는 프로젝트를 처음 접하는 사람으로 가정하되,
선수지식을 생략하지 말고 전문용어를 처음 사용할 때 설명해줘.
앞부분은 5분 안에 읽을 수 있는 팀 설명용 요약,
뒷부분은 혼자 공부할 수 있는 상세 해설로 작성해줘.

다음 구조를 따라줘.

1. 팀 설명용 핵심 요약
- 무엇을 해결하는 프로젝트인가?
- 어떤 데이터를 받아 어떤 결과를 만드는가?
- 현재 구현된 부분과 앞으로 제작할 부분은 무엇인가?
- 다음 작업과 팀원이 맡을 역할은 무엇인가?
- 전체 흐름을 간단한 도식으로 설명해줘.

2. 프로젝트 목적과 기본 개념
- 항적, 부분선, 특징, 라벨, 분류, 이상 탐지, 기준선
- 학습·추론·검증·보정·최종 평가의 차이
- 이상점수, 분류 확률, 사고 확률의 차이
- 기술적 완료와 학습자의 이해를 구분하는 이유

3. 데이터 구성과 활용
- 주요 필드, 행의 의미, WKT MULTILINESTRING 구조
- 실제 항적, 외부 환경자료, 고정 합성 예제,
  후속 가상 유닛의 차이와 사용 목적
- 좌표계, 축 순서, 단위, 부분선 내 순서, 결측, 라벨
- 공간 점 순번·실제 관측 시각·시뮬레이션 시각의 차이
- 환경자료의 관측·공개·예보 유효 시각과 시간 누수
- 각 데이터가 시스템의 어느 단계에서 사용되는지 설명해줘.

4. 전체 시스템 설계와 제작 방법
- 원자료 → 검사 → 특징 추출 → 모델 → 평가 → 결과 표시
- 각 단계의 입력, 처리, 출력, 오류·결측 상태
- 단계 사이의 인터페이스와 데이터 전달 예시
- 작은 전체 흐름부터 연결한 뒤 확장하는 제작 순서
- 현재 코드와 후속 설계 후보를 구분해줘.

5. 핵심 수학과 모델 상세 해설
다음 내용을 소스에 근거하여 설명해줘.
- 부분선 길이·변위·직선성과 조건부 측지 거리 계산
- 표준화와 상수 열·결측 처리
- softmax·교차엔트로피와 기울기 유도
- 유효 라벨·특징 마스크와 손실의 분모
- 공유 인코더·분류 헤드·재구성 헤드·결합 손실
- MAD·Mahalanobis 거리·재구성 오차와 점수 보정
- HMM과 소스에 나온 시계열 모델의 선택 조건
- 환경자료의 거리 가중 보간과 방향 벡터
- 혼동행렬·precision·recall·macro F1

각 방법은 반드시 다음 순서로 설명해줘.
① 필요한 선수개념
② 직관과 사용하는 이유
③ 기호·배열 크기·단위
④ 가정과 적용 조건
⑤ 수식과 단계별 유도
⑥ 작은 숫자를 사용한 손계산 예제
⑦ 결과 해석
⑧ 예외·실패 조건
⑨ 다른 방법과 비교 및 선택 근거

수식만 나열하지 말고 각 항이 왜 필요한지 설명해줘.
긴 계산은 중간 단계를 생략하지 마.
현재 채택한 방법과 비교 후보를 명확히 구분해줘.

6. 가상 유닛 제작
- 실제자료에서 생성 조건을 정하는 방법
- 활동 상태, 상태 전이, 기대 체류시간
- 위치·방향·속력 갱신과 Δt의 의미
- 환경 반응, 관측 잡음, 이동 잡음의 차이
- Low·Medium·High 변동 조건
- seed, 생성기 버전, 재현성과 생성 기록
- 라벨 보존과 실제자료와의 비교
- 가상 유닛 하나를 제작하는 순서를 예제로 설명해줘.
현재 고정 합성 계산 예제와 후속 시뮬레이터를 구분해줘.

7. 사람 팀과 AI의 협업
- 데이터·특징·모델·표시·통합 담당의 역할과 산출물
- 파일별 단일 작성자와 공용 계약 변경 절차
- 계약 확정 → 독립 작업 → 독립 검토 → 통합 결정
- 병렬화 가능한 작업과 선행 작업을 기다려야 하는 작업
- 작업을 다른 세션에 전달하는 프롬프트 예시

다음 AI 배정 정책을 반영해줘.
- GPT-6 Astra high: 종합 판단·결정·근거 설정
- GPT-6.1 Sol high: 검토·간단한 조건 설정
- GPT-6.1 Sol xhigh: 확정 계약 아래 독립 모듈
- GPT-6.1 Sol max: 복잡한 구현과 원인 분석
- GPT-6 Luna xhigh: 문서와 반복 작업

8. 단계별 검증과 완료 기준
- F1 자료 계약 → F2 무라벨 기하 → F3 모델 기준선
- 환경자료와 가상 유닛의 별도 착수 조건
- 학습·검증·보정·최종 평가의 역할
- 선박 분리, 파생자료 분리, 시간 누수 방지
- 코드 테스트·합성 검산·실제자료 평가·실측의 차이
- 단계별 구현물, 예상 결과, 검증 방법, 설명할 질문
- 기술 결과와 학습 성취를 별도로 평가해줘.

9. 개인 학습과 팀 설명 자료
- 각 장 끝에 이해 확인 질문과 작은 연습문제를 넣어줘.
- 해설은 문제 뒤 별도 구역에 배치해줘.
- 마지막에 학습 순서, 핵심 용어집,
  팀원에게 설명할 때 사용할 질문·답변을 정리해줘.
