## 확인·가정·미확인 구분

경도·위도 순서와 시간구간의 뜻은 첨부 공지에서 확인했다. 좌표별 시간은 제공된 열만으로 만들 수 없다. 정확 좌표계가 미확인인 상태에서 사용하는 구면/국소 형상 근사는 연구상 가정으로 별도 선언·검증해야 하며 실제 미터 거리·속력 측정으로 표현하지 않는다.

기존 shape9 MLP의 합성 정답 `straight/sweep/turn`은 실제 조업명에 대응하는 정답이 아니다. 실제 분류를 평가하려면 관측 라벨·선박별 일관성·그룹 분할을 확인하고 출력 클래스와 학습을 새로 구성해야 한다. Test A/B 제출샘플은 모델 선택용 정답으로 사용하지 않는다.

이 기록은 자료 구조와 평가 전제의 확인이다. 실제 모델 성능, 사고 탐지 성능, 학습자의 이해를 검증한 결과는 아니다.

## 2026-10-29 제출 목록과 선박 중복 추가 확인

원래 CSV 검사 캐시의 선박 hash와 제출샘플의 ID 목록을 읽기 전용으로 대조했다. [대조 결과](../outputs/submission_id_coverage_audit_20261029.json)의 테스트A 목록 100개 ID 중 91개가 라벨 있는 Train에도 있고, 100개 모두 파싱된 무라벨 자료에서 확인됐다. 테스트B 목록 100개 중 Train 중복은 95개, 파싱된 무라벨 자료에서 확인된 것은 99개다. 무라벨 6월 파일은 파싱이 완료되지 않았으므로 누락 1개가 원자료에 없다고 확정하지 않는다.

무라벨 CSV의 파싱된 범위에서는 7,621개 선박 hash 중 6,750개가 라벨 있는 Train과 겹친다. 원래 Train 캐시에는 구조가 깨진 1행에서 생긴 잘못된 선박 hash가 포함돼 있었으며 이 행은 정정 모델 입력에서 격리됐다.

이는 제공 파일명·템플릿 목록만으로 공식 Test A 신규 선박 분할을 확정할 수 없다는 근거다. 제출샘플의 예시 예측값을 정답으로 읽거나 기존 선박의 라벨을 복사해 시험 정확도로 제시하지 않는다. 현재 모델 비교는 별도로 고정한 라벨 있는 Train 안의 선박 분리 평가를 유지한다.
