# 실제 선박 분류 평가 최종 점검

검토일: 2026-10-29. 담당: 사용자 지정 Sol medium 감독. 학습과 최종 평가는 이미 끝났으며 이 검토에서 재학습·재선정·최종 재평가를 하지 않았다.

**사전에 정한 상대 개선 기준을 통과했다. 절대 분류 성능은 낮고 통발을 한 척도 맞히지 못해 실무 적용 준비가 됐다고 판단할 수 없다.** 결과는 2026년 labeled Train에서 선박을 분리한 내부 평가이며 공식 Test 점수·사고 탐지 성능이 아니다.

## 상대 개선과 절대 성능을 구분한 판단

기준 MLP는 평가가능 1,453척 중 1,451척을 연안복합으로 예측했다. 따라서 기준 대비 큰 F1 개선만으로 유용한 분류기가 됐다고 볼 수 없다. 다수 클래스 상수 예측의 같은 평가가능 선박 정확도는 .49690, Macro F1은 .16598이다. ExtraTrees의 조건부 정확도 .49897은 여기서 약 .21%p 높을 뿐이다.

유보를 오답으로 포함하면 ExtraTrees의 전체 final 정확도는 .49219다. 기하 없이 모든 선박을 연안복합으로 예측하는 상수 기준은 전체 final에서 .49559이므로 전체 정확도에서는 오히려 상수 기준보다 낮다. 조건부 정확도와 전체 정확도를 혼용하지 않는다.

## 코드·자료·검증의 구분

- 학습 전 구현 검증: geometry/model 테스트 15개와 mock 없는 40척/4클래스 fixture 전체 실행. 이는 코드 검증이며 실제 선박 성능 근거가 아니다.
- 자료 검증: 원본 SQLite와 정정 파생 캐시의 129,142행을 대조해 구조 오염 한 행만 제외, 월만 정정, 특징·선박·라벨·이유 불변을 확인했다. [독립 캐시 감사](../outputs/real_cache_independent_audit_20261029.json).
- 실제 평가: 저장된 final 예측으로 네 지표·혼동·support·분할·선박 bootstrap을 독립 재계산한 최대 오차는 0이다. [독립 성능 감사](../outputs/real_evaluation_independent_audit_20261028.json).
- 계보·분할 검증: 7,372척의 사전 hash 분할을 재구성해 모든 개발 역할과 final이 일치했고, 최종 1,473척의 원본 표본 25,876행 소속·라벨·유보 상태와 현재 source/snapshot SHA가 일치했다. [독립 계보 감사](../outputs/real_provenance_independent_audit_20261029.json).
- 모델 복원 검증: 저장한 두 초기화의 전처리·모델·온도를 복원해 calibration/final logits·확률과 앙상블 예측을 재계산한 최대 차이는 0이다. 추가 fit은 없고 snapshot과 source hash도 일치했다. [복원 검증](../outputs/evaluation_cycle_20261028/model_cycle/model_reload_verification.json).
- 실제 장치 실험이나 실선 운용 검증은 수행하지 않았다. 프로그램 실행·상대 개선·학습자의 이해는 서로 다른 완료 축이다.

## 남은 자료·적용 경계

모든 Train 행의 geometry를 검사한 것은 아니다. 선박·월별 고정 hash로 최대4개씩, 총 129,142개 선택 행에서만 형상을 계산했다. 정확 EPSG/측지 datum은 미확정이며 국소 접평면 무차원 형상은 명시적 연구 근사다. 부분선은 연결하지 않았고 실제 거리·속력·가속도를 만들지 않았다.

오염 라벨 한 행은 날짜·시간·geometry 구조 위반을 근거로 격리했다. 별도로 공백 라벨 한 행은 특징 표본에 없고 현재 캐시에 정확한 원본 위치가 없다. 두 행을 하나의 오류로 합치지 않았다. Test6은 CSV 파싱 오류로 부분 검사이며 사고현황과 선박 ID의 확정 매핑도 없다. 무라벨 파일과 제출 템플릿에는 Train ID가 상당히 겹치므로 파일 이름만으로 공식 TestA 신규 선박 구성을 확정할 수 없다. [ID 범위 확인](../outputs/submission_id_coverage_audit_20261029.json).

이번 단계의 기술적 완료는 **실제자료 점검·재학습·고정 반복 비교·최종 1회·독립 검산과 한계 기록**이다. 실무 분류 성능, 공식 제출 성능, 사고 탐지와 학습 성취는 완료로 표시하지 않는다. 상세 실행·오류 사례·이해 질문은 [학습자 결과 해설](fishing_evaluation_cycle_results_20261028.md)을 따른다.
