# 02 분석 해석과 다음 단계

[전체 정리로 돌아가기](../../2026%20%EB%8D%B0%EC%9D%B4%ED%84%B0%20%EB%B6%84%EC%84%9D%EB%8C%80%ED%9A%8C%20%EB%8D%B0%EC%9D%B4%ED%84%B0%20%EB%B6%84%EC%84%9D%20%EC%A0%95%EB%A6%AC.md)

## 이 자료로 답할 수 있는 질문

현재 샘플은 **입력 형식·부분선·반복 좌표를 이해하고 전처리 조건을 점검하는 자료**다. 10척 각각 1행이고 두 클래스가 1행씩이므로 모델 우열이나 대회 성능을 평가하기에 충분하지 않다. 이번에는 모델 학습·분할·거리·속력·사고 점수를 계산하지 않았다.

| 질문 | 이번에 답할 수 있는 정도 |
| --- | --- |
| 어떤 단위·컬럼으로 주어졌는가? | 첨부 공지와 실제 CSV를 대조해 설명 가능 |
| CSV와 WKT를 어디서 주의해서 읽어야 하는가? | 빈 7열, WKT 내부 쉼표, 부분선 보존, 반복 좌표 확인 가능 |
| 샘플의 클래스·점 수 분포는 어떤가? | 샘플 10행에 한정해 집계 가능 |
| 어떤 모델이 가장 정확한가? | 정식 데이터·분할·학습·평가가 없어 판단 불가 |
| 사고가 있었고 얼마나 빨리 탐지할 수 있는가? | 사고 정답·연속 시계열이 없어 판단 불가 |
| 실제 속력·가속도·체류시간은 얼마인가? | 좌표별 시각이 없어 계산 불가 |

## 대회 과제와 자료의 연결

[첨부 공지: 문제 과제](../../data/reference/competition_20261019/2026%20%EB%8D%B0%EC%9D%B4%ED%84%B0%20%EB%B6%84%EC%84%9D%EB%8C%80%ED%9A%8C/%EA%B3%B5%EC%A7%80%EC%82%AC%ED%95%AD/%EA%B3%B5%EC%A7%80-%EB%AC%B8%EC%A0%9C%20%EA%B3%BC%EC%A0%9C.png)와 [문제 개요](../../data/reference/competition_20261019/2026%20%EB%8D%B0%EC%9D%B4%ED%84%B0%20%EB%B6%84%EC%84%9D%EB%8C%80%ED%9A%8C/%EA%B3%B5%EC%A7%80%EC%82%AC%ED%95%AD/%EA%B3%B5%EC%A7%80-%EB%AC%B8%EC%A0%9C%EA%B0%9C%EC%9A%94.png)를 기준으로 목적을 나눈다. 이는 첨부된 공지 사본의 내용이며 현재 웹 공지를 다시 확인한 결과는 아니다.

| 과제 | 입력과 정답 설명 | 준비해야 할 분석 | 현재 부족한 자료 |
| --- | --- | --- | --- |
| 조업형태 분류 | Train의 `fishing_code` 학습. Test A에는 라벨이 없고 원칙적으로 신규 선박 구성 | 선박 ID를 외우지 않는 경로 특징, 선박을 나눈 검증, 클래스별 오류 분석 | 정식 Train/Test A, 전체 코드·분포, 공식 지표 계산식 |
| 이상항적 탐지 | 정상·사고 관련 구간을 포함할 수 있는 항적, 일부 사고선박의 ID·사고시각. 별도 Test B의 시간대별 이상점수 평가 | 평상시와 다른 정도의 정의, 사고시각과 정렬한 탐지·오경보·지연 평가 | 연속 항적, 사고정보, 관측/가용 시각, Test B와 평가 창 정의 |

사고 정보가 없는 행을 정상 정답으로 바꾸지 않는다. 이상점수와 사고 확률도 다르다. 첨부 제출 예시의 0~1 이상점수는 확률 보정을 입증하지 않는다. 실제 제출 단위·식별키·파일 형식은 정식 규격을 더 확인해야 한다. 시간대 전체 항적을 사용했다면 그 시간대 종료와 처리 지연 이전에 판단할 수 있었다고 주장할 수 없다.

## 전처리에서 보존해야 할 것

1. **원본과 가공본**: 원본 해시를 보존하고, 빈 열 제거와 파싱 실패 여부를 별도 이력으로 남긴다. 실패한 행을 조용히 버리지 않는다.
2. **부분선 경계**: `MULTILINESTRING`을 한 점 목록으로 납작하게 연결하면 관측되지 않은 구간을 이동거리로 더하게 된다. 각 부분선 내부에서만 계산하고 단절은 별도 표시한다.
3. **반복 좌표**: 좌표 반복을 바로 오류나 정박으로 처리하지 않는다. 원본 점 수·고유점·반복 비율을 관측 상태로 남기고, 형상 계산을 위해 연속 중복을 축약한다면 그 가공본을 구분한다.
4. **좌표와 단위**: 공지는 X=경도, Y=위도로 설명한다. 경위도 차이를 그대로 미터로 표시하지 않는다. 정확한 CRS·측지 기준이 확인된 뒤 적절한 거리 계산이나 투영을 선택한다.
5. **시간 정보**: 시간대 인덱스를 점별 시각으로 늘리지 않는다. `1시간 ÷ 점 수` 같은 가정을 실제 측정 간격으로 사용하지 않는다.
6. **식별과 라벨**: `rfid_id`는 그룹 분리·추적에 쓰고 숫자형 행동 특징으로 다루지 않는다. 라벨은 원문을 보존하고 공식 코드 표와 비교한다.

## 후보 특징을 해석하는 조건

아래는 구현 결과가 아니라 후속 분석에서 검토할 후보와 필요 조건이다.

| 특징 묶음 | 예시 | 조건·해석 |
| --- | --- | --- |
| 관측 상태 | 점 수·부분선 수·인접 반복 비율·파싱 상태 | 현 샘플에서 집계 가능. 조업보다 수집 방식을 학습할 가능성도 점검 |
| 경로 형상 | 부분선 내부 길이·직선성·방향 변화·공간 범위 | 좌표·단위 확정 후 계산. 0길이·점 부족을 결측 사유로 처리. 부분선 간 방향 변화는 만들지 않음 |
| 시간 변화 | 이전 시간대 대비 변화·연속성 | 같은 선박의 연속 시간대와 시간 기준 필요. 과거에 알 수 있었던 정보만 사용 |
| 실제 운동량 | 속력·가속도·체류시간 | 좌표별 시각·샘플링 의미가 확인돼야 함. 현 자료로는 산출 불가 |

첨부 제안서의 **형상 특징과 관측 상태 특징을 구분하자는 가설**은 반복이 많은 샘플과 연결된다. 그러나 관측 상태가 분류 정확도를 올리는지, 수집 방식에 과적합하는지는 실제 실험 전에는 모른다. 같은 경로에 반복만 추가한 가공본을 만들 경우 원본과 같은 그룹에 두고 학습·평가 양쪽에 나누지 않는다.

## 추가 제안서의 비교·평가 계획

[10월 19일 제안서 pp.6–8](../../data/reference/competition_20261019/additional/IT%EC%A2%85%ED%95%A9%EC%84%A4%EA%B3%84%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8_%EC%A0%9C%EC%95%88%EC%84%9C_C215192%20%EC%B5%9C%EC%8A%B9%EB%B9%88.pdf#page=6)의 계획을 기존 데이터 분석과 연결했다. 아래 비교표는 후속 실험의 점검표이며, 실행한 모델이나 결과표가 아니다. 소량의 F2 기하 확인과 F3 모델 비교는 각각의 선행조건이 충족된 뒤 진행한다.

| 비교 항목 | 고정할 조건·관찰할 결과 | 필요한 근거·기록 |
| --- | --- | --- |
| 분류 단독 모델 | TabM·RealMLP·작은 LightGBM에 같은 특징·선박 분할 적용. 모델 규모는 작게 시작 | 클래스별 정밀도·재현율, Macro-F1, 클래스별 표본 수. 모두 내부 지표안이며 공식 지표 확인 후 대조 |
| 분류 혼합 | 동일 클래스 순서를 확인하고, 단독 모델 대비 확률 혼합 이득·비용 비교 | 혼합비와 하이퍼파라미터는 검증자료로 선택해 고정. 최종 평가자료로 재조정하지 않음 |
| 특징 분리 | 형상만 / 형상+관측 상태 비교. 같은 경로의 반복만 늘린 짝도 비교 | 예측 변화와 관측 변화 구분. 원본과 가공 짝은 같은 분할에 보관 |
| 이상점수 기준 | 학습자료에서 중앙값·분포 등 기준을 정하고 새 항적 편차 계산 | 확인된 사고 관련 구간 분리 정책과 기준 오염 가능성 기록. 점수 방향·0~1 변환·임계값 규칙은 미확정 |
| 사건·시간 평가 | 같은 사건이 학습·평가에 겹치지 않도록 하고 당시 가용 정보만 사용 | 평가 가능 사건 수·사건별 탐지율·놓친 사건·경보량. 탐지 창·오경보·경보 묶음 규칙은 사전 정의 필요 |
| 효율·실패·확률 | WKT 처리부터 예측까지의 시간·메모리와 실패·결측, 확률 품질을 함께 관찰 | 입력 규모·장비·실행 조건·실패 분모를 기록. 구체 자원과 확률 지표는 후속 확정 |

추가 제안서의 분할 원칙은 기존 계약과 맞는다. 모델·전처리·일반 기준은 **학습자료에서만 적합**하고, 모델·혼합비·운영 임계값은 지정 검증자료에서 선택한다. 확률 보정을 수행한다면 별도 보정 자료를 두고 최종 평가는 모든 선택·적합·보정에서 제외한다. 현재 샘플에는 이런 분할을 만들거나 학습을 실행하지 않았다. 사고정보가 없는 구간의 경보를 확정 오탐으로 바로 세지 않으며, 정답이 확인된 비사고 범위와 평가 가능한 관측 구간을 구분한다.

### 조기 탐지의 시간 기준

[제안서 p.8·그림4](../../data/reference/competition_20261019/additional/IT%EC%A2%85%ED%95%A9%EC%84%A4%EA%B3%84%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8_%EC%A0%9C%EC%95%88%EC%84%9C_C215192%20%EC%B5%9C%EC%8A%B9%EB%B9%88.pdf#page=8)는 다음 **가상 예시**를 든다.

| 조건 | 가정한 시각 |
| --- | --- |
| 사용하는 항적 | 09:00–10:00 시간대 전체 |
| 데이터 처리·점수 계산 후 경보 가능 | 10:05 |
| 사고 | 11:30 |
| 선행시간 계산 | 11:30 − 10:05 = 85분 |

09:00부터 계산하면 150분으로 부풀려진다. 이 예시는 경보 가능 시각의 중요성을 설명하며 **85분 탐지나 5분 지연을 실측했다는 뜻이 아니다.** 실제 평가에서는 각 입력의 가용시각, 시간대 종료, 수집·처리 지연과 점수·경보 규칙을 기록하고 경보가 처음 실제 가능했던 시각으로 비교한다. 아직 경보가 없거나 사고 이후에만 가능했던 사례를 조기 탐지 성공으로 세지 않는다.

### 제안서의 추진 계획과 완료 증거

제안서 p.10은 날짜가 고정되지 않은 5단계 계획을 제시한다. 기존 F1~F3의 조건과 연결하되 현재 범위를 자동으로 넓히지 않는다.

| 제안 단계 | 기존 단계와 관계·현재 상태 | 다음 확인에 필요한 산출물 |
| --- | --- | --- |
| 데이터 구조 파악 | F1 일부: 제공 샘플의 구조·집계 확인 | 형상·관측 상태 후보와 미확인 계약 목록. 특징 구현 완료와 구분 |
| 학습·평가 준비 | F1 전체 및 F3 시작 조건 미충족 | 정식 자료·사고정보·제출 규격, 선박·사건·시간 분할 근거 |
| 기본 모델 구현·비교 | F2 확인과 F3 선행조건 이후의 계획 | 동일 조건 단독·혼합 비교, 학습자료 기준 이상점수 |
| 성능 검증·보완 | 실제자료 평가 전 | 가용시각을 반영한 사건·경보 평가, 확장별 이득·비용 |
| 결과 정리·발표 | 문서 통합은 진행, 예측 산출물은 미생성 | 예측 파일·재현 코드·분석 결과·한계를 설명하는 자료 |

## 후속 단계별 확인

| 단계 | 기술 목표·산출물 | 학습 목표·관찰할 현상 | 검증 방법·설명할 질문 |
| --- | --- | --- | --- |
| 현재 F1 일부 점검 | 파일 목록·CSV 구조·품질 집계·미확인 목록 | 설명 자료와 직접 계산의 차이 이해 | 10행·16부분선·246점을 다시 셀 수 있는가? 빈 헤더 오류와 기하 오류는 어떻게 다른가? |
| 후속 F1 전체 계약 | 정식 파일·버전·시간·CRS·라벨·사고·제출 규격 대조표 | 데이터가 말해주지 않는 것 구분 | 샘플의 날짜·분포를 전체로 일반화하지 않았는가? 관문별 미확인이 남아 있는가? |
| 후속 F2 무라벨 기하 | 핵심 시간·좌표·기하 계약을 통과한 소량 경로 계산·그림 | 단절·반복·단위가 결과에 주는 영향 설명 | 부분선 내부 손계산과 대조. 점별 시각이 없으면 속력 없이 설명할 수 있는가? |
| 후속 F3 분류·이상 기준선 | 라벨 의미와 분할을 확정한 뒤 최소 모델·독립 평가 | 누수·과적합·오경보 해석 | 학습 전용 적합, 검증 전용 선택, 필요 시 별도 보정, 고정 최종 평가를 지켰는가? |

현재는 첫 행의 점검 결과까지만 완료했다. F1 전체 통과나 F2·F3 실행을 선언하지 않는다. 학습자 수준·선수지식·시간·연산 환경이 미확인이므로 차시 수와 모델 규모는 지정하지 않았다.

분류는 선박 분리를 기본으로 Test A의 신규 선박 조건을 흉내 내야 한다. 이상 탐지는 같은 선박의 과거 기준 사용이 가능한지 별도로 정의하고 미래·사고 후 정보를 과거 판단에 섞지 않는다. **샘플 10행을 무작위로 쪼개 정확도를 제시하는 것은 이번 자료의 분석 결과에 포함하지 않는다.**
