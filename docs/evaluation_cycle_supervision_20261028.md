## 현재 근거와 모델의 적용 한계

최신 `docs/fishing_report_updated_20261028.md`와 root 실존 확인에 따르면 `F:/문제 데이터_수정_1027`에 실제 CSV 12개, 합계 11,834,630,398 bytes가 있다. 따라서 과거 10행 참조 표본만 있다는 상태는 현재 전체 자료 상태를 대표하지 않는다. 파일 존재는 형식·정답·좌표·분할 적합성 통과와 다르다.

root가 공식 첨부 이미지에서 X=경도, Y=위도, 시간대=0~23, 행=선박/일자/시간대 항적, Train의 fishing_code=조업형태 정답을 확인했다. Test A는 신규 선박이며 제출샘플은 선박 단위의 예측조업형태와 선택 클래스 확률 1열이다. 정확한 EPSG와 날짜/시간의 세부 계약은 아직 확인되지 않았다. Test B 사고현황에는 rfid_id·선명 헤더가 없어 바로 매칭할 수 없다. 사고현황은 167건, 발생일시 2026-01-05~06-30이며 제출 예시는 2025 날짜를 사용한다. 이번 분류 실험과 분리하며 정확한 구조는 `outputs/real_support_audit_20261028.json`을 우선한다.

Luna의 독립 읽기 검토는 기존 shape9 저장 모델이 `source_type=synthetic`, `coordinate_system=local_xy_m`, `[straight,sweep,turn]` 3개 생성 유형을 사용하는 것을 재확인했다. 전처리·Classifier 코드 일부는 재사용 가능하지만, 합성 모델의 세 출력을 실제 fishing_code와 등치할 근거는 없다. 실제 학습은 별도 클래스 정의·변환·분할·모델 산출물이 필요하다. 점별 시각이 없으므로 실제 속력·가속도는 만들지 않는다.

## 선행 입력 점검 계약

먼저 파일별 소량 스트리밍으로 처리시간을 측정한다. 전체 검사 전 범위·실행시간 추정·파싱 지원 범위를 보고한다. 전체 CSV를 읽는 경우 파일 hash, 읽은 byte/행과 미검사 범위, 인코딩·CSV 열 구조, 빈 헤더의 비공백 여부, 날짜/시간 형식, 라벨·선박 집계와 선박별 라벨 충돌, 후보키 중복, WKT subset 오류·부분선·점수와 유한성을 구분한다.

보고서·콘솔·오류에 CSV 원문 선박 ID·개별 좌표·geom을 출력하지 않는다. 공개 조업 범주명은 클래스별 성능·라벨 매핑 검증을 위해 집계로 보고할 수 있다. 집계 캐시는 원본 파일/레코드 위치와 해시 식별자·구조 요약을 사용하고 원본 행/geom을 전체 복사하지 않는다. CRS를 확인한 척하거나 lon/lat 범위 통과를 정확한 CRS 확인으로 해석하지 않는다. 부분선을 연결하지 않는다.

모델 학습 전에 공식 신규 선박 목적에 맞는 선박 단위 Train holdout과 validation/calibration/final 역할을 고정한다. 선박·날짜·중복 관계를 확인하고 분할 누수·선박별 라벨 불일치를 처리한다. 개발 반복 수, 단일 primary, 최소 개선/비열등성·확률·강건성 기준, seed/선박 단위 불확실성 및 중단 기준을 학습 전에 기록한다. 새 최종 자료를 열기 전에 후보·절차·소스 hash를 동결하고 최종을 본 뒤 재선택하지 않는다.

기술 실행, 실제자료 성능 평가, 학습자의 설계 설명 능력은 각각 별도 상태로 기록한다.

## 조건부 형상 변환 판단

정확한 측지 datum/EPSG가 미확정이어도 공식 경위도 순서를 근거로 제한된 내부 연구를 진행할 수 있다. 레코드 관측점의 기준 경위도 `(lon0,lat0)`를 정하고 `x=(lon-lon0)·π/180·cos(lat0·π/180)`, `y=(lat-lat0)·π/180`인 국소 접평면 근사를 사용한다. 지구반경은 공통 상수여서 무차원 shape9에서 생략하며 좌표의 단위는 접평면 각좌표다. 미터 거리·정확한 지리 측정·실제 속력으로 표시하지 않고 WGS84 확정으로 서술하지 않는다.

경도 래핑·극점·과도한 공간 범위를 검사하고 부분선 경계를 유지한다. 보정 전 degree 형상과 cos 보정 형상의 민감도는 개발 자료에서만 확인한다. datum 미확정은 잔여 한계다. 기존 합성 extractor가 내부적으로 산출하는 `length_m` 등은 실제자료 결과로 내보내지 않으며 실제용 특징 계약에는 shape9의 무차원/각도 통계만 포함한다. 실제자료의 시각을 만들어 내지 않는다.
