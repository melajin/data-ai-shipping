# 문제: 항적의 모양만으로 조업과 사고를 구분하기

배가 바다에서 여러 시간 동안 남긴 선은 이동 경로의 일부를 보여준다. 하지만 느리게 움직이거나 한 곳에 머무른 모습은 조업 과정에서도, 사고 상황에서도 나타날 수 있다. 항적의 모양만 보고 한 가지 상황으로 단정하기 어렵다.

프로젝트는 두 과제를 분리한다. Test A는 여러 항적을 가진 선박의 조업형태를 네 가지 중 하나로 분류한다. Test B는 시간별 항적 요약에서 평소와 다른 관측을 점수화하고, 사고 시각 검토에 사용할 후보와 근거를 생성한다. 재식별 실험과 합성 학습 경로도 존재하지만, 두 과제의 최종 실행 경로와 같은 모델로 합치지 않는다. ([프로젝트 검토](../project_review_20261104.md), [Test B 보고서](../../test_b/deliverables/testb_system_20261106/reports/어선_이상항적_시스템_결과보고서.md))

입력의 한 시간 구간에는 여러 부분선으로 표현된 항적이 들어갈 수 있다. 한 구간의 시간키는 있지만 각 좌표의 관측 시각은 확인되지 않는다. 떨어진 부분선을 이어서 가상의 이동을 만들거나, 점별 실제 속력·가속도를 계산할 수 없다. Test B에서 계산하는 중심점 역시 한 시간 기하의 요약이지 현재 GPS 위치가 아니다. ([입력 검토](../project_review_20261104.md), [Test B 입력 계약](../../test_b/deliverables/testb_system_20261106/src/run_analysis.py))

Test A는 선박별 정답과 선박 단위 평가 지표를 사용한다. 동일 조건의 대안 비교와 함께 소수 유형별 재현율을 확인해야 한다. Test B는 점수의 재현성과 사고시각 평가가 별개다. 2026년 사고기록과 선박은 시공간 조건으로 잠정 연결됐으며, 2025년 제출 대상의 사고 정답으로 취급할 수 없다. 공식 산식의 미확인 부분과 실제 수신 시각의 부재도 별도 한계이다. ([Round63 평가](../../test_a/deliverables/round63_submission_20261106/docs/과제1_모델설명.md), [Test B 평가](../../test_b/final/round_015_official_f1_20261106/ROUND015_공식F1_보고서_20261106.md))
