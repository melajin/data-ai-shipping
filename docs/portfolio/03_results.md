# 결과: 수치의 재현과 선택 절차를 함께 검토한다

## 분류: 재현된 점수와 유효한 선택은 다르다

Round26은 개발 OUTER 5,897척에서 3,552척 정답, micro-F1 0.602340을 공표했다. 후속 검산에서 예측 수치는 재현됐으나, 22개 후보 중 INNER 보호조건을 통과한 후보가 없었고 OUTER 결과를 이용해 선택한 점이 확인됐다. 검토의 수정 선택 결과는 3,538/5,897척, micro-F1 0.599966이며 기준선 대비 순증 41척의 McNemar 검정은 p=0.0675로 기록됐다. 이 기록은 높은 수치의 계산 여부와 독립적인 성능 주장 가능성을 구분한 사례다. ([독립 검토](../../test_a/11_04_final/rounds/round_026/review_20261105/REVIEW_ROUND026_0.60돌파_검증_20261105.md))

별도로 제공된 Round63은 개발 REPORT 1,475척 중 903척 정답, micro-F1 0.612203, macro-F1 0.563424를 기록했다. 통발은 209척 중 37척 적중해 재현율 0.177033이다. Round26과 Round63은 모집단과 분할이 달라 점수 차이를 직접 개선폭으로 계산하지 않는다. REPORT 역시 여러 회차 개발에 사용됐으므로 공식·독립 성능이 아니다. ([저장 지표](../../test_a/deliverables/round63_submission_20261106/data/reproduction/original_metrics.json), [원본 설명](../../test_a/deliverables/round63_submission_20261106/README.md))

원본 검증 기록은 4척의 337개 특징, 총 1,348개 값이 이전 생성 결과와 일치하고, TUNE·REPORT 2,949척의 재구현 최종 예측 변경이 없었다고 보고한다. 두 검사는 구현 재현을 다루며 독립 일반화 성능을 뜻하지 않는다. 이번 문서 작성에서는 원본 모델을 재실행하지 않았다. ([특징 회귀](../../test_a/deliverables/round63_submission_20261106/validation/feature_regression.json), [추론 회귀](../../test_a/deliverables/round63_submission_20261106/validation/report_regression.json))

## 이상 탐지: 선박 선정과 시각 선택을 나눈다

제출용 고정 입력 100척·46,705행에 대한 보관 검증은 저장 점수 네 컬럼의 최대 절대차 0.0과 후보시각 불일치 0을 보고한다. 이는 같은 입력에서의 재현성이다. ([검증 JSON](../../test_b/deliverables/testb_system_20261106/results/reproduction_001/summary.json))

사고 시각은 별도의 2026년 개발자료에서 확인했다. Round015의 자체 규칙은 잠정 연결 100사건을 82척 단위로 정리하고, 각 선박의 최고점 시각을 가장 가까운 연결 사고와 비교한다. 전원 예측 시 ±6시간 적중은 3/82척, 자체 F1은 0.0366이다. TP·FP·FN 공식 산식과 경계 처리는 미확정이므로 공식 성적으로 쓰지 않는다. 이 82척은 모두 사고 연결 대상으로 정상 선박 오경보를 측정할 수 없다. ([Round015](../../test_b/final/round_015_official_f1_20261106/ROUND015_공식F1_보고서_20261106.md))

후속 진단은 잠정 연결 82척 중 79척에서 사고창에 후보가 존재하지만 최고점이 다른 시각을 골랐다고 기록했다. 이는 해당 점수의 순위 문제를 좁힌 결과이며 모든 항적 모델에서 사고 탐지가 불가능하다는 증명은 아니다. 선박 선정 분석에서는 관측 수를 맞춘 조건에서 활동 반경이 사전 연관 기준을 통과했으나, 운영용 임계값은 채택하지 않았다. ([시각 진단](../../test_b/final/round_021_timing_diagnosis_20261106/ROUND021_report.md), [선박 선정](../../test_b/final/round_019_vessel_discrimination_20261106/ROUND019_보고서.md))

별도의 Round021 전체 선단 내부 평가에서는 7,372척 중 최고점 0.75 이상인 183척을 선정했고 그중 잠정 연결 선박은 7척이었다. 선박 선정 내부 F1은 0.05283, 사고시각까지 반영한 사건 단위 내부 F1은 0이었다. 이 평가는 미연결 선박을 음성으로 두는 내부 가정을 사용하며, 앞의 82척 선박 단위 지표와 분모가 다르다. ([평가 기록](../../test_b/final/round_021_internal_f1_judgement_20261106/execution_001/summary.json))

다른 방법들도 남겼다. 어업별 기준 G는 같은 개발 100사건에서 1건, B0는 3건을 맞혔다. 위치 조건 U/C의 최초 비교는 정렬 열 연결 오류로 무효화했고 수정 실행에서 다시 비교했다. 각 결과는 그 조건의 판단이며 다른 모델이나 새로운 데이터에 대한 일반적 결론으로 확대하지 않는다. ([Round004](../../test_b/final/round_004_20261105/ROUND004_상세보고서.md), [무효 기록](../../test_b/final/round_002_20261105/execution_001/INVALID_COMPARISON.md))
