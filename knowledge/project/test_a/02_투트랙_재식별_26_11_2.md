# 2026-11-02 투트랙 재식별 설계와 실험 기록

괄호 안 원본 경로는 DATA AI SHIPPING/ 저장소 루트 기준이다.

## 설계가 다루려던 문제

2026-11-02 설계는 선박별 항적에서 조업형태를 나누는 기존 모델과, 훈련에 보인 선박의 공간·시간 프로필을 이용하는 이웃 검색을 분리해 조합하려는 구상이었다. 핵심 질문은 이미 알려진 선박에서 항구·어장·시간 분포의 유사성이 조업형태 예측에 보탬이 되는지, 그리고 그 정보가 없는 새 선박은 일반 분류 모델로 처리할 수 있는지였다. (원본: 재식별_투트랙_시스템_설계.md; 26_11_2/README.md)

설계 문서는 이를 완성 시스템으로 확정하지 않고 단계형 검증안으로 제시했다. 투트랙은 알려진 선박의 유사 항적 후보와 미등록 선박 일반화 모델을 나눠 평가하고, 동일 선박 과거 이력을 사용한 값과 자기선박을 제외한 값을 별도로 보고하는 구조였다. (원본: 재식별_투트랙_지시001_데이터준비와_전제확인.md; 26_11_2/ROADMAP.md)

## 데이터 준비 및 평가 조건

001 재식별 실행은 2025년 Test 자료 7,768척과 개발 자료를 대조해 공통 ID 6,842척, 새 ID 926척을 구분했다. 지문은 0.01도·0.05도 공간 분포, 시간 정보 및 모항 정보로 만들었고, 거리 기준을 고정해 검색 순위를 평가했다. (원본: 26_11_2/outbox/001r1_report.md; 26_11_2/README.md)

같은 선박 지문 검색의 Rank-1 정확도는 0.66633, Top-10 포함률은 0.91406이었다. 이 값은 ID가 공통으로 존재하는 자료의 재식별 성능이며, 새 선박의 조업형태 분류 정확도와 같은 지표가 아니다. (원본: 26_11_2/outbox/001r1_report.md)

K=5 가중 다수결은 자기 ID를 후보 집합에 포함한 경우 동의율 0.76177, 자기 ID를 제외한 경우 0.55349였다. 사전 G1 기준은 자기선박 제외 동의율 0.60 이상이었고, 0.55349는 이 기준을 넘지 못했다. 자기선박을 포함한 값과 제외한 값의 차이가 커서, 이웃 정보가 일반화 성능을 입증했다는 결론은 채택되지 않았다. (원본: 26_11_2/outbox/001r1_report.md; 26_11_2/STATUS.md)

## 모델 결합 비교

002 단계는 기존 조업형태 분류기와 검색 이웃의 확률을 섞어 알려진 선박 정보의 추가 기여를 비교했다. 개발 OUTER 5,897척에서 기준 LightGBM Macro-F1은 seed42 0.5379, seed2026 0.5366, 평균 0.5373이었다. INNER에서 선택한 K=5 및 가중치 약 0.3–0.5를 적용한 결합의 OUTER 평균 차이는 +0.002927로 기록됐지만, seed별 95% 구간은 [−0.0083,+0.017839], [−0.012028,+0.014370]으로 0을 포함했다. (원본: 26_11_2/outbox/002_report.md; 26_11_2/STATUS.md)

결합은 연안복합 recall을 −0.014/−0.018 낮춰 보호 규칙도 통과하지 못했다. 관측일수 1–7일 하위집단은 +0.0339/+0.0241로 상승했지만 91일 이상에서는 하락했다. 이 구간은 기록된 관측일수이며 실제 운항 일수나 조업 시간으로 표기하지 않는다. 전체 개발 결과의 CI와 클래스 보호를 모두 고려해 G2 결합은 채택되지 않았다. (원본: 26_11_2/outbox/002_report.md)

003 단계의 짧은 문맥 TabICL 시험은 입력 특징 재구축 선행 조건을 통과하지 못했고, 최대 확률 변화는 0.039752 대 기준 0.001이었다. CPU 예상 시간은 약 206시간으로 적혀 있어 실제 성능 평가까지 진행하지 않았다. 상태 문서는 실행을 막힌 단계로 기록했다. (원본: 26_11_2/outbox/003_report.md; 26_11_2/STATUS.md)

## 채택 상태와 다음 작업에 미친 영향

재식별 지문 설계 자체는 제안과 자료 준비 단계로 남았고, 자기선박 제외 기준 및 결합 성능 기준은 미통과했다. 그래서 해당 방법을 최종 분류 시스템에 채택하지 않았으며, 일반 모델의 미등록 선박 대응과 자기 ID를 제거한 공간 이웃 성능을 구분해서 다루도록 후속 문서가 제한했다. (원본: 재식별_투트랙_시스템_설계.md; 26_11_2/STATUS.md; 26_11_2/outbox/002_report.md)

후속 2026-11-04 특징공학은 공간·행동 정보를 재식별 결과로 단정하지 않고, 기존 특징을 추가·결합하는 성능 비교와 평가 분할 검토로 이동했다. 그 단계에서도 데이터 모집단과 INNER/OUTER 간 선택 경계가 다시 쟁점이 됐다. (원본: 26_11_4/README.md; 26_11_4/RESULTS.md; docs/project_review_20261104.md)
