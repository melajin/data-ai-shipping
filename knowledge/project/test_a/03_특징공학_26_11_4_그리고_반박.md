# 2026-11-04 특징공학과 독립검토의 반박

## 2026-11-04 특징공학 단계

이 단계는 F156/T5 기준에 추가 특징과 여러 모델 출력을 더해 당시 보고된 macro-F1을 높이고, 관측된 오류를 줄일 수 있는 조합을 찾으려 했다. 문서들은 공식 채점 지표를 macro-F1이라고 표기했고, 이를 기준으로 모델 및 특징 후보를 비교했다. (원본: 26_11_4/README.md; 26_11_4/RESULTS.md; 26_11_4/20261104_종합보고서.md)

보고된 개발 평가에서 L_base F156+T5 macro-F1은 0.53185였다. 6모델 결합은 0.54307, S4 결합은 0.54524, 305개 특징 LightGBM S6는 0.54843으로 표기됐으며 S6은 L_base 대비 +0.01658, 제시한 paired bootstrap 95% 구간은 [+0.0027,+0.0304]였다. 이 수치와 채택은 해당 날짜 문서의 판단이며, 독립 holdout 점수로 해석하지 않는다. (원본: 26_11_4/RESULTS.md; 26_11_4/20261104_종합보고서.md)

11_upper_bound_report는 S4 가중 오라클 결과 0.55538을 S6와 비교해 차이 0.00695를 적고, 추가 특징 탐색을 닫는다고 결론냈다. 같은 문서는 Cover-Hart 추정 0.71395, 모델 선택 오라클 0.74059, 연안복합 분리 오라클 0.69452도 제시했다. 이는 당시 정의된 후보와 자료를 사용한 산출 결과로 기록한다. (원본: 26_11_4/11_upper_bound_report.md; 26_11_4/inbox/011_데이터상한선_측정.md)

당시 단계는 305개 특징 S6와 제한된 오라클 조합을 채택·상한으로 보고하며 끝났고, 후속 독립검토가 해당 평가 설계와 해석을 재검토하게 됐다. (원본: 26_11_4/20261104_종합보고서.md; docs/project_review_20261104.md)

## 독립검토가 지적한 평가 문제

독립검토는 5,897척 개발 모집단에서 후보 선택에 사용된 pooled INNER ID 2,121척과 OUTER 집단의 교집합을 fold별 699/716/706척으로 계산했다. 문제는 같은 fold의 FIT과 OUTER가 겹쳤다는 뜻이 아니라, 여러 fold의 INNER 결과를 합쳐 설정을 고르고, 그 선택에 쓰인 선박들이 다른 fold에서는 OUTER로 등장한 교차 역할 누출이었다. 이에 따라 보고된 OUTER 결과는 완전히 독립된 선택 후 평가로 볼 수 없다고 검토했다. (원본: docs/project_review_20261104.md)

검토자는 S4 TabICL의 INNER 확률 산출도 확인했다. 문서의 INNER 테이블은 same-fold inner_predictions.csv 대신 rfid_id를 키로 global OUTER OOF 확률을 가져온 것으로 지적됐다. 라벨이나 ID가 일치하는 것만으로 예측을 생성한 fold와 단계가 같음을 입증하지 못하므로, 해당 INNER 기준을 후보 선택의 독립 자료로 볼 수 없다는 판단이었다. (원본: docs/project_review_20261104.md)

S6의 “passed” 조건에서는 요구한 1–7일 관측 하위집단 보호 확인이 빠져 있었다고 검토했다. 또 0.55538은 선택된 제한 모델들의 사후확률 조합 진단이지 모든 가능한 AIS 모델의 전역 상한이 아니며, 이를 근거로 향후 모델이 0.7에 도달할 수 없다고 결론낼 수 없다고 지적했다. 따라서 특징 탐색을 닫았다는 선언은 원 보고서의 실제 계산 범위보다 넓은 해석이었다. (원본: docs/project_review_20261104.md)

검토는 과거 holdout의 ID 교집합 문제 302척, 1103_v2 자료 버전 비교 미완료, 별도 실행 경로에서의 핵심 계산 등도 추가 감사 항목으로 정리했다. 검토가 권고한 순서는 데이터 버전과 지표 정의, 평가 출처·fold 경계 감사, fold-local 선택, 동일 기준선과 후보의 모든 보호 조건 재평가였다. (원본: docs/project_review_20261104.md)

## 판정과 후속 재설계

따라서 2026-11-04 보고서의 “S6 채택”, “특징 종료”, “0.55538 상한”은 당시 문서가 적은 결론으로 남기고, 독립검토의 반박을 나란히 기록한다. 이 문서화에서는 어느 한 문서를 조용히 대체하지 않으며, 공표된 수치 자체의 재현과 그 수치를 선택한 절차의 유효성을 구분한다. (원본: 26_11_4/20261104_종합보고서.md; 26_11_4/11_upper_bound_report.md; docs/project_review_20261104.md)

독립검토 이후 11_04_final은 fold 및 데이터 단계의 분리, 후보 선택 규칙 고정, 소스·입력·실행 동결, OUTER 보호 검토를 각 라운드의 절차로 강화했다. 그 이후의 시험은 성능 모델 탐색뿐 아니라 저장 예측 재현, CPU 추론, 실행 증거와 평가 출처 검산까지 포함했다. (원본: 11_04_final/AGENTS.md; 11_04_final/CYCLE_PROTOCOL.md; 11_04_final/rounds/round_001/ROUND_REPORT.md)
