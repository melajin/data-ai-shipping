# 1차·2차 모델과 2026-10-29~31 후속 분석

괄호 안 원본 경로는 DATA AI SHIPPING/ 저장소 루트 기준이다.

## 1차 모델 — shape9 기반 분류의 초기 성능 확인

첫 실험은 어선 항적의 기본 형상 통계를 이용해 네 조업형태를 분류하고, shape9 요약이 기준 비교보다 나은지 확인하려는 시도였다. 12개 원본 CSV에 3,887,069개 행과 7,372척이 포함됐으며, 선박마다 월별 자료를 최대 4행씩 표집해 shape9 및 분포 통계를 만들었다. 평가 자료는 2025 holdout 1,473척이었고 이 가운데 1,453척에서 점수를 계산했다. (원본: 1차 모델 실험 결과.md; 어선항적_1차모델결과_총정리_해설.md)

개발 비교에서 기존 R0 Macro-F1 0.166075, ExtraTrees 후보 0.335753으로 기록했다. 2025 holdout 1,453척의 후보는 725척 정답, macro-F1 0.299575였으며 R0는 722척 정답, macro-F1 0.166900이었다. 정확도는 전체 1,473척 기준 후보 0.492193, 다수 클래스만 예측하는 기준 0.495587로 기록됐다. 후보가 holdout에서 맞힌 수의 순증은 3척이었고, 통발 204척은 한 척도 맞히지 못했다. (원본: 1차 모델 실험 결과.md; 어선항적_1차모델결과_총정리_해설.md)

보고서는 macro-F1 증가를 근거로 후보를 긍정 평가했지만, 최종 holdout의 정답 수와 다수 클래스 기준 비교는 작은 차이를 보였다. 이 결과 이후 2차 실험은 입력량, 클래스 가중치, 규모 특징이 개발 성능과 통발 recall에 미치는 변화를 분리해 보도록 설계됐다. (원본: 1차 모델 실험 결과.md; 어선항적_1차모델결과_총정리_해설.md; 어선항적_2차모델결과_총정리_해설.md)

자료 검토 과정에서 시간 좌표와 CRS가 없다는 점도 기록됐다. 그러므로 해당 실험은 실제 속력 계산이나 좌표계 기반 이동 거리 검증을 한 것으로 설명하지 않는다. (원본: 어선항적_1차모델결과_총정리_해설.md; 어선 항적 분석 소개.md)

## 2차 모델 — 표본량·가중치·규모 특징의 요인 비교

2차 실험은 1차 점수 상승이 표본 확대, 클래스 균형 가중치, 규모 특징 중 무엇과 함께 나타나는지 확인하려는 요인 비교였다. ExtraTrees 256개 트리를 고정하고 2×2×2 조합으로 세 요인을 비교했으며, 동일 데이터 분할을 사용했다. 입력 표본 비율은 3.3%와 100%, 클래스 가중치는 none과 balanced, 규모 특징은 기존 shape9+dist36에 8개 척도 특징 요약을 더하는 조건이었다. (원본: 어선항적_2차모델결과_총정리_해설.md)

모든 표본·balanced 가중치·규모 특징을 쓴 조건의 개발 Macro-F1은 0.416952였고, 기준 재현값은 0.33540이었다. 개발 정확도는 0.50038로 다수 클래스 기준 0.49544보다 13척 더 맞혔다. 표본 확대 효과 평균은 +0.04903, balanced 가중치는 +0.01302, 규모 특징은 +0.01216으로 기록됐다. 이 요인 차이는 실험의 지정 분할에서 측정한 평균 변화이며, 세 효과가 서로 독립적이거나 가산적이라는 의미는 아니다. (원본: 어선항적_2차모델결과_총정리_해설.md)

통발 recall 최고는 0.06684였고, 새 특징과 가중치 조합만으로 통발 분류 문제가 해결되지는 않았다. 1차 때 제기된 6월 데이터 버전 차이 설명은 같은 파일을 파싱하다 중도 종료된 비교 문제로 정정됐다. 2025 holdout은 2차 학습·점수 산출에 쓰지 않았고, 이번 단계는 개발 자료 결과였다. (원본: 어선항적_2차모델결과_총정리_해설.md)

이 단계는 1차의 소량 표본형과 비교해 전체 3,482,766개 유효 특징 행을 사용했고, 데이터 범위 및 형상은 확대했지만 통발 recall은 낮은 상태였다. 후속 자료는 입력 정밀도와 0확률, 통발 이진 분리력, 월별 집계 효과를 각각 확인하도록 범위를 나눴다. (원본: 어선항적_2차모델결과_총정리_해설.md; 29-30일 모델 심층 분석/30일/어선항적_2차후속_최종정리_및_향후과제_20261030.md)

## 2026-10-29~31 후속 확인 — 모델 점수와 입력·확률 처리 구분

후속 분석은 새 모델을 한 번에 키우기보다 과거 값의 정밀도와 확률 처리 원인을 확인했다. float32 저장으로 낮게 기록됐던 기준 셀은 float64 재실행에서 Macro-F1 0.33524에서 0.33540으로 복원됐고, 나머지 기존 보고값 8/8도 일치했다. (원본: 29-30일 모델 심층 분석/30일/어선항적_2차후속_최종정리_및_향후과제_20261030.md)

0확률 비교에서는 epsilon 혼합이 두 셀의 0확률을 해소했으며, 18개 조합에서 argmax를 바꾸지 않았다. 온도 보정의 추가 변화는 NLL 0.0003 안쪽이었고 분할별로 효과가 일관되지 않았다. 통발 이진 ExtraTrees·Logistic 모델의 AUC는 0.55~0.62 범위였으며, 설정된 운영 기준 0.65 이상인 비교가 3개 중 0개였다. 이 값은 해당 설정의 분리력 결과이며 모든 가능한 모델이나 특징에 대한 불가능 판정은 아니다. (원본: 29-30일 모델 심층 분석/30일/어선항적_2차후속_최종정리_및_향후과제_20261030.md; 29-30일 모델 심층 분석/30일/어선항적_2차후속_진행상황_쉬운해설_20261030.md)

S1 집계의 2×2 비교에서는 validation 집계를 s4에서 전량으로 늘린 변화가 6개 분할 모두 양수였고, train 집계 변화는 −0.012에서 +0.013으로 작고 부호가 섞였다. 문서는 이 결과를 방향이 맞는 기술 통계로 정리하고, 일반적인 원인으로 확정하지 않았다. 최종 holdout은 이 후속 사이클에서 재평가하지 않았다. (원본: 29-30일 모델 심층 분석/30일/어선항적_2차후속_최종정리_및_향후과제_20261030.md)

F156/T5 결합 보고서는 팀원 자료의 개발 명부 및 원래 분할과 프로젝트 기존 분할 차이를 확인했다. 팀원 OOF 판정 F1 0.5379/0.5366 재계산은 일치했고, F156+T5 결합은 보고상 OOF 판정 F1 0.5363으로 기록됐다. 두 자료의 holdout 교집합은 302척이어서 같은 표본 결과처럼 병합할 수 없었고, 이 수치는 후속 자체 명부의 분할 결과로 보존한다. (원본: 29-30일 모델 심층 분석/31일/_handoff/outbox/005_report.md; 29-30일 모델 심층 분석/31일/data_remeasure_20261031.md)

## 채택 및 다음 단계로 이어진 판단

1차의 macro 상승은 남았지만 holdout 순증은 3척이고 통발은 0/204였다. 2차는 요인을 분리해 개발 Macro-F1을 0.416952까지 높였지만 통발 recall 최고가 0.06684에 머물렀다. 후속에서는 확률 수치와 기준선 재현 문제가 해결 또는 분리됐으나 통발 구분력이 크게 바뀌지 않았고, 이에 따라 다음 날짜 자료는 이웃 선박 정보, 공간 정보와 행동 요약을 별도 가설로 검토한다.
