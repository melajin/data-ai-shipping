# Test A 전체 개요와 지표 표기의 시점 차이

## 과업 범위와 읽는 법

Test A는 어선별 GPS 항적을 입력으로 받아 연안복합/자망/통발/채낚기연승 네 조업형태 중 하나를 예측하는 분류 과업이다. Test A 문서들은 항적 자료를 WKT 선형 기하와 선박 단위 특징으로 요약해 비교하며, 실험 범위에 따라 FIT, INNER, OUTER, 개발 반복평가를 구분한다. (원본: 어선 항적 분석 소개.md; 11_04_final/AGENTS.md; 11_04_final/CYCLE_PROTOCOL.md)

여기서 개발 OUTER 5,897척은 여러 보고서에서 반복 사용된 개발 모집단이다. 분할에서 학습되지 않은 OUTER 행이라는 의미와, 연구자가 결과를 보지 않은 독립 평가라는 의미는 서로 다르며, 후자의 지위는 노출 이력 검토에 달려 있다. (원본: 11_04_final/rounds/round_001/ROUND_REPORT.md; docs/project_review_20261104.md; 11_04_final/STATUS.json)

문서에 기록된 계산은 실제 자료를 사용한 소프트웨어 계산, 합성 입력 검사, 저장 확률 재검산으로 구분한다. 이들 중 어떤 것도 실제 선박 장치에서의 하드웨어 실험을 뜻하지 않으며, 아래 서술은 원문에서 보고한 평가 모집단과 단계를 함께 적는다. (원본: 11_04_final/AGENTS.md; 11_04_final/CYCLE_PROTOCOL.md; 11_04_final/rounds/round_004/ROUND_REPORT.md; 11_04_final/rounds/round_025/ROUND_REPORT.md; 11_04_final/rounds/round_029_domain_features_dtype_correction/ROUND_REPORT.md)

## 지표 표기의 시점 차이

2026-11-04 날짜 스냅샷 문서는 대회 공식 채점 지표를 macro-F1이라고 적고, 그 기준에 따라 L_base 0.53185와 S6 0.54843 등을 비교했다. 이 표기는 그날의 문서 내용으로 기록한다. (원본: 26_11_4/README.md; 26_11_4/RESULTS.md; 26_11_4/20261104_종합보고서.md)

이후 11_04_final 문서군은 목표를 개발·독립 근거를 분리한 선박 수준 micro-F1 0.7 이상으로 적었다. 단일 정답 네 분류에서 micro-F1이 정확도와 같다는 설명도 이 문서군에 나온다. 이 표기는 이후 계획과 라운드의 목표로 기록한다. (원본: 11_04_final/AGENTS.md; 11_04_final/CYCLE_PROTOCOL.md; 11_04_final/STATUS.json; 11_04_final/rounds/round_002/ROUND_REPORT.md)

두 시점은 서로 다른 문서의 실제 표기다. 여기서는 공식 지표가 macro인지 micro인지 판정하거나 한쪽으로 통일하지 않는다. (원본: 26_11_4/20261104_종합보고서.md; 11_04_final/AGENTS.md; 11_04_final/STATUS.json)

## 결과를 읽을 때 유지할 구분

1차·2차의 홀드아웃, 반복 노출 개발 OUTER, 라운드별 FIT 내부 CV, 저장 예측의 재현 검산은 각각 다른 모집단과 목적을 가진다. 각 점수는 그 조건과 함께 제시하며, 작은 내부 CV 개선을 전체 OUTER나 독립 평가의 개선으로 옮겨 쓰지 않는다. (원본: 1차 모델 실험 결과.md; 어선항적_2차모델결과_총정리_해설.md; 11_04_final/rounds/round_025/ROUND_REPORT.md; 11_04_final/rounds/round_029_domain_features_dtype_correction/ROUND_REPORT.md)

round_026과 round_027 일부 보고서는 더 높은 OUTER 값을 채택 후보로 공표했지만, 후속 독립검토는 OUTER를 사용한 선택 또는 실패한 INNER 보호게이트를 확인했다. 그러므로 공표 점수, 재현 가능한 점수, 선택 절차가 유효한 점수를 구별한다. (원본: 11_04_final/rounds/round_026/ROUND_REPORT.md; 11_04_final/rounds/round_026/review_20261105/REVIEW_ROUND026_0.60돌파_검증_20261105.md; 11_04_final/rounds/round_027_fallback_ovr/review_20261105/REVIEW_ROUND027_검증_20261105.md)

현재 상태 기록에는 기존 채택 기준과 탐색 최고가 별도로 남는다. 이전 채택 기준은 LightGBM sqrt_macro 5-seed 3,497/5,897이고, 확인된 더 높은 S0 등가중 관찰은 3,528/5,897이나 채낚기연승 TP 기준을 통과하지 못해 채택되지 않았다. (원본: 11_04_final/STATUS.json; 11_04_final/reports/round025_status_context/WHOLE_SCORE_CONTEXT.md)
