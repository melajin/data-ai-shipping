복사해서 사용할 제안서 문안
[설계 제안] 공식 양식의 제안내용 칸에 사용할 수 있는 통합 초안입니다.
1. 데이터 활용 방안 및 분석 방법론
1. 입력과 품질 확인
정식 데이터 수령 후 좌표계, 점·선의 순서, 관측 단절, 라벨 분포와 사고정보 연결 조건을 확인한다. 분리된 선은
 보존하고, 반복 좌표는 형상 계산용으로 압축하되 원래 관측 수와 중복 정보를 유지한다.
2. 항적 기반 조업형태 분류
이동거리·직선성·방향 변화·범위 등 사용 조건이 확인된 기하 특징으로 로지스틱 회귀와 작은 LightGBM을 비교
한다. 선박 ID를 입력에서 제외하고 신규 선박 검증을 적용한다. 클래스별 성능과 내부 Macro-F1을 보고한다.
3. 경량 이상항적 탐지
전역 강건 편차와 Isolation Forest를 각각 기준 모델로 평가한다. 조업형태별 기준·선박 과거 대비 변화는 사용 
가능한 이력과 검증 개선이 있을 때 추가한다. 현재의 이상항적 때문에 조업 분류와 기준이 함께 바뀌는 위험을 
점검한다.
4. 검증과 차별화
사고시각 기반 약한 라벨과 실제 이상구간을 구분한다. 시간순 평가에서 사전 탐지·사고 후 반응·정상 관측시간
당 경보를 따로 보고한다. 반복 압축, 관측 밀도 보정, 실제 크기/정규화 형상의 효과는 한 요소씩 추가·제거해 검
증한다.
2. 추진일정(계획)
자료·평가 조건 확인 → 기준 모델 구현 → 시간순 오류 분석 → 유효한 개선 요소 추가 → 경량화·제출 점검 순으
로 진행한다. 실제 마감일과 가용 작업 시간에 맞춰 일정을 정하고, 강화학습은 핵심 과제 완료 후 선택 실험으
로 검토한다.
3. 예상 결과물
항적 품질 점검·특징 추출 코드, 조업형태·확률 및 시간별 이상점수 파일, 검증·오류 분석표, 사고 전후 시각화, 모
델 크기·CPU 시간 측정과 재현 절차를 포함한 보고서를 작성한다. 공식 채점·제출 규격이 확정되면 이를 우선 적
용한다.
점별 시각이 없으면 순간 속도·가속도·체류시간은 산출하지 않습니다. 강화학습 보상 개선을 실제 사고 예방 성과로 해석하지 않습니
다.

상세 방법론: 계획을 설명하는 근거
[설계 제안] V1의 상세 방법론을 V2의 검증 조건에 맞춰 정리했습니다. 3쪽 문안의 설명 자료입니다.
1. 자료와 전처리
샘플 10행 전체에서 WKT·연속 중복·분리 선 구조를 확인했습니다. 정식 데이터에서는 클래스별 행/선박 수, 기
간·해역·관측 공백, 좌표계, 점·선의 순서와 사고 연결을 점검합니다. 원본 키·행 순서를 보존하고 품질 정보와 형
상 정보를 분리합니다.
2. 신규 선박의 조업형태 판별
선 내부 길이·직선성·굴곡·범위로 작은 지도학습 모델을 비교합니다. 선박 ID는 그룹 분리와 연결에만 쓰고 분류 
입력에서 제외합니다. 절대 위치 포함/제외를 비교해 해역 의존성을 확인하고, 클래스별 F1·Recall과 고유 선박 
수를 함께 보고합니다.
3. 정상 후보 대비 이상점수
강건 편차와 전역 Isolation Forest를 각각 평가합니다. 사고 주변을 제외해도 나머지 전부가 정상이라고 확정할 
수 없으므로 기준 오염을 점검합니다. 0-1 순위 점수는 사고 확률로 표현하지 않습니다. 조업/개인 기준은 추가 
개선이 확인될 때만 적용합니다.
4. 사고 전후 평가와 오류 분석
사고시각과 실제 이상구간을 구분합니다. 항적과 계산 결과를 사용할 수 있는 시점을 기준으로 사전 탐지율·선
행시간을 계산합니다. 정상 확인이 가능할 때 정상 관측시간당 오경보를 보고하고, 미확인 구간은 경보 빈도로 
구분합니다.
5. 차별화와 경량화
반복 압축·거리 표본화·실제 크기/정규화 형상을 한 요소씩 비교합니다. 특정 모델의 우위를 미리 주장하지 않고,
 성능이 비슷하면 특징·잎·트리·모델 수가 적은 후보를 선정합니다. 저장 크기·메모리·특징 추출/추론 시간을 측정
합니다.
확장 범위
선박의 허용된 과거 이력과 주변 선박/외부 자료는 제공·사용 조건이 확인된 경우만 추가합니다. 강화학습
은 경보 시점·반복 제어의 연구 실험이며, replay 보상 개선을 실제 사고 예방 효과로 해석하지 않습니다.
제출란에는 3쪽 문안을 사용하면 됩니다. 이 쪽은 설명용 상세안이므로 같은 내용을 중복해서 붙일 필요는 없습니다. 분량·별첨 규정
이 있으면 해당 규정을 우선 적용합니다.
