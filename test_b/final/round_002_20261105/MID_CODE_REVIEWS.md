# 수정 코드 독립 검토와 총괄 결정

Terra msg_582425dce50c: 점수 라우팅·후보 예산·RFID 공유·짝 bootstrap은 계약 일치. 다만 base/common random 확률을 한 배열에서 평균내므로 동일 후보군 관문을 판정할 수 없다고 실행 차단. 빈 B0_common의 candidate_count도 수정 요구.

Sonnet msg_6f6e4675a172: 점수별3승자 fixture와 라우팅, 예산, 시간창 등을 확인해 실행 승인. random 개별 수식은 계약 일치라고 보았고 candidate_count는 비치명으로 평가했다.

총괄 판정: 두 검토의 차이는 개별 random 확률 수식과 그 상위 집계 수준에 있다. 코드를 직접 읽어 base와 common 레코드를 같은 values 배열에 append한 후 하나의 평균을 계산하는 것을 확인했다. Terra의 집계 오류 지적을 채택해 수정 후 실행한다. 이는 새 성공조건이 아니라 원계약의 ‘후보군별 기대 분리’ 구현 복구다. Sonnet의 .05pp 표기는 단위 오기이며 원관문 .05 확률차=5%p를 유지한다.

각도 격자나 특징 수식을 새로 튜닝하지 않는다. 수정은 혼합 집계와 실제 풀 크기 표시에 한정한다.
