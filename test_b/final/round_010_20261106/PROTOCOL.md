# Round10 — 과거 중심위치 근접도의 관측 가능성

## 코어 시작 점검

1. 기존 선로·반복 공간과 현재 관측의 관계를 다루기 위한 작은 준비 단계다. 시간행 **평균 중심위치**의 자기 과거 근접도만 계산한다. 이 점검 자체를 실제 항로 추종이나 단계적 사고 탐지 구현 완료로 세지 않는다.
2. 작은 run/재개 재탐색, 실제 항로·항만·대기/정상/통신 장애·사고 원인·속력은 범위 밖이다. 중심좌표는 시간행 여러 부분선 좌표의 평균일 수 있고 실제 항적 위에 있지 않을 수 있다.
3. 기술 목표는 결과 독립 과거 위치 거리·유보 장부와 독립 이력 가용성 집계다. 학습 목표는 평균 위치 대리값과 원부분선/항로, 반복 관측과 정상 정답, 과거/현재/미래를 구분하는 것이다. 산출물은 위치 장부·선박/어업 요약·독립 집계·12개 거리 대조·정답 동결 후 사건창 가용성이다. 관찰은 좌표 결측, 과거 수/날짜, 최근접 거리, 동료 적격이다. 검증은 범위·현재/미래 제외·경계·독립 개수와 거리 대조다. 설명 질문은 ‘이 값으로 무엇을 알 수 있고 항만이나 실제 선로를 왜 확정하지 못하는가?’다.
4. R4의99,677행/82척 중심·시간·ordinal과 R3 어업 코드를 확인했다. 정상/대기/항만/실제 항로 정답·점별 시각·정확 CRS/시간대·확정 사고 신원은 없다. 원자료 재추출·외부 수집은 하지 않는다.
5. 자료 관문은82척별 관측/과거 적격 수와12거리 독립 일치다. 다음 점수 설계로 갈 시작선은 Tier01 사건±6h 안의 **자기 적격 거리 관측이50/60 이상**, peer 적격 행을 하나 이상 가진 RFID가6척 이상이다. 이는 탐색 가용성 조건이며 적중률 기준이 아니다. 실패하면 창·개수·좌표 규칙을 바꿔 재시도하지 않는다. 통과해도 사고 성능은 미확인이고 별도 고정 점수 설계 및 기존4개 성능 관문이 필요하다.

## 고정 범위

공통 관찰은 같은 배의[t−720,t) 유효 중심 24개 이상·source-clock 날짜3일 이상일 때 현재 중심과 과거 중심 사이의 최단 구면거리다. 과거의 정확한 선로나 부분선 사이를 연결하지 않는다. 어업 추가는 같은 시각 t에 같은 이력 조건을 만족하는 다른 동일 단일 어업 선박5척 이상이 있는지 가용성만 기록한다. 자기/동료 과거 기준은 결과를 보지 않고 전체기간에서 구성한다. 장부 저장·검증이 끝난 뒤에만 기존100사건/60Tier01의 창에 적격 관측이 있는지 센다.

이번에는 후보 순위·예측 목록·bootstrap 적중률을 만들지 않는다. 연산·자료 정리 자체를 성능 진척으로 표현하지 않는다. 이전 자료·계약·실패 결과를 보존한다. 두 경쟁 검토의 실제 제안과 root 채택/정정은 Round9 FINAL_RESULT_RECONCILIATION.md에 남겼다.
