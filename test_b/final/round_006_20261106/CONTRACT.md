## Rules: Luna owner

Input canonical frame unique RFID/ts with rfid_id,ts,source_ordinal,len_m,bbox_m,cen_lon,cen_lat,score; read selected numeric columns from R4 execution_001/candidate_ledger.parquet. Registry R3 primary_gear/is_single_code. Geometry finite nonnegative; small len<=100 AND bbox<=100. A run is a maximal sequence of small observations at exact successive integer hours; invalid geometry or missing hours breaks it. Stable run_id=RFID:start_observed_ts. Current L is observed count so far, never future total. Left confirmed iff exact preceding hour is observed valid non-small; otherwise current L is a lower bound. Right confirmed iff exact following hour after last small is observed valid non-small; close_ts=that non-small hour. Gaps/invalid/end-of-data censor the run; they cannot be called completed.

Registry of runs must preserve starts,ends,observed length,left/right confirmation,close_ts,source ordinals and censor reasons. Reference at t: fully left+right confirmed, start>=t-720 AND close_ts<t. n>=10 references and >=3 distinct start dates are required; current run excluded by strict close condition. self_cdf=(#length<L+.5*#length==L)/n. At SAME t obtain reference CDF(L) for OTHER same-single-code RFIDs individually with same n/date criterion. >=5 eligible peers required; peer_cdf_mean is vessel-equal average, not pooled runs. No accident fields, old U/C or future completion in scoring. Unknown/mixed/singleton cannot get gear comparison.

Stages and status: d0_ok=current geometry valid and finite legacy score; invalid input status defer. d1_ok=d0 and small (not-small reject as outside this branch). d2_ok=d1 and exact previous hour valid small, L>=2. Missing/invalid previous is defer, observed previous non-small is reject as only1 observed key. d3_ok=d2 and self-history eligible; shortage defer. d4_ok=d3 and peer-history/gear eligible; shortage/unknown/singleton defer. For every dN store dN_status (keep/reject/defer/not_applicable), dN_reason; upstream-ineligible rows are not_applicable for later stages, not double counted. These are computational condition statuses, not actual normal/accident decisions.

Pools per RFID: B0=d0. S=d3 if nonempty else d2 if nonempty else d0. G=d4 if nonempty else S actual pool. fallback_reason explicit no_self_history_candidates / no_peer_history_candidates / no_continuation_candidates / no_observations as applicable. All methods cap=min(4,len(G actual pool)); no observations cap0. No distinct-run quota or spacing. Same prediction list per RFID for all linked events.

Rank B0 and fallback d0/d2 by legacy score desc,ts asc,ordinal asc. S at d3: self_cdf desc,legacy desc,ts,ordinal. G at d4: self_cdf desc FIRST,peer_cdf_mean desc SECOND,legacy desc,ts,ordinal. G fallback d3 uses S ranking. predictions columns: rfid_id,method(B0/S/G),rank,ts,ordinal,method_score,secondary_score,legacy_score,score_kind,run_id,actual_pool_n,cap,fallback_reason. method_score=legacy for d0/d2, self_cdf for d3/d4; secondary_score=peer_cdf_mean only d4 else null. score_kind legacy/self_cdf/self_then_peer_cdf. These are ranking statistics, not probabilities.

API build_duration_rules(frame,gear_registry)->dict {ledger,predictions,pool_manifest,run_registry,diagnostics,stage_spec}. ledger retains input order/index and fields, adds stage statuses, current L/lower-bound/start, run_id, self ref counts/dates/cdf,peer eligible count/mean and missing reasons. pool_manifest one row RFID/method with pool_stage(d0/d2/d3/d4),actual_pool_n,cap,fallback_reason. stage_spec is fixed list of dictionaries with keys stage_id(d0..d4),label,input_stage(null for d0 else previous dN),mask_column(dN_ok),status_column(dN_status),reason_column(dN_reason). Evaluator loops this generic schema rather than inventing meaning.

Luna owns duration_rules.py,check_duration_rules.py,rule_checks.json,RULE_NOTES.md. Tiny meaningful checks: reference requires BOTH observed boundaries, gap/invalid censor,strict close_ts<t,start-window boundary,10refs/3dates/5peer boundaries,current lower bound,future append invariance of earlier scored fields,unknown/singleton fallback,distinct B0/S/G winners/shared caps.
