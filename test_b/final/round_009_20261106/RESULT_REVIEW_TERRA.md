## 다음 한 가지: 과거 위치 근접도 관측 가능성 점검

사전 선언된 중단 조건에 따라 small-run의 길이·개시·지속·종료나 같은 전이의 시간·거리 문턱을 다시 바꾸지 않는다. R8 부분선 희귀성도 재조정하지 않는다. 현재까지의 결과는 새로운 위치 점수가 고정 적중 관문을 넘을 것이라는 직접 근거를 주지 않으므로, **즉시 성능 개선 실험을 시작하기보다 저장된 시간별 중심좌표로 선박별 과거 위치 근접도를 계산할 수 있는지 한 번만 점검**할 것을 권고한다.

이 값은 각 시간행 좌표들의 기존 산술 중심에 대한 **관측 위치 대리값**이다. 실제 부분선 경로, 항로 추종, 항만, 같은 장소에 머문 시간이나 정상/사고 상태가 아니다. 현재 캐시에는 전체 부분선의 원점열이 없고 R8 추출물도 선택 부분선의 요약이므로, 실제 선로 일치·부분선 간 겹침을 현재 입력으로 재구성하지 않는다.

### 고정된 작은 실현 가능성 점검

- **공통 관찰:** 82척의 전체 관측시간에 대해 유효한 경위도 범위의 현재 중심과 `[t−720,t)`의 같은 RFID 유효 중심을 비교한다. 기준은 과거 24시간행 이상 및 source-clock 날짜 3일 이상이며, 각 현재 중심에서 과거 중심 중 최단 구면거리 하나를 계산한다. 기존과 같은 지구 반경 6,371,000m 가정으로 단위를 명시하고 정확 CRS·실제 측지 오차는 미확인으로 남긴다. 기준은 사고표 없이 정하며 현재·미래·사고좌표는 사용하지 않는다.
- **어업 맥락:** 같은 시각 t 이전에 위 조건을 충족한 다른 동일 단일 어업 RFID가 5척 이상인지 관측 가능성만 기록한다. 선박별 시간행 수와 날짜 수, 좌표 결측, 적격 이력 및 peer 수를 선박 균등 요약하고 singleton·미확인은 유보한다. 이번 점검에서 어업 집단을 정상 행동의 기준으로 확정하거나 특정 위치를 하드 제외하지 않는다.
- **계보와 편향:** source ordinal·시간·좌표 유효 상태와 과거 이력 범위, 자기 제외 여부, 결과값·유보 사유를 장부에 남긴다. 장부 고정 후에만 전체 100건/Tier01 60건의 ±6시간 창에서 유효 대리값 존재 여부와 사건별 분자·분모를 산출한다. 참조와 후보 선택을 사고시간 ±6시간으로 제한하지 않는다. 결과를 이용한 실패 사례 설명은 과거 기준 구성과 구분한다.
- **사전 중단 조건:** 82척별 관측/이력 수와 전체·Tier01 coverage를 먼저 제시한다. Tier01의 적격 관측이 있는 사건창이 **50/60 미만**이거나 동료 조건을 충족하는 RFID가 **6척 미만**이면 이 질문은 입력·표본 부족으로 보류한다. 50/60과 6척은 실용적인 탐색 출발선이지 통계적 증명이나 제출 관문이 아니다. 관측 가능하더라도 비율만으로 사고 판별이 입증되지 않는다. 실패하면 이 수치나 기간을 조정해 재시도하지 않는다.
- **후속 성능 평가 조건:** 위 적격성이 확인되고 총괄이 별도 고정 설계를 선택한 경우에만, 같은 후보 수의 B0 및 G를 사건별로 비교한다. 주관문은 Tier01 G−B0 top1 +5%p 이상, 선박 paired bootstrap 95% 하한 양수, 전체 100건 비악화, Tier01 G의 실제 풀·동일 예산 무작위 기대 초과다. 동료 조건 부족은 유보/fallback하고 전체 분모를 유지한다. 이번 제안 자체에는 결과를 보고 점수·문턱을 선택하는 실험이 포함되지 않는다.

이 대리값의 위험은 같은 선박의 관측 밀도·기간과 좌표 양자화가 거리에 영향을 주며, 평소와 다른 위치가 정상 운항인지 사고 관련인지 알 수 없다는 것이다. 반복 관측이 많은 장소가 실제 항만이거나 정상이라는 근거도 없어 “대기 false alarm”을 계량할 라벨이 없다. 반복된 개발셋을 이용한 어떤 후속 적중률도 탐색 결과이며 독립 일반화를 증명하지 않는다.

## 다섯 가지 시작 점검

1. **코어:** 같은 선박이 과거 관측 공간과 다른 중심 위치에 나타나는가, 어업별로 이력 가용성이 어떻게 다른가를 설명한다. 실제 항로 추종 증명과 구분한다.
2. **범위 밖:** 중단된 small-run 규칙군 재탐색, 부분선 정답 복원, 항만·대기·속력·사고 원인 판정, 새 학습·외부 수집·Test B 제출은 포함하지 않는다.
3. **기술·학습:** 결과 독립적 과거 위치 대리값과 단계별 유보 장부가 기술 산출물이다. 학습 질문은 중심 위치와 항로의 차이, 과거 기준과 정답 누수의 차이, 결측과 정상 판정의 차이다. 시간 경계·중복·동료 자기 제외·미관측 fallback을 작은 합성 사례로 확인한다.
4. **입력과 미확인:** 기존 수치 장부의 중심좌표·시간키·원행 ordinal과 R3 어업등록을 사용한다. 정확 CRS, 시간대, 점별 시각, 검증된 항만·대기 정답, 확정 사고 신원과 제출 선박의 어업정보는 미확인이다. 하드웨어 실측은 없다.
5. **다음 관문:** 위의 사전 실현 가능성 기준을 먼저 적용하고, 통과해도 동일 예산 성능 비교의 별도 설계와 고정 주관문을 만족해야 한다. 결과 미지원 시 같은 문턱이나 창을 조정하지 않고 보류한다.

단순히 모든 관측 중심의 전역 희귀도를 쓰는 대안은 구현이 쉽고 넓은 후보를 유지하는 장점이 있다. 하지만 배별 통상 해역과 관측 수 차이를 섞어 빈번한 지역 차이를 사고 단서로 오해할 위험이 있어, 이 제안에서는 먼저 동일 선박의 시간상 과거와 데이터 가용성에 질문을 한정한다.
