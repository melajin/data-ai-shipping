# Round1 상세 보고서 — 기준과 다음 실험 확정

## 결과와 결정

이번 회차의 기술 결과는 기존 결과의 사용 범위와 다음 실험의 정의를 확정한 것이다. 사고 탐지 성능이 개선됐다고 판단하지 않는다. 새 회차는 사용자 지시에 따라 round1부터 시작했다. 기존 Round015로 만들었던 폴더를 이 폴더로 이동했고, 과거 원본은 보존했다.

과거 Round014의 6/49·10/100·p<.01·Level1 통과는 저장된 dev 다중시각 예측/평가표로 연결되지 않았다. 저장된 A–G 7개 단일선택 중 최고는2/49, 전체3/100이며 모두 옛 Level1 false다. 4시각 합집합이 불가능하다는 반증은 아니고 확인할 계산표가 없는 상태다. 이 성공주장을 새 기준선이나 개선 근거로 승계하지 않는다. 사례보고서의 실제속력·예인·모항·확정신원·인과 해석은 계약상 허용되는 요약범위를 초과한다. 수치/기제 증거로 사용하지 않는다.

## 입력과 실제 확인

- 연결 CSV 직접 집계: 전체100사건82RFID, Tier0–1=60사건55RFID. tier0 36,1 24,2 6,3 8,4 6,5 17,6 1,8 2. conflict=True 5사건. 신원은 잠정 연결이다.
- Parquet footer 직접 확인: 기존 dev822,000행/51,584,418bytes, 추가dev45,750행/3,373,601bytes. 이 전체가100사건의행수는 아니며 다음단계에서82RFID로필터한다. Test B파생점수46,705행/3,765,001bytes.
- 입력schema/해시는input_metadata.json, 집계는cohort_counts.json. 원자료새로추출·대형모델학습·후보변경은이번회차에서없었다.
- 샘플양식에는4시각과4점수필드가존재하지만추가시각의공식채점의미는확인되지않았다.4개내부후보합집합성능을공식점수로바꾸지않는다.

## 위임과 경쟁 검토

Luna는수치계보,Gemini는자료의미를독립감사했다. Terra와Sonnet이각자하위결과를평가했고,서로의제안과총괄수정안을한차례교차검토했다. 실제dispatch와model/effort는MODEL_AND_RUN_EVIDENCE.md와상위TEAM_STATUS.json을따른다. 모든모델은요청/Orca반환증거이며provider내부인증이아니다.

Terra의한쪽하위꼬리점수는평소작은값에도높은값을줄수있어양쪽희귀성으로수정했다. Sonnet의같은시간대비교는일주기맥락을반영하지만타선박backoff와미래자료혼입범위가넓어이번회차에채택하지않았다. Sonnet의분모혼동과기존결과로상위규칙을선택하는제안도직접집계/사전고정비교로대체했다.두사람모두수정된CvsU위치조건비교에동의했다.

교차검토에서보완한사항: primary1시각은secondary4개중첫번째이며총5개가아니다.적격행1~3개이면실제후보수를양방법에동일적용하고기록한다.무작위예측은같은RFID의모든사건에공유한다.전체분모fallback평가와공통후보군비교를분리한다.
