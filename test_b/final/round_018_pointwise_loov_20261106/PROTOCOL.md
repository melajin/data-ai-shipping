# Round018 사전 고정 규칙

이 문서는 결과를 읽거나 학습하기 전에 고정한다. `freeze.json`은 이 문서·평가 코드·입력의 SHA256과 고정 시각을 저장한다. 한 번의 실행에서 82개 제외선박 모형을 학습하고 한 번 평가한다. 결과 확인 후 특징·창·가중치·임계값·솔버를 변경하지 않는다.

## 가설과 범위

기존 전기간 최고점의 시간 간격 포화·중심점 점프 편향을 새로운 점별 기하 학습으로 대체한다. 서로 다른 선박에서 공통으로 나타나는 부분선 길이, 경계상자 크기, 좌표 수의 조합이 사고창을 구별할 수 있다는 **미검증 가설**이다. 관측 전이, 시간대, 동료 동시성, 위치 순위, 공란 임계값, 상태 필터를 재시도하지 않는다. 좌표별 시각이 없으므로 실제 속력·가속도를 계산하지 않는다.

2026 자료만 사용한다. 정확히 지정된 월별 parquet 6개와 기존 `devset_positives.csv`만 자료로 읽는다. 2025 테스트·F:·외부 자료·추가 ID 매핑은 읽지 않는다. 제공된 rfid_id는 기존 평가 대상의 묶음 분리, 학습 제외, 정답 대조에만 쓰며 특징·재식별·새로운 연결 근거로 쓰지 않는다. 라벨의 row_ts, 연결거리, tier, 사고종류, 톤수, 위치는 모델에 넣지 않는다. 지역 사전확률 및 기존 참조자료를 새 모델에 사용하지 않으므로 지역 자가포함이 없다. 고정 기준선 코드는 변경·실행하지 않고 제공된 **3/82**를 비교 대상으로 유지한다.

## 고정된 학습 규칙

- 대상은 제공 정답 100사건에 연결된 82척 전체다. 나머지 선단은 미사고 정답으로 취급하지 않으며 학습에 쓰지 않는다. 전체 파일은 청크로 검사하고 해당 82척의 행만 유지한다.
- 원래의 모든 행을 후보로 보존한다. 같은 시각의 여러 행도 각각 점수를 계산한다. 시간별 점수는 해당 시간의 행 점수 최댓값과 같다.
- 82회 leave-one-vessel-out: 평가선박의 모든 관측과 모든 사건을 학습·정규화에서 제외한다. 각 학습은 다른 81척만 사용한다. 82회는 한 규칙의 사전 고정된 교차검증이며 82개 규칙의 선택이 아니다.
- 입력 세 값은 `log1p(len_m), log1p(bbox_m), log1p(n_coords)`. 학습 행만으로 각 열의 중앙값과 IQR을 계산한다(NumPy linear percentile). IQR=0이면 1로 대체한다. 표준화 후 [-5,5]로 자른다.
- 특징 9개는 z1,z2,z3,z1²,z2²,z3²,z1z2,z1z3,z2z3이다. 좌표·날짜·시간·ID·간격·중심점 점프·상태·기존 점수·순위·선박별 이력 통계는 특징으로 쓰지 않는다.
- 학습 라벨은 해당 학습선박의 사건 중 하나와 `abs(ts-acc_ts)<=6`이면 1, 그 밖은 대조군 0이다. 대조군은 확인된 정상 정답이 아니다. 모든 사건을 함께 제외하므로 다중사고 누수가 없다.
- 학습선박마다 총 가중치 1/V를 준다. 두 클래스가 있으면 각각 1/(2V)를 행 수로 균등 분배한다. 한 클래스만 있으면 그 클래스에 1/V를 균등 배분한다. V는 후보가 있는 학습선박 수다. 표본추출·특징 선택·튜닝은 하지 않는다.
- 절편과 계수의 초기값은 모두 0. 목적함수는 `sum(w*(logaddexp(0,eta)-y*eta)) + 0.01*sum(beta**2)/2`. 절편은 벌점에서 제외한다. SciPy L-BFGS-B, analytic jacobian, maxiter=1000, ftol=1e-12, gtol=1e-8, maxls=50. 성공 플래그가 없으면 실행 무효이며 다른 설정으로 재평가하지 않는다.
- 예측 점수는 선형 로짓 eta다(확률 변환과 순위가 동일). 최고 점수, source_ordinal 오름차순, ts 오름차순 순으로 한 행을 선택한다. 반올림하지 않는다. 이 점수는 보정된 사고 확률이 아니다.
- 유한한 비음수 기하값·정수 시간/순번 계약 위반은 조용히 제외하지 않고 실행을 무효화한다. 후보가 없는 선박은 실패 예측으로 남기며 분모에서 빼지 않는다.
- 학습 분할 전체가 단일 클래스이면 벌점 없는 절편의 유한 최적해가 없으므로 실행 무효다. 입력은 사전 지정 경로만 허용하고 실제 해석된 경로가 작업 루트를 벗어나면 읽기 전에 중단한다.

## 평가와 채택 기준

예측 82개를 먼저 저장한 다음 평가한다. 주 지표는 선박별 내부 지표 `h=±6h top-1 적중 수/82`. 다중사고는 해당 선박의 모든 acc_ts에 대한 최소 절대 오차를 쓴다. 사건별 100행과 선박별 82행을 모두 저장하되 사건 분모를 선박 분모와 섞지 않는다. 후보가 없는 선박은 오차 +infinity로 중앙값에 포함한다(JSON에서는 null과 상태로 표시).

우연 모델은 **관측된 고유 시간 중 균등하게 한 시간을 고르는 선택기**다. 각 선박에서 모든 사고 ±6h 창의 합집합에 드는 고유 후보 시간 수/고유 후보 시간 수를 q_i로 계산한다. 후보 없음은 q_i=0. 기대 적중 수=sum(q_i), 기대율=mean(q_i). 82개의 q_i로 Poisson-binomial 분포를 정확한 동적계획으로 계산하고 관측 적중 수 이상의 단측 꼬리확률을 기록한다. 중위 후보 수와 13시간으로 계산한 1.07%는 거친 기존 진단값이며 이번의 정확한 조건부 기대와 구분한다. 행 균등 선택기의 기대도 보조 기록하되 판정에는 쓰지 않는다.

기준선은 고정된 3/82다. 어떤 세 척인지 추가 자료를 읽어 복원하지 않는다. 신규 적중 H와 기준선 적중의 가능한 교집합 k 전체에서 gains=H-k, losses=3-k를 계산하고, `Binomial(gains+losses,0.5)`의 gains 이상 단측 꼬리확률 중 **최대값**을 사용한다. 가능한 k는 max(0,H+3-82)..min(3,H). 이는 기준선 적중의 겹침을 모르므로 보수적으로 적용하는 McNemar식 비교다.

**채택 조건을 모두 충족해야 한다:** H>3, 위 최악 겹침 p<=0.05, 관측시간 균등 우연모델 p<=0.05, 계약·누수·수렴·무결성 검사 통과. 기준선 비교만으로도 H>=10이 필요하다. 미충족이면 **기각**이다. 계약/구현 실패이면 실행 무효로 별도 표시하며 성공으로 포장하지 않는다. 중앙 오차는 보조 지표이며 선택 기준으로 삼지 않는다.

이 검정의 p값은 독립 선박 가정의 개발셋 내 명목적 선별 기준이다. 이미 여러 라운드에 사용한 잠정 연결 정답이며 LOOV 학습 자료도 서로 겹친다. 이를 새 독립 평가자료에서 확인된 유의성·공식 F1·실시간 성능으로 주장하지 않는다. 교차검증은 자가 학습을 막지만 과거 개발셋 탐색 이력을 없애지 않는다.

## 실행·검증·학습 기록

한 프로세스·한 BLAS 스레드로 순차 실행한다. 실행 전과 자료 로딩/학습 단계에 가용 RAM, 실행 중 프로세스, 예상 최대 사용량, 근거, 시각을 남긴다. 예상 사용량+640MiB 미확보면 보류한다. 청크 32,768행, 유지 자료 최대 128MiB. 로딩 추정 768MiB, 학습 추정 max(768MiB, 유지자료×6+256MiB), 전체 상한 가정 약 1GiB. 부족하면 자료 로딩·학습을 진행하지 않고 재개 직전에 새로 확인한다. 반복 RAM 감시 루프 및 사용자 프로세스 종료는 금지한다.

새 폴더의 execution_001만 독점 생성하고 재실행 덮어쓰기를 차단한다. 원자료와 문서/코드 해시를 전후 비교한다. 합성 검사에서는 다중사고 창 합집합, 동점 규칙, 최악 겹침 검정, 학습 제외 계약을 확인한다. 실제 2026 평가와 합성 코드 검사를 구분한다.

메모리 부족 보류는 평가 완료로 세지 않는다. 실행 폴더 생성 전 보류라면 같은 고정 코드로 재호출할 수 있다. 생성 후 보류라면 보류 기록을 보존하고 종료하며 기존 실행 폴더를 덮어쓰는 자동 재개는 제공하지 않는다. 재개가 필요할 때에는 새 RAM 확인과 평가 전 실행 증거 보존을 우선하며 규칙·하이퍼파라미터 변경이나 결과가 나온 평가의 재시도는 허용하지 않는다.

기술 목표는 재현 가능한 한 번의 LOOV 평가다. 학습 목표는 이상점수와 사고시각 예측, 학습 제외와 개발셋 재사용, 고유시간 우연모델과 단순 13/N 근사의 차이를 설명하는 것이다. 관찰할 현상은 신규 적중 수·중앙 오차·우연 대비 차이다. 설명 질문: 왜 점프의 최대값이 사고시각의 근거가 아닐 수 있는가? 왜 평가선박의 사건 전체를 제외하는가? 왜 비사고창을 정상 정답으로 부르면 안 되는가?
