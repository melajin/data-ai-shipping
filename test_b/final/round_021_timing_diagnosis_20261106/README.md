# Round021 사고시각 오차 진단

전체 2026 선단 7,372척의 동일한 고정 점수를 사용해 시각 선택만 비교한다. 82척의 잠정 사고 연결은 조건부 진단에 사용하며 나머지를 확정 정상으로 취급하지 않는다.

이번 착수 시 실행 계획에 다른 진행 기록의 Round020 완료가 이미 반영돼 있었다. 처음 안내했던 Round020 번호를 재사용하지 않고 새 Round021로 구분했다. Round020의 저장 학습 모델·±6시간 가중합 규칙을 반복 실행하지 않는다. 기존 문서·산출물은 보존한다.

- PROTOCOL.md와 freeze.json: 결과 확인 전 고정 규칙, 분할, 판정 및 가정.
- 점수화: 모든 선박에 기존 최고점, 최고점 동점 구간 중앙, 최고점 직전 원행과의 공백 중앙 시각을 예측한다. 이때 사고시각 라벨은 읽지 않는다.
- 평가: 개발에서 한 규칙을 선택·봉인하고 검증에서는 그 규칙과 기준선만 비교한다. 최초 독립 검증으로 부르지 않는다.
- 전체 선별 집계: 전부 제출/최고점≥0.75/반경≥전체 선단 95분위의 선정 수와 잠정 연결·시간 적중을 같은 표에서 계산한다.
- 오차 진단: 후보 존재 부족, 점수의 순위 선택, 동점 선택을 구분한다. 관측 공백을 사고 원인으로 단정하지 않는다.

코드·원자료·잠정 연결의 한계, 실행·검산 결과는 최종 ROUND021_report.md와 AUDIT.md에 기록한다. 작업 진행 중에는 완료 표시와 봉인 파일이 없는 중간 산출물을 최종 결과로 읽지 않는다.

모든 메모리 집약 단계는 직전 가용 RAM과 실행 중인 작업을 확인한다. 파티션별 처리를 사용하고 부족하면 보류한다. 2025 Test B·Test A·외부 선박 재식별·새 ID 연결·공식 제출·실선 실험은 수행하지 않는다.
