# Round013 상세보고서 — 설계 단계

상태: 인계 검토와 다음 회차 설계 완료. 실제 자료 전수 처리·새 학습·예측·정량 결과는 아직 없다.

총괄은 [인계 판단](HANDOFF_REVIEW.md)에 따라 [실행 설계](PROTOCOL.md)를 작성했다. 전체 학습 가능 선박의 어업별 기준 적합과 사고 전후 연속 항적을 연결하고, 시간별 경로량 급감이라는 단일 가설을 검증 대상으로 정했다. 기존 지표의 결함을 고친다는 이유로 6시간 적중과 미사고 FP를 평가에서 밀어내지 않는다.

이번에 실제 확인한 근거는 인계서·재집계 코드, Round001 보고서, Round002 계약, Round012 결정, 현행 실행 계획, 기존 버전 해시 감사, 초기 gap/jump 코드와 메타데이터다. F드라이브 두 버전의 항적 CSV12개와 사고표가 같다는 것은 기존 해시 감사의 결과이며 이번 재해시 결과가 아니다.

이번 회차의 순서는 전자료 역할/분할 확정 → 전체 어업 기준과100사건 연속 관측 → 단일 급변 점수 적합/적용 → 고정 분모의 시간오차·순위·적중·커버리지 평가다. 상세 원항적12사례는 선정 방식을 사전 고정했다. 잠정82척은 평가 집합이며 적합 범위가 아니다.

기술적 설계가 완료됐지만 성능 개선은 아직 측정하지 않았다. 학습자가 이해했다고도 검증하지 않았다. 다음 실제 실행의 조건·산출물·분모·자원·중단/복귀 기준은 PROTOCOL을 따른다. 공식 F1 정확식과 확정 양성/음성 부족은 명시하되 내부 행동 분석의 전면 중단 사유로 쓰지 않는다.
