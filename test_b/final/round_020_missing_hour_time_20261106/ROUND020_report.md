# Round020 — 관측 없는 시간까지 포함한 사고시각 추정

**판정: 기각.** 사용자가 요청한 완화 기준을 평가 전에 적용했지만, ±6시간 적중은 **3/82(3.6585%)**로 기준선과 같았다. 중앙 오차는 573.5시간으로 줄었으나 목표인 적중 수는 증가하지 않았다.

## 평가 전에 완화한 기준

사용자가 "판정을 조금 러프하게", "판정 기준"이라고 지시한 뒤, 실제 예측·평가 전에 [프로토콜](PROTOCOL.md)을 다음처럼 변경했다.

| 조건 | 개발 판정 |
|---|---|
| 5척 이상 적중하고 새 후보 공간의 우연 기대율보다 높음 | 개선 후보 |
| 4척 적중하고 우연 기대율보다 높음 | 보류 |
| 3척 이하 또는 우연 기대율 이하 | 기각 |

p값은 참고 수치이며 통과 조건에서 제외했다. 개선 후보도 통계적 유의성·독립 검증·운영 채택을 뜻하지 않는다. 허용 오차 ±6시간, 분모 82척, 정답, 모델, 누수·무결성 검증은 변경하지 않았다. [변경 기록](decision_revision_before_freeze.json)의 최초 기록 시각은 **14:56:42 KST**, 프로토콜·코드 동결은 **14:59:56 KST**, 새 예측 봉인은 **15:00:14 KST**다. 모두 2026-11-06이며, 결과를 확인한 뒤 판정을 완화한 것이 아니다. 보조 변경 기록의 한글 인용 인코딩만 사후 복구했고 해당 사실을 기록에 명시했다. 변경된 판정식과 정상 한글 지시는 평가 전 동결 프로토콜에서도 확인된다.

## 한 번 시험한 규칙

Round018에서 평가선박을 제외하고 학습한 저장 모델 82개를 그대로 재사용했다. 부분선 길이·경계상자 크기·좌표 수의 기하 특징과 계수·정규화는 변경하지 않았으며 **새 학습은 없었다**.

각 관측시간의 로짓 eta를 `w(t)=exp(eta(t)-max(eta))`로 변환했다. 후보 c마다 **±6시간 내 관측의 w 합 / 해당 선박 전체 w 합**을 계산하고 가장 큰 후보 하나를 선택했다. 같은 시간의 중복 행은 최대 로짓 하나로 처리했다. 동점은 실제 최대점 후보를 시간순으로 정렬한 뒤 아래쪽 중앙 원소로 결정했다. 합은 `math.fsum`을 사용했다.

후보는 선박별 최초 관측부터 최종 관측까지 모든 정수시간으로, 관측 없는 내부 시간도 포함했다. 주변 관측이 없는 후보의 0점은 **근거 없음**이며 정상 판정이 아니다. 합산 점수는 상대 모델 근거 비중이지 보정된 사고 확률이 아니다. 관측 밀도에 영향을 받으며, 원 모델도 이미 ±6시간 라벨로 학습했다는 한계를 유지한다.

공백 길이·관측 전이·시간대 가중·상태 필터·위치 순위를 추가하지 않았다. 과거 Round013도 정수시간을 검사했으므로 단순 후보 확장만을 신규성으로 보지 않는다. 이번의 신규 가설은 **고정된 기하 모델의 한 점 최고값 대신 허용 오차 구간의 근거를 모아 선택하는 것**이었다. 창 길이를 비교하거나 결과에 맞춰 선택기를 수정하지 않았다.

## 결과

| 항목 | 결과 |
|---|---:|
| 선박별 ±6h top-1 적중 | **3/82 — 3.6585%** |
| 기준선 대비 추가 적중 | **0척** |
| 선박별 최소 절대 오차 중앙값 | **573.5시간** |
| 사건별 보조 적중 | 3/100 |
| 전체 정수시간 균등선택 기대 적중 | 0.3850/82 |
| 이번 후보 공간의 우연 기대율 | **0.4695%** |
| 우연모델 단측 p — 참고 | 0.0068920 |
| 기준선 최악 적중 겹침 단측 p — 참고 | 1.0 |
| 예측 없음 | 0척 |

선박별로 해당 선박의 **모든 사고시각 중 최소 오차**를 사용했다. 제공 정답은 100사건/82척, 다중사고 선박은 11척이고 첫 사건을 넘는 초과 사건이 18건이다. 사건별 100행을 선박 분모에 섞지 않았다.

**기각 이유는 p값이 아니라 적중 수가 3척에 머문 것이다.** 새 우연 기대는 넘었지만 개선 후보 기준인 5척과 보류 기준인 4척을 충족하지 못했다. 기준선 3/82, Round018 3/82와 동일하다. Round018 중앙 오차 760시간보다 작아졌어도 이를 h 개선이라고 부르지 않는다.

## 후보 확장의 실제 효과와 한계

| 항목 | Round018 관측 후보 | Round020 전체 정수시간 후보 |
|---|---:|---:|
| 후보 합계 | 99,677 | 293,384 |
| 선박당 후보 중위수 | 910 | 4,120 |
| 각 선박에 사고 ±6h 후보가 존재 | 82/82 | 82/82 |

관측 없는 후보 **193,707시간**을 추가했지만, 실제 선택된 시각은 **82척 모두 관측이 있는 시각**이었다. 기존 최고점과 선택 시각이 달라진 선박은 **81척**이다. 선택은 크게 달라졌지만 맞힌 수가 늘지는 않았다. 미관측 시각 선택이 기술적으로 가능한지는 합성 검사에서 확인했으며, 이번 실자료에서 미관측 시각을 선택했다고 주장하지 않는다.

전체 후보 중 149,757시간은 ±6h 내 관측이 없어 근거 0이었다. 이 시간들을 정상 정답으로 취급하지 않았다. 새 우연모델은 이런 시간도 포함한 전체 후보에서 균등 선택하므로, 관측시간만 사용한 Round018의 우연 기대 2.2689%보다 낮다. **우연모델 p값이 작아진 것만으로 기존 규칙보다 좋아졌다고 결론낼 수 없다.** 이번 판정에서는 같은 82척의 실제 적중 수를 우선했다.

## 실행과 검증

- 2026 요약 3,887,065행/7,372척을 청크 검사하고 대상 82척의 99,677행만 유지했다. 원자료를 수정하지 않았다.
- 저장 모델 82개 모두 학습 ID가 정확히 다른 81척인지 확인했다. 기존 최고점의 시각·source_ordinal은 전부 일치했고, 최고 로짓 최대 절대차는 **0.0**이었다. 기존 선택기의 적중률을 다시 평가하지 않은 출처 검증이다.
- 새 후보 점수·예측 82개를 저장·해시 봉인한 다음 사고시각을 해석하여 한 번 평가했다. 16개 동결 입력·코드·프로토콜의 전후 해시가 일치했고 봉인한 예측·후보 점수·모델 재사용 기록도 확인했다.
- 합성 테스트 **12개 통과**. 독립 검토의 선택기·우연 기대·완화 판정 경계 검산도 통과했다. 합성 검증은 실제 사고 탐지 성능과 구분한다.
- 로딩 직전 RAM **4,553.2MiB**, 예측 직전 **4,425.1MiB**로 예상 768MiB+여유 640MiB를 충족했다. 실행 최대 프로세스 RAM은 **181.75MiB**, 실행 구간은 **10.32초**였다. 한 프로세스·한 BLAS 스레드로 처리했다.

2025 Test B·F:·외부 자료·새 선박 재식별/ID 연결은 사용하지 않았다. 별도 Round019의 선박 판별 결과를 결합하지 않았다. 이번 h는 제공된 2026 잠정 연결 선박에 조건부인 내부 시각 지표이며, 미사고 선박 오탐을 포함한 공식 F1이 아니다. 반복 개발자료와 중첩 LOOV 모형의 p값은 독립 확증이 아니다. 전체 관측기간을 사용하는 사후 분석이며 실시간 탐지·실제 장치 성능을 검증하지 않았다.
