## 후보·점수·동점

선박별 원본 행을 ts, source_ordinal 순으로 정렬한다. 같은 정수시간 t에 여러 행이 있으면 `eta(t)=max(row_eta)`로 하나의 시간별 로짓을 얻는다. 중복 행을 여러 번 가중하지 않는다.

후보 C는 해당 선박의 최초 관측시간부터 최종 관측시간까지의 **모든 정수시간**이다. 관측이 없는 내부 시간도 포함하며, 관측 전후로 외삽하지 않는다. 이는 본 실험의 내부 범위이며 주최 측이 정한 제출 범위라고 설명하지 않는다. 후보 범위는 정답을 보고 자르지 않는다.

시간별 근거 가중치는 `w(t)=exp(eta(t)-max(eta))`, 총합은 `Z=sum_t w(t)`다. 후보 c의 점수는 다음과 같다.

`S(c) = sum_{observed t: abs(t-c)<=6} w(t) / Z`

각 합은 관측시간 오름차순 `math.fsum`으로 계산한다. 분자는 고유 정수시간 최대 13개만 포함한다. 누적합의 차감으로 동점이 흔들리지 않게 한다. 온도 매개변수·시간별 가중·보간 좌표·가상 관측행을 도입하지 않는다.

S는 **상대 모델 근거의 비중**이며 보정된 사고 확률이 아니다. 관측이 없는 후보도 주변 관측의 근거로 점수를 얻을 수 있다. ±6h 내 관측이 전혀 없는 깊은 공백은 S=0이고 이는 **주변 근거 없음**이지 정상 판정이 아니다. 후보마다 `observed_at_center`와 주변 고유 관측시간 수를 기록한다. 무관측 후보에 실제 GPS·속력·항적을 생성하지 않는다.

최대 S와 정확히 같은 후보들을 시간순으로 정렬하여 아래쪽 중앙 원소 `(len(maximizers)-1)//2`를 선택한다. 떨어진 여러 최대 구간이 있어도 실제 최대점 후보 중 하나를 고른다. 반올림·동점 허용 오차·source_ordinal 우선·결과 후 임의 선택은 사용하지 않는다. 정답을 보지 않고 모든 82척의 새 예측과 후보 점수를 저장하고 예측 파일을 해시로 봉인한 뒤 평가한다.

원본 기하·시간·순번의 형식이나 유한성·비음수 조건 위반은 조용히 삭제하지 않고 실행 무효로 처리한다. 관측이 전혀 없는 대상은 예측 없음, 오차 무한대, 적중 실패로 남기며 분모는 82다. 이러한 결측과 정상은 구분한다.

## 한 번의 평가와 판정

- 주 지표 H/82: 선택 시각과 해당 선박의 제공된 모든 acc_ts 중 최소 절대 오차가 6시간 이하면 적중이다. 사건별 100행은 별도 보조표이며 선박 분모와 혼합하지 않는다. 선박별 오차 중앙값, 신규 미관측시각 선택 수, 선택 시각 변경 수, 후보 수, 근거 시간 수를 함께 기록한다.
- 우연 모델은 **이번 전체 정수시간 후보 C에서 균등하게 한 시간을 고르는 선택기**다. q_i는 C와 모든 사고 ±6h 창 합집합의 교집합 시간 수/|C|다. 분모에 관측 없는 후보도 포함하고, 후보 없음은 q_i=0이다. 기대 적중 수=sum(q_i), 기대율=mean(q_i), Poisson-binomial 정확 동적계획의 H 이상 단측 꼬리확률을 기록한다. 기존 관측시간 기준 2.2689%를 새 후보 공간에 그대로 적용하지 않는다.
- 기준선은 사용자 제공 3/82다. 적중 교집합 k의 모든 가능한 값 `max(0,H+3-82)..min(3,H)`에 대해 gains=H-k, losses=3-k로 단측 Binomial(gains+losses,0.5)의 gains 이상 꼬리확률을 계산하고 가장 큰 값을 쓴다. 불일치 쌍이 없으면 p=1이다.
- **완화한 개발 판정:** 계약·모형 출처·무결성 검사를 통과한 실행에 한해, **H≥5이고 H/82가 새 후보 우연 기대율보다 엄격히 높으면 개선 후보**, **H=4이고 우연 기대율보다 높으면 보류**, **H≤3이거나 우연 기대율 이하이면 기각**이다. H=5는 6.0976%이며 기존보다 2척 이상 증가하는 실용적 기준이다. p값은 두 종류 모두 보고하되 판정 관문에서 제외한다. 이는 사용자의 평가 전 지시에 따른 변경이며 결과를 보고 완화한 것이 아니다.
- **개선 후보는 확정 채택·통계적으로 유의한 개선·운영 배포를 뜻하지 않는다.** 기각과 보류도 실제 적중 수·우연 기대·p값을 함께 공개한다. 계약/구현 실패는 별도 **무효**다. ±6h 허용 오차, 분모, 정답, 점수 규칙, 동점, 재평가 금지, 메모리 및 누수 검증은 완화하지 않는다. 중앙 오차 감소·우연 기대 감소·미관측 후보 증가를 h 개선으로 바꾸어 보고하지 않는다.

반복 사용한 잠정 연결 개발자료이며 저장 LOOV 학습 분할도 중첩된다. p값은 독립 선박 가정하의 개발셋 내 명목적 선별 기준이고 독립 확증이 아니다. Round018 자체가 ±6h 사고창 라벨을 학습했으므로 다시 ±6h 주변을 합산하는 S를 잠재 사고시각 분포의 최적 확률로 설명하지 않는다. 근거 합산은 관측밀도에 민감하고, 단일 최고점의 문제를 해결할지는 미검증이다. 기존 82척 모두 관측시간 안에도 사고 ±6h 후보가 있었으므로 후보 확장 자체가 성공 근거는 아니다.

## 메모리·산출물·검증

새 `execution_001`을 독점 생성한다. 다른 라운드와 기존 실행 산출물을 수정하지 않는다. 자료 읽기는 32,768행 청크, 대상 자료 유지 상한 128MiB이며 전체 선단을 합쳐 올리지 않는다. 한 프로세스·한 BLAS 스레드, 기존 모델만 재사용하며 후보 점수는 순차 출력한다.

시작·로딩·예측 단계에 현재 RAM과 다른 실행 프로세스를 함께 기록한다. 예상 최대 768MiB+여유 640MiB가 확보되지 않으면 해당 단계를 보류한다. 추정은 Round018 실측 약 209MiB, 작은 저장 모형, 최대 82×4,344시간 후보와 스트리밍 출력을 근거로 넉넉히 잡은 값이다. 다른 Python 작업도 OS 가용 RAM과 프로세스 기록에 반영한다. 메모리 polling이나 사용자 프로세스 종료는 하지 않는다.

입장 게이트는 실행 폴더 생성 전에 확인한다. 폴더 생성 후 보류/오류는 기록을 남기고 멈추며 덮어쓰는 자동 재개를 하지 않는다. 모델을 다시 학습하는 실패 우회도 없다. 보류는 평가 완료가 아니다.

산출물: 사전 규칙, 평가 코드와 합성 테스트, 동결 해시, 후보별 추정 점수, 시간별 원 모델 근거, 원 모델 재현 검증, 새 예측과 봉인, 선박별·사건별 CSV, summary.json, RAM·무결성 기록, Round020 보고서와 독립 검토 기록.

기술 목표는 모형을 고정한 채 시각 선택 단계의 변경만 재현·검증하는 것이다. 학습 목표는 관측과 추정, 점수와 확률, 최고 단일 시각과 허용 오차 구간, 내부 h와 공식 F1의 차이를 설명하는 것이다. 설명 질문: 관측 없는 시각에 점수를 주는 근거는 무엇인가? 근거 없는 공백을 왜 정상이라고 부를 수 없는가? 후보가 늘면 왜 우연 기대도 다시 정의해야 하는가?
