## 독립 실행 증거 — 합성 검사만 수행

1. `python testB/final/round_020_missing_hour_time_20261106/test_evaluate.py`를 독립 실행했다. **12개 테스트 통과**, 테스트 자체 시간 0.182초, exit code 0. 미관측 중심·떨어진 최대점 동점·중복시간·음수 로짓·지수 underflow·다중사고 합집합·H3/4/5·정확 우연 기대 경계·학습 제외/원래 최고점 재현 실패·봉인 선행·메모리 보류를 확인했다.
2. 최종 소스에 대해 별도 직접 계산 oracle을 실행했다(seed 20261106). **선택기 600사례**, **전체 격자 사고창 합집합/우연 기대 600사례**, **H=0..82의 판정 경계 415사례**가 모두 일치했다. 선택기는 각 후보를 직접 순회하는 ±6h `math.fsum` 및 실제 최대점 중앙 선택과 비교했다. 판정은 우연 기대 미만·같음·초과와 H3/4/5를 포함했다. 이 oracle은 표준 라이브러리만 사용했다.
3. 실제 parquet·모델 출력 본문·정답 본문을 읽거나 실제 평가를 실행하지 않았다. `--selftest`, `--freeze`, `--run`도 이 검토자가 호출하지 않았다. 테스트의 임시 합성 파일을 제외하면 이 검토 파일만 새로 작성했다.
