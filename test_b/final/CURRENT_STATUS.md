# Test B 현재 결과와 검토 패킷

## 2026-11-06 인계 후 Round013 설계

[Round013 설계](round_013_20261106/PROTOCOL.md)와 [인계 판단](round_013_20261106/HANDOFF_REVIEW.md), [설계 단계 보고서](round_013_20261106/ROUND013_상세보고서.md)를 작성했다. 전체 학습 가능 항적의 어업별 기준 → 사고 전후 연속 관측 → 시간별 경로량 급감이라는 단일 가설 → 고정 분모의 적중/오차/커버리지 비교 순서다. 새 학습·예측은 아직 실행하지 않았다.

사용자 최신 채점 설명을 반영한다. RFID와 사고시각이 평가 대상이며 6시간까지 시간오차를 고려한 F1이다. 보조 시각/점수만 기재한 것은 FP가 아니고 미사고 선박에 사고시각을 기재하면 FP다. 아래 과거 문서의 보조 시각 역할 미응답 상태는 이 설명으로 일부 해소됐다. 정확한 가중식과 확정 사고/미사고 정답의 미확인은 별도로 남는다.

이하 회차12까지의 결과와 실패 판정은 역사적 기록으로 보존한다. 연속 오차를 새로 보더라도 과거 실패를 성공으로 바꾸지 않는다.

**현재 목표는 미달이다. 제출 가능한 성능 개선안을 확보하지 못했다.** 고정한 내부 주관문을 통과한 변경안은 없다. 새 Test B 추론이나 외부 제출은 하지 않았다.2026-11-06 회차12까지의 원본·실패 결과·실행 코드·독립 검토를 보존했다.

[기준선 검토 패킷](round_012_20261106/review_packet_001/README.md)은 저장된 Test B 기준선의 변경 없는 사본과 현재 개발 B0의 평가를 한곳에 연결한다. 개선된 제출본이나 공식 적합성 확인본이 아니다. [총괄 결정](round_012_20261106/FINAL_DECISION.md)에 후속 판단과 필요한 정보를 기록했다.

## 성능 평가 결과

개발 비교는 잠정82RFID/100사건,주평가는Tier01 55RFID/60사건이다. 내부 적중은±6h 포함 top1이며,회차 안에서는 같은 후보 cap을 썼다. 아래 변경안은 각 회차 사전 비교의 대표 결과이며 회차별 풀·가용성 차이가 있다.

R3·R7은 기초 행동/부분선 관찰,R10은 거리 대리값 가용성,R12는 저장 결과 진단이다. 이들의 기술 검증을 적중 개선으로 세지 않았다. 여러 저장 목록의 사후 적중 합집합도 실행 가능한 예측기로 부르지 않았다.

## 제출 검토에서 확인한 것

저장 Test B 기준선은100척·시간점수46,705행이고,주 후보100개·존재하는 직전3/2/1시간 참조가 원 점수와 일치했다. 제공 양식과ID 집합·순서도 같다. 단 보조 시각칸은33/38/58척만 채워져 있고,기존CSV의시각3헤더와 제공XLSX의빈H1은 다르다. 공식 결측·시간 형식·추가 시각 의미가 확인돼야 한다. 원본 파일은 바꾸지 않았다.

저장 Test B 시간범위는2025-01-01~2025-06-30이다. 내부 개발 사고표는2026년이므로3/100·2/60을 Test B100척의 실제 적중률로 옮기지 않는다. 공지의 사고 전후 정확성·조기 탐지와 내부 사후±6h근접성도 동일하다고 확정하지 않는다. 원문 셀·문구 근거는[RULES_EVIDENCE](round_011_20261106/RULES_EVIDENCE.md),해석 정정은[근거 조정](round_011_20261106/FINAL_EVIDENCE_RECONCILIATION.md)에 있다.

## 다음 판단에 필요한 정보와 실행 상태

비동기로 요청한 두 정보는 아직 미응답이다.

1. 시각1~3의 역할,공식 채점식·허용창·조기탐지/결측·시간 형식·대상 기간의 주최자 원문 경로.
2. 실제 사고 선박과RFID를 연결한 확정 대조표의 존재·경로.

두 중간관리자의 반박 검토 결과,현재 사후 적중 집합만으로 새 통합의 분기 우선순위를 정할 독립 근거가 없다. root는 임의 통합이나 이미 중단한 조건 재탐색을 새 성능 실험으로 선정하지 않았다. 이는 모든 내부 proxy 작업의 금지나 코어 전체 불가능 판정은 아니다. 현재 **실행 중인 성능 실험은 없고 목표도 완료로 표시하지 않았다.** 새 규격·확정 대조/독립 관측 근거가 오면 원본을 보존하는 새 버전 계약부터 이어간다. 단순히 기존 라벨을 덮어쓰거나 과거 실패를 사후 성공으로 바꾸지 않는다.
