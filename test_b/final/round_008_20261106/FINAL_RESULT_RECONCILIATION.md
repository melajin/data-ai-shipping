# 총책임자: 경쟁 결과 검토의 채택과 정정

Terra(msg_be8bc5c20b09, RESULT_REVIEW_TERRA.md)와 Sonnet(msg_d891d7914a69, RESULT_REVIEW_SONNET.md)이 실제 적중·후보·표본 선박 순위를 독립 대조했다. 실패 판정은 일치하며 G를 채택하지 않는다. Terra는 정확한 small-small-non-small 순서와 과거 전이율의 어업 상대 비교, Sonnet은 R6의 run 종료 시점에 run 길이 희귀도를 재적용하자고 제안했다. 서로 다른 실험이며 섞지 않는다.

총책임자는 다음에 Terra의 **정확한 3시간키 관측 순서**를 채택한다. 이는 코어의 ‘작은 경로량이 이어진 뒤 조건이 다시 바뀌는 과정’을 직접 다룬다. Sonnet의 run 종료 시각 재활용은 I/O가 적다는 장점이 있지만 right_confirmed만으로 시작이 확인된 run은 아니고 관측 길이가 하한인 구간이 섞인다. 완료 run 길이 분포와 비교하려면 검열 처리를 다시 설계해야 하며 이미 실패한 지속 길이 순위를 다시 적용하는 효과와 종료 시각 선택 효과가 섞인다. 다음 회차에 이를 추가하지 않는다.

Sonnet 원문은 보존하되 아래 해석은 채택하지 않는다.

- s3/s4 사건창에 후보가 없는19건이 모두 ‘자기 이력 부족’이거나 ‘그 RFID가 B0 fallback’하는 것은 아니다. Tier01은 s0 60→s1 50→s2 50→s3 41→s4 41이고, 사건창 후보의 부재와 선박 전체 기간 풀의 공백은 다르다. 실제 S 전체 fallback은2척, G는 그2척과 singleton의 S fallback이다.
- 동료 정보 때문에 Tier01이 S보다 나빠졌다는 부등식 0<0 또는2<2는 성립하지 않는다. Tier01 S/G는 동률이고 전체 top4에서만 G4가 S5보다 적다.
- 41사건에 strict 후보가 남았다는 사실로 ‘coverage 문제가 전혀 없는 순수 랭킹 실패’나 ‘사고와 음의 상관’을 확정하지 않는다. 후보 손실도 있고, 남은 사건에서 선택 실패도 있다. 상관 계수나 인과는 계산하지 않았다.
- R8은 non-small 형상 분기였으므로 R4/R6/R8이 모두 작은 run 내부만 다뤘다는 설명은 틀렸다. R6은 CDF 우선순위였으며 종료 시점 양꼬리 희귀도가 이미 동일하게 검증된 성공 기준은 아니다.

다음 Round9은 결과 독립적인 전체82척 관측에서 정확한 small-small-non-small 후보를 만들고 S는 기존 점수, G는 같은 어업 과거 전이율에 대한 자기 전이율 상대순위로 비교한다. 기간·100m·24참조/3일·5동료·적중 관문을 사후 조정하지 않는다. 후보가 없는 경우와 사건창에서 후보가 없는 경우를 구분해 기록한다. Round8 산출물과 두 검토 원문은 보존한다.
