# Round8 경쟁 검토 — 조건부 진행

**판정: 계약을 고정한 구현과 합성 검사에 진행할 수 있다. 실제 추출 및 채점은 계약에 명시된 총괄의 통합 확인과 자료 관문을 통과한 뒤 진행한다.** 현재 계약에서 실험을 막을 새로운 설계 결함은 발견하지 못했다. 이 검토는 정적 계약 검토이며 추출 코드의 완성, 실제 데이터의 적합성 또는 모델 성능을 검증하지 않았다.

## 실제 두 제안과 총괄 결정

- Sonnet 안의 부분선 내부 형상 활용은 행 전체 `bbox/len`이 가리지 못하는 구조를 관찰할 수 있다는 장점이 있다. 다만 사고 ±6시간으로 원행 추출과 후보 풀을 제한하면 평가 정답이 예측 후보 생성에 들어가므로 동등 예산의 사후 선택 성능으로 쓸 수 없다. 그런 선택은 R7처럼 평가 후 실패 사례 관찰에만 한정한다.
- 점 수 3개 이상이라는 조건은 고유 좌표 3개 이상을 보장하지 않는다. 기존 `parts.json` 101부분선 중 고유 좌표 3개 이상은 79개였고, 2점 11개를 포함한 나머지 22개는 해당 조건에 미달한다. 최소 D/L 부분선은 작은 부분선 하나의 영향을 크게 받을 수 있으며 R6 지속 점수 혼합은 이번 단일 형상 가설의 기여를 흐린다.
- 총괄이 확정한 전 82척·전체 관측시간 추출, 가장 긴 적격 부분선, 순수 형상 이력 비교를 지지한다. 가장 긴 부분선 선택은 사전 고정된 설계 가정이고 최적 통계 또는 실제 항해 상태의 판정은 아니다. 대안인 행 `bbox/len`은 추출 부담이 적지만 떨어진 부분선의 배치가 영향을 주므로 동일한 부분선 내부 형상이 아니다.
- G는 자기 희귀도가 같은 경우에만 peer 값으로 순서를 바꾼다. 동률이 드물면 어업 추가의 효과도 적을 수 있으므로 S와 G의 순위·선택 변경 수 및 peer 적격률을 보고한다. 결과를 본 뒤 우선순위나 집계 방식을 바꾸지 않는다.

## 코어 시작 점검 다섯 가지

1. **코어:** 같은 선박의 non-small 관측에 대해 부분선 내부 형상을 추출하고, 공통 유효성 → 형상 → 자기 과거 → 동일 어업 맥락의 순차 규칙과 후보 변화를 설명한다. 사고 인근 선택 품질도 고정 비교로 확인한다.
2. **범위 밖:** 선로 추종, 실제 속력·대기·정상 여부, 항만 및 어구 위치, 원인의 인과 판정, 새 학습과 외부 수집은 이 설계에서 도출하지 않는다. 부분선 분리를 실제 통신 공백으로 해석하지 않는다.
3. **목표·활동·검증:** 기술 목표는 원행 계보가 있는 형상 장부와 같은 예산의 B0/S/G 예측이고, 학습 목표는 행 전체 요약과 부분선 형상, 고유 좌표와 과거 기준의 차이를 설명하는 것이다. 단계별 유지·제외·유보 수, 풀 크기·fallback, 사건별 ±6시간 적중과 peer가 실제로 순위를 바꾼 수를 검증한다. 질문은 “이례적 형상이 무엇을 뜻하며 왜 곧바로 사고가 아닌가?”다.
4. **입력과 제한:** R4의 99,677개 시간 대표행과 ordinal, R3의 개발자료 어업 코드, 제공 1~6월 CSV·캐시가 입력이다. 경위도 순서는 알려져 있지만 정확한 CRS, 점별 시각, 정상 행동 정답과 확정 사고 선박 신원은 미확인이다. 사고 기준의 B 사례는 정상 참조가 아니다.
5. **다음 관문:** 결과를 읽기 전에 원행 키·캐시 검증, 행 보존, 단계 포함과 엄격한 과거 사용을 확인한다. 그 뒤 G 대 B0 Tier01 top1의 절대 +5%p 이상, 선박 paired bootstrap 95% 하한 >0, 전체 100건 비악화, 같은 Tier01 G 실제 풀 무작위 기대 초과를 모두 요구한다. 실패하면 문턱·집계 통계를 결과에 맞춰 바꾸지 않고 후보 손실과 실패 관측을 해석한다.

## 계보·후보 풀·평가 보호 조건

- **원행 계보:** 6개 캐시 메타데이터 행 수와 ordinal 월 경계를 고정하고 모든 대상에서 raw RFID·날짜·시간과 원행 계보 및 캐시의 점 수·길이·bbox·중심값을 대조한다. 1·5·6월만 R7에 기록된 기존 전체 해시와 비교하며, 2~4월 해시는 이번 관측값으로만 기록한다. 키·캐시 불일치와 파싱 실패는 조용히 제외하지 않고 진단 보존 후 채점 출고를 중단한다. 형상 계산이 불가능하지만 입력 자체가 검증된 행은 이유와 함께 99,677행에 보존한다.
- **유효 형상:** 모든 좌표 유한, 고유 좌표 3개 이상, 부분선 내부 양의 길이 및 유한 D/L 범위 검사를 통과한 부분선 중 최대 길이 하나를 선택하고 동률은 원 part index가 작은 것을 쓴다. 오차 허용 후 범위로 제한한다. 부분선 사이 길이·변위를 연결하지 않으며 위치/형상의 관측값을 실제 운동량이나 원인으로 바꾸지 않는다.
- **시간과 사건 격리:** 대상 추출은 전체 관측 ordinal로 고정하고 사고 시각·좌표·결과를 참조하지 않는다. 현재 t와 각 peer의 기준 모두 `[t-720,t)`의 유효 s2 관측만 사용하며 24행·3일과 다른 단일 어업 선박 5척을 동일 t에서 확인한다. 입력의 시각은 정수 epoch-hour로 명시하며 1시간 전체 형상에 의존하는 사후 선택과 실시간 경보를 구분한다. 예측·풀은 사건 라벨을 읽기 전에 저장한다.
- **같은 예산:** B0=s0, S=s3 또는 s0, G=s4 또는 S의 실제 풀이다. G 실제 풀의 행 수로 `min(4,n)`을 정해 세 방법에 똑같이 적용하고, 예측이 없는 사건을 전체 분모의 miss로 보존한다. 동일 RFID는 사건마다 같은 예측 목록을 사용한다. 무작위 기대는 각 방법·코호트의 실제 풀과 cap으로 따로 계산하고 Tier01 G는 Tier01 G 무작위 기대와 비교한다.
- **검산과 불확실성:** 합성 검사에는 중복 좌표, 0길이, 폐곡선, 부분선 동률, 월 경계, 키 불일치, 미래행 추가 불변성과 fallback을 포함한다. 장부에는 원행·상태·미충족 사유를 남긴다. 이번 개발셋은 반복 사용됐고 사고 연결은 잠정적이므로 관문을 충족하더라도 독립 일반화나 실제 위양성률을 입증하지 않는다.
