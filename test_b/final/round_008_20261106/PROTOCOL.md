# Round8 — 부분선 내부 공간형상의 과거 비교

## 시작 전 코어 점검

1. 어업 큰 유형을 유지하고 ‘작은 경로량’ 분기에서 놓친 공간형상으로 돌아온다. 공통 유효성→non-small→부분선 형상→자기 과거→어업 추가의 판정 규칙을 순차 적용한다. 입력 특징 제거 실험이 아니다.
2. 선로추종, 항만 구분, 실제 대기·속력, 조업상태 분류는 이번에 구현하지 않는다. 원자료 추출은 코어 구현을 위한 준비이며 추출량 증가 자체는 적중률 진척이 아니다.
3. 기술 목표는 제공82척 전체99,677시간행에 대한 결과 비의존 부분선 요약과 단일 B0/S/G 비교다. 학습 목표는 행 집계와 부분선 내부 형상, 고유 좌표, 과거 참조와 사건시각 누수를 구분하는 것이다. 산출물은 형상장부·순차상태·예측·풀·사건지표·자원기록이다. 관찰은 유효성/후보 감소와 어업 추가의 영향이다. 검증은 원키/캐시 대조, 엄격한 과거, 동일 예산과 분모, 미래추가 불변성이다. 질문은 ‘형상 이례성이 기존 점수보다 사고시각 선택에 도움이 되는가?’다.
4. 원자료 CSV1~6월, 월별 캐시와 ordinal 공식, R4 숫자장부, R3 어업등록이 확인됐다. 월2~4 원파일의 독립 예상hash는 이번에 새로 기록하는 관측값이며 과거hash 일치라고 부르지 않는다. 실제 사고신원·정상/행동정답·점별시각·정확CRS는 없다.
5. 자료관문: 라벨을 읽기 전 전체 선택 원키/캐시 일치, 정보부족과 파싱실패의 명시, 99,677행 보존, 코드의 순차상태 포함관계와 미래참조 금지. 결과관문: G-B0 Tier01 top1>=.05, paired RFID bootstrap95%하한>0, 전체100 비악화, Tier01 G 실제풀 random 기대보다 관측적중률 높음. 전부 충족해야 탐색적 개선이다. 미통과 시 임계/부분선 집계 통계를 사후 교체하지 않는다.

## 근거와 범위

R7 실제22행101부분선에서 행 bbox/len과 부분선 내부 직선성이 다르다는 증거를 얻었다. 79부분선만 고유 좌표3개 이상이므로 n_points>=3만으로 채택하지 않는다. R5 비소형 손실28건은 가설 동기일 뿐 이번 후보선택은 사건시각과 무관한 전82척/전체기간이다. 가장 긴 적격 부분선을 선택해 작은 부분선 하나가 행을 지배하는 것을 피한다. 이는 설계가정이지 검증된 최적 통계가 아니다.

과거720시간·24행/3일·5동료 조건은 앞선 회차의 해상도/다양성 가정을 유지한다. 새모델/복잡특징/기간스윕/외부수집/제출변경은 없다. 이번은 반복dev 탐색이고 1시간 전체 기하를 사용하므로 실시간 선행탐지로 표현하지 않는다.

먼저 extractor 구현과 경쟁검토만 위임한다. 중간관리자 논점 대조와 총책임자 계약 확정 전 실제 대량추출·점수계산을 시작하지 않는다. RAM은 실행 직전에 새로 확인한다.
