# Test B 기준선 검토 패킷

**성능이 개선된 제출본이 아니다.** 기존 파일의 재현·형식 검토용 사본이다. 새 추론·새 XLSX 작성·외부 제출은 하지 않았다. 모든 원본은 보존했고 사본의 바이트 hash를 대조했다.

## 바로 확인할 내용

- [저장 기준선 CSV](testB_existing_baseline_UNVERIFIED.csv): 기존100척의 주 후보와 직전 참조 점수. 개선안이나 사고 정답이 아니다.
- [검증 기록](VERIFICATION.json):100개 주 후보 최고점·원행 대조,존재하는 직전3/2/1시간 참조 대조,원본 hash·ID·빈칸 수.
- [개발 B0 사건 결과](development_B0_event_results_100events.csv): 전체100사건·Tier01 60사건의 저장 평가. Test B100척의 공식 성능과 별개다.
- [패킷 manifest](PACKAGE_MANIFEST.json): 사본과 문서의 hash/크기.

## 확인한 것

기존 시간점수46,705행·100척에서 주 후보100개가 원 점수 최대값과 일치했다. 동률은 기존 구현의 원 ordinal 순서를 따랐다. 각 주 후보가 원 관측에 있고6자리 반올림 점수가 일치했다. 별도 candidate lineage의 원 ordinal도 일치했다. 보조 칸은 실제 관측된 주 시각−3,−2,−1시간을 기존 구현처럼 담았는지 대조했다. 이는 **기존 프로그램 동작의 재현 검증**이며 그 배치가 공식 필수 규칙이라는 검증은 아니다.

제공 양식100개 ID의 집합·순서와 저장 CSV가 일치했다. 제공 XLSX는 읽기 전용으로 XML을 확인하고 원 바이트 사본만 보관했다. 양식 재작성·재계산·스타일 변경·export는 하지 않았다.

## 미확인 사항

| 항목 | 현재 상태 |
|---|---|
| 보조 시각1/2/3 채움 | 각각33/38/58척. 나머지는 원본처럼 빈칸 |
| 헤더 동일성 | 기존CSV H열은 시각3,제공XLSX H1은 빈 헤더 |
| 시간 문자열 규칙 | 기존 구현은 시를0붙임 없이 표기. 공식 필수 문자열 형식 미확인 |
| 네 시간 칸의 역할 | 독립 후보인지 직전 참조인지 공식 확인 필요 |
| 결측 칸 허용 | 공식 확인 필요 |
| 공식 계산식·허용창·조기탐지 처리 | 미확인 |
| 실제 Test B 사고-RFID/시각 정답 | 미확인,공식 성능 미계산 |

저장 Test B 관측은2025-01-01 0시~2025-06-30 23시다. 이 범위는 저장 파일의 값이며 공식 대상 기간을 확정하는 규칙이 아니다. 개발 비교는2026년 사고표와 잠정82개RFID/100사건이고 B0 top1은전체3/100·Tier01 2/60이다. 이 수치를2025 Test B100척의 실제 적중률로 옮기지 않는다.0~1 점수는 기존 비지도 이상 통계이며 사고 확률로 보정됐다는 뜻이 아니다.

## 사본과 재현

`testB_existing_hourly_scores.parquet`와`testB_existing_candidate_lineage.csv`는 기존 점수/원행 사본이다. `submission_template_UNCHANGED_REFERENCE.xlsx`는 제공 양식의 변경 없는 사본이다. `baseline_storage_checks.csv`는100척별 대조 결과다. 개발 예측과 사건 결과는 서로 별도 파일로 두었다.

검증 코드는[prepare_review_packet.py](../prepare_review_packet.py)에 있다. 이 코드는 새 폴더를 요구하므로 현재 패킷을 덮어쓰지 않는다. 기존 산출물 검증만 하며 old 모델 추론을 재실행하지 않는다. 원 추론 구현은`testB/과거/first_results/run.py`,원 점수/참조 데이터는같은 폴더에 남아 있다. 제공 양식 원본은`testB/과거/intake/1103_v2/inspection_001/reference_02_제출샘플.xlsx`다. 정확한 절대 경로와 원본 hash는VERIFICATION에 기록했다.

전체 실험 경과는[현재 판단과 회차 색인](../../CURRENT_STATUS.md),추가 정보와 다음 판단은[총괄 결정](../FINAL_DECISION.md)을 따른다. 목표인 제출 가능한 개선안은 아직 확보하지 못했다.
