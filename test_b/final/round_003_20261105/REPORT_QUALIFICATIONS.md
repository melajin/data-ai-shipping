# 총괄 보충 — 관측 통계와 행동 해석의 경계

원 report.md와 표는 보존한다. 어업 코드 연결과 수치 요약은 후속 검토 대상으로 활용하되 아래 해석은 제한한다.

- 82개 RFID가 Train fishing_code의 단일 문자열로 연결됐다는 결과는 사용 가능하다. 연안복합37, 자망31, 통발13, 채낚기연승낚시1이다. 이는 사고와 잠정 연결된 개발집합의 구성이지 전체 어업 모집단 표본이 아니다.
- ‘채낚기연승낚시’는 원래 코드 문자열을 유지한다. 1척의52/60개 연속 시간키에서 작은 경로량이 관측됐다는 사실로 정상 집어·표류 조업을 확정하거나 해당 어업의72h 이상 규칙을 만들 수 없다.
- len<=100,bbox<=100은 설계상 작은 경로량 조건이다. run길이는 조건을 충족한 연속 관측 시간버킷 수이며 실제 연속 정지·대기시간이 아니다. 시간키 간 공백은 별도로 끊는다. ‘이후 조건 이탈’도 자력 출항·수리·조업재개를 뜻하지 않는다.
- report의 ‘시간당 이동거리’는 시간버킷 안의 관측 부분선 경로량 요약으로 읽는다. 점별 시각이나 완전한 경로 관측이 없어 실제 속력으로 바꾸지 않는다. 연안복합을 자동으로소형선,통발을외해작업선으로확정하지않는다.
- 반복셀은항만·정박지·어장·어구위치의정답이아니다.반복셀전체를정상으로제외하면사고를놓칠수있다.
- 표의선박별비율평균42.57%,중앙값40.39%,전체행비율42.38%는서로다른통계다.‘전체관측42.6%’로혼용하지않는다.
- 실행의tracemalloc46.33MiB는Python추적메모리다.RSS증가280.34MiB와종료시RSS366.14MiB도전프로세스최대메모리의직접실측값은아니다.최대메모리46MiB로과장하지않는다.가용RAM확인과512MiB추정의충분성은영수증을따른다.
- report의Stage4-A/B/C/D 어업별설명·72h같은규칙은검증된기준이아니다.다음실험에자동채택하지않는다.정상/대기정답이없어위양성배제능력은입증되지않았다.

다음 설계는 실제 관측할 수 있는 작은 경로량의 전후 순서·그 배의 과거 빈도·어업그룹 차이를 기록하는 공통/추가 규칙 장부로 한정한다. 관측하지 못하는 선로 추종·부분선 직선성·항만 여부는 유보 열로 남긴다. 사고 시각 적중률은 규칙별 후보 변화와 함께 별도로 평가한다.
