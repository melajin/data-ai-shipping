# Round3 — 어업 그룹과 행동 관찰의 연결

## 라운드 시작 코어 점검

1. 코어 관계: 어업 유형별 전체 항적 특성을 먼저 살피고, 작은 경로량의 연속·이후 관측 변화·반복 위치·공백을 항목별로 구분할 수 있는지 확인한다. 향후 공통 규칙과 어업별 추가 조건을 차례로 적용할 기반이다.
2. 다른 문제: 사고 시각 최고점 최적화나 새 모델 학습은 이 회차의 작업이 아니다. Round2 오류 수정과 별도로 진행한다.
3. 기술 목표: 실제 Train fishing_code와82RFID 관측의 연결·유일성 및 유형별 관찰 요약을 만들기. 학습 목표: 어업 유형과 시각별 행동 상태를 구별하고, 작은 항적을 대기/사고로 단정하지 않기. 산출물은gear_registry,행동항목정의,선박별/그룹별요약,작은고정사례,순차규칙장부설계다.
4. 확인된 입력: Round008의99,677대표시간행과원래remeasure Train캐시6개. 캐시에fishing_code가있다는선행코드는확인했지만실제82RFID의단일어업라벨보유여부는이번회차에서직접확인한다.독립항만경계·실제행동상태정답·점별시각은미확인이다.
5. 다음 관문: 실제라벨연결,어업별표본수와불확실성,관찰항목의입력가용성,공통/어업별추가조건의구분,대기·공백오인방지와후보장부설명이가능해야새순차규칙실험을고정한다.

## 고정 범위

이분석은사고잠정연결된82RFID의개발관측집합이다.전체어업모집단의정상패턴이라고일반화하지않는다.사고표어업면허를선박라벨로복사하지않고Train캐시의실제fishing_code를읽는다.다중코드·결측은혼합/미확인으로보존한다.

관찰항목:len/bbox분포,관측시간수·날짜수·공백,연속1시간키에서작은경로량조건의run과그뒤조건변화,반복각도격자비율.작은경로량은len<=100m및bbox<=100m라는설계가정으로만정의하고실제정지로명명하지않는다.공백은run을끊는다.그룹요약은선박별통계를먼저만들어행수가많은배가그룹을독점하지않게한다.

geometry원문이나정확한부분선종점/방향이없으면선로추종·직선성을임의로계산하지않고입력부족표시한다.독립항만근거없으면반복방문셀로만표시한다.실제속력·가속도·예인·사고원인·어구위치추정없음.

규칙을차례로적용한다는사용자결정에따라다음실험을위한후보장부열을제안한다:단계,입력후보,관찰조건,유지/제외/유보,후보수변화,이유,대안설명,공통/어업별표시.아직검증되지않은어업별정상규칙을하드필터로적용하지않는다.

새학습·Test B추론·외부수집·제출파일변경없음.실행전RAM·예상피크·동시작업을기록하고부족하면스트리밍/순차또는보류한다.출력은이폴더에만저장한다.
