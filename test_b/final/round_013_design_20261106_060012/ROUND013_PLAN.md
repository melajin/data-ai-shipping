## 사고 여부·공란 처리 계약

입력 장부는 vessel_id, dataset_version, period_start/end, label_status(confirmed_positive/confirmed_negative/provisional/unknown), label_source, event_ids, coverage, split를 가진다. 시각·시간대는 명시하고 불명이면 불명으로 남긴다. 단순 사고표 미등재는 confirmed_negative가 아니다. 잠정 RFID 연결도 확정 양성으로 승격하지 않는다.

출력 내부 장부는 vessel_id, decision(accident/non_accident/abstain), score, score_semantics, predicted_time, missing_reason, evidence_version을 가진다. 보정 전 score는 사고 확률이 아니다. abstain과 non_accident를 내부에서 구분한다. 공식 제출에는 유보 표현이 확인되지 않았으므로 변환을 보류한다. 비사고로 판정하는 경우 관련 예측 칸 전체를 공란으로 내보내는 계약을 두되, 공식 열별 규격 확인 전 XLSX를 생성하지 않는다.

사고 여부 평가는 대표성 있는 확정 양성·음성과 관측 기간, 선박 분리 검증/보정 자료가 필요하다. 대상 사고 비율 또는 그 대표성을 뒷받침하는 근거 없이 운영 임계값을 교정하지 않는다. Test B 사고 수를 추정해 상위 k척만 강제 선택하지 않는다. 음성 확보 전에는 confusion matrix, precision, F1, 사고확률, 보정된 임계값을 NA로 기록한다.

확정 대조표가 오면 새 라벨 버전·중복 사건 처리·분모·기간 적합성을 감사한다. 과거 devset을 수정하지 않는다. 반복 사용한 100사건은 탐색 자료로만 쓰며 신규 가설의 독립 최종 검증 자료로 부르지 않는다. 새 독립 분할을 확보하지 못하면 성능 확정 관문은 닫지 않는다.

## 평가 계약과 진단

공식 규격이 오기 전 시간오차 가중 F1은 수식·숫자를 만들지 않고 슬롯으로 남긴다. 사고 여부 분류와 사고시각 국소화를 나눠 장부를 작성한다. 공식 수식 확보 후 TP/FP/FN 단위, 다중사고 매칭, 오차 감점, 조기/지연 대칭성, 정확히 6h 경계와 미예측 처리까지 고정한 새 계약에서만 계산한다.

지금 설계 가능한 저장 결과 진단은 다음과 같다.
1. 각 회차에서 자기 B0와 공통 사건을 짝짓고 전체 100/Tier01 60 원분모 및 누락 수를 보존한다. 풀·cap이 다르면 동일 조건 비교라고 표시하지 않는다.
2. abs_error 및 R5 abs_error_hours는 시간 단위다. /3600하지 않는다. 빈 predicted_times는 미예측이며 오차 0으로 대체하지 않는다.
3. 미예측률과 후보창 coverage를 먼저 보고, 유효 예측 조건부 오차 중앙값·분위수와 고정 원분모 창별 적중률을 함께 기록한다. ±720/72/24/6h는 해상도 진단이지 순차 승격·공식 점수·결과에 따른 승자 선택 기준이 아니다.
4. 누락 예측은 창별 적중 실패로 포함한다. 유효 예측에서만 오차를 비교하는 선택 편향을 명시한다. 정답 후보 순위는 전체 후보 점수가 없으면 산출 불가로 둔다.
5. 통계 검정은 사전 비교군·방향·결측 처리를 고정하고 RFID 단위 의존성을 반영한다. 다중 비교는 Holm 보정한다. 기존 사후 비교는 탐색으로 표시하고 p=0 대신 반복 수에 따른 Monte Carlo 보정값/해상도를 보고한다. 시기·coverage 차이를 무시한 사건 셔플을 인과적 신호 증명으로 쓰지 않는다.

검산 예제: 실제 양성 2척/음성 2척, 예측 양성 중 TP=1·FP=1, 나머지 FN=1·TN=1이면 이진 precision=recall=F1=0.5다. 이는 사고 여부 계산기의 합성 단위검사이며 공식 시간가중 F1 예제가 아니다. 시간 검산은 오차 6h, 6h 초과, 미예측을 구분한다. 시간대 불명·중복 ID·다중사건은 조용히 통과시키지 않는다.

## 급변 피처와 후속 범위

R13에서는 관측 가능성만 감사한다. gap/jump 기존 코드를 이름만 보고 재사용하지 않는다. 시간 구간 간 관측 누락은 측정 가능해도 사고나 정지의 정답이 아니다. 시간별 MultiLineString으로 점별 실제 속력·가속도·급정지를 계산하지 않는다. 부분선 단절을 연결하지 않는다. 급선회·표류 전환은 좌표계·순서·시간·정상 조업 반례가 확보될 때 정의한다. 최초/최종 관측의 검열과 전송 누락을 구분하며 미래 재등장을 사용한 gap은 온라인 조기 탐지로 부르지 않는다.

다음 성능 회차에서는 근거가 있는 급변 피처 하나만 사전 고정한다. hard 제외→soft 감점은 별도 대조 실험으로 분리하여 효과를 섞지 않는다. 학습·분석 가능 모집단은 전체 제공 자료 목록에서 정하되 82척으로 자동 제한하지 않고 최종 평가·선박/시간 누수 금지는 유지한다. 시각1~3은 정성 근거와 시계열 설명 산출물로 계획하며 네 번의 독립 채점 기회로 간주하지 않는다.

재탐색 금지: 기존 스태커/임계값/공간압축/월별 drift, 3성분 재가중, CDF 격자·꼬리·창 튜닝, 무효화된 ID 조인·재식별, 사후 top4/부분집단 주지표 변경. 신설 공란 임계값 연구는 과거 금지된 점수 튜닝의 우회가 아니며 새 라벨·검증 계약을 선행한다.
