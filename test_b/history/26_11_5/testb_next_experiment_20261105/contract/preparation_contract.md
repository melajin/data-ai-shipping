# Test B 실행 전 공통 준비 계약 v0.1

작성: 감독 세션, 2026-11-05 KST. 현재 허용 범위는 W1 연결근거 검토와 W2 시각추정 준비다. 실제자료 점수 적합·임계값 선택·사고 성능 평가는 감독의 후속 게이트 판정 뒤 별도 버전으로 고정한다.

## 목표와 불변 조건

전체 제공 항적에서 선박별 사고 여부와 시각 하나를 추정하고 독립 자료로 놓침·오탐·시각오차를 평가한다. 후보 매칭 수와 A/B/C 합의는 성능이 아니다. 단일 후보·안정 단일 E0023도 신원 정답이 아니다. 사고목록 부재·미연결을 정상으로 만들지 않는다.

2025 Test B 점수는 2026 사고 정답과 기간이 다르다. 2026 점수는 아직 생성됐다고 가정하지 않는다. 사고시각 근처만 잘라 예측하거나 연결 잔차를 탐지 오차로 쓰지 않는다.

## 입력 및 분할 manifest 준비

- 기존 감사 run_001 및 derived_001은 완료된 읽기전용 입력이다. 기존 manifest의 경로·해시를 계승하고 실제 사용하는 파일은 별도 사용 명부·전후 해시를 남긴다.
- 2026 사고 167건, 2026 rows_train_1..6 캐시, 2025 scored_rows.pkl 및 원 제출 CSV를 연도·목적별로 분리한다.
- W1은 사용한 사고/후보/원행/문서의 식별정보를 linkage_review/manifest.json에 기록한다.
- W2는 점수·참조자료·전처리의 적합 범위, 필수 열·단위·버전, 개발/평가 제외 규칙과 미확인점을 timing/input_split_manifest.json에 기록한다. 실제 분할은 아직 활성화하지 않는다.
- 후속 분할은 사건과 선박(반복 후보 관계 포함)의 중복을 차단해야 한다. 참조 적합·모델 선택·보정·최종 평가의 역할을 분리한다. 신원/개발사용/정상근거가 미확인인 현재는 train/dev/eval 배정을 fabricated하지 않고 pending으로 남긴다.

## 점수·시각 규칙

- A는 기존 점수의 최대점 시각이며 동점은 기존 입력의 최초 등장이다. 기존 A 재현은 완료이므로 전량 재검사를 반복하지 않는다.
- B는 A가 속한 동일 이상 구간의 첫 임계 초과 시각. C는 그 구간의 지속 근거 확인이며 통과하면 C=B이다. 독립 세 모델 투표가 아니다.
- 임계값 출처, 초과 경계, 구간/지속 간격·행수 조건은 아직 미정이다. 테스트 분위수로 정하지 않는다. 수치 파라미터를 받는 인터페이스와 합성 단위 검사는 준비 가능하나 실제자료 B/C 실행은 보류한다.
- 누락 시간과 NaN을 가로질러 구간을 연결하지 않는다. 시간대는 실제 점별 시각이 아니라 [시간대 시작, 다음 시간대 시작)이다. 시간대 표준은 자료의 같은 기준이라는 기존 가정으로 표시하고 확인 근거 없는 변환을 하지 않는다.
- 부분선을 임의 연결하지 않고 좌표별 시각 없는 실제 속력·가속도를 계산하지 않는다.
- 정상예측/사고예측/자료부족·계산불가/판정기준미확보를 구분한다. 판단기준 미확보나 C 실패를 정상 정답 또는 미사고 예측으로 바꾸지 않는다.
- 공식 F1 수식·6시간 경계 미확정. 내부 시간 지표와 공식 점수는 구분한다.

## 후속 결정 게이트

W1·W2를 받은 감독은 확정 평가 가능 / 연결 불확실성을 명시한 탐색 평가만 가능 / 아직 시각 비교 준비만 가능을 판정한다. 개발용 사용 근거·정상 정답·독립 분할·고정 예측·임계 출처를 항목별로 확인한다. 부족한 조건은 false 또는 unknown과 이유로 보존한다. 근거 부족이어도 사건별 검토표와 A/B/C 준비·계산불가표 및 쉬운 설명을 산출한다.
