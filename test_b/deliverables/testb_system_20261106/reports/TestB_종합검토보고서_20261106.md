# Test B 종합 검토 보고서

**대상:** 2026 데이터 분석 경진대회 목표 2, Test B 어선 이상항적 분석  
**작성일:** 2026년 11월 6일  
**문서 성격:** 내부 종합 평가와 다음 작업 결정을 위한 보고서. Test A 조업형태 분류는 포함하지 않는다.

## 핵심 판단

Test B용 기존 점수 계산과 제출 입력 재현은 기술적으로 확인했지만, **사고 시각을 찾아내는 성능은 입증하지 못했다.** 개발 사고자료에서 관찰한 평균적 항적 요약 차이는 탐색 근거로 보존한다. 해당 차이를 실제 사고의 원인 신호나 현장 탐지 성능으로 해석하지 않는다.

이번 검토에서 데이터와 결과에 대한 불만은 타당한 문제 제기로 확인됐다. 적용 항적에는 사고 정답이 없고, 개발 사고의 선박 연결은 잠정적이며, 시간·공간 정보는 실제 운항 상태를 직접 나타내지 않는다. 기존 `s_gap`은 1시간 관측 간격에도 높은 시간항을 주고, 이력 부족에 따라 종합점수에 들어가는 성분 수도 달라진다. 새 `lin_raw`의 평균 차이도 사고 시각 순위 개선으로 이어지지 않았다.

따라서 기존 점수와 `lin_raw`는 **후보 검토용 참고값**으로만 다룬다. 새 점수·모델을 계속 추가하기 전에 사고 정답의 신뢰도, 사고 주변 관측 가능성, 공식 채점 규칙을 먼저 확정해야 한다. 다음 성능 관문은 ±6시간 국소화를 사전 고정하고, 계산 불가·판단 유보·사고창 후보 없음도 전체 분모와 함께 드러내는 방식이어야 한다.

## 1. Test B에서 요구하는 것과 이번 검토 범위

보관된 과제 공지는 Test B의 시간대별 이상점수와 사고 전후 이상징후·조기 탐지를 요구한다. 확인한 공지와 포스터에서는 관제 화면 구현 의무를 찾지 못했다. 동일 선박의 앞뒤 전체 항적을 참고할 수 있다는 기록된 주최 측 답변은 사후 제출 분석의 허용 범위이며, 실제 당시 이용 가능했던 정보만 쓰는 온라인 경보 성능을 대신하지 않는다.

이번 보고서는 Test B의 제공 항적, 기존 점수 패키지, 개발 사고자료를 이용한 시간·위치·행동변화 실험, 최신 자료 신뢰도 감사를 함께 검토한다. 조업형태 분류 F1, 실제 선박 장치 실험, 온라인 경보 운영은 이 평가에 합산하지 않는다.

## 3. 제출용 점수 시스템에서 확인한 것

기존 고정 기준선을 분리된 실행 패키지에 복사하고 2025 Test B의 46,705행·100척을 재계산했다. 저장 결과와 비교했을 때 종합점수와 세 구성점수의 최대 절대차가 0이며, 결측 위치·상태·최고 후보 시각·원행번호의 불일치도 없었다. 이는 **계산 재현성**의 증거다. 새 기준자료 적합, 새 모델 학습, 공식 사고 정답 평가를 했다는 뜻은 아니다.

시스템은 세 구성점수를 계산 가능한 것끼리 평균해 종합점수를 만들고, 선박별 제공 기간에서 가장 큰 값을 후보로 고른다.

| 성분 | 계산 개요 | 값이 뜻하는 범위 |
|---|---|---|
| `s_zone` | 과거 방문 위치·학습 밀도 참조 | 위치가 과거 자료에서 얼마나 낯설거나 드문지 |
| `s_change` | 과거 길이·형상 요약 및 상태 빈도 변화 | 자기 이력과의 기하 요약 차이. 과거 이력 24행 전에는 계산되지 않음 |
| `s_gap` | 관측 시간간격과 시간행 중심점 거리의 참조 순위 평균 | 공백 길이와 중심점 간격의 대리 점수 |

점수가 높다는 것은 이 수식에서 상대적으로 큰 점수가 계산됐다는 뜻이다. 사고 확률, 사고 원인, 경보 신뢰도로 보정된 값이 아니다. `s_change`가 결측이면 두 성분 또는 한 성분만 평균에 들어갈 수 있어 후보마다 점수 구성도 달라진다.

| 재현·입력 계약 확인 | 결과 | 의미 |
|---|---:|---|
| 고정 기준선 재계산 | 100척·46,705행, 100개 후보 | 저장 점수와 종합·구성점수의 최대 절대차 0.0, 후보 시각·결측·행 계보 불일치 0 |
| 후보 분포 | 중앙값 0.548824 | 점수 분포의 요약이며 사고율·확률로 보정되지 않음 |
| 후보 시점 과거 이력 부족 | 39/100척이 과거 24행 미만 | 변화점수의 가용성에 영향을 줌 |
| 계산 실행 자원 | 33.38초, 최대 RSS 약 299 MiB | 저장된 기하 요약과 고정 참조로 재현한 실행 기록 |
| 시간순 입력 계약 예제 | 가공 9행: 수락 3, 중복 1, 격리 3, 유보 2 | 점수·경보는 생성하지 않은 입력 계약 재생 |
| 입력 계약 합성 검증 | 26개 통과 | 미래·역순·중복·가용시각 오류 처리 확인. 실제 항적·사고 성능 실험 아님 |

시간순 입력 계약 재생은 실제 수신 자료를 분석한 실험이 아니다. 실제 수신시각과 기준자료의 생성·가용시각이 확인될 때만 쓸 수 있도록 입력 조건을 확인했으며, 자동경보·점수 어댑터·외부 수신은 연결되지 않았다.

## 4. 기존 공백 점수와 자료 부족 문제

현행 식은 `s_gap = 0.5 × F_gap(시간간격) + 0.5 × F_jump(중심점거리)`다. 구현과 기준자료에서 연속 1시간 간격의 `F_gap` 값은 **0.8991**이며 `s_gap`에 약 **0.4496**을 더한다. 모든 연속 1시간 후보에서 이 시간항은 사실상 같은 값이므로, 그 후보들 사이의 `s_gap` 순위는 중심점 거리 항에 의해 결정된다. 따라서 이를 단순한 “신호 공백 점수”로 읽으면 실제 기능을 오해한다. 중심점 거리는 관측된 실제 항로 길이나 속력이 아니다.

최근 후보 감사에서 최고 후보의 `s_gap`가 가장 큰 성분이었던 88건은 연속 1시간 관측 사례 54건과 공백 종료 후 상승 사례 34건으로 나뉘었다. 이는 높은 점수가 반드시 장시간 공백을 의미하지 않음을 보여준다. 1시간 시간항을 다시 설계할 필요는 있지만, 새 산식은 사고 성능을 본 뒤 유리한 쪽으로 조정하지 말고 지표 정의·가용 자료·평가 기준을 먼저 고정한 후 비교해야 한다.

희소성 지표도 서로 다른 조건을 가리킨다.

| 조건 | 수치 | 정확한 의미 |
|---|---:|---|
| 전체 제공기간 관측이 24행 미만인 선박 | 25/100 | 선박 전체 이력이 매우 짧음 |
| 최고점 직전 과거 관측이 24행 미만인 후보 | 39/100 | 후보 시점까지 `s_change` 계산 이력이 부족함. 이 중 14척은 전체 자료는 24행 이상 |
| 직전 과거 행이 전혀 없는 최고 후보 | 6/100 | 과거 비교 근거가 없음 |
| 사고창 `n_rows≤4`인 Tier0–1 사례 | 12/60 | 사고 주변 관측창이 성기거나 불완전함. Round010의 주 매칭 평가에서는 3건이 포함되고 9건은 제외됨 |

전체 기간이 짧은 선박, 후보 시점까지의 이력이 짧은 선박, 사고 주변 관측창이 희소한 사건은 같은 문제가 아니다. 이들을 모두 잘라내면 평가 대상이 쉬운 사례로 바뀐다. 계산 불가와 판단 유보는 정상으로 간주하지 말고 분모와 함께 보고해야 한다.

Round010의 `top-1=0/48`은 사고시각 매칭 백분위 점수의 운용형 선택 결과다. 다른 후보 정의를 쓴 원 `lin_raw` 직접 argmin에는 별도 결과가 있으며 같은 분모로 합칠 수 없다. 또한 `top-10` 12.5%는 보고된 근사 우연값 12.3%보다 아주 조금 높다. 그러므로 정확한 표현은 “top-10은 대략 우연 수준이고, 더 큰 k에서 우연 기대보다 낮은 구간이 관찰됐다”이다.

이들 내부 사고창 실험은 승인된 ±6시간 기준에 따른 사후 국소화 평가다. 공식 채점식·허용 시간창·제출 양식의 보조 시각 열 의미가 확인되지 않아 공식 점수, F1, 조기 경보 시간, 실제 오경보율로 부르지 않는다.

## 6. 지금까지 확인한 것과 확인하지 못한 것

**확인한 내용**은 기존 점수 패키지가 저장된 Test B 점수를 전수 재현한다는 점, 일부 `lin_raw` 대조 비교에서 평균 백분위 차이가 관찰됐다는 점, 여러 사전 고정 개발 실험이 ±6시간 사고시각 국소화 개선 기준을 통과하지 못했다는 점, 그리고 후보·입력 가용성의 제한이 크다는 점이다.

**확인하지 못한 내용**은 해당 후보가 실제 사고였는지, 사고 직전 조기경보가 가능한지, 정상 운항 중 오경보가 얼마나 발생하는지, Test B 제공 입력에서 실제 사고 탐지율이 얼마인지, `lin_raw` 평균 차이가 독립 자료에서도 재현되는지다. 2026 기준자료로 2025 항적을 사후 재현한 결과는 당시의 실시간 예측이 아니다. 입력 계약을 검사한 합성 예제도 실제 사고 탐지 실험이 아니다.

이를 바탕으로 데이터와 결과에 대한 현재 판단은 “분석이 끝났으니 지표를 더 고르면 된다”가 아니다. **현재 근거는 제출에 필요한 구현 재현성은 충족하지만, 사고시각 특정의 실용성은 충족하지 못한다. 정답·관측 구조의 불확실성이 결과 해석을 제한한다.**

## 7. 다음 Test B 단계의 기준

다음 실험 전에 다음 계약을 먼저 고정한다.

1. **사고 정답과 공식 평가 규칙:** 확정 사고-RFID 대응, 사건시각의 기준, 공식 허용창과 점수식, 제출 열·결측 규칙을 문서로 확인한다. 기존 잠정 연결은 원본과 분리해 보존한다.
2. **사건별 관측 가능성:** 사고 ±6시간의 실제 유효 행 수, 시간 공백, 유효 창 여부, 평가 불가 사유를 기록한다. 사건별 필터로 어려운 사례를 사후 제외하지 않고 전체 사건 수와 유보 건수를 함께 표시한다.
3. **국소화 주평가:** 사고 ±6시간 내 top-1 적중을 개발·검증 계약의 주 관문으로 고정한다. 동일한 사건·후보집합의 선박별 무작위 선택과 고정 B0 기준선을 비교한다. top-k와 평균 백분위는 보조 지표로 분리한다.
4. **선택 편향 통제:** 같은 100건을 반복해 본 개발 결과는 탐색 결과로 기록한다. 그 자료에서 산식·창·가중치를 고른 뒤 같은 자료를 새 홀드아웃이라고 부르지 않는다. 선택이 끝난 뒤 미사용 자료에서 한 번 평가할 수 있도록 역할을 사전에 고정한다.
5. **점수 정의의 재검토:** 시간 공백, 중심점 거리, 행동변화 대리값을 분리해 명세한다. 1시간 정상 관측에서 시간항이 높은 값이 되는 이유, 초기 이력 부족 시 성분 수 변화, `n_rows≤4` 처리 방식을 결과를 보기 전에 명시한다. 계산 불가·판단 유보와 정상 점수를 구분한다.

국소화 적중률을 중심 관문으로 삼되, 커버리지와 판단 유보를 함께 제시해 어려운 사건을 제외하는 방식으로 수치만 높아지지 않게 한다. 공식 성능을 주장하려면 확정 정답과 독립 평가 자료가 필요하다. 새 점수를 추가하는 일은 그 두 조건을 충족하고도 정보가 남는지 확인한 뒤 판단한다.

## 8. 최종 보고 문구

> 기존 고정 기준선은 Test B 입력 100척·46,705행에 대해 저장 결과와 일치하게 재현되었다. 이는 소프트웨어 계산 재현성의 확인이다. 별도 개발 사고자료에서는 `lin_raw` 관련 평균 백분위 차이가 탐색적으로 관찰됐으나, 라운드 간 반복 선택은 보정되지 않았고 현재 점수의 사고시각 국소화 개선은 검증되지 않았다. 여러 사전 고정 내부 실험은 ±6시간 주관문을 통과하지 못했다. 사고 선박 연결, 시간대·자료 가용성, 희소 구간, 공식 평가식의 한계가 남아 있으므로 기존 점수와 `lin_raw`는 검토 후보를 고르는 참고값으로만 다룬다. 공식 사고 탐지 성능·온라인 경보·실제 오경보율은 미확인이다.
