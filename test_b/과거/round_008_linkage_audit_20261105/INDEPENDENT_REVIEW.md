위 표는 도구에 명시한 요청 모델·effort와 수신한 작업 결과다. 런타임 내부 모델 메타데이터를 별도 조회한 증거는 아니며 부모 세션 설정 변경을 뜻하지 않는다.

검토에서 발견한 빈 개발셋 스키마, 음성 풀 수 비교, 동률 증거행 결정성을 보완했다. 추가 채점은 원 S4의 행 필터·source ordinal·정렬·항구 검색·참조·밀도 자기 기여 차감/복원과 일치한다. 다중사건 합집합과 정확 Poisson-binomial 검산도 소스 검토에서 일관됨을 확인했다.

백분위 재측정의 무작위 평균은 빈 창을 제외한 **유효 창 전체 평균**으로 명시한다. 빈 창이 많으면 사건별 기여가 달라지므로 사건별 동일 가중치 평균과 구별한다. 원 난수/짝짓기 코드는 없어 보조 절차를 새로 명시했으며 기존 수치의 정확 재현으로 부르지 않는다. 선박 단위 민감도·AUC의 빈 부분집합은 null과 분모로 처리하도록 보완한다.

최종 보고서·새 인계서를 작은 JSON 및 CSV와 추가 대조해 사건/선박·신원/티어/충돌 변경·적중/p값·AUC·F1·원본 보존 수치가 일치함을 확인했다. 정확 검정은 A_peak에만 수행했으므로 모든 14규칙의 유의성을 검정했다는 표현으로 넓히지 않도록 최종 문구를 좁혔다. 부모 최종 회귀 9개와 독립 집계 검증도 통과했다.
