# Round010 완료·교차 비교 실행 계획

사용자 최신 요청: Round010 작업을 완료하고 Gemini 값과 비교해 비교·결과 보고서를 작성한다. 이전 Dispatch는 사용하지 않고 현재 직접 요청으로 수행한다.

이 계획은 두 실행의 결과를 이미 본 후 작성한 사후 감사 계획이다. 원 실험의 사전 등록이나 새로운 맹검 평가가 아니다. 원자료·Gemini 결과·Codex 독립 결과를 보존하고 새 비교 산출물에 출처와 해시를 남긴다.

1. Gemini 원 보고서와 수치·코드의 현재 사본을 보존한다. 루트 T1 소스·메모리·종료기록에는 Codex 경합 흔적이 있어 Gemini 생성 당시 실행 증거로 쓰지 않는다.
2. 동일 지표·창폭·시각대·행수매칭·층만 정렬해 수치와 유효 사건 분모를 비교한다. 서로 다른 정박권역·지속시간 정의의 직접표류 값은 성능 우열로 해석하지 않는다.
3. 중간순위·검정·제외수를 별도 구현으로 재계산한다. 가능하면 원 parquet에서 재계산하고, 메모리 관문 미달이면 저장된 사건별 자료의 저메모리 검산부터 수행한 뒤 새 작업 경계에서 재확인한다. 반복 RAM polling은 만들지 않는다.
4. 다중검정은 통상 Bonferroni의 동치인 `원 p<0.05/7` 또는 `보정 p<0.05`로 감사한다. 계약의 `보정 p<0.00714` 문구를 문자 그대로 적용한 더 엄격한 판정도 함께 보존한다. 원 데이터·효과를 바꾼 새로운 검정으로 가장하지 않는다.
5. 검증되지 않은 물리 기제, 비유의=효과부재, 창폭 민감도=정확한 사고시각 증명 주장을 철회한다. 원래 문장은 사본에 보존한다.
6. 비교 JSON/CSV·재계산·최종 보고·다음 라운드 인계와 상태 기록을 작성한다. Round011의 모델 학습·추가자료 수집·공식 제출은 이번 요청 범위 밖이며 시작하지 않는다.

완료 범위는 교차 비교와 계산 감사다. 동일 작성자의 별도 구현 검산을 별도 세션 검토자 또는 새로운 독립 데이터 평가라고 표현하지 않는다. 실행 모델·effort를 새로 생성하지 않으며 이 작업을 Luna/Astra가 수행했다고 주장하지 않는다.
