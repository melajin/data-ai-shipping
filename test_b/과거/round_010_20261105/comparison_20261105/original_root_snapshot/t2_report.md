## 4. 최종 판정: 분류기가 표류를 놓치는가, 항적에 표류가 없는가?

**판정**: **"두 요인이 결합되어 있으며, 근본 원인은 해양 물리 환경과 저속 임계치(10백분위)의 불일치에 있다."**

1. **분류기 규칙의 결함 (놓침)**:
   - `state` 분류기는 `len_m <= 50m`를 '정지'의 필수 전제로 못 박았습니다.
   - 그러나 해상에서 엔진이 정지한 어선은 조류(해류), 조석류, 바람에 의해 시속 0.2~1.5노트(370~2,800 m/h)로 외해를 밀려다닙니다.
   - 따라서 실제 기관고장 표류 선박은 1시간 이동 거리(`len_m`)가 50m를 훨씬 초과하므로, 분류기 상에서 기계적으로 `stop=False`가 되어 **모두 `저속굴곡`으로 전락**했습니다(기관손상 사고창의 89.3%가 저속굴곡).
2. **표류 직접 정의의 물리적 결함 (항적에 없음)**:
   - `len_m < 10백분위` 역시 선박이 항만이나 안벽에 묶여있을 때의 계류 지터 속력(보통 < 5 m/h)을 가리킵니다.
   - 조류가 흐르는 외해에서 2시간 이상 지속되는 시속 5m 미만의 초정지는 해양 물리적으로 불가능합니다. 따라서 사고창 발생률이 0.0%로 나타났습니다.
3. **인계 시사점**:
   - 표류를 "속력의 완전 정지(0 kts)"로 정의하는 모든 기구학적 임계값은 해양 환경에서 작동하지 않습니다.
   - 사고 시 나타나는 실재하는 이상 신호는 '정지'가 아니라, T1에서 확증된 **"일정 속력을 유지하며 좁은 공간 내에서 제자리 회전·선회·예인선 결속 저속 기동을 하는 `lin_raw`의 급감(Δ=−0.1511)"**입니다.
