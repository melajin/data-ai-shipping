# Test B Round 001 상세 보고서

## 결론

이번 라운드의 핵심 발견은 두 가지다.

첫째, 기존 단일 후보30건을 추가 검토했지만 직접 신원이 확인된 사고–선박 연결은0건이다. 정상 정답과 사고자료의 개발용 사용 범위도 미확인이다. 놓침·오탐·사고시각 오차의 확정 성능은 계산하지 않았다.

둘째, **신구 Test B 제출 명부는 교집합0척이지만 새100척 모두 기존 원자료 기반 항적 캐시에 관측된다.** 항적이 없는 것이 아니라 제출 대상이 바뀐 것이다. 이전100척의 점수·예측을 새100척에 이식할 수 없다.

최종 변경 독립 감사는 **pass10 / fail0 / unknown2, 실제 verifier exit0**이다. 미확인은 실제자료 점수·사고/B/C/분할·성능 평가와 provider 내부 모델 계측이다. 기술 검산과 사고 성능 검증을 구분한다.

## 조건·예상·이전 결과와 비교

목표는 동일 선박의 전체 제공 항적으로 사고 여부와 발생시각 하나를 추정하고 독립 자료에서 놓침·오탐·시각오차를 검증하는 것이다. 후보 수와 A/B/C 합의는 정답이나 성능이 아니다. 사용자 제공 공식답변에 따라 전체 항적을 활용하되 Test 학습·의사라벨·Test 분위수 임계값 생성은 금지한다.

선행 후보 감사167/118/30, 안정 단일1건, 독립검사43+31을 완료 근거로 인수했고 전량 재실행하지 않았다. W1은 신원·사용규정·정상근거, W2는 시각추정 입력·분할·인터페이스, W0는 새ZIP 호환성을 확인했다. 원자료·canonical·기존 캐시·제출물은 읽기전용이었다.

## 연결 근거 검토

W1은 E0023, 다선박 사고3건(E0042/E0108/E0123), 시간 확대로 다후보가 되는7건의 합집합10건을 우선 검토하고 나머지20건까지 정리했다. 중복 E0123은 한 번 검토하되 사건 관계를 보존했다. 안정1·확대다후보7·다선박3·우선10 집계는 독립 감사에서 일치했다.

선택 캐시 요약행30개와 사고 원행30개를 대조했다. 캐시에 원WKT/부분선이 없어 복원하지 않았다. E0023의 약435.9m 중심점 거리와 사고5분 전 버킷 시작은 연결 근거이며 탐지 오차가 아니다. 부분선을 연결하거나 좌표별 시각 없는 속력·가속도를 계산하지 않았다.

RFID·선명·등록번호 대응표는 조사한 로컬 목록·문서·머리글에서 찾지 못했다. 이는 조사범위의 부재이며 보편적 부재 증명이 아니다. 선종·톤수만으로 후보를 제거하거나 사고목록 부재·미연결을 정상 정답으로 만들지 않았다.

사용자가 전달한 공식답변은 계승한다. 2026 사고파일의 개발 학습·임계값 선택 허용과 사고 신원·정상 정답은 별도 미확인이다. 현재 판정은 **시각 비교 준비만 가능**이다.

## 새 명부 직접 재확인과 입력 버전

사용자의 재확인 요청으로 W0와 다른 Luna가 ZIP 내부 새 제출샘플, F: 구원본, intake 사본을 직접 읽었다. 문자열·숫자·공백·안전 정규화를 구분했다. 기존점수 캐시는 ID 키만 조회했고 A는 재계산하지 않았다.

| 비교 | 교집합 |
|---|---:|
| 구Test B ↔ 새Test B | 0/100 |
| 새Test B ↔ 기존 점수캐시/제출CSV | 각각0/100 |
| 구Test B ↔ 기존 점수캐시/제출CSV | 각각100/100 |
| 구Test A ↔ 새Test B | 13척 |
| 새Test B ↔ legacy 항적캐시 관측ID | 100/100 |

이0은 **명부와 이전 점수의 중복 수**다. 원항적 부재를 뜻하지 않는다. 새100척은 구1027원본 기반 parquet의 RFID열 청크 투영과 parse manifest 범위에서 확인했다. 이 검산에서 원CSV를 다시 파싱하지 않았다.

제출샘플의 각 시트A2:A101 값100개가 바뀌었다. Test A 집합 교집합은2척이다. ID 외 시간·점수 예시, 셀 타입·유효서식, 빈H1은 유지됐고 명시 열너비는 제거됐다. 예시 시간·점수는 사고 정답이 아니다.

W0는12CSV 전체를4MiB 청크로 읽어 신구SHA와 EOF CRC를 확인했다. 독립 감사는 전체 저장표·코드·경로·실행/해시 증거를 검토하고 XLSX를 직접 비교했다. CSV 직접 대조는 train1/test1의 **시작부4MiB씩**이다. 독립 감사가12CSV 전체를 다시 읽었다고 주장하지 않는다. 파일 호환성은 캐시 수치 정확성이나 사고 성능을 인증하지 않는다.

## 실패·수정·최종 검산

W1의 BOM 영수증 읽기·메타데이터 문법·영수증 인덱스 오류 시도는 exit1 기록을 보존했다. 최종 exit0이며 독립 감사에서 근거표·E0023 원행/캐시·집계·해시·실행 기록이 일치했다.

첫 W3 감사는 pass13/fail2/unknown3, verifier exit2였다. A 코드와 manifest/생성기의 동점 문구가 달랐고, max_gap_hours가1보다 크면 미관측 시간대를 연결할 수 있었다. 이를 통과로 표시하지 않았다.

감독이 timing_guard_contract.md를 고정하고 별도 W2F가 국소 수정했다. A는 원입력 최초 최대값이며 시간 정렬은 B/C 구간 탐색에만 사용한다. hourly gap은(0,1]이고1초과는 거부한다. 같은 시각의 상충 점수는 data_conflict와 A/B/C 공란으로 남긴다. 같은 점수의 중복은 원행을 보존하되 지속 행수는 고유 시각으로 센다. C가 통과하면 C=B다. 자체 합성14검사와 문법검사는 exit0이었다.

W0의 metadata 문자열/dict 비교 오류는 수정 전 원시기록을 보존하고 구조화된 bytes/mtime로 재판정했다. 기록된14파일 metadata/content-posthash가 일치했다. 대용량 재해시나 임의true 대체는 하지 않았다. W2F 문서의 깨진 중복 문단도 수정했으며 첫 무결성 확인 exit1과 정정 후 exit0을 보존했다.

최종 감사 자체의 assertion·로그 인코딩·대소문자 처리 오류는 exit2/1/2로 보존하고 고쳤다. 생산 파일은 수정하지 않았다. **최종 exit0, pass10/fail0/unknown2**, 독립 합성9사례 통과, 검사대상64경로 전후 해시 일치다. 실제 점수·사고/B/C/분할·성능과 provider 내부 모델 계측은 미확인이다. 양의floor 점수의 실제 사고판정 의미도 미정이다.

## 역할·RAM·완료 세션

감독 요청은 GPT-6.1 Sol high다. 현재 감독의 provider 실제 모델/effort를 인증하는 영수증은 확보하지 못해 unknown이다. 실제 Luna workers는 --model gpt-6-luna --effort xhigh로 시작했고 Orca 응답도 같은 launch설정을 반환했다. 이를 provider 내부 계측이라고 확대하지 않는다. 실제 task/dispatch·종료 영수증은 integration/runtime_receipts에 있다.

실행·독립 검산은 별도 세션이고 감독은 계약·판단·통합을 맡았다. 사용자 RAM 지시에 따라 큰 작업 전 가용량과 예상피크를 확인하고 부족하면 다른 작업 뒤 재확인한다. W2F 검사 전4621.5MiB, 최종 감사 표본 전4918.7MiB가 가용했다. 예상 최대128MiB는 추정이며 최대RAM 실측이 아니다.

완료 세션은 최신 dispatch와 동일handle의 실행 중 후속 유무를 확인한 뒤 닫기 절차를 수행한다. W1·수정W2F는 released가 관찰됐다. W2 일부는 user_kept, W0와 최종 감사자는 identity_unproven 응답으로 닫힘을 확인하지 못했다. 이를 성공으로 기록하지 않는다. 식별되지 않은 창을 강제 종료하지 않는다.

## 성공 기준과 후속

이번 기술 검토는 완료됐다. 사고 신원·정상 정답·독립 분할·실제 발생시각 평가·공식 수식은 미완료이며 근본 목표는 진행 중이다. 학습자의 설명 능력과 실제 선박 안전성은 검증하지 않았다.

다음 라운드는 새100척의 입력계보·필수특징·참조자료·고정 scorer를 확인하고 Test 적합 없이 탐색 점수를 생성할 수 있는지 검증한다. 가능하면 점수와 최고점 후보A를 남기되 사고 예측이나 검증된 발생시각으로 표시하지 않는다. B/C·사고 여부 임계값은 근거 게이트 충족 후 계산한다.

성능 평가에는 신뢰할 사고–RFID 연결, 확인 정상자료/추적범위, 사고자료 개발사용 근거, 정확한 시간오차 F1 수식이 더 필요하다. 이를 매칭·합의·임의 정상라벨로 대체하지 않는다. 유효한 로컬 검증은 계속하되 외부 근거 없이는 해결할 수 없는 조건은 blocked_external_evidence로 구체화한다.

라운드별 새 Sol high 감독과 실제 Luna xhigh 실행/검산을 유지한다. 새 감독의 인수 ACK와 단일 소유권 전환 전에는 다음 라운드를 중복 시작하지 않는다.
