## 1. 이번 라운드의 질문은 하나다

> **Round 009가 "완전한 영 효과"로 폐기한 직선도 계열 신호(Tier0-1에서 Δ백분위 −0.08~−0.12)는 실재하는가? 실재한다면 어느 성분이 만드는가?**

Round 009 검증에서 13개 지표 중 **유일하게** 10개 설계 변형 전부에서 부호가 유지된 것이 `lin_mean = bbox_m / max(len_m, 1.0)`이다(최적 설계 −0.1249, p=0.0095, 95% CI [−0.205, −0.040]). 다만 Bonferroni(α=0.0038) 미통과이므로 **확증이 아니다.** 사건 수는 100건이 상한이라 늘릴 수 없다. 따라서 **지표를 분해해 효과 크기를 키우는 것**이 유일한 경로다.

부수 목표 하나를 함께 둔다: **`state` 분류기 감사.** 기관손상 58건이 포함된 양성셋에서 `해상정지` 비율이 전체 기저율(3.18%, 26,172/822,000행)과 동일하다. 사고 표류를 포착하지 못하고 있으므로, `state`를 더 쓰기 전에 분류 규칙 자체를 확인한다.

**이번 라운드는 모델을 만들지 않는다.** 특징 1개를 승격시키거나 경로를 최종 기각하는 것이 전부다.

Round 009의 결함 C1~C5를 교정한 평가 설계다. **모든 측정은 이 설계로 한다.** 임의 변경 시 결과는 무효다.

| 항목 | 값 | 근거(R009 결함) |
|:---|:---|:---|
| 단위 | 사건(event) 단위, 사고 100건 | — |

| 대조창 가드 | 같은 선박의 **모든** 사고로부터 `|t_c − t_acc| ≥ 76h` (가드 72h + 창 반폭 3h + 1) | **C3** 12h 가드는 예인·수리 여파 포함 |
| tie-break | **금지.** 조건을 만족하는 대조창을 **전수** 사용 | **C2** 1회 추출로 분산 25% 자작 |
| 시각대 | `hod` 원형거리 `≤ 1h` (민감도 ±0/±2/±3h 추가 보고) | **C5** 주야 혼합이 모든 차이를 오염 |
| 관측행수 | `n_rows(t_c) == n_rows(t_acc)` 완전일치 | 선택편향 제거 |
| 공백 계열 지표 | `n_rows` **미매칭** 버전으로 **별도** 검정 | **C4** 노출 조건화는 동어반복 |
| 최소 대조창 수 | 15개 미만 사건은 제외하고 **제외 건수를 반드시 보고** | — |
| 통계 | 사고창 값의 대조창 분포 내 **중간순위 백분위** → 1표본 Wilcoxon(`pct − 0.5`) + 부호검정 + 부트스트랩 2000회 95% CI | **C1·C2** |
| 영 과다 지표 | 사고창 값이 0인 비율 > 50%면 **백분위 금지** → `0 초과 여부`에 McNemar 정확검정 | **N3** 동률 인공물 |
| 이진 지표 | Wilcoxon 금지 → **McNemar 정확검정** | **C8** |
| 다중검정 | 검정 지표 수 `K`로 Bonferroni, `α = 0.05/K`를 **표에 명시** | **C9** |
| null 주장 | 비유의 보고 시 **MDE(최소검출효과) 동반 필수** | **C1** 등가성 오류 |

**통과 판정 (사전 고정, 사후 완화 금지)**

지표가 Round 011 특징으로 승격되려면 **네 조건을 모두** 만족해야 한다.

1. `|Δ백분위| ≥ 0.05`
2. Bonferroni 보정 p `< α`
3. 부트스트랩 95% CI가 0을 포함하지 않음
4. 설계 변형 10종(`hod ±0/±1/±2/±3/무통제` × `n_rows 매칭/미매칭`) 중 **8종 이상에서 부호 일관**

**하나도 통과하지 못하면 직선도·기구학 경로를 최종 기각하고 기록한다.** 그 경우 Round 011은 다선박 시공간 공변량(예인선 동반 귀항) 경로로 전환한다. 기준을 낮춰 통과시키지 않는다.

## 4. 작업 분담

### T1 — 직선도 분해 (주 작업)

`lin_mean`의 −0.1을 만드는 성분을 특정한다. 아래 7개 지표를 **R010-GATE로** 측정한다(K=7, α=0.00714).

| # | 지표 | 정의 | 왜 보는가 |
|:---|:---|:---|:---|
| 1 | `lin_raw` | `bbox_m / len_m`, `len_m < 1 m` 행은 **제외**(클램프 제거, 제외 수 보고) | R009 지표의 분모 클램프 결함 제거 → 효과가 커지는가 |
| 2 | `straight_win` | 창 수준: `haversine(첫 관측 중심점, 마지막 관측 중심점) / Σ len_m` | 창 전체의 직선성. 시간 내 선회가 아니라 시간 간 이동 방향 |
| 3 | `speed_mean` | `len_m` 시간당 평균(관측 시간만) | 순수 활동량. R009 H1 재검정 |
| 4 | `step_mean` | 연속 **관측** 중심점 간 haversine / 시간 간격 | 시간 간 실이동. R009 특징 집합에 없던 것 |
| 5 | `bearing_consistency` | 연속 변위 벡터 방위의 원형 집중도(R̄) | 표류는 조류 방향으로 **일관**되게 밀린다. 조업 선회는 방위가 흩어진다 |
| 6 | `turn_rate` | 연속 변위 벡터 간 방위 변화 절대값 평균 | 제자리 선회 성분 |
| 7 | `still_frac` | `len_m`이 해당 선박 자기 분포 10백분위 미만인 시간 비율 | 정지 성분. 절대 임계값 금지, 선박 내 상대값 |

**추가 층화 보고 (각각 전체·Tier0-1)**
- 사고유형: 기관손상 58 / 부유물감김 20 / 침수 14 / 화재 11 / 운항저해 11 — 표류를 겨냥한 지표가 **기관손상·부유물감김에서 더 큰가**가 핵심 확인이다.
- 창 폭: ±3h / ±6h / ±12h. 효과가 창을 넓힐 때 커지면 사고시각 보고 지연을 시사한다(해석만, 결론 금지).

**산출물**: `t1_decompose.py`, `t1_gate_results.json`(지표×설계변형×층화 전수), `t1_event_percentiles.csv`, `t1_report.md`

### T2 — `state` 분류기 감사 (부 작업)

1. `state` 생성 규칙의 원천 코드·파라미터를 추적해 경로와 규칙을 문서화한다. 미확인이면 미확인으로 적는다.
2. 사고창 `state` 분포 vs **R010-GATE 대조창** `state` 분포를 비교한다(5개 상태 각각, McNemar).
3. `state`에 의존하지 않는 **표류 직접 정의**를 세워 재검정한다: `저속(선박 자기 10백분위 미만) AND 정박권역 아님 AND 2시간 이상 지속`. 정박권역 판정은 **절대 좌표·격자 ID를 특징으로 쓰지 않고** 해당 선박 자신의 평가기간 체류 빈도로만 정의한다.
4. 기관손상 58건에서 이 정의의 Δ백분위를 보고한다.

**산출물**: `t2_state_audit.py`, `t2_state_distribution.json`, `t2_report.md`

### T3 — 독립 검산

1. T1·T2 코드가 R010-GATE를 **문자 그대로** 지켰는지 확인한다(가드 76h, hod ≤1h, 전수 대조창, 최소 15개, Bonferroni α 표기, MDE 동반).
2. `t1_gate_results.json`의 수치 중 **최소 3개를 독립 구현으로 재계산**해 일치를 확인한다.
3. 보고서의 **모든 수치가 산출 파일에 존재하는지** 대조한다(R009 결함 C6 재발 방지). 없는 수치는 보고서에서 삭제를 요구한다.
4. 부분집합 수치를 전체 서술로 올린 문장이 있는지 검사한다(C7 재발 방지).

**산출물**: `t3_verification.json`, `t3_audit_report.md`

## 5. 금지 사항

1. **시각대 미통제 수치 보고 금지.** R010-GATE 밖의 숫자를 결과로 제시하지 않는다.
2. **가드밴드 12h, 시간근접 tie-break, 대조창 1개 추출 금지.**
3. **노출변수를 매칭한 채 그 노출을 검정하지 않는다**(공백 계열은 `n_rows` 미매칭 설계).
4. **절대 위경도·격자 ID를 특징으로 쓰지 않는다.** 양성이 사고 좌표 근처에서 식별됐으므로 dev에서만 올라간다.
5. **2025 테스트 데이터 학습 금지**(운영측 공식 규칙 4번). 모든 측정은 2026 dev에서만.
6. **모델 학습·임계값 설정·제출물 생성 금지.** 이번 라운드 범위 밖이다.
7. **비유의를 등가로 쓰지 않는다.** "완전한 영 효과", "무신호" 같은 표현 금지. MDE와 함께 "이 설계로는 X 미만을 검출할 수 없다"로 쓴다.
8. **산출 파일에 없는 수치를 보고서에 쓰지 않는다.** 집계 수준(행/창/선박/사건)을 모든 수치에 명시한다.
9. **사용자 승인 없이 git push·원자료 수정·외부 발송 금지.**
10. **질문으로 멈추지 않는다.** 불확실하면 가장 근거가 명확한 쪽으로 판단하고 "이번에 내린 판단과 근거"에 기록한다.

### 혼동 주의 — 동일 선박 과거 항적 규칙

"동일 선박 과거 항적 프로필 금지"는 **과제1(조업형태 분류)**의 재식별 차단 규칙이다. Test B 사고시각 추정에서는 운영측 공식 규칙 1번("동일 선박의 전체 항적 사후 참조 허용")에 따라 **평가 대상 선박 자신의 평가기간 항적을 쓰는 것이 적법하다.** R010-GATE의 선박 내 대조 설계는 이 규칙 안에 있다.

## 6. 메모리 운영 (AGENTS.md 승계)

- 대용량 로딩·변환 **직전마다** 가용 RAM·예상 최대 메모리·동시 작업·확인 시각을 JSON에 기록한다.
- parquet은 필요한 컬럼만 선택 로딩한다(T1 필요 컬럼: `rfid_id_int, ts, len_m, bbox_m, cen_lon, cen_lat, state, score`). 전체 로딩 금지.
- 예상 최대 512MiB, 여유 1GiB 요구. 부족하면 **보류하고 의존관계상 가능한 다른 작업을 먼저** 한다.
- RAM 확인용 polling·watch 루프를 만들지 않는다. 사용자 프로세스를 임의 종료하지 않는다.
