# Round011 시간과 위치를 고려한 행동 변화 실험

## 목적과 사용자 결정

2026-11-05 사용자는 lin_raw를 **특징 후보로 채택**하고, 표류를 단일 값으로 판단하지 않고 자료의 시간·위치를 비교하여 가설과 실험을 진행하도록 요청했다. 이 결정은 사고 탐지 성능이나 실제 표류 원인의 확증과 구분한다. 본 계약은 Round011 결과 계산 전에 저장하며 결과를 본 뒤 수치 조건을 바꾸지 않는다.

lin_raw는 `len_m >= 1m`이고 두 값이 유한한 시간행의 `bbox_m / len_m` 평균이다. 시작점·끝점 순변위/경로길이가 아니다. len_m은 관측 부분선의 경로량 대용치다. 시간행 중심점 변화 역시 실제 선박의 순간 속력으로 부르지 않는다.

## 표류에 대한 작업 가설

물리적으로는 선체 이동에 물의 흐름·바람 등 외력이 크게 기여할 수 있다. 현재 자료만으로 추진 명령·조종 의도·기관 상태를 식별할 수 없으므로 이번 출력은 **사고 관련 행동 변화 후보**다. 표류는 저속 또는 곡선이라는 필수조건을 두지 않으며, 기존 q10 저활동 AND 고빈도 구역 밖 AND 지속 규칙을 표류 정답으로 사용하지 않는다.

- H1: 같은 선박의 과거 시간과 위치를 함께 맞춘 lin_raw의 상대적 저하가 시간만 또는 위치만 맞춘 것보다 사고 시점을 더 잘 국소화한다.
- H2: 같은 맥락에서 관측 경로량이 줄지만 시간행 중심점 이동은 계속되는 조합이 사고 시점 국소화에 도움이 된다. 정상 조업·대기·예인·관측 구조도 대안 설명으로 남긴다.
- 품질 질문: 공동 조건을 요구하면 비교 가능한 자료가 얼마나 줄고, 희소 관측 사건을 얼마나 잃는가?

## 입력과 시간 의미

입력은 Round008의 `dev_hourly_scores.parquet`와 `devset_positives.csv`다. 잠정 연결 100사건/82척, Tier0-1 60사건을 그대로 사용한다. 새로운 연결·외부 자료 수집·2025 테스트·모델 학습은 이번에 하지 않는다. CSV의 acc_ts와 parquet ts는 기존 epoch-hour 정수 해석을 그대로 사용하며 실제 현지 시간대 교정은 미확인이다. 따라서 시간대는 저장 시각 modulo 24 조건으로만 표현한다. 실제 월·시간을 복원한 값을 기록한다.

현재 창은 관측 시간행이 존재하는 시점 t까지의 **trailing 7개 시간대 [t-6,t]**다. 원자료의 마지막 시간행이 완성된 뒤 계산할 수 있는 분석이며 초단위 실시간·조기경보를 주장하지 않는다. 현재/과거 창은 똑같은 정의다. 미래 행을 특징 또는 기준 분포에 쓰지 않는다. `n_rows`는 창 안의 전체 관측행 수다. 품질 조건은 len_m과 bbox_m이 모두 유한·비음수인 행 >=4/7, 그중 len_m>=1인 lin_raw 유효행 >=3, 정확히 1시간 차이인 유효 중심점 쌍 >=2다. A는 유한·비음수 len_m 행에서 독립 계산하고, M도 유효 좌표쌍에서 독립 계산한다. 좌표는 위도[-90,90]·경도[-180,180] 범위를 요구하며 L/TL의 현재·참조 마지막 행 좌표도 유효해야 한다. 결측을 연결하거나 보간하지 않는다. 관측 부족은 unknown으로 남긴다.

## 비교 기준 분포

각 현재 시점 t에서 같은 선박의 **[t-720h,t-24h]** 끝시점만 참조한다. 양 끝은 포함한다. 현재 창과 최소 17시간의 비중첩 여유가 있고, 이미 발생한 사고를 포함한 이력도 사건 정답으로 제거하지 않는다. 이는 사고시각을 모르는 배치 계산이다. 참조 창도 위 품질 조건을 충족하고 관측행 수 차이는 1 이하여야 한다.

|설계|추가 조건|
|---|---|
|T 시간|저장 시간대의 원형 차이 <=1시간|
|L 위치|현재 마지막 시간행 중심점에서 참조 마지막 시간행 중심점까지 구면거리 <=10km|
|TL 시간과 위치|위 두 조건 모두|

각 설계는 조건을 통과한 끝시점 가운데 과거 **서로 다른 epoch-day 10일**을 사용한다. 최근 날짜부터 10일을 고른다. 하루 안에서는 T는 시간대 차이→관측행 수 차이→빠른 시각, L은 위치거리→관측행 수 차이→빠른 시각, TL은 시간대 차이→위치거리→관측행 수 차이→빠른 시각 순으로 한 창을 선택한다. 10일 미만이면 해당 설계는 unknown이다. 30일·10km·시간대1시간·10일은 물리적 표류 경계가 아닌 이번 탐색의 고정 분석 선택이다. 자료 희소성을 이유로 사후 확대하지 않는다.

## 고정 특징과 점수

각 창에서 lin_raw 평균, `log1p(len_m)` 평균 A, 연속 1시간 중심점 쌍 구면거리 평균 M(m/관측 시간간격)을 만든다. 음수 길이와 비유한 좌표는 무효다. 모든 조건부 백분위는 10개 참조 창에서 `< + 0.5*==` 중간순위로 계산한다. 부동소수 동률은 원 float의 정확 일치로 고정한다.

- 형태 점수: `1 - P(lin_raw)` (낮은 형태 비율 방향).
- 저활동 점수: `1 - P(A)` (보조 진단).
- 이동 동반 저활동 점수: `(1 - P(A)) * P(M)` (H2). 높은 점수는 비교 이력보다 경로량은 작고 중심점 이동은 큰 조합이다. 물리적 표류를 보편적으로 포괄하지 않는다.
- 원 lin_raw 점수 `-lin_raw`도 동일 후보 시각에서 기술 비교한다.

임계값·가중치 학습은 하지 않는다. 세 맥락×세 점수 9개와 원 lin_raw를 모두 보고하며 결과를 보고 하나를 새 승자로 재채택하지 않는다.

## 평가와 판정

실제 국소화가 주종점이다. 선박별로 T/L/TL과 세 지표가 **모두 유효한 공통 후보 시각**만 사용하여 점수 순위를 비교한다. 해당 선박의 공통 후보가 100시각 이상이면 평가 가능하다. 사건 ±6h에 유효 후보가 없더라도 해당 사건을 성공 분모에서 제외하지 않고 실패로 기록한다. 선박별 후보 수·기간·사고 부근 coverage, unknown 사유를 별도 저장한다. 상대시각을 써서 특징을 만들지 않고 평가에만 사용한다.

주종점은 top-1 시각이 사고 ±6h에 드는 비율이다. 최대점 동률에서는 균등 무작위 선택의 **기대 적중값** `동률 중 적중 시각 수 / 최대점 동률 수`를 계산한다. 따라서 적중 합은 소수일 수 있다. 대조 우연값은 같은 공통 후보에서 ±6h인 비율이다. top-10은 동률 경계의 비복원 균등 선택에 대한 적어도 한 번 적중 확률을 정확 조합식으로 계산하는 보조 종점이다. 후보 시각 간 강한 중첩이 있어 독립 경보 10개로 해석하지 않는다.

주요 집합은 Tier0-1, 전체100은 보조다. H1의 TL-T와 TL-L, H2의 TL-T와 TL-L **4개 차이**를 사전 가족으로 고정한다. 사건 평균 차이와 같은 선박의 사건을 함께 재표집하는 cluster bootstrap B=4000, seed=11052026의 98.75% 구간(4개 Bonferroni)을 보고한다. 구간 전체가 0보다 크고 공통 평가 사건 >=30일 때에만 해당 비교의 탐색적 개선을 지지한다. 표본 부족은 판단 유보다. 반복 사용한 dev이므로 어떤 p/CI도 라운드 간 사전선택을 보정한 확증이 아니다.

조건부 평가 외에 Tier0-1 전체60/전체100을 분모로 한 **평가불가를 실패 처리한 보수적 적중률**도 기록한다. 이는 unknown을 실제 정상/실패 정답으로 바꾸는 것이 아니라 현재 파이프라인의 서비스 범위를 포함한 출력 성과다. 같은 선박의 여러 사건은 별도 독립 표본으로 취급하지 않는다. 결과가 나쁘면 가설 미지지와 coverage 제한을 그대로 남기며 자동 다음 라운드 튜닝을 하지 않는다.

## 자원과 재현

사전 확인 2026-11-05 16:39 KST: 가용 RAM 1.512GiB/총13.809GiB. 입력 parquet 51,584,418bytes/822,000행/한 row group. 처음 고려한 1.5GiB 전체 계산은 보류한다. 필요한 열만 8192행씩 읽어 대상82척만 보관하고 선박별 순차 계산한다. 배열 규모는 대상행×약64bytes와 현재 선박×고정720h 이력 후보이며, Python/Arrow/SciPy 여유 포함 작업 예상 peak **512MiB**로 낮춘다. 실행 직전·단계 전환에 가용 RAM을 재확인하고 추가 작업 여유 768MiB보다 적으면 종료75로 보류한다. 동시 데이터 계산은 금지한다. 반복 polling·사용자 프로세스 종료는 하지 않는다.

산출물은 이 폴더 내부의 코드, 계약 해시, 메모리·실행 기록, 시각별 점수 CSV, 사건별 평가 CSV, summary JSON, 검토 결과, 최종 보고서다. 기술 목표는 시간·위치 조건부 비교와 국소화 검산, 학습 목표는 물리 원인과 관측 특징·상대 비교·coverage를 구분해 설명하는 것이다. 예측한 현상은 TL의 국소화 개선이며 관찰값이 반대여도 그대로 기록한다.
