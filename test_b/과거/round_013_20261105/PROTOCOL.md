# Round013 설계 — 항차 내부 국소 붕괴 탐지와 자기참조 정상 기준

작성 2026-11-05. 이 문서는 **실행 전** 계약이다. 결과를 본 뒤 조건(임계값·창 크기·분모·통과선)을 바꾸지 않는다. 바꿔야 할 사정이 생기면 이 문서를 고치지 않고 새 문서(PROTOCOL_v2.md)로 분기하고 이유를 적는다.

## 0. Round012에서 승계하는 것 (재검증하지 않음)

- 시각 추정의 단위는 관측행이 아니라 **항차**다. 항차는 같은 선박 내 공백 ≥6h를 경계로 분할한다(`testB/round_012_20261105/g_gate_v2.py`).
- 사고는 100% 어떤 항차 안에 있다(천장). 항차를 정확히 고르고 중앙/종료 시각을 적을 때 ±6h 적중 천장은 **ALL 38.0% / Tier0-1 45.0%**, 기준선은 선박내 무작위 항차 **ALL 1.42% / T01 1.97%**다.
- 항차 단위 요약 특징 12개×2방향(24검정) 전수 탐색은 전부 Bonferroni 미통과였다. 최고는 `lin_voy|min` 4/100(4.0%), 원p=0.055.
- 사고 후 영구통신두절(4.0%)·사고 후 장기계류(28.0h vs 27.75h) 두 거시 가설은 기각됐다. 탐색 방향은 **항차 내부**로 못박는다.
- `lin`(bbox/len) 계열이 R009(관측행 단위)→R010(평균이동 확증)→R012(항차 단위 1위, 미확증)에서 세 번 같은 방향으로 1위다. Round013은 이 계열 하나를 더 정밀하게 재정의하는 라운드다. 새 특징 계열을 추가로 만들지 않는다.
- 정량 채점 손익분기(§1 유도): `F1 = 2TP/(C+A)`, 칸 추가 조건 `q > F1/2`. 통과선은 ±6h 적중률 약 **12~45%** 구간.

## 1. 이번 라운드가 메우는 구멍 — 두 가지

**구멍 A.** Round012의 24개 특징은 항차 **전체 평균**(`lin_voy = Σbbox/Σlen`, 항차 전 구간)이었다. 사고가 항차의 일부 구간에서만 기하학적으로 붕괴한다면 전체 평균은 그 붕괴를 정상 구간과 섞어 희석한다. 이번 라운드는 항차를 **시간 단위로 쪼개 국소 최저점**을 찾는다.

**구멍 B.** Round012의 선택은 "같은 선박의 다른 항차들과 raw 값으로 순위 비교"였다. 이건 틀리지 않지만 두 가지가 비어 있다:
1. **선박마다 그 비교가 통계적으로 가능한지**를 사전에 거르지 않았다(항차 수가 너무 적은 배가 있다 — §3).
2. **시각대(hour-of-day) 교란**을 항차 레벨에서 아직 확인하지 않았다. R009가 관측행 레벨에서 "시각대 미통제 시 신호가 소멸한다"고 못박았는데(net_m +0.1049→+0.047), 같은 함정이 항차 레벨에도 있는지 모른다.

이번 라운드는 §4(국소 붕괴 특징 재정의)와 §5~6(자기참조 기준의 전제조건 확인)을 **이 순서로** 수행한다. 뒤 단계는 앞 단계가 통과해야 진행한다.

## 3. 선행 관문 — 자기참조 기준이 성립하는 선박만 센다

자기참조(leave-one-out) 정상 분포는 "그 선박의 다른 항차들"로 만든다. 다른 항차가 너무 적으면 분포가 아니라 잡음이다.

**규칙:** 평가 대상 항차를 제외한 **나머지 항차 수 ≥ 10**인 선박만 주 분석(primary)에 포함한다. 미달 선박은 "자료부족(insufficient_history)"로 별도 집계하고 주 분석의 분모에서 제외한다 — 빼는 게 아니라 **따로 보고**한다(배제 자체가 숫자다).

이번 실행 전 dev와 2025 Test B 양쪽의 항차 수 분포를 실측해 둔다(`testB/round_012_20261105/g2v2_voyages.csv`, `first_results/hourly_scores.parquet`에서 이미 확인):

| | dev 82척 (Round008 연결) | 2025 Test B 100척 (실제 제출 대상) |
|---|---|---|
| 선박당 항차수 중앙값 | 44 | **20** |
| 항차 <10 (주분석 미달선) | 9/82 (11%) | **36/100 (36%)** |
| 항차 <5 | 5/82 (6%) | **21/100 (21%)** |
| 최소값 | 2 | 1 |

**결론: dev에서 쟤는 통과율은 2025 Test B의 실제 가용성을 과대추정한다.** 이번 라운드는 dev 적중률 하나만 보고하지 않고, **"자료부족으로 판정 대상에서 빠지는 비율"을 2025 Test B 모집단 기준으로 함께 보고**한다(§8 산출물 목록 참조). 이 수치가 나쁘면(예: 실제 제출 대상의 36%가 애초에 판정 불가) 그 사실을 감추지 않고 적는다.

## 4. 국소 붕괴 특징의 정의 (사전 고정)

### 4.1 창 크기 — 두 값을 가족으로 등록한다

`w ∈ {3, 7}`. 7은 기존 scoring 창(원 파이프라인의 trailing 7시간) 및 Round011과 정합, 3은 Round012에서 1위였던 `lin_last3`와 정합. **사후에 w를 고르지 않는다. 둘 다 돌리고 둘 다 보고하며 Bonferroni 가족 크기 2로 보정한다.**

### 4.2 국소 lin 값

항차 안의 시각 `h` (항차 시작 + w-1 번째부터 항차 끝까지, 항차 경계를 넘어 이전 항차로 역참조하지 않음)에 대해, **trailing window `[h-w+1, h]`** 안의 유효 행(len_m·bbox_m 유한, len_m ≥ 1m)으로:

```
lin_w(h) = Σ bbox_m(유효행) / Σ len_m(유효행)
```

유효 행 수 조건(Round011 §"입력과 시간 의미"의 품질조건을 그대로 축소 적용):
- w=7: 창 안에 len_m·bbox_m 둘 다 유한한 행 ≥4, 그중 len_m≥1인 유효행 ≥3
- w=3: 창 안에 len_m·bbox_m 둘 다 유한한 행 ≥2, 그중 len_m≥1인 유효행 ≥2

조건 미달 시각은 `lin_w(h) = NaN`으로 두고 뒤 계산에서 제외한다(보간하지 않는다).

### 4.3 항차 요약 — 국소 최저점과 그 시각

```
lin_min_w(voy)  = min_h lin_w(h)     (유효 h에 대해. 전부 NaN이면 항차 자체가 무효)
t_collapse_w(voy) = argmin_h lin_w(h)   (그 최저점이 나온 창의 끝 시각)
```

`t_collapse_w`가 이번 라운드가 실제로 보고할 **후보 사고시각**이다. Round012는 항차의 중앙/종료 시각을 적어 천장(38~45%)을 쟀지만, 이번에는 "그 항차 안에서 기하학적으로 가장 붕괴한 지점"을 직접 적는다 — 이 지점이 중앙/종료보다 실제 사고시각에 가까운지가 새 검증 대상이다.

## 5. 시각대 교란 선행 점검 (§4 이후, §6 이전에 실행 — 통과 못하면 §6의 설계를 바꾼다)

R009 교훈: 시각대(hour-of-day) 미통제 시 신호가 소멸한 전례가 있다. 항차 레벨에서 같은 함정이 있는지 **먼저 확인**한다.

**점검 방법:** 전체 항차(ALL + Tier0-1 선박 모집단)에서 `t_collapse_w`의 `(ts mod 24)` 분포와, 그 항차의 `lin_min_w` 값이 시각대와 상관되는지(Spearman)를 w별로 각각 1회 보고한다. `|rho| ≥ 0.2`이거나 사고/대조 항차 간 시각대 분포가 유의하게 다르면(카이제곱 또는 KS, α=0.05, 가족 크기 2) **교란이 있다고 판정**한다.

- **교란이 없으면** §6을 그대로 진행(leave-one-out에 시각대 구분 없이 전체 다른 항차 사용).
- **교란이 있으면** §6의 "다른 항차" 모집단을 **같은 시각대 버킷(주/야간 2분할, 06-18시/18-06시)** 으로 제한한 뒤 leave-one-out을 다시 정의한다. 이 분기는 결과를 보고 임의로 고르는 게 아니라 이 점검 하나의 이진 결과로만 갈라진다 — 사전에 못박는다.

## 6. 자기참조 정상 기준과 선택 규칙

### 6.1 항차 선택 (선박 내부, w별 독립)

선박 V의 §3 통과 항차 집합에서,

```
선택 항차 = argmin_voy  lin_min_w(voy)
```

(raw 최솟값 순위이며, 선박 내부 단일 특징 단일 방향 순위이므로 leave-one-out 백분위와 순서가 동일하다 — 별도 정규화가 선택 순서를 바꾸지 않는다. §6.2는 이 선택과 무관하게 별도 목적으로 수행한다.)

### 6.2 자기참조 백분위 — 용도를 분리해서 쓴다

"자기참조 정상 기준"은 두 가지 다른 일에 쓰이며, 이번 라운드는 **(a)만 평가하고 (b)는 다음 라운드로 명시 이연한다.**

- **(a) 항차/시각 선택** — §6.1의 raw argmin. 선박 내부에서만 비교하므로 정규화가 불필요하다. **이번 라운드의 주 평가 대상.**
- **(b) 선박 간 비교 가능한 확신도 점수** — 선택된 항차의 `lin_min_w`가 "그 선박 자신의 다른 항차 분포에서 몇 백분위인가"(leave-one-out percentile, robust: median/MAD 또는 rank 기반)를 계산해, 서로 다른 선박을 하나의 척도로 비교할 수 있게 만드는 것. 이건 추후 "100척 중 몇 척을 사고로 제출할지" 게이트(Stage 3, 당초 세션 초반에 논의된 거절 게이트)에 쓰일 재료이지만, **이번 라운드는 이 확신도 점수를 계산해 `g3_confidence.csv`에 남기기만 하고, 그것으로 선박을 거르거나 제출물을 만들지 않는다.** 새 가설·새 통과선을 이번에 걸지 않는다(사후선택 방지).

## 7. 평가 — 사전 고정 종점

### 7.1 주 종점

```
집합   : Tier0-1, §3 통과 선박만 (자료부족 제외, 비율은 별도 보고)
창     : w=7 (1차), w=3 (2차) — 가족 크기 2, Bonferroni α = 0.025
지표   : |t_collapse_w(선택 항차) - acc_ts| <= 6  →  적중
기준선 : 같은 §3 통과 선박 집합에서, 선택 항차는 그대로 두고
         "그 항차 안의 무작위 시각 1개"를 적었을 때 ±6h 기대 적중률
         (항차를 완벽히 맞췄다는 가정 하의 무작위 — Round012 천장 계산과 동일 원리)
통과선 : 적중률 >= 12%  AND  이항검정(기준선 대비 one-sided) 가족보정 p < 0.05
```

### 7.2 부 종점

- ALL 100사건(§3 통과분) 동일 지표.
- `t_collapse_w` 대신 **항차 중앙/종료 시각**을 적었을 때와의 직접 비교(Round012 수치와 동일 정의로 재현 — 이번 라운드가 Round012보다 개선인지 확인). 같은 가족(α 보정 범위)에 넣지 않고 기술 비교로만 보고한다(이미 Round012에서 측정된 값의 재확인이므로 새 가설 검정이 아니다).
- §3 미달(자료부족) 선박의 사고 포함 비율: 그 선박들 중 실제 사고 선박이 몇 %인지(이 비율이 높으면 §3의 10개 컷오프가 비용이 크다는 뜻).

### 7.3 보정과 보고

- 사건 단위 cluster bootstrap(같은 선박의 다중사건을 함께 재표집) B=4000, seed=11052026, 97.5% CI(가족 크기 2 Bonferroni).
- 신호 없음(null)을 주장할 때는 반드시 MDE(최소검출가능효과)를 함께 보고한다(R009/R010 선례).
- 사전등록 외 셀을 추가로 탐색했다면 "사전등록 외 추가 탐색"으로 명시 구분하고 확증으로 올리지 않는다.
- `lin` 계열에 대한 라운드 간 사전선택(R009→R010→R012→R013)이 이미 존재한다는 사실을 보고서에 다시 명시한다. dev 상한 100건 안에서는 이 사전선택을 영구히 보정할 수 없다.
